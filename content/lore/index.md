## 📸 这一栏是什么

塔科夫的地图不缺攻略，缺的是**解释**：为什么宿舍楼里全是抽屉、为什么红仓库的二楼有一间办公室、为什么检查站的门房还锁着。这些东西官方从没集中讲过，但都散在商人台词和物品描述里——一页一页翻过去，其实讲得相当完整。

战区纪事做的事只有一件：**把散落的句子按「地点」重新排一遍**。

| | 地图条目（entries/） | 战区纪事（本栏） |
|---|---|---|
| 回答的问题 | 怎么活着出去 | 这里为什么是现在这样 |
| 主要素材 | 机制、数值、Boss、战利品 | 商人台词、物品描述 |
| 读者 | 正在打这一局的人 | 想知道这座城市发生过什么的人 |
| 写法 | 判据与纪律 | 结论 + 逐条原文 |

## 🧭 一张区域卡长什么样

每片区域固定六块，顺序不变：

| 字段 | 写什么 | 判据 |
|------|--------|------|
| **一句话** | 以前是什么 → 现在是什么 | 40 字内，须由下方证据支撑 |
| **三段线** | 战前 / 冲突期 / 现在 | 每段至少一条证据可回源 |
| **谁在这里** | 具名人物、身份、下落、留下的东西 | 只写文本里出现过的名字 |
| **与主线的关系** | 罪证链 / 邪教 / 封锁 / 撤离 | 无关就写无关，不硬扯 |
| **证据** | 逐条列原文，标级别与出处 | 见下方四级 |
| **图上能看到** | 场景物件 → 地形锚点 | 锚点名与交互地图一致 |

## 📐 证据四级

| 级别 | 来源 | 载体与等级 | 用法 |
|------|------|------------|------|
| **A1** | 商人台词、任务文本 | 玩家维基转录（**三级**） | 逐字可引，单条不超过两句 |
| **A2** | 物品描述（钥匙、任务物品、情报） | `json.tarkov.dev` 直读（**二级**） | 用来定楼栋、定房间、定归属 |
| **B** | 官网地图简介、补丁说明、官方小说与短片 | 官方（**一级**） | 补战前设定，标注出处 |
| **C** | 维基编者与社区推演 | 社区（**三级**，无官方背书） | 必须写「社区口径认为」，不与 A 级同段 |

> **A2 比 A1 硬**这件事有点反直觉：台词内容来自游戏内，但公开转录在玩家维基；物品描述则是直读数据源。
> 所以定房间号、定楼层这种事，优先引 A2；讲「谁说了什么」，才用 A1。

## ⚠️ 四条纪律

1. **没有证据就不写。** 现场看得见、但没有任何文本支撑的，只写「现场可见，无文本佐证」。
2. **不替官方下结论。** 原文写「也许」「据传」的地方，正文保留这层不确定；把「也许」改成「是」，就是编造。
3. **不写走位与配装。** 那是地图条目与交互地图的事，这里不重复。
4. **人名只认文本。** 没在台词或物品里出现过的名字，一律不补。

这四条都有机器在看：`scripts/check_region_lore.py` 会把每条引文回源校验，改一个字就构建失败。

## ✍️ 已知的空白

| 空白 | 现状 | 影响 |
|------|------|------|
| 77 份笔记／信件／报告的**正文** | 只有物品描述里的摘要（12–50 字），未公开转录 | 「现场文件」这一层只能到摘要粒度 |
| 瓦片图没有地名表 | 实验室有 31 个地名，破冰船、迷宫、终点站为 0 | 这三处的区域卡只能写「位置以文字描述为准」 |
| 终点站没有商人任务 | 全图 0 条任务，证据全部来自物品描述 | 那两张卡是「仅有物件证据」，不是台词考据 |
| 台词里的地名多于锚点表 | 街区锚点 36 条已覆盖主要街区，但 ULTRA、Kiba 这类「店内名」仍无锚点 | 区域卡选择按锚点走，店内细节写进正文 |
