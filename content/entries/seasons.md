# 赛季与修改器 (Seasons & Modifiers)

<a id="top"></a>

> “从 1.1 开始，清档不再是被迫的，而是你主动选择的挑战。”
> —— 第一赛季 KORD BREACH

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 赛季机制（1.1.0.0「KORD BREACH」引入） |
| **上线时间** | 2026 年 8 月 3 日 |
| **核心变化** | 清档从“强制”变为“可选”——赛季角色与持久角色并存 |
| **规则层** | 6 项全局修改器 + 30 项个人修改器（正负点数平衡为 0） |
| **赛季长度** | 最短约 74 天，通常按 4–6 个月一轮规划 |
| **适用范围** | 仅 PvP；PvE 没有赛季模式 |

---

## 💡 核心机制

### 1. 三种档案并存

1.1 之后，你的 PvP 进度被拆成互不影响的档案：

| 档案 | 说明 |
|------|------|
| **持久 PvP** | 原有角色，赛季不影响它 |
| **PvE** | 独立进度，不参与赛季 |
| **赛季 PvP** | 从零开始的赛季角色，赛季结束后清档 |

赛季角色运行在**独立服务器**上，不会与持久角色同局相遇。这既保护了老玩家的积累，也带来了玩家基数分散的隐忧。

### 2. 全局修改器：这一赛季的基调

全局修改器对**所有赛季角色**生效，不可更改。第一赛季的六项分别是：

| 修改器 | 效果 |
|--------|------|
| **无保险** | 物品无法投保，失去即永久失去 |
| **黑师出没** | 黑师成员可能出现在更多地图 |
| **护甲短缺** | 商人出售的护甲更少 |
| **藏身处免 FiR** | 藏身处建造物品不再要求“战局内找到” |
| **多面手** | 制造时间缩减，赛季角色开局即拥有较高制造等级 |
| **老练 PMC** | 赛季角色从 raid 中获得更多经验 |

其中的**“无保险”是影响最大的一条**：它把每一局的失败成本抬到最高，也让赛季的装备循环与持久角色完全不同。

### 3. 个人修改器：自己搭规则

个人修改器由玩家在赛季开始时自选：

- **正向**修改器花费点数（跑得更快、消耗更慢、抗性更强等）；
- **负向**修改器提供点数（过敏、某些物资无法使用、失去市场权限等）；
- **点数必须平衡到零**——想要便利，就得接受代价；
- 选定后**整赛季锁定**，无法中途更改。

这使得“赛季开局前”成为一次真正的策略决策，而不是例行公事。

### 4. 通行证与赛季收集物

赛季引入了免费的战斗通行证，奖励通过收集**TerraGroup 文档**类道具推进。它的两个特点值得注意：

- **进度与奖励跨模式共享**（赛季 / PvP / PvE 通用）；
- 收集物可由 PMC 或 Scav 获取，且**同一份文档允许多名玩家各自取得**，不会互相争抢。

官方强调所有奖励都可以通过正常游玩获得，不需要额外付费。

### 5. 反馈：分裂的评价

- **正面**：持久角色被广泛欢迎——终于不必“每半年重来一次”；
- **负面**：通行证与赛季货币机制被部分玩家批评为“手游化”；无保险规则让不少玩家认为风险回报不匹配；
- **争议**：赛季服务器分走了玩家基数，冷门时段的对局质量受影响。

---

## 🧭 实战要点

1. **赛季开局前认真读修改器**：这是唯一一次“免费”的选择机会，错过就锁死整季。
2. **无保险环境下配装要降档**：把总损当默认，别把家底带进赛季。
3. **善用正向修改器**：跑速、消耗、抗性类改动在长赛季里的累积收益很高。
4. **想稳就玩持久角色**：赛季是给想要“重新体验”的人的。
5. **通行证不用买**：奖励走正常游玩即可，别被“进度焦虑”推着走。

---

## ⚠️ 常见错误

- **用持久角色的思路玩赛季**：保险、库存、市场规则都不一样。
- **随手选修改器**：点数平衡是零和的，选错要忍一整季。
- **以为赛季结束装备会保留**：赛季角色会被清档，只有奖励与成就是长期的。
- **期待 PvE 也有赛季**：官方明确 PvE 没有赛季模式。
