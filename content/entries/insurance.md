# 保险机制 (Insurance)

<a id="top"></a>

> “保险不是让你浪，是让你死得起。”
> —— 新手第一笔投资

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 经济保护机制 |
| **提供者** | Prapor、Skier（以及后续版本可用的其他商人） |
| **保的是什么** | 背包、护甲、武器、容器等**装备类**物品 |
| **不保什么** | 消耗品（弹药、药品、食物）与安全箱内的物品无需保险（安全箱本来就丢不了） |
| **回收条件** | 阵亡后，若尸体未被其他玩家**完全搜刮**，物品会在延迟期后通过邮件返还 |

---

## 💡 核心机制

### 1. 基本流程

1. 进图前，在商人处为装备栏与背包内的物品投保（按物品价值的小比例收费）；
2. raid 中阵亡；
3. 若你的物品**没有被其他玩家拿走**，商人会在一段延迟后把物品寄回；
4. 从商人邮件页面免费领取。

### 2. 什么情况能拿回来

- **没人拿走**：尸体位置偏僻、或对手没翻你的包——物品原样返还；
- **对方翻了但没拿完**：剩下的照样寄回；
- **Scav 杀死你**：AI Scav 通常不搜刮装备，保险返还率极高。

### 3. 什么情况拿不回来

- 被玩家搜刮拿走；
- **MIA（超时未撤离）**：人不在图内，尸体消失，保险基本无从谈起。

### 4. 延迟时间

不同商人的返还延迟不同：便宜的慢（数十小时游戏内时间），贵的快。**热门地图与高峰时段的返还也会更慢**——死于人挤人的地图，寄回更慢。

### 5. 赛季模式：保险可能被禁用

自 1.1 赛季系统（2026-08）起，赛季模式通过**全局修改器**调整规则，其中一项就是**赛季 PvP 中禁用保险**。换句话说：

- 持久档案（PvP / PvE）：保险照旧；
- 赛季角色：进图前要默认“死了就是全损”重做装备预算。

赛季修改器每个赛季都可能不同，进赛季前先看角色创建页的修改器清单（详见[重大版本更新史](../docs/version-history.md)）。

## 🧭 实战要点

1. **每一枪都买保险**：保险费相对装备价值是零头，养成“进图先全选投保”的肌肉记忆。
2. **保险决定敢带什么**：买保险的玩家可以带中等装备进图，死几次也不伤筋动骨——这是穷人维持装备循环的关键。
3. **赛季角色另算**：赛季 PvP 保险被禁用，配装按“全损”预算，别把持久档案的习惯带进赛季。
4. **Scav raid 是保险回收器**：哪怕活下来，Scav 身上白捡的装备也构成收益；死了保险大概率回来，双向往复。
5. **死前把值钱的小件塞保险箱**：安全箱内的物品永不丢失，保险只覆盖箱外的。
6. **别用保险替代谨慎**：保险保装备，不保心态。指望“死了会还”而乱冲，返还率会教育你。

## ⚠️ 常见错误

- **忘记投保**：打完一整局才发现没勾保险——最贵的学费。
- **只保枪不保包**：背包和护甲往往比枪贵。全选投保才是正确姿势。
- **MIA 误区**：以为超时失踪也走保险——通常不会，撤离时限同样重要。
- **重装不保险**：越是贵的套装越要保，裸奔反而无所谓。
