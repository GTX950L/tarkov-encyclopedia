## 💡 核心机制

> 本篇的“机制”是**设定层面的因果链**：每条结论都回答一个“为什么”。读完它，全站很多条目的前提会自动对上。

<a id="sez"></a>

### 1. 起点：一个被设计成“门户”的经济区

诺文斯克地区设立**特别经济区**，定位是**俄罗斯与欧洲之间的商业门户**。塔科夫市是这个经济区的**中心**，靠国际投资在短时间内长成一座拥有完整基建的大都市。

| 设定要点 | 内容 |
|----------|------|
| 地理 | 俄罗斯西北部、芬兰湾右岸、卡累利阿地峡南部 |
| 人口 | 曾经接近**一百万** |
| 前史 | 20 世纪 60 年代中期建有大批**仪表与电子国防企业**，因此一度是 **ZATO（封闭行政区）**，**1994 年**才取消该地位 |
| 结局 | 战乱后被封锁，**进出不可能** |

**“曾经是封闭的军工城”**这一点值得记住：它解释了塔科夫为什么既有精密工业设施、又有与外界隔离的城市结构——城市的“能进不能出”不是战乱后才有的第一次。

<a id="terragroup"></a>

### 2. TerraGroup：这座城市真正的主角

**官方口径**：TerraGroup 官方上是**生物技术研发公司**，在**18 个国家**设有办公室——但**它的利益范围远超所声称的，而且胃口一直在长**。塔科夫与诺文斯克地区**大多数主要企业**都和它有直接或间接的关系。

它在这座城市里的实体包括：**总部、实验室、工业企业车间**，以及**USEC 私营军事公司的分部**（由它雇佣，用于安保）。

- **实验室（Labs）不是无名设施**——游戏里那张地图就是 TerraGroup 的核心研究设施（见 [实验室](labs.md)）；
- **游戏里大量物品的描述都在给它做注脚**：以 “TGLabs” 或实验编号命名的药品与器材，指向的就是这家公司的研发线。

<a id="trigger"></a>

### 3. 导火索：腐败丑闻与那句“不许进来”

转折点是一条**巨大的腐败丑闻**。当局面明显无法平息时，**TerraGroup 管理层下令 USEC 干员：不让政府与执法人员进入设施**。

USEC 执行了这道命令。**这是 USEC 从“安保承包商”变成“武装阻碍执法者”的那一刻**，也是整场冲突的分水岭。

紧接着发生两件事：

1. **TerraGroup 几乎全部中高层管理人员离开了城市**——留下的是资产、实验室和还在执行命令的安保；
2. **大规模撤离公司资源**开始，**城市陷入混乱**。

<a id="pmc"></a>

### 4. 两支 PMC：USEC 与 BEAR

| | **USEC** | **BEAR** |
|---|---|---|
| **全称** | United Security（联合安保） | Battle Encounter Assault Regiment（遭遇战突击团） |
| **雇主（官方口径）** | 跨国集团 **TerraGroup**，用于安保 | **诺文斯克地区官方**；其成立与俄当局的关系见下方说明 |
| **任务** | 保护 TerraGroup 资产、阻止调查与执法进入 | 查找证据、揭露 TerraGroup 的非法活动 |
| **人员背景** | 西方特种部队背景 | **前苏联国家**的特种部队背景 |
| **装备与语音** | 北约系装备，讲**英语** | 俄系装备，讲**俄语** |
| **游戏内差异** | 只有**外观、语音与初始技能倾向**，不影响受击判定与数值 | 同上 |

> **必须分清的一层：BEAR 到底是谁建的。**
> **官方补丁说明的原话是**：BEAR 是一支**新组建的 PMC，“官方上与政府无关，但据传有俄罗斯当局的直接保护”**。
> 而大量百科与攻略直接写成“**BEAR 是由俄罗斯联邦政府秘密法令设立的**”——**官方只承认到“据传”这一层**，从未确认由政府设立。
> 两者差别不在细节：**一个是官方立场，一个是流传说法**。按本站体例，前者写进设定，后者标为说法。

<a id="lockdown"></a>

### 5. 封锁：为什么你出不去

这是全篇最关键的一段，它直接解释**玩家的处境是怎么来的**：

| 顺序 | 发生了什么 |
|------|-----------|
| ① | 两支 PMC 之间**爆发正面交火**，各类武器都用上了 |
| ② | 平民由**城市自身资源 + 俄罗斯武装部队 + 联合国维和部队**协助撤离 |
| ③ | **整个官方部队撤出**——没有人留下来维持秩序 |
| ④ | **只有边缘与犯罪分子留下**，因为想趁机牟利、劫掠城市 |
| ⑤ | **塔科夫被封锁，进出成为不可能** |
| ⑥ | **大量 BEAR 与 USEC 干员失去与指挥部的联系**，只能**自己找路离开** |

**第 ⑥ 条就是“你是谁”的答案。** 你不是在执行一项任务，你是**被困住之后自己找出口的人**——这也解释了为什么：

- 游戏没有“通关闭环”，只有**一局接一局的撤离**；
- 没人给你补给、没有救援、没有警察——**城里的一切秩序都不存在**；
- “逃离塔科夫”这个标题，说的是一件**很字面**的事。

<a id="who"></a>

### 6. 城里现在都有谁：把设定接回游戏内容

设定里的身份，和你在战局里遇到的目标，是同一批人：

| 设定里的身份 | 你在游戏里遇到的是 | 详见 |
|--------------|-------------------|------|
| 与指挥部失联的 USEC / BEAR 干员 | **玩家 PMC**（PvE 中还有 AI PMC） | [PMC 与 Scav](pmc-scav.md) |
| 选择留下的当地居民与犯罪者 | **Scav**（AI 与玩家） | [Scav 互动与叛徒判定](scav-relations.md) |
| 叛逃的 PMC、前军警人员 | **Raider** | [Boss 图鉴](bosses.md) |
| TerraGroup 的失联安保（**本来就是 USEC**） | **Rogue**（灯塔） | [灯塔](lighthouse.md) |
| 占据各据点的头目 | **Scav Boss** | [Boss 图鉴](bosses.md) |
| 夜间活动的异端团体 | **Cultist（邪教徒）** | [声望与 Karma](karma.md) |

其中最后两行值得单独记一句：**Rogue 之所以“穿得像 PMC”，是因为他们在设定上就是失联的 USEC**——这不是美术偷懒，是设定（见 [敌我识别与身份判断](iff.md) 里“外形判断会在灯塔失效”那一条）。

<a id="why"></a>

### 7. 这条设定链解释了什么

把上面几条串起来，可以一次性回答站内反复出现的几个“为什么”：

| 现象 | 设定上的原因 |
|------|--------------|
| 同阵营也照杀 | 两支 PMC 的僵局本来就没有和平机制，且都**已与指挥部失联**——没人下令，也没人约束 |
| 没有任何队友标识 | 你是**失联的个人**，不是建制内的作战单位 |
| 保险、邮件、商人却还在运转 | 留下的不只是暴徒，还有**想赚钱的人**（见 [经济周期](economic-cycle.md)） |
| 实验室里有超规格装备与研究资料 | 那是 **TerraGroup 的核心设施**，资源与价值本就不属于常规战场 |
| 为什么“撤离”比“打赢”重要 | 你的目标从来不是取胜，而是**离开** |

---

## 🧭 实战要点

1. **把“赢”这个念头去掉**：设定决定了这场冲突不可终结，玩家能做的只有**把每一条命换成资产并带出去**。
2. **同阵营不是盟友**：[敌我识别与身份判断](iff.md) 那套“没有阵营标签”的现实，源头就在这里——**失联的佣兵之间不存在指挥链**。
3. **看到像 PMC 的 AI，先想 Rogue**：灯塔的 Rogue 在设定上就是失联 USEC，别用外观给 AI 归类。
4. **别指望秩序**：没有警察、没有救援、没有补给线——遇到的一切“秩序”都是别的玩家临时建立的。
5. **地名不是装饰**：实验室 = TerraGroup 核心设施；街区 = TerraGroup 总部与办公集群所在——理解设定能让地图判断更有方向感。

---

## ⚠️ 常见错误

- **把“BEAR 由俄政府秘密设立”当官方设定**：官方原文只写到“官方上与政府无关，**据传**有俄当局的保护”，从未确认由政府设立。
- **以为选 BEAR 还是 USEC 会影响数值**：只影响**外观、语音与初始技能倾向**，不影响受击判定。
- **把玩家当成“执行任务的雇佣兵”**：设定上玩家是**失联被困、自己找出口**的人——这决定了游戏的整个循环。
- **把维和部队写成北约参战**：官方口径只有**联合国维和部队参与平民撤离**，没有北约作战介入这一说。
- **把 TerraGroup 当成背景板**：它是一条贯穿实验室、药品描述、灯塔 Rogue 与部分任务线的**实体**，不是一句世界观口号。
