# 彩蛋与制作组的恶意 (Easter Eggs & Design Traps)

<a id="top"></a>

> “塔科夫最温柔的地方，是它还记得给玩家留了几个玩笑；最狠的地方，是这些玩笑旁边都埋着雷。”

---

| 项目 | 信息 |
|------|------|
| **类型** | 元内容：制作组留下的致敬、彩蛋与刻意设计的恶意 |
| **彩蛋形式** | 地图涂鸦与道具、装备与物品、配音、藏身处陈设 |

## 💡 核心机制

<a id="quest"></a>

### 1. 彩蛋不是花絮：它被做成了一条任务线

塔科夫的彩蛋**不是给你看的，是给你考的**。Fence 有一条专门的任务线 **「Is This a Reference?」（这是个彩蛋吗？）**：

| 项目 | 内容 |
|------|------|
| **发布者** | **Fence** |
| **前置** | **等级 25** + **Scav Karma ≥ +1** |
| **内容** | 在 **9 张地图**的**彩蛋点位**安装 **约 27 台 WI-FI 摄像头** |
| **奖励** | **Streamer Item Case**（**无任何其他获取途径**）+ 约 20 万卢布 + 约 3 万经验 |
| **衔接** | 是 **1.1.5.0** 起 Fence 后续任务（「Can't Drink Away Skill」）的前置 |

两点值得记住：

1. **那 27 个点位就是彩蛋点位本身**。想快速找齐，等于把全图的彩蛋过一遍；
2. **Streamer Item Case 只能用这个方式拿到**——它不卖、不换、不掉落。**这是全站唯一“必须懂彩蛋才能拿到”的容器**。

摄像头密度最高的是**工厂**（含夜间工厂，约 7 台，一趟夜图能刷掉一大半），其次是**灯塔**（约 4 台）与**储备站 / 海关**（各约 3 台）。

### 3. 藏在装备与语音里的彩蛋

不在地图上，而是你每天带在身上：

| 类别 | 彩蛋 |
|------|------|
| **装备与物品** | **Red Rebel 冰镐**（《古墓丽影》）；**Bomber Beanie**（《Ed, Edd n Eddy》里 Edd 的帽子）；某件 Boss 板载具的弹匣袋里塞着一台**镜面 iPhone** |
| **配音** | 部分 PMC 语音的配音演员**就是社区内容创作者**；有几句台词是明显的电影梗（例如那种“我有种不祥的预感”式的老梗） |
| **行为** | 某条 BEAR 语音在按下“嘟囔”键时有小概率**开始轻轻唱歌** |

<a id="hazards"></a>

### 4. 另一面：地图危害是“设计”，不是 bug

塔科夫的“恶意”有明确规则，理解它们就能把随机死亡变成可规避风险。

**① 雷区**

| 规则 | 说明 |
|------|------|
| **看不见** | 雷区里的地雷**无法从外部用肉眼观察** |
| **会刷新** | 爆炸后会**重新生成新的雷区**，所以**永远无法清干净** |
| **多数有警示** | 通常设有警告标志——**但也有完全无警示的**（例：森林北部的营地一带） |
| **判定按步数** | 踩雷判定与你的**步数**相关，不是走到某点必炸 |

**踩雷后的正确动作**：第一颗通常**只扣双腿少量血量**——**立刻治疗，然后沿原路返回**。**不治疗就继续走、踩到第二颗，基本必死**。

**② 边界狙击手**

- **隐形、无法杀死**，纯粹作为**人工边界**存在；
- 分布在**海关、灯塔、储备站、森林**；
- 有各种警告标志，但**别指望看清人在哪**——它不是敌人，是一堵会开枪的墙。

**③ 阔剑地雷（Claymore）**

- **可探测 5–10 米内的目标**，爆炸**基本直接致死**（除非有掩体挡住）；
- **无法被武器或爆炸物摧毁**，听起来无解——但**位置固定，且引爆后不会重生**；
- 仅出现在**灯塔、中心区（Ground Zero）、街区**。

> **关于雷区与边界狙击手的致死规则，中文 wiki 的表述是「健康值降为 1%」**——原文如此。实际体验中，残血已经算运气好，多数情况是直接出局。

<a id="no-insurance"></a>

### 5. 最“恶意”的设计：保险不生效的三张图

真正会让人付出代价的不是陷阱，而是**规则本身**：

| 地图 | 说明 |
|------|------|
| **终点站** | 保险**不生效** |
| **破冰船** | 保险**不生效** |
| **迷宫** | 保险**不生效**，且**五道出生间各有一道必须破解的环境危害，全程陷阱** |

**在这三张图里丢的东西，永不返还。**这里的谨慎不是性格问题，是财务问题——出发前先看[保险机制](insurance.md)。

## 🧭 实战要点

1. **想拿 Streamer Item Case，就先看彩蛋点位表**——那 27 台摄像头的位置就是它。
2. **工厂一趟夜图可以刷掉大半摄像头**，密度最高、成本最低。
3. **彩蛋点位常与高价值物重合**，顺路看彩蛋等于顺路搜刮。
4. **看到雷区警告牌就绕**，不要试探；**无警示的雷区只存在于少数区域，第一次走新路线时贴主路走**。
5. **踩雷后先治疗再原路退**——这条动作能救命。
6. **去终点站 / 破冰船 / 迷宫前，先把“能接受永久失去”的装备换上**。
7. **阔剑的位置固定且引爆后不重生**——死过一次的地方，第二次是安全的。

## ⚠️ 常见错误

- **把彩蛋当纯观光**：它是**唯一能拿到 Streamer Item Case 的途径**，有实际价值。
- **踩雷后拔腿就跑**：正确动作是**原地治疗 + 原路返回**。
- **以为雷区能清**：会刷新，永远清不完。
- **试图反击边界狙击手**：**无法杀死**，只能离开边界。
- **带着好装备进这三张图**：**保险不生效**，丢了就是丢了。
- **拿旧点位表刷摄像头**：点位可能随版本增减，**以游戏内彩蛋清单为准**。
