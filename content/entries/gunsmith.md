## 💡 核心机制

### 1. 三角权衡

- **人机工效（Ergo）**：决定开镜速度、持枪耐力消耗——CQB 的命根子；
- **后坐力**：决定连发可控行——中远距离对枪的命根子；
- **精度/初速**：决定远距离表现——狙击图的命根子。

**没有三项全满的枪**。改装的本质是按交战距离做减法。

### 2. 配件体系：三层，八个功能位

**改装之所以难上手，是因为配件太多**——官方数据里带配件标记的条目超过 2,000 件（含同一件的不同平台与配色版本）。逐件记型号是不可能的，也不需要：**记住“哪个位置管哪件事”，比记住任何一个型号都值钱。**

官方把配件先分成三层，**名字就说明了各自的位置**：

| 层 | 官方分类 | 说明 |
|----|----------|------|
| **必要件** | `essential` | 缺了枪就不能开火的件（枪管、机匣、枪机）——**通常决定这把枪的改装上限** |
| **功能件** | `functional` | 真正改参数的件（枪口、护木、握把、枪托、瞄具、弹匣）——**钱花在这里** |
| **适配件 / 外观件** | `gear` | 解决“能不能装上”与外观问题，**本身不改参数** |

然后是真正要背下来的部分——**八个功能位，各自管一件事**：

| 功能位 | 官方件数 | 管什么 |
|--------|----------|--------|
| **枪管 / 护木** | 643 | 精度与初速的上限、人机与重量 |
| **瞄具 / 光学** | 307 | 交战距离与识别速度——**决定你在哪个距离上打得赢** |
| **枪托 / 握把** | 258 | 后坐控制与人机——**性价比最高的一档** |
| **枪口 / 消音装置** | 241 | 后坐补偿与**声音特征**（声音是情报，见[听声辨位与音频机制](audio.md)） |
| **弹匣** | 212 | 容量、换弹节奏与占格 |
| **机匣 / 枪机** | 114 | 平台基础件，决定**能不能上某类件** |
| **功能件**（活塞 / 弹簧 / 扳机等） | 44 | 后坐恢复与射击节奏的细调 |
| **战术装置**（激光 / 手电） | 22 | 夜战与近战的辅助，见[光照与夜战](lighting.md) |

> **从件数能读出一个结论**：**枪口 + 握把 / 枪托合计近 500 件，是配件体系里最厚的一片**——这与站内那条老兵经验的判断一致：**枪口与握把是性价比之王。** 一个生态做到这么厚的位置，通常就是“所有人都绕不过去”的位置。
>
> **另一条推论**：数据里另有少量夜视 / 热成像挂件也归在配件体系内（它们装在头盔导轨上）。**这类不属枪械改装**，见[夜视与热成像](night-vision.md)。

**为什么本站不做“配件图鉴”**：2,000 件逐件列会**立刻过期**，且没有决策价值。真正不会变的只有两件事——**功能位的分工**（上表）与**三角权衡**（上一节）。**型号会换，位置不会。**

### 3. 按距离定形态

| 交战场景 | 优先级 | 形态 |
|----------|--------|------|
| 室内/CQB（工厂、实验室） | 人机 > 后坐 | 短枪管、轻量化、红点/机瞄 |
| 中距离通用（海关、地面零点） | 后坐 ≈ 人机 | 中长枪管、全息/低倍镜、枪口补偿 |
| 远距离（森林、海岸线） | 精度 > 人机 | 长枪管、高倍镜、两脚架 |

### 4. 枪匠任务

商人 Mechanic 的 “Gunsmith” 系列任务要求玩家按精确规格改装武器——**这是系统性地教你认识配件体系的课程**，建议认真做，等于免费上改装培训班。

## 🧭 实战要点

1. **先解决后坐，再谈别的**：连发打不中人，人机再高也没意义。
2. **CQB 枪拼命压人机**：开镜快 0.1 秒，就是先手 0.1 秒。
3. **不要堆满配件**：每个配件都有人机代价，用不上的功能全部拆掉。
4. **按功能位想，不按型号想**：先说“我要改哪个位置”（枪口、握把、瞄具……），再看这个位置里有什么——**顺序反了就会被型号牵着走**。
5. **弹匣容量是隐藏属性**：CQB 换弹慢半拍可能致命，50 发弹鼓有它的道理（代价是换弹更慢、占格更大）。
6. **先确认“能装上”**：必要件与适配件决定适配关系，改件买回来装不上是这类系统里最常见的白花钱。
7. **抄作业要理解**：照搬网课改装前，想清楚它为什么这么配——地图和弹药变了，配方就该变。

## ⚠️ 常见错误

- **满配幻觉**：所有贵配件堆上去，枪重人机差，还不如半配。
- **CQB 带高倍镜**：工厂里 4 倍镜是自废武功。
- **忽视枪口与握把**：这两个位置是“性价比之王”，花小钱办大事——**官方件数也印证了这一点**（两处合计近 500 件）。
- **改装费超过枪价**：改装前的枪不如别人的裸枪值钱，死了损失不小。
- **只记型号不记功能位**：记住某个“神配件”的名字没用——平台一换它可能装不上，而**功能位永远存在**。
- **把夜视 / 热成像当枪械配件**：它们装在头盔上，属于[夜视与热成像](night-vision.md)那条线。
