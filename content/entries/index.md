# 百科条目总览

<a id="top"></a>

已收录 **92 个**条目，分十二篇组织。**前八篇是「读」的主线**，从撤离规则一路讲到设定背景，按顺序看即可；
**后四篇是「查」的栏目** —— [物品图鉴](../catalog/index.md)收录 **4,983 件**物品、[任务图鉴](../quests/index.md)收录 **503 个任务**、[参考](../docs/citation.md)收齐速查表与口径、[交互地图](../maps/index.md)管点位。
**「用」的东西（作战台 / 我的进度 / 物品反查）不在这一页**，它们是工具不是条目，走侧栏第二栏。

> **为什么是这个顺序？** 先懂撤离与保险，才敢进图 → 知道死在哪，才懂该练什么 → 看懂穿深与护甲，才明白为什么死 →
> 把每一条命变成资产，才有本钱练 → 同一套装备为什么打出不同结局，想通这个才谈得上进阶 →
> 机制吃透了，再把知识变成动作 → 会玩了、想换规则重来，才用得上赛季 → 最后补上设定，才算看懂战场。
> 每篇内部也是按这个逻辑排的，所以同一篇里从上往下读，就是推荐顺序。
