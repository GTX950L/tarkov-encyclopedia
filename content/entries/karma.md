## 💡 核心机制

### 1. 商人忠诚度：你的采购权限

每个商人有忠诚度等级（LL1–LL4）。等级提升通常取决于：**等级门槛 + 声望/消费额**。等级越高，货架越贵重的商品才会解锁——这也是“有钱也买不到”的原因。

1.1 版本之后，**任务开放方式改为与忠诚度挂钩**：不再要求按顺序清完某条长链，而是达到对应忠诚度即可接取。这让成长路径从“排队”变成了“攒信任”。

### 2. Scav Karma：Fence 的那本账

Scav 阵营的声望（通常称 Karma）记录你的行为：

| 行为 | 影响 |
|------|------|
| 与其他 Scav / 玩家 Scav 和平共处、合作撤离 | 声望上升 |
| 击杀 Scav、玩家 Scav | 声望下降 |

声望的高低会反馈到：

- **Scav 冷却时间**（声望高 → 更快能再玩 Scav）；
- **Scav 出生装备**（声望好时配置更佳）；
- **Fence 的商品与价格**；
- 部分高级内容的准入条件。

### 3. 数值细则：逐项加减分

声望的加减是**按行为逐条记账**的。下表为社区维基整理的通行口径，可用于估算一局行为的净收益：

**加分项**

| 行为 | 变化 |
|------|------|
| 以 Scav 撤离或转场 | +0.01 |
| 完成 Scav 任务 | +0.01 ~ +0.05 |
| 击杀曾杀过 Scav 的 PMC（以 Scav） | +0.02（杀过两人以上 +0.03） |
| 帮助 Scav | +0.01 ~ +0.02 |
| 帮助 Boss 护卫 / Boss | +0.02 / +0.05 |
| 击杀叛徒 Scav（以 Scav） | +0.03 |
| **车辆撤离（以 PMC）** | **+0.2（首次）** |
| **合作撤离（任意阵营）** | **+0.25（首次）** |

**扣分项**

| 行为 | 变化 |
|------|------|
| 击杀 AI Scav（以 Scav） | −0.03 ~ −0.05 |
| 击杀玩家 Scav（以 Scav） | −0.1 |
| 击杀 Boss 护卫（以 Scav） | −0.05 |
| 击杀 Boss（以 Scav） | −0.2 |
| 击杀圣诞老人一类的特殊中立角色 | **−1.0**（全系统最重） |
| 击杀 Raider / Rogue / 邪教徒 | **无扣分**（不属于 Scav 阵营） |

**两条容易被忽略的记账规则：**

1. **重复收益递减**——车辆撤离与合作撤离的首次数值最高，之后按“首次数值 ÷ 累计次数”折算，所以它们是**一次性的大额入账**，不是可以无限刷的流水线；
2. **高分区有惩罚加速**——在高声望区间（约 +6 至 +8）扣分按 +6 的档位计算；超过约 +8 之后还会有额外惩罚。**声望越高的角色，犯错越贵。**

> 分值为社区通行口径，版本更新会调整具体数字；机制方向（谁加分、谁扣分）稳定可靠。

### 4. 声望影响的所有面

声望不只影响“能不能买”，它同时作用于**撤离、容量、周转与出生配置**：

| 受影响项 | 说明 |
|----------|------|
| 车辆撤离费用 | 声望越高越便宜 |
| BTR 货箱容量 | 声望影响可寄运的格位 |
| 转场寄送容量 | 转场时的物品寄送同样受声望影响 |
| Scav 箱周转时间 | 藏身处 Scav 箱的返还速度 |
| Fence 的收购价 | 声望越高的角色，Fence 收东西给价越好 |
| **Fence 折扣货架** | 高声望开放额外货架，享折扣，**可购买其他玩家遗落在禁区（如实验室）中的装备** |
| Scav 冷却时间 | 高声望 → 更快轮到下一局 Scav |
| Scav 可选撤离点数量 | 高声望 → 可选撤离点更多 |
| Scav 出生装备质量 | 高声望 → 出生配置更好 |
| AI Scav 听令概率 | 高声望时 AI 会响应跟随/停下的指令 |

### 5. Kappa 的门槛（1.1 后）

“收藏家”任务的要求被大幅简化：多数支线的前置被移除，取而代之的是**除 Ref 以外的全体商人达到 LL4**，外加一个 Fence 声望门槛。**旧的 Kappa 之路成就已永久绝版**——历史成就不会回来。

### 6. 声望是复利的

声望高的人：买得到更好的货、接得到更多的任务、Scav 收益更稳。这是典型的**正反馈循环**——所以别在前中期随便砸掉好感度。

### 7. 另一本账：PMC 业力（0.15.0.0 起）

以上讲的都是 **Scav 业力（= Fence 声望）**。官方明确说过：**PMC 有另一套独立的业力机制**，两套并行、各有规则。

| 项目 | 内容 |
|------|------|
| **性质** | **隐藏参数**，界面上没有数字；官方称它反映玩家在这一局里的“荣誉” |
| **上涨** | 更“开放”的玩法——**与 Scav 合作撤离**、**击杀已经杀害过队友的玩家** |
| **下跌** | **击杀队友**；**长时间停在同一个点不动** |
| **主要后果** | 低 PMC 业力 → **Boss「Partisan」出现概率上升，且他会主动猎杀业力低的玩家**；**即使你以 Scav 角色进图，照样会被他追杀** |
| **与 Fence 声望的关系** | **完全无关**——Partisan 不在乎你 Fence 声望多高，帮助或击杀他也不改变任何业力 |

**两条官方给出的自查手段**：

- **战局结算界面的「总体声望变化」（Overall standing change）一行**，可以看到本局的业力变动；
- **业力涨与跌有各自不同的音效提示**——听到那声提示，就该回想一下刚才发生了什么。

> **顺手更正两条常被记错的口径**：① **PMC 击杀 Scav 不在官方扣分清单里**（清单只列“以 Scav 身份”的两种情形）；但击杀过 Scav 的 PMC 会被玩家 Scav **标价**——对方击你能拿 +0.02，杀过两人以上 +0.03。② **高声望时“大多数 Boss 对 Scav 中立”**，官方列出的例外是 **Killa、掠夺者系首领、Zryachiy**。

## 🧭 实战要点

1. **每个商人都要有用途**：只刷一两个商人，会卡在装备与任务门槛上。
2. **Scav 别乱开枪**：杀同行扣声望，长期成本远高于一局的收益。
3. **优先解锁关键货架**：能买到穿甲弹与护板，比多攒钱更有价值。
4. **别忘了 Fence**：他的声望独立计算，且是 Kappa 条件的一部分。
5. **合作撤离值得做**：既涨声望，也是最容易赚到的双赢。

---

## ⚠️ 常见错误

- **把声望当虚荣指标**：它是实打实的购买权限。
- **为了小钱杀 Scav**：扣掉的声望，需要多局才能补回来。
- **只开一个商人的货架**：装备链会断档。
- **忽略版本改动**：任务解锁机制与 Kappa 条件在 1.1 已变，旧攻略不再适用。
