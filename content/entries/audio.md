# 听声辨位与音频机制 (Audio & Sound Cues)

> “在塔科夫，先被听见的人先死。”
> —— 音频优先原则

| **类型** | 感知机制 |

## 💡 核心机制

### 1. 声音是一套“代价系统”

塔科夫的每一个动作都会发出声音，而**每个动作的音量与该动作的收益正相关**：

| 动作 | 音量 | 你换来了什么 |
|------|------|--------------|
| 冲刺 | 最大 | 速度 |
| 走路 | 中等 | 速度与安静的折中 |
| 蹲走 | 最小 | 完全安静，代价是慢 |
| 开镜（ADS） | 明显 | 精度 |
| 换弹 | 明显且长 | 火力续航 |
| 搜刮 / 开包 | 明显 | 物资 |
| 开门 / 破门 | 明显 | 通路 |
| 击发（无消音） | 极大 | 杀伤，同时**公开你的位置** |

**判断原则**：当你准备做一件有声音的事，先问“这个声音值不值”。

### 2. 耳机是唯一直接提升听力的装备

- **作用**：**放大脚步声与移动音**、压低环境噪音，让你更早发现接近者；
- **定位**：不同耳机的音色与放大曲线不同，影响你对**方向与距离**的判断习惯——**换耳机就是换习惯**；
- **取舍**：全覆面头盔（Altyn、Vulkan-5 一类）会**压缩听力**，见[护甲与头盔图鉴](armor-catalog.md)。面罩与耳机经常二选一；
- **0.16.5.0 的均衡调整**：官方**拉平了“戴耳机与不戴耳机”的音量差异**，也拉平了各款耳机之间的音量——过去“某些耳机靠音量差占便宜”的时代结束了，现在比的是**音色与定位**。

### 3. 声音的距离、遮挡与混响

- **距离衰减**：声音随距离衰减，但**不同动作的衰减曲线不同**——枪声能传很远，脚步只在近距离可闻；
- **遮挡**：墙体与地形会削弱声音并改变音色，**穿墙听到的脚步通常更闷**；
- **混响**：室内回声会让方向判断变难；0.16.5.0 **降低了各场景的混响强度**，室内定位因此明显变准；
- **植被声**：植被摩擦声曾经存在“别人听不到”的 bug，0.16.5.0 修复——现在**蹭草丛是会出声的**。

### 4. 拆掉一个流传很广的误解：感知不是听力

社区里常把**感知（Perception）**叫成“听力技能”，但它的面板效果是**提升物资探测半径**（精英级会给物资近距离提示），**并不直接放大声音**。

同时值得记住的是**专注（Attention）**：它提升的是**搜刮速度与检视速度**，精英级还有概率“一开箱就发现物品”。这两个技能和“听力”是三条不同的线——详见[技能系统](skills.md)。

> 所以，想听得远，靠的是**耳机**；想搜得快，靠的是**专注**；想找人找物资，靠的是**感知**。

### 5. 环境声源与地图线索

- **鸟类受惊**：区域内的鸟群被惊飞，往往意味着**附近有人活动**；
- **引擎声**：BTR 的发动机声能传很远，是[转场与 BTR](transit.md) 的重要线索；
- **交战声**：远处的连续枪声告诉你“哪边有人在打”——这既是风险也是机会（Boss 被谁打了、谁在撤离点守株待兔）。

---

### 6. 声音线索 → 行动：听到什么该做什么

<a id="cues"></a>

前面几节讲的是**声音怎么传播**；这一节回答的是**听到之后该做什么**——这才是声音真正的用处。**声音的战术价值不在“知道有人”，而在“知道他在做什么”。**

| 你听到的 | 他在做什么 | 你的窗口 |
|----------|------------|----------|
| **开镜 / 拉栓声** | 枪已经举起来，正在架你 | ❌ 没有窗口。**别露身**，换角度，或者先用投掷物 |
| **换弹声** | **他的枪有几秒钟不能用** | ✅ **明确的进攻窗口**（见[交火中的技术动作](firefight.md)） |
| **打药声 / 撕绷带声** | 他在治疗——**不能开枪、也不能移动** | ✅ **最快的一次机会**。这是三段最脆弱的时间之一（见[搜刮效率与战利品取舍](looting.md)） |
| **翻越 / 跳落声** | 他在移动，且**动作期间不能还击** | ✅ 也是窗口——但**注意它可能是故意做出来的**（见[投掷物来袭处置](grenade-response.md) 的假动作） |
| **涉水声** | 他在水里：**很慢、很响，而且很难听清你** | ✅ 你听得见他、他听不太清你——这是你能拿到的信息差 |
| **开门 / 关门声** | 有人正在通过那道门 | ⚠️ 别动、别出声——**等他走进来**，而不是开门出去找他 |
| **搜刮声 / 拉链声 / 翻箱声** | 他在翻容器：静止、低头、注意力在菜单上 | ✅ 窗口，但**他可能已经听到你来了** |
| **远处的连续枪声** | 哪边在打、打的是谁、是几把枪 | 决定**绕开**还是**去捡漏**——全图上最有价值的一条免费情报（见[战局流程与节奏](raid-flow.md)） |

**三条读声音的高级判据**：

1. **“该有的声音没有”也是信息。**一个一直在走的人突然安静下来——他多半听到了你，正在等你先动。**这时候最该做的不是去找他，而是换一个位置**；
2. **同一个声音在不同环境里结论不同。**室内有混响、室外会衰减，**不要拿室外的经验判断楼里的距离**（见第 3 节）；
3. **声音是可以被制造的。**换弹、开门、开枪都能“演”——所以听到声音之后先问一句：**他有没有理由故意让我听见？**（投掷物的假动作、VOIP 的喊话，都是同一套逻辑。）

## 🧭 实战要点

1. **耳机优先级高于头盔等级**：听不见的 5 级头，不如听得见的 3 级头。
2. **听脚步先判断“快慢”**：冲刺是急躁、蹲走是谨慎——对手的速度暴露他的意图。
3. **用声音做假动作**：故意换弹、开门、开枪，可以制造位置假象。
4. **接近关键区域前停三秒**：静止听一次，比快速突入更省药。
5. **避免非必要噪音**：在已知有敌人的区域，能不搜就不搜，能不开门就绕。
6. **善用“公开声源”**：绿信号弹、BTR 喇叭、警铃都是双向信息——你能听见，别人也能。
7. **把声音当作“他在做什么”的线索**：换弹、打药、翻越，是三张可以打出去的牌；而**突然安静**往往意味着他已经听到你了。

## ⚠️ 常见错误

- **不戴耳机进图**：等于自愿放弃一半情报。
- **边打边搜刮**：搜刮音是引诱敌人定位的最有效诱饵之一。
- **面罩 + 耳机一起堆**：听力与视野双重代价，实战表现往往低于纸面等级。
- **以为感知能补听力**：技能树里没有“听力”这个技能。
- **忽视混响差异**：室内与室外的判断逻辑不同，别把室外的经验照搬到楼里。
