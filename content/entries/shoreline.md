# 海岸线 (Shoreline)

<a id="top"></a>

> “疗养院一栋楼，就是一场完整的战争。”
> —— 垂直攻防教科书

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 大型混合地图（海滨 + 内陆小镇 + 巨型建筑） |
| **体量** | **大型** |
| **raid 时长** | 较长 |
| **玩家数** | 中等，但**向疗养院高度集中** |
| **强度** | 中高——**强度的分布极不均匀**（见下文第 1 节） |
| **Boss** | **Sanitar**（疗养院出没，带护卫） |
| **保险** | **正常生效** ✅ |
| **适合阶段** | 中期到后期 |
| **标志性地点** | 疗养院（Resort）、码头、气象站、内陆小镇、**东南角雷区** |

---

## 💡 核心机制

### 1. 一张图，两个完全不同的游戏

海岸线最大的特点不是大，而是**强度分布极不均匀**：

| 区域带 | 玩家密度 | 收益 | 实际体验 |
|--------|----------|------|----------|
| **疗养院内** | ⭐⭐⭐ 极高 | 高价值房密度全游戏前列 | **PvP 主战场**，一栋楼里可能同时有几队人 |
| **外围（小镇 / 码头 / 气象站）** | ⭐ 低 | 中低，但**遍地隐藏 stash** | **安静、安全、稳定**——适合练级与做任务 |
| **海滨线与东南角** | ⭐ 低 | 低 | ⚠️ **有大片看不见的雷区** |

> **这条事实直接决定策略**：**你不需要进疗养院也能源源不断地赚钱。** 海岸线的外围独立 stash 密度，是它比森林更适合“中期稳定收益”的原因。

### 2. 疗养院是一栋“垂直建筑”，楼梯间是它的心脏

疗养院是**两翼 × 三层 + 地下层**的结构，每一层、每一翼都是独立的攻防战场。这带来一条铁律：

> **楼梯间是所有交火的必经之路，也是收装备最多的地方。**
> **上楼之前先听，下楼之前先看拐角。**

### 3. 窗口：清楼的人也是别人的靶子

疗养院窗口数量多——这意味着**在楼里搜刮的人，同时也暴露在楼外的视野里**。“只盯楼里不看窗外”是这张图的常见死法。

### 4. 东南角雷区

海岸线东南角有**大片看不见的雷区**。规则与其他图的雷区一致：**肉眼不可见、爆炸后刷新、踩中第一颗通常只伤腿**——治好后**原路退回**（见[彩蛋与制作组的恶意](easter-eggs.md)）。

## 🗺️ 区域结构

<a id="areas"></a>

| 区域 | 特征 | 主要风险 | 该注意什么 |
|------|------|----------|------------|
| **疗养院（两翼 + 三层 + 地下）** | **全图核心**：房间密集、钥匙房多、高价值物资与 Boss 齐聚 | **PvP 主战场**；楼梯间与楼道的遭遇战 | 一次清一层；**上楼先听、下楼先看拐角** |
| **疗养院外围（窗下区域）** | 楼外的观察位与进攻通道 | **窗口火力**——楼里楼外互相看得见 | 靠近时**贴着建筑走**，别站在窗户正对面 |
| **码头与海滩** | 撤离点与开阔地 | **撤离点附近的守株** | 撤离路线提前定；海滩别直线冲锋 |
| **气象站** | 制高点小建筑，任务与物资点 | 小建筑的门口固定伏击位 | 进前先听，任务做完就走 |
| **内陆小镇** | 民居抽屉与保险柜，**中低价值搜刮区** | 建筑间视野被切断 | 适合低配搜刮；这里**没有疗养院那种人流** |
| **东南角 / 海滨线** | 边缘地带 | ⚠️ **看不见的雷区** | 只走已知路径 |
| **隐藏 stash 点位** | 外围各处的埋藏点 | 位置固定但需要经验 | 熟悉 stash 路线 = 海岸线最稳的收益（见[战利品分布与热点](loot.md)） |

---

## 💡 核心打法流派

1. **疗养院清楼流**：一层层向上推进，考验 CQB、听声与楼梯博弈——塔科夫垂直攻防的必修课。
2. **外围搜刮流**：绕开疗养院主战场，低速安全地扫小镇与码头，适合练级与任务。
3. **远距离游猎流**：海滨线视野开阔，狙击与反狙击频繁。

**再补两条**：

4. **stash 巡回流**：外围隐藏 stash 位置固定，**跑熟一趟就是一条稳定现金流**——这是海岸线最被低估的玩法。
5. **转场流**：海岸线是**转场路线上的重要节点**，部分任务会要求你从这张图转出去（见[转场与 BTR](transit.md)）。

## 🎯 Boss：Sanitar

<a id="boss"></a>

| 项目 | 内容 |
|------|------|
| **位置** | 出没于**疗养院区域**（含外围附属建筑） |
| **护卫** | 随行护卫数名 |
| **特殊能力** | ⚠️ **会使用医疗品自我恢复**——缠斗能力极强 |
| **应对核心** | **要有“秒杀窗口”意识**：拖久了他在楼梯间跟你耗血，吃亏的是你 |
| **装备要求** | 需要**足够的爆伤或高穿深**，否则打不死会回血的对手 |
| **收益** | 稀有医疗物资与任务物品 |

> **一句话**：**Sanitar 的战斗是“输出 vs 治疗”的赛跑**——你不会嫌自己输出高。

## 🧭 战利品与任务

<a id="loot"></a>

| 项目 | 内容 |
|------|------|
| **价值档次** | 疗养院内**中高**（电子件、医疗品、钥匙房）；外围**中低** |
| **主要产出** | 疗养院钥匙房（高价值密度全游戏前列）、**外围隐藏 stash**、小镇民居 |
| **任务密度** | 中高——**医疗与搜集类任务常驻** |
| **推荐姿态** | ⭐ **按技术水平分流**：打得动就去疗养院，打不动就做外围 stash——**两条路都赚钱** |

**一条被低估的事实**：**海岸线外围的收益比很多人以为的高**。隐藏 stash 位置固定、路线可重复，**风险却远低于疗养院**。

---

## 🧭 实战要点

1. **先决定“今天走哪条线”**：疗养院（高风险高回报）还是外围 stash（低风险稳定）——**别两头都想占**。
2. **上楼先听、下楼先看拐角**：楼梯间是疗养院的心脏。
3. **靠建筑走**：疗养院窗口多，站在窗户正对面就是当靶子。
4. **清楼时注意窗外**：你在楼里搜刮，楼外的人也在看你。
5. **打 Sanitar 要快**：他会自愈，拖久了等于白打。
6. **海滩与码头别直线冲**：撤离点附近永远有人蹲。
7. **东南角只走已知路径**：那片雷区肉眼看不见。
8. **外围 stash 值得专门跑一趟**：位置固定，跑熟就是稳定收益。

---

## ⚠️ 常见错误

- **单人清疗养院还开大音量**：楼内回声与脚步判位是硬功夫，新人容易“盲清楼”。
- **只盯楼里不看窗外**：疗养院窗口多，清楼的人也是别人的靶子。
- **海滩直线冲锋**：码头撤离点附近同样有人蹲守。
- **不带够输出去打 Sanitar**：他会回血，打不死的缠斗对你最不利。
- **为了高价值硬闯疗养院**：外围 stash 的收益风险比更划算——**先认清自己的水平**。
- **抄近道走东南角**：那里有看不见的雷区。
