# 耳机与听力装备 (Headsets)

<a id="top"></a>

> “先听见的人先开枪。耳机买的不是声音，是那半秒。”
> —— 关于信息差这件事

## 💡 核心机制

### 1. 耳机只做两件事

- **放大**：把脚步、换弹、涉水、开镜这类低频动作音**抬高到能分辨的程度**——它不创造信息，只是**把原本接近听觉门槛的信息推过门槛**；
- **压低**：把枪声、爆炸这类环境噪音**压下去**，避免你在交火后短暂失去耳朵。

它**不提供任何护甲值**，也不改变子弹伤害。把它当防护买，是这类条目里最常见的一次误购。

> 想理解它在整个信息链里的位置，先看[听声辨位与音频机制](audio.md)——那里讲的是「声音怎么传播、听到 X 该做什么」，这里讲的是「买哪个」。

### 2. 0.16.5.0 那次均衡改掉了什么

这是选型的**分水岭**，写在这里可以省掉一轮试错：

- 过去**戴耳机与不戴耳机**之间存在明显的整体音量差——不戴的人等于聋一半；
- 过去**不同耳机之间**也有音量差，于是「某些款靠响度占便宜」；
- 0.16.5.0 把这两条**都拉平了**。

**结果**：今天各款耳机之间的差异**不再是“听得见 vs 听不见”**，而是**音色取向**——同一段脚步在不同耳机里的**明亮与沉闷程度不同**，而这个差异会重塑你判断方向与距离的**肌肉记忆**。

> 所以那句常被引用的结论要读准：**换耳机就是换习惯。** 不是“换了更清楚”，是**你过去建立的听感坐标系要重算一次**。

### 3. 结构只有两大类

| 结构 | 代表型号 | 特点 |
|------|----------|------|
| **头戴式耳罩** | GSSh-01、Peltor Tactical Sport、Opsmen Earmor M32、Walker's Razor Digital / Slim、MSA Sordin Supreme Pro XL、Safariland Liberator HP 20、Peltor ComTac 各代、Ops-Core FAST RAC | 传统军用形态，主流选择 |
| **入耳式耳塞** | CENS Proflex DX5、Peltor TEP-300 | 不占头部两侧空间，与**全覆面头盔**的兼容性更好 |

**两类之间没有绝对优劣，只有一个判断**：你**是否长期戴全覆面头盔**（Altyn、Vulkan-5、Rys-T 一类）。这类头盔会**压缩听力**，而耳罩式耳机在它下面往往戴不进去或效果打折——这就是为什么「**面罩与耳机经常二选一**」（见[护甲与头盔图鉴](armor-catalog.md)）。

### 4. 台面型号（按价位档）

站内不给逐款音色评分——**那是主观的、也会随版本变**。这里给的是**档位与族系**，足够支撑一次选型：

| 档位 | 族系 | 型号 |
|------|------|------|
| **入门** | 军用基础 | GSSh-01 |
| | 廉价民用 | Opsmen Earmor M32、Peltor Tactical Sport |
| **中端** | Walker's | Razor Digital、Razor Slim、XCEL 500BT |
| | Safariland | Liberator HP 20 |
| | MSA | Sordin Supreme Pro XL |
| **高端** | Peltor ComTac | ComTac II、ComTac IV Hybrid、ComTac V、ComTac VI |
| | Ops-Core | FAST RAC |
| **入耳** | CENS / Peltor | Proflex DX5、TEP-300 |

> **同款多配色不构成差异。** 官方数据里这一组共 28 个条目，去掉配色、迷彩与联名版本后是 **17 个基本型号**——其中 `tw-exfil-` 前缀的几款（ComTac V / VI）是**与 Team Wendy EXFIL 头盔同体系出现的版本**，结构相同、配色体系不同。挑外观可以，但**不要为配色付溢价**。

**两个容易看错的点**：

1. **`EXFIL` 不是型号，是配套体系**——看到它先确认底下的耳机本体是哪一代；
2. **ComTac 的罗马数字是代际**（II → IV → V → VI），**不是等级**。代际越新通常越贵，但「越贵是否越适合你」取决于你对**音色**的偏好，而不是代际数字。

## 🧭 实战要点

1. **进图前先决定“戴不戴”**：这是唯一一个**每局都用、且不需要花钱维护**的装备决策——不带的理由是“我需要全覆面头盔”，不是“我习惯裸耳”；
2. **长期用全覆面头盔 → 选入耳式**；其余情况**耳罩式即可，档位够用就好**；
3. **买完不要频繁换**：0.16.5.0 之后各款差异只剩音色，**频繁换耳机等于反复重置你的听感坐标系**，反而降低你对声音的判断准确度；
4. **耳机与头盔分属不同槽位，可以同戴**——常规头盔下戴耳机是最常见的搭法，真正的冲突只在全覆面头盔上；
5. **把省下的钱花在弹药上**：耳机不决定你能不能打死人，[弹药](ammo-table.md)决定。

---

## ⚠️ 常见错误

- **把耳机当防护**：它不挡子弹、不减伤，被击中时它不会替你挡任何东西；
- **为配色付溢价**：同款不同配色的听感是同一套；
- **在嘈杂环境里测耳机**：音色差异要在**同图、同场景**下比较才成立，换一张图再比等于重新开始；
- **忽略 0.16.5.0 的分水岭**：引用“某款比某款响”的旧结论——那套口径已经作废；
- **戴全覆面头盔还硬上耳罩式**：结果是**既压了听力、又没换来耳机的增益**，两头落空。
