# 服装与外观 (Clothing & Appearance)

<a id="top"></a>

> “衣服不挡子弹。它只决定别人先用多少秒判断你是谁。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 可购买的**纯外观**装备 |
| **购买入口** | **Ragman 的「服务」标签**（交易菜单顶部） |
| **结构** | 分 **上衣（upper）**与 **下装（lower）**，**可任意组合** |
| **阵营池** | **BEAR 与 USEC 各有自己的部件池**；唯一例外是 **The Unheard 版可以混穿两边** |
| **解锁条件** | **商人等级 + 玩家等级 + 卢布**；一部分绑定 **Ragman 的任务线**；一部分可由官网扩展包永久解锁 |
| **是否影响数值** | **不影响**——不提供防护、不改变受击判定，也没有任何数值加成 |
| **死亡后** | 外观是账号层面的解锁，**死亡不会失去**（与护甲、武器不同） |
| **配套条目** | 队内识别请用[臂章](iff.md)，不是服装——两者分工见第 5 节 |

---

## 💡 核心机制

### 1. 先摆正定位：它是“外观槽”，不是“防护槽”

护甲、头盔、面罩、胸挂各自管各自的数值；**服装只占外观槽**。

- **换一套衣服不会让你更耐打**——被打中的结算与穿什么衣服无关；
- **它也不会改变你的移动、耐力或噪音**——影响因素在负重与装备上，不在衣服上。

所以它的价值全部落在**另一件事**上：**别人看到你的半秒里，先把你判断成什么。**

### 2. 上衣与下装分件组合，但阵营池不通用

服装是**分件**的：一件上衣 + 一条下装，**可以自由搭配**——只要它们都来自你能用的部件池。

| 规则 | 内容 |
|------|------|
| **分件** | 上衣、下装各自独立购买与更换，**可以混搭不同款式** |
| **阵营池** | **BEAR 的部件池与 USEC 的部件池是分开的**，正常情况不能互穿 |
| **唯一例外** | **The Unheard 版本**的所有者可以**混穿两个阵营的部件**（这是版本权益，不是通用规则） |
| **预览** | 在服装菜单里**右键**某一款式可以直接看人物模型效果，也可以把已装备的护甲隐藏起来对比 |

**这意味着同一个“看起来像平民”的效果，BEAR 和 USEC 手里能用的具体款式是不一样的**——你在攻略里看到别人穿的某件衣服，未必在你的池子里。

### 3. 怎么解锁：三条路径

服装不是“有钱就能全买”，它有三条并行的解锁路径：

| 路径 | 说明 | 例子档位 |
|------|------|----------|
| **等级 + 钱** | 最常见的路径：达到**商人等级与玩家等级**门槛后，用卢布购买 | 入门档约在 **Ragman LL1 / 十几级**；进阶档需要 **LL2 ~ LL3 与二十到三十级以上**，价格跨度很大 |
| **任务线** | 一部分款式绑定 **Ragman 的「Drip-Out」系列任务**，完成任务才解锁购买权 | 该系列的第一环要求**击杀 100 名 Raider**并**上交 50 件战局内发现的 WARTECH 品牌装备**——**这是一条后期任务线，不是新手目标** |
| **扩展包** | 部分服装可以**通过官网购买对应的扩展永久解锁**（不占用任务与等级门槛） | 见[购买指南（地区与版本）](../docs/buying-guide.md) |

**判断顺序建议**：**先问“买它做什么”**（伪装 / 识别 / 顺眼）→ **再看它与 AI 势力的配色会不会撞**（下一条）→ **最后才看价格**。反过来做，最容易买一堆用不上的。

### 4. 它真正的作用：**伪装**

这是服装唯一有战术含量的用途，而且**方向是单向的**：

| 你想做什么 | 服装能帮你吗 |
|------------|--------------|
| **PMC 想被当成 Scav**（降低被优先开火的概率、混进 Scav 群里） | **能**——PMC 的部件池里有明显偏民用风格的款式（运动服、T 恤、休闲裤一类），这正是它们的价值 |
| **Scav 想假装成 PMC** | **基本不能**——**Scav 的底层衣裤改不了**，看袖子就露馅（见[敌我识别与身份判断](iff.md)） |
| **改阵营** | **不能**——**服装不能证明阵营**，穿美式款不等于 USEC |

**所以服装的伪装是“降级伪装”**：让一个 PMC 看起来**不像一个值得优先开枪的目标**。它降低的是**别人犹豫的成本**，不是你的受击概率。

### 5. 与臂章的分工：一个对内，一个对外

这两件东西经常被混为一谈，但它们的作用方向正好相反：

| | **臂章（Armband）** | **服装（Clothing）** |
|---|---|---|
| **归属** | **官方给的唯一队伍标识** | 纯外观商品 |
| **槽位** | **专用槽** | 上衣 / 下装两个外观槽 |
| **能否被拾取** | **不能** | 不适用（不是掉落物） |
| **死亡后** | **不丢失** | **不丢失** |
| **跨局稳定性** | **可长期固定**，是做队内识别的正确工具 | 可随时更换 |
| **主要用途** | **对内**：告诉队友“我是谁” | **对外**：告诉别人“我是什么” |
| **选择原则** | 选环境里**不常见、且不与 AI 势力撞色**的颜色，开局统一口径 | 按用途选：想低调就压低辨识度，想识别就统一 |

**一句话**：**识别用臂章，伪装用服装**。把服装当成队内标识用，等于把唯一的官方标识工具放着不用。

### 6. 为什么值得花这笔钱

抛开外观喜好，服装的实际收益只有一条：**它影响“第一次判断”**。

在塔科夫里，**第一次判断的代价极高**——判断错误要么是误伤，要么是自己先倒下。而服装是**唯一能在对方开火前就介入判断的装备**。它不能保证结果，但它能**改变对方犹豫的长度**——而那半秒，往往就是[遇敌处置与接战决策](contact-drill.md)里说的那个窗口。

## 🧭 实战要点

1. **先明确用途再买**：要伪装就压低辨识度，要识别就统一款式，别混着来。
2. **别拿服装当队内标识**：那是[臂章](iff.md)的活，而且臂章**不能被拾取、死亡不丢**，跨局稳定得多。
3. **注意与 AI 势力撞色**：穿得像某个势力的人，可能被当成那个势力的人先打。
4. **“低调”的意义是降低优先级，不是隐身**：它减少别人犹豫的成本，不减少伤害。
5. **The Unheard 的混穿是版本权益**：没有它就别按“混搭两阵营”做规划。
6. **Drip-Out 是后期目标**：为了外观去买一条“杀 100 个 Raider”的任务线，性价比要自己算清。
7. **买之前右键预览**：把已装备的护甲隐藏起来对比，能避免“穿上之后完全不是那个效果”。

## ⚠️ 常见错误

- **以为服装能提供防护或数值**：它不提供任何一点。
- **以为换衣服能改阵营或骗过看袖子的人**：**服装不能证明阵营**；反过来 Scav 装 PMC 也会被袖子出卖。
- **把服装当队内识别工具**：臂章才是；服装可以随时换，队友无法据此长期识别。
- **忽略撞色风险**：与 AI 势力同款配色，等于主动把自己放进别人的“优先目标”清单。
- **先看价格后想用途**：最容易买一堆穿不到的东西。
- **把 Drip-Out 当新手任务**：它的门槛是**后期**级别。
- **以为死了要重买**：外观是账号解锁，**死亡不失去**。
