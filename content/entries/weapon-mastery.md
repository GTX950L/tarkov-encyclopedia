# 武器掌握 (Weapon Mastering)

<a id="top"></a>

> “同一把枪，在你手里是铁疙瘩，在老兵手里是工具——差别不在配件，在命中过多少次。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 被动成长（按武器平台累计） |
| **等级结构** | **3 级**（按平台家族，不按单把枪） |
| **经验来源** | **在线战局中命中目标**，1 次命中 = 1 点精通经验 |
| **多弹丸武器** | **每颗弹丸各计 1 点**——霰弹枪成长显著更快 |
| **主要回报** | 新的换弹动画（L2 / L3）；**瞄准状态下换弹**（L3） |
| **是否跨 wipe** | **不跨**。每个 wipe 重练；**转生可带走一定比例** |
| **是否影响数值** | 精通本身**不改后坐力与装填速度**——那是[技能系统](skills.md)的事 |

---

## 💡 核心机制

<a id="not-skill"></a>

### 1. 先分清：“武器精通”不是“武器技能”

这是全站最容易混淆的一对概念，必须先拆开：

| | **武器精通（Weapon Mastering）** | **武器技能（Weapon Skill / Skills）** |
|---|---|---|
| **归类** | 附在武器平台上 | 属于**角色技能**（如“突击步枪”“手枪”） |
| **怎么涨** | **命中目标**（在线战局） | **射击、换弹、上膛、排障**等行为 |
| **等级** | **3 级** | 多级，直至精英级 |
| **给什么** | **换弹动画与姿态**（见下） | **后坐力削减、换弹速度、切换速度、人机工效**等数值 |
| **在哪看** | 武器检视界面的精通条 | 角色技能面板 |

一句话记住：**精通改“动作”，技能改“数值”**。两者还能互相加成——**武器技能达到精英级时，精通经验翻倍**。

<a id="how-to-level"></a>

### 2. 精通怎么涨：只有一条路——打中

官方规则很干脆：**在线战局中对实体造成命中，每次命中给 1 点精通经验**。

由此推出三条实用推论：

1. **打中比打死重要**：一发命的近战秒杀和十几发压制的成长效率不同，但**尸体不算数，命中才算**；
2. **霰弹枪成长最快**：一发霰弹有多颗弹丸，**每颗命中各计 1 点**——同一枪命中 8 颗就是 8 点；
3. **离线模式不加**：规则限定在**在线战局**，离线练习刷不出来。

> **一个容易忽略的账**：精通经验的获取方式是“命中次数”，所以**高射速、高弹丸量、能持续对枪**的武器天然更容易练满，而慢速栓动与狙击枪练起来最慢。

<a id="levels"></a>

### 3. 三个等级分别给什么

| 等级 | 奖励 |
|------|------|
| **L1** | 起始状态，无额外效果 |
| **L2** | **新的换弹动画** |
| **L3** | **更新一档换弹动画 + 该平台所有武器都可在瞄准状态下换弹** |

**L3 是质变**：它不是一个数值加成，而是一个**动作能力**——你可以在保持瞄准、持续盯住目标的同时完成换弹，不被迫退出枪托视野。对中远距离对枪，这条的实战价值高于任何“换弹快 X%”。

<a id="platform"></a>

### 4. 按“平台”共享，门槛还各不相同

精通**挂在武器平台上**，同平台的枪共享进度。这意味着**练一把，等于练一族**：

- 练满 ADAR/M4/HK416 这一族，你的 TX-15 也一起受益；
- 练满 AKM 一族，AK-103、AK-105 等卡拉什尼科夫系一起受益。

不同平台所需经验**并不相同**，官方 wiki 列出的门槛差异很大：

| 平台家族（示例） | 升 L2 所需 | 升 L3 所需 |
|------------------|-----------|-----------|
| **AKM / VPO-209 / Vepr** 系 | **500** | **600** |
| **ADAR 2-15 / M4A1 / HK416 / TX-15** 系 | **1600** | **2000** |
| **AK-74 / AK-100 / RPK-16 / RD-704 / SAG** 系 | **2000** | **2200** |

> **上表只是示例，不是全表。** 各家族的阈值从数百到数千不等，且随版本调整；**开练前先在武器检视界面看一眼自己那把枪的实际进度条**，比背表更可靠。

<a id="wipe"></a>

### 5. 和 wipe、转生的关系

- **每个 wipe 重置**：精通与技能一样，跟角色进度一起清零。所以**越早开始练，收益周期越长**；
- **转生按比例保留**：转生时可带走**一定比例**的技能与武器掌握，比例随转生档位提高（见 [Prestige 转生](prestige.md)）。

这条组合起来推出一条策略：**别每 wipe 分散练十几族**，锁定 **2–3 个主力家族**长期投入，才能把 L3 拿到手。

---

## 🧭 实战要点

1. **挑 2–3 个家族主练**，别摊薄。优先你每局都会带的那一族。
2. **霰弹枪是练精通最快的工具**，可作为“顺手练”的选择。
3. **想让 L3 早到，就多用同一平台**：同一族换枪不换平台，进度不浪费。
4. **瞄准换弹（L3）值得专门练**：中远距离对枪时，它决定你能不能“边压边换”。
5. **确认是在线战局**：离线不加精通经验。
6. **转生前把主力家族练到 L3**，否则比例带走后可能退回 L2 甚至更低。

---

## ⚠️ 常见错误

- **把精通当成会降后坐力的系统**：降后坐力是**武器技能**，不是精通。
- **以为练单把枪就够**：精通按平台共享，同族切换不亏，但**跨平台一切归零**。
- **用离线模式刷精通**：不加经验。
- **忽略阈值差异**：AKM 一族 500/600 就能满，AR 系要 1600/2000，投入预算完全不同。
- **只在实战里硬练**：命中数才是经验，专程刷命中往往靠打 AI 更稳。
