## 💡 核心机制

### 1. 格子经济学

背包是有限资源，**每件战利品都在花你的格子**。衡量战利品的不是标价，而是“**每格价值**”——两格的黄金链比十格的电视更值得带（大致示例，价格随版本波动）。

### 2. 安全箱：命根子

安全箱内的物品**阵亡不掉、无法被搜刮**。用途优先级：

1. **撤离保命物资**（止血、止痛、钥匙）；
2. **高价值小件**（捡到贵重小物先塞箱）；
3. **任务物品**（丢了任务进度最伤）。

安全箱越大越好，但**箱子装满枪弹药就失去了保命容量**——别把它当第二个背包。

### 3. 弹匣盒与专用容器

- **弹匣盒**：整装弹匣集中管理，换弹更快更整洁；
- **弹药包**：散装弹药集中收纳，省格子；
- **战术胸挂/ Rig**：装备层的一部分，把常用物资外挂到身上——**逐型号的格数、布局与重量见[载具图鉴：背包与胸挂](loadout-carriers.md)**。

#### 3.1 专用容器：格数与效率表

**口径先写死**：**格数**＝容量上限；**储物效率**＝格数 ÷ 该容器自身占用的空间——**大于 1 表示「装进去比它自己占的地方多」**，越大越划算。容器箱与[安全箱](containers.md)是两回事：**安全箱死了还在，容器箱死了会掉**（除非放进安全箱里）。

| 容器 | 格数 | 效率 | 装什么 |
|------|------|------|--------|
| **T H I C C 物品箱** | **196** | **13.07** | 几乎所有东西（不含其他箱、弹药纸盒） |
| Lucky Scav Junk box | **196** | 12.25 | 以物换物材料 |
| **Dogtag case** | **100** | **100** | 狗牌——效率全表最高 |
| Ballistic plate case | 96 | 12 | 插板 |
| **T H I C C 武器箱** | 90 | 9 | 武器 / 弹药 / 配件 |
| Streamer item case | 88 | 9.77 | 收藏家任务物品 |
| **Poster tube** | 80 | **26.67** | 海报 |
| **钥匙箱（Key case）** | 77 | 13.83 | 钥匙与钥匙卡 |
| 物品箱 | 64 | 4 | 几乎任何东西（效率最低的一档） |
| **弹匣盒** | 64 | **10.66** | 弹匣 |
| 医疗箱 / 手雷箱 / 保温袋 | 64 | 7.11 | 各自的专类 |
| 现金箱 / 弹匣箱（弹药） | 49 | 8.17 / 12.25 | 货币 / 弹药 |
| S I C C 收纳包 | 25 | 12.5 | 货币、钥匙、狗牌、海报 |
| **文件包 / 钥匙串（Key tool）** | 16 | 8 / **16** | 文件 / 钥匙 |
| 注射器盒 / 钥匙卡盒 / 钱包 | 9 | 9 | 各自的专类 |
| 手枪盒 | 12 | 3 | 手枪与弹匣 |

来源：二级（英文 EFT Wiki）。**未列出的容器尚未取到可核数值，留白不猜**。

> **三条读表结论**：① **「效率」和「格数」是两件事**——狗牌箱效率 **100**、海报筒 **26.67**，而格数最大的物品箱只有 **13.07**、物品箱更低到 **4**；**专类容器几乎总是比通用容器划算**，代价是它只装那一类。② **S I C C 收纳包（25 格）能进安全箱**，这是「把值钱小件带出图」的关键一步。③ **专类箱是「同格数、不同用途」**：同为 64 格，弹匣盒效率 10.66、医疗箱只有 7.11——**别只看格数挑箱子**。

> **还有三个格子不占背包，而且死了也不掉**——那是角色面板上的[特殊槽装备与工具](special-equipment.md)。它是这套收纳体系里唯一“零风险”的一层，别空着。

### 4. 嵌套与“套包”

大背包可以装入小背包形成“套娃”，撤离时带货效率翻倍。但注意：

- 嵌套有层数上限；
- 套包里的包被搜刮时会连内容一起被拿走——**敌人的背包就是你的死亡盲区**。

### 5. 重量

超重后移速、耐力恢复全面下降。**跑得慢 = 死得快**。满载撤离前问自己：多赚的几万卢布，值不值得把撤离速度打七折？

## 🧭 实战要点

1. **进图前清背包**：只带任务和作战所需，空格越多捡得越多。
2. **边搜边整理**：把值钱小件往安全箱和内层包挪，把垃圾丢给尸体“保管”。
3. **学会丢枪**：弹尽粮绝时，捡敌人的枪比自己扛两把枪划算。
4. **贵重先入箱**：捡到高价值小件的第一反应是进安全箱，而不是“待会儿再说”。
5. **撤离前最后一轮压缩**：合并弹药、拆解堆叠，把“被迫丢弃”降到最低。

## ⚠️ 常见错误

- **安全箱塞满弹药**：阵亡时弹药都不掉——问题是保命药没地方放了。
- **见什么捡什么**：满包垃圾，见到真货反而没格子。
- **忽视重量**：满装撤离变成步战车，被跛行的自己气死。
- **套包当保险箱**：套娃包里的东西照样会丢，它只是扩容，不是保护。
