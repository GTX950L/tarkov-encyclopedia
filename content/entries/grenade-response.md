# 投掷物来袭处置 (Grenade Response)

<a id="top"></a>

> “手雷的问题从来不是‘冲还是躲’，是‘你为什么会站在它的落点上’。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 听到投掷物之后的动作决策（不是投掷物本身） |
| **核心问题** | **冲、退、不动，还是反骗** |
| **唯一的时钟** | **引信**——从 2 秒（VOG-25）到 5 秒（M67），差别是生死 |
| **最容易误判的地方** | 把**拔销声**当成“雷已经来了”——它可能只是一次**假投掷**（见第 4 节） |
| **关键事实** | **捂雷（cooking）未实装**——你没法靠引信长度反推对面扔的是哪一种 |
| **配套条目** | [手雷与投掷物](grenades.md) 讲**它是什么**；本篇讲**它来了怎么办、以及这段声音能被谁利用** |

## 💡 核心机制

### 1. 你听到的不是一个声音，而是三个

<a id="sounds"></a>

新手把“听到手雷”当成一件事，其实它有**三段音频**，各自回答不同的问题——**而且只有前两段是可以造假的**：

| 声音 | 回答什么 | 能不能造假 |
|------|----------|------------|
| **拿雷 / 拔销音** | **“他要扔了”**——最早的一级预警，但只在近距离听得到 | ✅ **能**。这是全篇最容易被利用的一个信号（见第 4 节） |
| **投掷动作音**（甩出） | **“东西已经出手了”** | ⚠️ 较难造假，但可以**投向别处** |
| **落地与滚动音** | **“还剩多久”**——金属碰撞与滚动说明**还没炸**，滚得越久，你能用的时间越多 | ❌ 不能。**这是唯一诚实的一段** |

**为什么这个区分关键**：塔科夫**没有实现“捂雷”**（在手里掐着引信再扔）——全部投掷物都是**出手即开始计时**。所以引信的长短会直接体现在“**落地之后多久才爆**”上。

> **结论**：不要试图在听到的第一秒判断型号，也**不要在听到拔销音的瞬间就做动作**——**等落地音**。它滚了三秒还没炸，你就有余量；它几乎落地即响，那是另一种雷（见第 2 节）；**而它一直没有落地——那就是有人骗了你**。

### 2. 引信就是这道题的全部：2 秒和 5 秒是两个不同的世界

<a id="fuse"></a>

下面是站内需要记住的一组数字（游戏内数据，随版本可能有微调）：

| 型号 | 引信 | 爆炸半径 | 破片 | 你实际能做什么 |
|------|------|----------|------|----------------|
| **F-1** | **3.5 秒** | 3–8 m | 150 | 有一次转身离开的机会，但**半径很大，跑不干净就会吃到破片** |
| **RGD-5** | **3.5 秒** | 3–7 m | 100 | 同上，半径略小——**最“标准”的一颗** |
| **M67** | **5 秒** | 3–9 m | 100 | 时间最充裕：**既能换位反打，也是最适合做假投掷的一颗**（见第 4 节） |
| **VOG-17** | **2.5 秒** | 2–6 m | 60 | **来不及跑出半径**。答案是“贴硬掩体”，不是奔跑；**室内破片还会在墙壁间反弹** |
| **VOG-25** | **2 秒** | 3–9 m | 40 | **最短引信**。听到落地音时基本已经进入结算倒计时；对面常用来**预判走位直接扔** |
| **RGO / RGN** | **撞击即爆（约 0.3 秒）**，另有 **3.5 秒备用引信** | — | — | **没有“落地后”这一段**。唯一的解法是别站在它可能撞到的位置 |
| **Zarya（震撼弹）** | 2 秒 | — | — | 不致命，但会致盲与耳鸣——**它后面一定跟着人** |
| **RDG-2B（烟雾）** | 3.5 秒 | — | — | 不是杀伤，是视线博弈（见第 6 节） |

**从这张表能读出三条判据**：

1. **VOG 系列与 RGO / RGN 属于“反应型无解”**——它们的设计意图就是“不给你跑的时间”。对付这类，唯一的办法是**不站在会被投掷到的位置**（门后、窗口正对面、走廊直线、已知的交战点）；
2. **碰炸雷撞到玻璃会立即引爆**——所以**不要贴着窗户和玻璃隔断站**。这是社区里最经典的“自己把自己炸死”；
3. **投掷物会滚出意料之外的距离**——落在你附近不等于停在它落地的位置，判断余量时要把滚动算进去。

### 3. “冲”只在三个条件同时成立时才正确

<a id="push"></a>

“听到雷就冲出去”听起来勇，实际是拿命赌对面用的是长引信。**冲（push）成立的条件是三条同时满足**：

| # | 条件 | 为什么 |
|---|------|--------|
| **①** | **你确切知道他在哪** | 不知道位置地冲，是从一个暴露点跑向另一个暴露点 |
| **②** | **你离他近于离爆心远**（雷落在你与他之间或你脚边） | 冲的目的是**穿过/避开杀伤区并进入他的射程**，否则你只是从中心跑向边缘 |
| **③** | **你的枪是抬起的** | 冲过去之后要立刻开枪——**这是一次进攻，不是一次逃跑** |

**反过来，下面三种情形必须退或不许动**：

- **雷落在隔断（墙 / 拐角 / 集装箱）的另一侧** → **最好的动作往往是不动**。塔科夫的破片会被硬掩体阻挡（社区实测口径），你移动反而可能把身体移进破片的分布区；
- **雷落在开阔地、而你附近没有硬掩体** → **离开半径，跑出去**。⚠️ **不要在开阔地趴下或蹲下**：官方社区导师（Sherpa）的明确提示是——**露天趴下会让你成为更容易命中的目标**，你失去了移动能力，而破片覆盖的正是地面。**能跑就跑；跑不掉就找硬掩体，并把头与躯干转向远离爆心的一侧**（头是最少血量、最先死的部位）；
- **你已经被确认位置、且对面不止一人** → 退，但**退要有方向**（见[遇敌处置与接战决策](contact-drill.md) 的“断联脱离”五个细节）。

**一句话判据**：**有硬掩体 → 把掩体挡在你和落点之间；有空间 → 离开半径；两者都没有 → 这次你赌的是引信。**

### 4. 拔销声是一张可以双向打的牌

<a id="bluff"></a>

这一节最容易做错。**“拿出手雷”这个动作和一个信号是等价的**——因为它有独特音效，而且**做这个动作的人在此期间不能开枪**。

> 官方社区导师（Sherpa）的原话：**处于投掷动画中时你无法还击**，所以永远从掩体后投掷。

既然它是个信号，**信号就可以造假**——这一手因此是双向的：**别人可以骗你，你也可以骗别人、更可以趁别人做这个动作时打他。**

#### 4.1 别人可能在骗你：假投掷

玩法很直接：对方**拿出雷（发出拔销声）→ 收回雷 → 掏出枪**，等你按“雷来了”的剧本做出反应（换位、离开掩体、跑动），然后打你移动中的那一秒。

**反制的核心判据只有一个——等第二段声音。**

| 你听到的 | 含义 | 该做什么 |
|----------|------|----------|
| **只有拔销音，一直没有落地音** | 雷**根本没出手**——这是假投掷 | **不要换位**。保持原位、保持枪口对着他可能出现的方向。他白付了一次收雷掏枪的时间 |
| **拔销音 + 落地/滚动音** | 雷真的来了 | 进入第 2、3 节的判断（按引信余量决定退 / 贴 / 压低） |
| **拔销音 + 落地音，但落点明显不在你这边** | 投掷是真的，**目标不是你** | 大概率是**调虎离山**（见[AI 行为逻辑](ai-behavior.md) 的声响诱饵）——同样不要按他给的方向动 |

**为什么这条最重要**：假投掷的全部收益来自“**你动了**”。你不按他写的剧本走，这一手就是零收益。

#### 4.2 你也可以推：趁他拔销的时候上

反过来看，当**距离足够近**、而你听到对方拔销时，那是一个**明确的进攻窗口**——因为对方此刻只有两个选择，**而两个都需要时间**：

- **把雷收回去、再掏出枪** → 这段时间他手里没枪；
- **硬着头皮把雷扔出来** → 投掷动画期间他同样不能开枪。

所以你推进时面对的是一个**暂时没有还手能力的人**。这是社区里的标准打法，官方社区导师也把它写成了一条明确建议：**离得近时听到拔销声，可以借这段时间推进**，因为对方要么收雷、要么必须换一种方式投掷。

**“听到拔销就推”的成立条件**（注意与第 3 节的区别：**第 3 节是躲雷，这一节是抢硬直**）：

| # | 条件 | 为什么 |
|---|------|--------|
| **①** | **距离近**（一个房间、一段楼梯、一道门之内） | 远距离推进等于给他留出“完成投掷 → 抬枪”的完整时间 |
| **②** | **你确切知道他在哪一格** | 推进是往一个具体位置去，不是往一个方向去 |
| **③** | **对面是单人** | 多人时可能一人投掷、同伴架枪——你推进正好撞进枪口 |

**⚠️ 一条反向纪律**：**单排扔雷时，离对手太近会被反推**。所以自己按 G 之前要保证**有足够的距离或掩体**——否则你拔销的那一刻，就是对方开始推进的信号。

#### 4.3 你也可以骗：假投掷的用法

这是**零消耗**的一手（雷收回去了，没花掉），但有三条硬纪律：

1. **必须在硬掩体后做**。拿雷与收雷的动画期间你**不能开枪**——站在开阔地做这件事，等于把命递出去；
2. **M67 是最适合假投掷的一颗**：它的引信有 **5 秒**，足够你**收雷 → 掏枪 → 抬枪**，甚至再等一拍。短引信的 VOG 系列不适合——收得慢一点就真炸在自己手里；
3. **挑只有一个出口的位置用**：楼梯口、门后、拐角。**对方被骗产生的“动”，必然是走向你预瞄的那个方向**；
4. **不要连续用同一招**：同一个位置连着两次拔销不下蛋，第二次就没人上当了。

#### 4.4 一张表看完这条博弈

<a id="bluff-table"></a>

| 谁 | 做了什么 | 对方的最优解 |
|----|----------|--------------|
| 你 | 拔销（假） | **不动**，等落地音 |
| 你 | 拔销 → 真投 | 按引信余量决定：退 / 贴掩体 / 离开半径 |
| 对方 | 拔销（假） | **不动**——他白付一次收枪时间 |
| 对方 | 拔销，且**距离很近** | **推**：他要么收雷掏枪、要么投掷硬直 |
| 对方 | 已经进入投掷动画 | 换位 + 反打（见第 5 节） |

**一句话总结**：**拔销声不是“雷来了”，是“有人正在做一个不能开枪的动作”。** 你要判断的不是雷在哪，是**他想让你做什么**。

### 5. 雷出手之后：换位窗口，不是等待窗口

<a id="counter"></a>

一旦确认雷已经出手（听到落地/滚动音），你的动作回到物理判断；但**雷响之后**还有一段被很多人浪费掉的时间：

| 你的处境 | 该做什么 |
|----------|----------|
| **雷不在你脚下**（落在远处 / 对面乱扔） | **换位并反打**。他在收枪动作里，这是你唯一的先手 |
| **雷在你脚边附近** | **先解决这颗雷**（离开半径 / 贴硬掩体），别想着反打 |
| **你已经听到第二颗** | **立刻离开这一片**。连续投掷说明对面在**系统地清你的位置**，站在原地等第三颗是最差的选项 |
| **爆炸刚响过** | **不要立刻回原位**。等他以为你已经死了的那一拍，或者直接换位离开 |

**并且记住**：**他投完，你的位置也已经被确认了。** 雷的价值有一半是“逼你动”——所以躲过之后的第一件事不是回原位，而是**换一个他不会预判的位置**。

### 6. 不同投掷物的应对完全不同

<a id="bytype"></a>

| 类型 | 应对 |
|------|------|
| **破片（F-1 / RGD-5 / M67 / VOG）** | 见第 2、3 节。**核心是硬掩体，不是距离**。注意室内 VOG 系列的**破片会在墙壁间反弹**——“退到墙后”有时不够，要退到**另一个房间** |
| **震撼 / 闪光（Zarya 等）** | 不致命，但**它后面一定跟着人**。应对是按“3 秒后有人进门”来准备：抬枪、对着入口，或者干脆先离开房间。**不能跑开时可以背对它**，减少致盲与耳鸣 |
| **烟雾（RDG-2B 等）** | **它不是掩护，是双向遮蔽**——你看不见他，他也看不见你。正确用法是**移动**（穿过去、换楼层、走出交火区）；而如果是**别人封的烟**，正确动作是**架好枪等突进**，因为对方也会借烟冲进来 |
| **燃烧 / 榴弹** | 作用是**封路**，不是杀伤。应对是**承认这条路暂时不能走**，改路线而不是硬穿（见[战局流程与节奏](raid-flow.md) 的动线原则） |

### 7. 你自己扔雷时的纪律

<a id="your-own"></a>

投掷物的风险是**双向**的——站内[手雷与投掷物](grenades.md) 讲过反弹，这里补行为层面的四条：

1. **投完立刻换位**。你的手雷同时告诉了所有人“你在哪”和“你扔向哪”；
2. **永远从掩体后投**。投掷动画期间不能开枪（官方口径），站在开阔地投掷等于把自己变成靶子；
3. **优先用“声音”而不是“杀伤”**。一颗投向**反方向**的雷能让人和 AI 转头，这是最标准的调虎离山（见[AI 行为逻辑](ai-behavior.md) 的声响诱饵）；
4. **够近就别真扔**——此时**假投掷 + 掏枪反打**往往比把雷扔出去更划算（见第 4.3 节）。真扔出去的那一刻，你也把主动权交出去了。

## 🧭 实战要点

1. **拔销声不是“雷来了”，是“有人正在做一个不能开枪的动作”**——先判断他想让你干什么。
2. **只信落地音**：只有拔销音没有落地音 = 假投掷 = **不要换位**。
3. **距离近 + 听到拔销 = 推进窗口**：他要收雷掏枪，或要硬投——两件事都需要时间。前提是单人、且你知道他在哪一格。
4. **开阔地不要趴下**：跑出去，或者找硬掩体把头与躯干转离爆心；趴下会让你成为更容易命中的目标。
5. **有硬掩体就把掩体挡在中间**；室内还要注意破片反弹，必要时退到另一个房间。
6. **听到第二颗就离开这一片**——被“点名”说明对面在系统清点。
7. **闪光之后不要站起来找路**，按“3 秒后有人进来”准备；跑不掉就背对它。
8. **烟雾用来走，不用来对枪**；别人封的烟，按“他要冲”来架枪。
9. **自己扔雷前先保证距离或掩体**——否则你拔销的瞬间就是对方开推的信号。
10. **M67 适合假投掷**（5 秒引信够你收雷掏枪），VOG 系列不适合。

## ⚠️ 常见错误

- **把拔销声当成“雷来了”**：这是全篇最大的认知错误——它只是一段可以被造假的音效。
- **听到拔销就换位**：正中假投掷的下怀。**他要的就是你动**。
- **在开阔地趴下**：官方社区导师明确提醒这反而更容易被炸——你放弃了移动，而破片覆盖地面。
- **默认所有手雷都有 3.5 秒**：VOG 系列只有 2–2.5 秒，RGO / RGN 几乎落地即爆。
- **捏着引信反推型号**：捂雷没有实装，等你数秒，它可能已经炸了。
- **雷在墙另一侧时慌张移动**：把身体探进了本该被掩体挡住的破片分布区。
- **在开阔地或没有掩体时投掷**：投掷动画期间你不能开枪，这是最贵的一次暴露。
- **离对手太近还硬扔雷**：你会被反推。假投掷或直接对枪都比这好。
- **闪光之后站起来**：最常见的“致盲后被补枪”死法。
- **用烟雾掩护对枪**：双方都看不见，先动的一方才有收益。
- **连续投掷下原地坚守**：对面在清你的位置，第三颗会落在你换过的地方。
- **忽略反弹与滚动**：室内低抛弹回来、落地后滚远，都是经典自杀方式。
