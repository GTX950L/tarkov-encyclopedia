# 工厂 (Factory)

<a id="top"></a>

> “在工厂，你从落地到交火，平均不超过一分钟。”
> —— CQB 爱好者的天堂

---

| 项目 | 信息 |
|------|------|
| **类型** | 小型室内地图 |
| **体量** | **全图最小**，数分钟可横穿 |
| **raid 时长** | **极短**（约 15–20 分钟级，全游戏最短） |

---

## 💡 核心机制

### 1. 距离被压缩到极限，所以“装备优势”在这里最不值钱

工厂是全游戏唯一一张**大多数交火发生在 20 米内**的图。这条事实改写了三件事：

| 常规经验 | 在工厂的实际情况 |
|----------|------------------|
| “穿深高的弹更贵、更强” | **贴脸距离上，弹种差距被大幅压缩**——便宜的近战弹完全够用 |
| “倍镜能让你先看到人” | **长枪管与倍镜是累赘**，举枪速度才是命 |
| “拉开距离打阵地战” | **没有距离可拉**——这张图上“退”的选项很少 |

**推论**：工厂考验的是**反应速度与举枪速度**，而不是配置。这也是它成为最佳“练枪房”的原因——**它把胜负从装备拉回到人**。

### 2. 铁结构 = 全图广播

工厂的建筑主体是**钢结构**，而铁格栅、铁楼梯、铁平台的声音辨识度**远高于其他材质**：

- **上楼梯的声音在另一层听得清清楚楚**，还能大致判断方向；
- 枪声全图可闻——**工厂没有“安全的角落”**；
- 因此**听声辨位在这里的收益是其他图的两倍**，也是老手敢 Rush 的底气。

### 3. 它是全游戏“单位时间收益”最高的 Scav 图

对 Scav 而言，工厂的真正价值是**周转率**：图小、局短、撤离快，**十几分钟就能跑完一轮**。单局收益不高，但**单位时间的期望收益排在前列**——前期攒钱最稳的方式之一。

## 🗺️ 区域结构

<a id="areas"></a>

| 区域 | 特征 | 主要风险 | 该注意什么 |
|------|------|----------|------------|
| **主厂房** | 两层钢结构车间，铁架、集装箱与办公隔层构成**大量垂直交火线** | **头顶**——二层铁架是全图最好的伏击位 | **进门先看上面**，再处理地面 |
| **地下 / 管道区** | 狭长走廊，拐角密集 | **贴脸交锋的高发地**，几乎没有反应时间 | **能绕就绕**；必须过时用[探头四纪律](firefight.md) |
| **办公区** | 电脑与贵重小件集中，枪械配件箱出没 | 房间小，进门即是必争点 | 一次只清一个房间，别串联推进 |
| **外侧装卸区** | 相对开阔，**部分撤离点所在** | 进出主楼的咽喉，最后一段路最危险 | 撤离线要**提前想好**，别在这儿现找路 |

> **一句总纲**：**工厂没有“安静的地方”。** 任何区域的枪声全图都听得见，所以“打完就换位”在这里比在任何图都重要。

---

## 💡 核心打法流派

1. **Rush 流**：工厂的节奏不允许“苟”。落地 → 拿近战枪 → 直接压人。
2. **听声辨位流**：脚步声在这里就是雷达。铁结构楼梯的声音辨识度极高。
3. **Boss 蹲守流**：Tagilla 会在固定区域巡逻，掉落焊工面罩与大锤，是收藏与任务目标。

**补充一条被低估的**：

4. **撤离点守株流**：工厂局短，**大部分人的撤离时间是可预期的**。熟悉装卸区的撤离窗口，能让你用最少的移动换最多的遭遇——**这是独狼在工厂最稳的收益方式**。

## 🎯 Boss：Tagilla

<a id="boss"></a>

| 项目 | 内容 |
|------|------|
| **武器** | **大锤（近战）**——近距离一锤致命；另有投掷燃烧瓶 |
| **行为特征** | 主动性极强，**会直接冲脸**；戴焊工面罩，正面防护好 |
| **威胁点** | 在走廊里遭遇＝必死；**锤子敲击铁管的声音是他的定位广播** |
| **应对核心** | **保持距离用枪解决**，绝不在走廊里和他拼刺刀 |
| **收益** | 焊工面罩、大锤，以及任务相关目标 |

> **一条声音线索**：**听见锤子敲铁管的声音——跑，不是绕，是跑。** 那个声音说明他已经在你附近，而且正在往你这边来。

## 🧭 战利品与任务

<a id="loot"></a>

| 项目 | 内容 |
|------|------|
| **价值档次** | **中低单价、高密度**——单件不值钱，但量大 |
| **主要产出** | 工具与配件类、办公小件；**枪械配件箱**是这里的特色 |
| **任务** | 早期任务的常见舞台，多条商人任务有工厂环节 |
| **Scav 价值** | ⭐ **全游戏单位时间收益最高的 Scav 图之一**（局短、周转快） |
| **推荐姿态** | **快进快出**：搜刮路线要短，别追求搜满 |

**一条纪律**：**抽屉与工具箱的密度大，适合练“搜刮效率”这项基本功**——但工厂不是赚钱的地方，是**练手与刷周转**的地方（见[搜刮效率与战利品取舍](looting.md)）。

## 🧭 实战要点

1. **带短枪，不带长枪**：距离在 20 米内，**举枪速度 > 穿深**。
2. **落地就进入状态**：工厂没有“开局缓冲期”，**前 60 秒是死亡率最高的时段**。
3. **进门先看头顶**：铁架二层是天降正义高发区。
4. **走廊能绕就绕**：工厂的走廊是死亡走廊，绕路的成本远低于对枪。
5. **打完立刻换位**：全图可闻的枪声意味着“你打完的那一刻，别人已经知道你在哪”。
6. **Scav 来这里刷周转**：单局收益不高，但**十几分钟一轮**，单位时间收益很稳。
7. **撤离路线提前定**：装卸区是咽喉，别到最后一分钟才开始找路。

---

## ⚠️ 常见错误

- **带狙击枪进工厂**：视野最远不过几十米，长枪管是累赘。
- **在走廊对枪**：工厂走廊是死亡走廊，能绕就绕。
- **忽视头顶**：铁架二层是“天降正义”高发区，进门先看上面。
- **为“搜满”而恋战**：这是一张短图，**收益靠周转不靠单局**。
- **以为装备能压死人**：贴脸距离上，**先举枪的人赢，不是配置好的人赢**。
- **在 Tagilla 附近开火试探**：你一试探，他就冲过来了。
