# 迷宫 (The Labyrinth)

<a id="top"></a>

> “它不在选图列表里。你得先知道它存在，再找到钥匙。”
> —— 关于塔科夫最深的那扇门

| 项目 | 信息 |

| **进入方式** | 从海岸线**转场**进入，需 **Labrys 门禁卡**；进入设施还需 **Knossos LLC 设施钥匙** |

## 💡 核心机制

### 1. 怎么进去

迷宫不是“选一张图”就能进的地方，它是一段**任务 → 钥匙 → 转场**的链条：

1. 完成 Mechanic 的三环任务线（找车、找日记、跑六个点位），解锁“隐藏层”；
2. 在**海岸线疗养院**设法取得 **Knossos LLC 设施钥匙**，进入疗养院地下的厂房；
3. 携带 **Labrys 门禁卡**，从地下室转场进入迷宫。

**三样东西缺一样，链条就断。** 这也是为什么绝大多数玩家在相当长时间里只知道“有这么个地方”。

### 2. 五个出生间，五道题

迷宫把“开局”设计成一道**解谜**：每个出生间都堵着一道环境危害，不解决就出不去——

| 危害 | 形态 |
|------|------|
| 毒池 | 涉水区域持续掉血，需绕行或吃药硬穿 |
| 蒸汽 | 高温区，靠位置与节奏 |
| 火焰 | 定时喷发 |
| 霰弹陷阱 | 触发式，方向固定 |
| 毒水洼 | 小范围高伤 |

### 3. 陷阱是常驻变量

| 陷阱 | 规则 |
|------|------|
| **绊线** | 由 Toggle 之影布设，进局后约 **10 分钟自动解除**——所以“等一等再走”是有实战意义的 |
| **毒化铁丝网** | 随机位置出现，会造成**持续中毒伤害** |
| **陷坑** | **永久存在，但每一局随机开合**——同一段路，上一局能走，这一局是洞 |
| **中央警报** | 迷宫中心附近会响警报，必须在**散布各处的按钮上手动关闭** |

> **结论**：迷宫不考记忆，考**当场的判断**。这也是它和其他地图最大的区别——**几乎没有“背地图”能解决的成分**。

### 4. Toggle 之影

Boss **Toggle 之影**是 Tagilla 的变体，在本图**必定刷新**：

- **血量极高**，硬吃爆炸物、无视部分陷阱——**赌爆发不如比消耗**；
- **位置不固定**，他会在整张图游荡，最终你得在狭窄的实验室空间里跟他打一场**耐久战**；
- 部分资料记载，他倒下之后还会引出**“复仇的 Killa”**作为第二场对战——**把它当成两场仗，而不是收尾**。

### 5. 两条撤离路线

| 撤离点 | 条件 |
|--------|------|
| **阿里阿德涅之路** | 位于内层地下西南侧、靠蒸汽危害出生点附近，需**阿里阿德涅记号钥匙** |
| **上升通道** | 位于地图中东部、朝霰弹陷阱出生点方向的通道，**战局开始 15 分钟后**才开启，届时会有一声开门音效 |

⚠️ 迷宫**没有向外转场的出口**——进来只有一条路，出去只有这两条。

### 6. 保险在这里是废纸

和[破冰船](icebreaker.md)、[终点站](terminal.md) 一样的规则：**保险不生效**，即使超过常规返还时限，投保物品也不会寄回。进来之前请把“全损”写进预算。

## 🗺️ 区域结构

<a id="areas"></a>

迷宫的结构是**“内层 + 外层 + 五个出生间”**的复合体。理解它的关键在于：**它不像其他地图那样可以自由绕圈，而是被出生间和陷阱切成了若干段**。

| 结构 | 特征 | 该注意什么 |
|------|------|------------|
| **五个出生间（外围）** | 每间堵着一道**必须破解的环境危害**（毒池 / 蒸汽 / 火焰 / 霰弹 / 毒水洼） | ⚠️ **出生即是第一道考验**——解决方式在进入前就该想好 |
| **内层地下** | 空间狭窄、房间密集，**Toggle 之影最终在这里交战** | 狭窄空间里**续航比爆发重要**（见[交火中的技术动作](firefight.md)） |
| **迷宫中心区** | 会响**中央警报**，需手动关闭散布各处的按钮 | **不关警报＝持续暴露位置** |
| **中层通道** | 连接各层的通路，**陷坑随机开合** | **别跑**——跑就是赌命 |
| **两条出口** | 阿里阿德涅之路（需钥匙） / 上升通道（15 分钟后开启） | 进来前确认钥匙，否则**两条可能都走不了** |

**一条结构性结论**：**迷宫的“路线”不是固定的**——因为陷坑每局随机、Boss 游走、警报位置分散，所以**你不能像在海关那样背路线图**，只能现场判断。

## 🧭 实战要点

1. **先去认路，再去打 Boss**：第一次进图的目标应该是“活着出来”，不是“打赢他”。
2. **解出生间的题目别硬扛**：毒池与蒸汽能用药硬穿，但成本要自己算。
3. **记住 10 分钟这个数**：绊线会自动解除，赶路和等路是有取舍的。
4. **别在陷坑区跑**：随机开合的坑，跑就是赌命。
5. **警报要关**：不关就是持续暴露位置。
6. **按两场仗准备弹药**：Boss 血厚、空间小，续航比爆发重要。
7. **确认两条出口的条件**：一条要钥匙、一条要等 15 分钟——**出发前想清楚走哪条**。
8. **把它当“考试”而不是“农场”**：这里考的是当场判断，不是肌肉记忆。

## ⚠️ 常见错误

- **带唯一一套家当进图**：这里没有保险，输了就是真输了。
- **把迷宫当收益图刷**：陷阱 + 必刷 Boss + 无法转场，风险收益比不适合“稳定刷钱”。
- **忘了拿阿里阿德涅钥匙**：到头来发现两条出口一条开不了。
- **盲目 rush**：在随机陷阱的环境里，速度是最贵的资源。
- **以为信息透明**：迷宫至今没有完全公开的权威全图，别指望“抄作业”。
- **只准备一场 Boss 战**：Toggle 之影之后可能还有第二场。
