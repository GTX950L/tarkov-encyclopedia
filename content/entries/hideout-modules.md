## 💡 核心机制

### 1. 模块按“产出类型”分四层

| 层 | 模块 | 性质 |
|----|------|------|
| **地基层** | 生成器、太阳能 | 供给能源，其他一切的前提 |
| **生存层** | 水收集器、营养单元、医疗站、卫生间 | 产水/食物/医疗，**把日常消耗变成自产** |
| **生产层** | 工作台、情报中心、空气过滤单元 | 制造弹药与物资、加速全局产出 |
| **收益层** | 比特币矿场、私酒厂、Scav 包裹（Scav Case）、十字路口（供奉） | 把材料变成钱 |
| **成长层** | 健身房、射击场、图书馆、名人堂 | 练技能、加属性（见[技能系统](skills.md)） |

### 2. 主要模块功能表

| 模块 | 主要作用 | 备注 |
|------|----------|------|
| **生成器** | 提供全藏身处电力 | 消耗燃料，**忘补燃料等于全线停产** |
| **太阳能** | 降低燃料消耗 | 后期项目，按燃料支出回本 |
| **水收集器** | 产净水 | 净水既是消耗品也是硬通货 |
| **营养单元** | 产食物 | 覆盖非 raid 时间的饮食消耗 |
| **医疗站** | 制造医疗品、加速离线恢复 | 与药品消耗直接挂钩 |
| **卫生间** | 产织物与清洁材料 | 部分产出是工作台的输入 |
| **工作台** | 制造弹药、武器零件、改装件 | **长期玩家的弹药主来源** |
| **情报中心** | 产情报类物品、缩短 Scav 冷却、解锁任务 | 2 级需要**专注（Attention）技能 3 级** |
| **空气过滤单元** | 提升各模块产出速度 | 属于“乘数型”投入 |
| **比特币矿场** | 用显卡产出比特币 | 投入大、回本慢，偏后期 |
| **私酒厂** | 产出私酒用于出售 | 与酒类材料价格强相关 |
| **Scav 包裹** | 定期开出随机物品 | 零成本收益，运气成分大 |
| **十字路口 / 供奉** | 以材料换取指定类物品 | 用于定向获取难买物资 |
| **健身房 / 射击场** | 离线训练体能类 / 战斗类技能 | 把不在图里的时间变成成长 |
| **图书馆** | 加速技能成长 | 与健身房、射击场形成组合 |
| **名人堂** | 陈列战绩并提供战斗属性加成 | 0.14 加入 |

| 模块 | 等级 | 标志性数值 | 来源 |
|------|------|-----------|------|

| **照明** | **3 级** | 蜡烛 → 基础照明 → 荧光灯；建造耗时 即时 / 即时 / 6 小时 | 一级（官方 Wiki） |
| **空气过滤单元** | **单级**（1 级） | **生理类技能组升级速度 +40%**；运行需持续消耗 **FP-100 过滤吸收器** | 一级（官方 Wiki） |

| **易碎墙** | **5 级** | 4 级时：燃料消耗 **−8%**、能量 **+4.8 EP/小时**、**生命回复 +35.6 HP/小时**、额外战局经验 **+5%**、生理技能组 **+5%**。**没做清洁时会反过来扣**：燃料 +5%、能量 −3、**生命 −22.8 HP/小时**、经验 −3%、生理 −3% | 一级（官方 Wiki） |

### 4. 优先级推荐（按角色档案分）

| 顺序 | 持久档案（PvP / PvE） | 赛季档案 |
|------|------------------------|----------|
| 1 | 生成器 → 水收集器 → 医疗站 | 生成器 → 水收集器 |
| 2 | Scav 包裹 → 卫生间 → 营养单元 | 医疗站 → Scav 包裹 |
| 3 | 工作台 → 情报中心（1 级） | 工作台（1 级） |
| 4 | 空气过滤单元 → 比特币矿场 | 情报中心（缩短 Scav 冷却） |
| 5 | 健身房 / 射击场 / 图书馆 / 名人堂 | —（赛季重置，收益回不来） |

**判断依据很简单**：**赛季角色的所有投入会随赛季结束清零**，所以赛季只建“能立刻回本”的模块；持久档案才值得往高阶模块砸资源（见[赛季与修改器](seasons.md)）。

### 5. 1.1 对前期建造的减负

1.1.0.0 明确放宽了前期藏身处的门槛，方向有三个：

1. **初期模块建造时间缩短**；
2. **模块之间的依赖条件减少**（不再“必须先升 A 才能碰 B”）；
3. **对“战局内发现”材料的要求降低**——这条对新手影响最大，过去为了几个 FiR 材料反复跑同一条路线的情况明显减少。

> 效果：藏身处的“启动成本”下降，但**高等级模块的资源门槛依然存在**——减负集中在前期，不涉及后期产出。

### 6. 藏身处的经济角色

- **它是“时间的复利”**：收益按现实时间累积，适合游戏时间碎片化的玩家；
- **它产出的是“可交易物资”**：净水、弹药、医疗品都能进入[跳蚤市场](flea-market.md)，因此藏身处产能就是市场供给的一部分；
- **它决定你的成本结构**：自产弹药的人，与完全靠买的人，在赛季中期的装备循环成本完全不同。

## 🧭 实战要点

1. **先算燃料**：开工前确认燃料补给线，否则产出断在半夜。
2. **按“消耗最多”的顺序建**：你花钱最多的那一项，优先自产。
3. **工作台是收益率最高的投资之一**：把便宜材料变成贵弹药。
4. **情报中心优先升 1 级**：缩短 Scav 冷却，等于增加资源产出频率。
5. **别用跳蚤补所有材料**：能搜到的先搜，跳蚤只买瓶颈件。
6. **赛季角色按“够用”建设**：赛季结束什么都不留，别把家底搬进去。

---

## ⚠️ 常见错误

- **先建好看的不建有用的**：射击场很爽，水与医疗才是刚需。
- **断电还以为是 bug**：生成器停了，所有产线一起停。
- **忽略技能门槛**：情报中心 2 级、水收集器 2 级都有技能前置（专注类）。
- **把比特币矿场当第一目标**：显卡成本高、回本周期长。
- **对赛季角色做长期投资**：赛季重置，投入收不回。
