# 跳蚤定价与手续费 (Flea Pricing & Fees)

<a id="top"></a>

> “跳蚤不禁止你标天价，它只是按天价收税。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 市场机制 + 数值速算 |
| **费用性质** | **上架即扣**，无论卖不卖得掉 |
| **定价基准** | 物品的**底价（Base Price）**，由商人体系给定 |
| **基础费率** | 1.1 起由 3% **上调至 5%** |
| **可减免项** | 情报中心等级（最高约 −30%）、藏身处管理技能（叠加至约 −45%） |
| **信誉与槽位** | 起始信誉决定同时上架数量，成交涨、流拍跌 |
| **准入限制** | 需达到解锁条件；**只有带“战局内发现（FiR）”的物品可上架** |

---

## 💡 核心机制

### 1. 手续费是“可预测的惩罚”，不是随机数

很多人把手续费当成黑箱，其实它是一条确定公式——**你的标价离底价越远，费率上升越猛烈**。

通行的计算结构（社区维基整理）：

```
手续费 = VO x Ti x 4^PO x Q  +  VR x Tr x 4^PR x Q
```

| 符号 | 含义 |
|------|------|
| **VO** | 报价总价值 ≈ 底价 × 数量 / Q |
| **VR** | 需求物总价值（以物易物时适用），纯卢布挂单时取底价口径 |
| **PO / PR** | 由 VO 与 VR 的对数比构成；两者比较后其中一方会被额外乘方放大 |
| **Q** | 数量因子：勾选“对报价中所有物品统一要求”时为 1，否则等于物品数 |
| **Ti / Tr** | 费率常数，基准值为 **0.03**（1.1 起整体上调至约 0.05） |

不需要背公式，只要记住结论：

> **标价接近底价 → 费率很低；标价远高于底价 → 费率呈指数级上升。**

### 2. 底价从哪来：商人回购价 ÷ 加成系数

底价是系统给每件物品预设的值，玩家侧可以用一条近似关系反推：

```
底价 ≈ 商人回购价 ÷ 该商人的收购加成系数
```

| 商人 | 加成系数 |
|------|----------|
| 军备官（Prapor） | 0.50 |
| 治疗师（Therapist） | 0.63 |
| 黑市（Fence） | 0.40 |
| 走私客（Skier） | 0.49 |
| UN 维和军官（Peacekeeper） | 0.45 |
| 技师（Mechanic） | 0.56 |
| 旧衣商（Ragman） | 0.62 |
| 猎人（Jaeger） | 0.60 |
| 竞技场裁判（Ref） | 0.50 |

**操作启示**：想知道一件东西的底价，右键查看它在各商人处的回购价，挑最高的那个回推即可获得最近似值。

> 注意：**物品的剩余耐久与使用次数会压低回购价**，用旧装备反推会得到偏低的底价。要测底价请用全新品。

### 3. 减免路径：情报中心 + 藏身处管理

| 减免来源 | 幅度 |
|----------|------|
| **情报中心（Intelligence Center）等级 3** | 免除手续费总额约 **30%** |
| **藏身处管理（Hideout Management）技能** | 每级额外减免约 **0.3%**，技能满级时总减免可达约 **45%** |

这是塔科夫里少见的“纯省钱型”藏身处投资——**如果你长期以跳蚤为主要出货渠道，情报中心的回报周期比多数模块都短**。

### 4. 信誉与上架槽位

| 项目 | 规则 |
|------|------|
| **起始信誉** | 约 0.20 |
| **上涨** | 每成功售出约 50,000₽ 的交易额 +0.01 |
| **下跌** | 报价流拍或超时会掉信誉 |
| **作用** | 信誉决定**同时可挂单数量**（起始约 2 个，随信誉增加） |

所以“挂得多”不是免费的：槽位少的时候，每一个槽位都是机会成本；而流拍既浪费时间也伤信誉。

### 5. 资金结算与领取期限

成交后的货款通过**游戏内邮件（由 Ragman 渠道发放）**送到你手上，有领取期限：

- 常规版本：**7 天**；
- 高级版本（The Unheard）：延长至 **14 天**。

过期未领即作废——这是新手最常见的“凭空的损失”。

### 6. FiR 与“卖不掉的战利品”

只有带**战局内发现**状态的物品可以上架跳蚤。这意味着：**从别人尸体上扒下来的装备，通常无法直接卖到跳蚤**，只能卖给商人（价格更低）。

这条规则同时决定了三件事的优先级：

1. 自己捡的、自己造的、任务奖励的 → 可以走跳蚤；
2. 从 PMC 尸体上扒的 → 只能走商人或自己用；
3. **保险寄回的装备会失去 FiR**，因此“投保 → 死了寄回 → 卖掉回血”这条链条在跳蚤层面并不成立。

### 7. 定价的实用算法

抛开公式，实战只有三步：

1. **先看当前最低报价**（右键 → 筛选物品），确认市场价格；
2. **再填一个略低于最低价的数字**，并当场读手续费；
3. **如果手续费离谱**，说明你的标价已经远离底价——降回来，或者干脆卖商人。

一个更省事的判断：**当手续费接近甚至超过预期利润时，这笔挂单不值得挂**。

---

## 🧭 实战要点

1. **上架前一定看手续费**，不要凭感觉定价。
2. **标价贴着市场最低价走**，把费率控制在低位。
3. **优先投资情报中心**，这是最直接的增益型藏身处模块。
4. **合并同类批量上架**，减少槽位与操作次数。
5. **及时领取邮件**，7 天过期不候。
6. **分清 FiR 与非 FiR**：扒来的装备别指望跳蚤。
7. **低价值杂货直接卖商人**，省下的时间比差价值钱。

---

## ⚠️ 常见错误

- **给垃圾标天价**：手续费按上架即扣，流拍是纯亏。
- **用旧装备反推底价**：耐久与使用次数会污染结果。
- **忽略 FiR 限制**：从尸体上扒的东西挂不上去。
- **忘记领邮件**：过期即作废，且没有补救。
- **只盯售价不算税**：到手价才是真收益。
- **频繁取消挂单**：会掉信誉，槽位跟着减少。
