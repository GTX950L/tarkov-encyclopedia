## 💡 核心机制

### 1. 它是“开局任务最集中”的图，因此人流也最密

海关承担了**最多条早期商人任务线**（Prapor / Therapist / Skier 的成长线都从这里起步）。这条事实有一个不那么直观的后果：

> **任务点扎堆 ⇒ 玩家扎堆 ⇒ 同一个房间可能同时有三拨人在做不同的事。**

所以在海关，**你要防的不只是“敌人”，还有“同样在做任务的同行”**——他们没有理由放过你，因为你的出现本身就是一次免费的装备补给。

**推论**：海关的**任务点＝交火点**。做任务前先想“这里现在会不会有人”，而不是“这里有没有任务”。

### 2. 三种地形，三种规则

海关是全游戏**地形过渡最典型**的一张图：

| 地形 | 代表区域 | 主导的打法 |
|------|----------|------------|
| **室内 CQB** | 大红砖宿舍、老煤气站 | 听声、贴墙、清房间（见[交火中的技术动作](firefight.md)） |
| **工业/半开阔** | 加油站、检查站、仓库区 | 掩体切换与交叉火力 |
| **纯开阔** | 马路、铁路、河岸 | ⚠️ **这里没有战术，只有运气**——沿掩体走，别横穿 |

**新手最常犯的错**：把这三段当成同一种地形来走。

### 3. 保险生效，所以“敢带”是这里的优势

海关保险正常生效。这意味着**队友（或你自己下一局）有机会把装备捞回来**——所以海关是**最适合练“带正常装备打”的图**。前期别因为怕死而只带手枪：在入门图练出“带得起也输得起”的心态，比省几件装备重要（见[保险机制](insurance.md)）。

### 4. 1.2.0.0（2026-10-06）的改动：撤离点、上锁容器与两把新钥匙

这一版对海关的改动集中在**收益密度与撤离选择**上：

**① 撤离点调整**——官方写明「**调整了 PMC 与 Scav 的撤离点：新增了出口**」。

> **含义**：海关的撤离路线选择变多了，**“只能从卡车出口走”的旧路线规划需要重画**。走之前先确认当前可用的几个出口（见[撤离点详解](extraction-points.md)）。

**② 上锁容器现在保证出货**——**多处区域的上锁容器必定含有战利品**。

| 变化 | 含义 |
|------|------|
| **旧**：上锁柜可能空 | **新：上锁容器必定有东西** |
| **对策** | 宿舍区的钥匙房与上锁柜**从“顺手看看”升级为“值得专门跑一趟”** |

**③ 新增战利品点位**——**上锁的宿舍房间**、**USEC 仓库**等区域增加了新的战利品位置。

**④ 两把新钥匙**：

| 钥匙 | 说明 |
|------|------|
| **ZB-1013 Key** | **1.2.0.0 新增** |
| **Guard Post Key**（岗哨钥匙） | **1.2.0.0 新增** |

> 两把钥匙的**具体用途点位以游戏内为准**——官方补丁说明只公布了钥匙名称，没有逐个标注对应房间。列入[钥匙与钥匙房](keys.md) 的新增清单，见该页说明。

**⑤ 同期修复（会改变你的既有做法）**：

- **信号枪撤离点**：狙击手**不再沿墙移动时开火**——这个老版本的触发式挨打点**已经不存在**；
- **公司董事办公室的保险箱**此前**无法开启**，现在**可以打开了**；
- **锅炉房地窖（Co-op）撤离点**：现在**无论你从图的哪个区域出生都可用**——此前存在出生点位置限制；
- 若干**原本被「工厂紧急出口钥匙」锁住的门**已修正。

## 🗺️ 区域结构

<a id="areas"></a>

| 区域 | 特征 | 主要风险 | 该注意什么 |
|------|------|----------|------------|
| **大红砖（宿舍区）** | 早期任务与**钥匙房**集中，抽屉与电脑密集 | **新手死亡最高发的区域**；楼道与房间门口是固定伏击位 | 进楼前先听；**一次清一层**，别跳层推进 |
| **加油站** | 地势枢纽，连接城区与工业区的必经之路 | 四面八方都可能来枪 | 通过时**别在油枪区停留**——那是无掩体的开阔点 |
| **老煤气站 / 工厂区** | 大型厂房，任务目标常驻 | 室内 CQB 交火、多层视野 | 进厂房走侧门，别从正门正对长走廊 |
| **军事检查站** | 靠近**边界狙击手**的边界区 | **边界狙击手是隐形且杀不死的**，属于人工边界 | 见到警告标志立刻离开边界带（见[彩蛋与制作组的恶意](easter-eggs.md)） |
| **马路 / 铁路 / 河岸** | 纯开阔，贯穿全图 | **“免费靶场”**——远距离视野无遮挡 | 沿掩体分段移动；宁绕 20 秒，不横穿 5 秒 |
| **卡车出口等撤离点** | 部分撤离点**需要付费** | 到了才发现没带钱 | **出发前确认撤离条件**（见[撤离点详解](extraction-points.md)） |

## 💡 核心打法流派

1. **任务速通流**：海关是**开局任务最集中**的图，跟着任务走就是最优搜刮路线。
2. **宿舍抽屉流**：低配装备进门，靠钥匙房与抽屉淘金——新手经济的第一桶金。
3. **Boss 猎人流**：Reshala 的保镖队伍是穿甲弹与团队配合的试金石。

**再补两条实战里常见的**：

4. **边缘推进流**：沿地图外圈移动，只在任务点深入——**避开主干道的人流**，适合独狼。
5. **宿舍守株流**：热门区域的守方收益稳定，但要注意**守株的人也会被守**——同一个位置待久了，你也会被清。

## 🎯 Boss：Reshala

<a id="boss"></a>

| 项目 | 内容 |
|------|------|
| **位置** | 出没于**宿舍区附近**（含加油站一带） |
| **护卫** | **4 名装备精良的保镖**，火力与防护都强 |
| **威胁点** | 护卫比 Boss 更致命——**他们是真正的火力来源** |
| **应对顺序** | ⚠️ **先杀保镖，再杀 Boss**；顺序反了等于给他站岗 |
| **装备要求** | 护卫护甲等级高，**穿深不足的弹打上去只是提醒他你在哪**（见[弹药选型速查表](ammo-table.md)） |
| **收益** | 任务所需物品与稀有装饰 |

## 🧭 战利品与任务

<a id="loot"></a>

| 项目 | 内容 |
|------|------|
| **价值档次** | **中低为主，钥匙房有惊喜** |
| **主要产出** | 宿舍区的抽屉与电脑、钥匙房高价值物、工业区工具类 |
| **任务密度** | **开局任务最集中**——Prapor / Therapist / Skier 的早期线都从这里起步，**等级 ≤15 的任务有 21 条落在这里，为全图之首**。⚠️ 但**单图任务总数最多的是[街区](streets.md)（47 条）**，别把“开局最集中”听成“总量第一” |
| **推荐姿态** | **任务优先，顺路搜刮**；宿舍区是唯一值得专程去搜的地方 |

**一条效率纪律**：**海关的任务按“区域”分批做**——同一片宿舍区的任务一次做完，比来回穿越开阔地安全得多。

## 🧭 实战要点

1. **出发前确认撤离条件**：卡车出口一类要付费，**没带钱等于白走**。
2. **马路不是路**：横穿开阔地是海关的头号死因，沿掩体分段走。
3. **任务点＝交火点**：进任务房前先听三秒，别把门当入口，当“别人的视野缺口”。
4. **宿舍区一次清一层**：楼道与房间门口是固定伏击位。
5. **打 Reshala 先打保镖**：护卫才是火力来源，顺序错了就是站岗。
6. **别只蹲宿舍**：热门区域蹲守密度极高，学会从侧翼进入。
7. **保险生效，就敢带**：这是最适合练“正常装备打法”的图，别一直带手枪。
8. **走外圈的人更安全**：主干道是最多人走的路线，也是最容易遭遇的路线。
9. **上锁容器现在值得专门跑一趟**：1.2.0.0 起**多处上锁容器保证出货**，宿舍区钥匙房的收益层级上移了。
10. **别再沿用旧的撤离路线**：1.2.0.0 **新增了出口**，同时**锅炉房地窖撤离不再受出生点位置限制**——出发前重新确认可用出口。

## ⚠️ 常见错误

- **在开阔地直线跑图**：海关的马路和铁路是“免费靶场”，沿掩体走。
- **只守宿舍**：热门区域蹲守密度极高，学会从侧翼进入。
- **忽视撤离点条件**：车辆撤离需要付费，到了才发现没带钱——撤离点条件要提前确认。
- **低估护卫**：Reshala 的四人组里，**威胁最大的是护卫不是 Boss**。
- **把三段地形当一段走**：室内、工业、开阔，规则完全不同。
- **开车站油枪区停留**：那是全图最典型的无掩体开阔点。
