# 交火中的技术动作 (Firefight Technique)

<a id="top"></a>

> “交火的目标不是打死他，是让他打不到你。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 决定要打**之后**的操作（不是“要不要打”） |
| **核心问题** | **怎么在不中弹的前提下，把枪口对准他** |
| **三个变量** | **暴露面积** × **暴露时间** × **信息差**——只有前两个由你控制 |
| **最大误区** | 把“探头对枪”当成默认动作 |
| **最容易忽略的一张牌** | **副武器**——主武器卡壳或打空时的第二条命 |
| **配套条目** | [遇敌处置与接战决策](contact-drill.md) 讲**开火之前怎么决定**；[姿态、移动与射击](movement.md) 讲**姿态与移速的机制**；本篇讲**打起来之后手上怎么做** |

## 💡 核心机制

### 1. 一次交火由三个变量决定

<a id="three"></a>

| 变量 | 是什么 | 你能不能控制 |
|------|--------|--------------|
| **暴露面积** | 你身体露出掩体的部分有多大 | ✅ 姿态、侧身、蹲高都能改 |
| **暴露时间** | 你在对方视野里停留多久 | ✅ 靠“露—打—退”的节奏控制 |
| **信息差** | 谁先看到谁、谁更清楚对方在哪 | ⚠️ 只有在开火之前能争取 |

**三个变量里，枪法与装备一个都不占**——它们决定你的**上限**，而这三个变量决定你的**下限**。

> **一条推论**：既然暴露面积与暴露时间是你能控制的，那么**“打了没中”不等于失败**——只要你能退回去、换一个角度再来，你就还在用可控变量打这场仗。**最贵的行为是站在原地不动地重复同一个动作。**

### 2. 探头：四条纪律

<a id="peek"></a>

“探头”是交火里最高频的动作，也是新手最容易做错的动作——**错的地方不是探得准不准，而是探了几次、从哪儿探**。

| # | 纪律 | 为什么 |
|---|------|--------|
| **①** | **先预瞄，再露身** | 准心要在**你露身之前**就对准他会出现的位置。露出来再找目标，等于把“寻找”的时间也送给了对方 |
| **②** | **不要重复从同一处探头** | 对方（无论是真人还是 AI）会**盯着你最后出现的位置**。第二次从同一个角度出去，你是在走进他的准心 |
| **③** | **换角度，不是换姿势** | “退回原位再探一次”和“不动”差不多。有效的是**换一个能打到他的新角度**——平移几米、换一扇窗、上一层楼 |
| **④** | **打两三发就退** | 连射的收益递减、暴露时间线性增加。**短促点射 → 退回 → 判断 → 换位**，这才是可持续的节奏 |

**配合机制用**：侧身（Q / E）把暴露面积压到最小，**C + 滚轮**可以连续调节蹲高——**只露眼睛就够看到人**。慢速侧身（Alt + Q / E）会让你停在侧身姿态里，适合长时间架着同一个角度（见[姿态、移动与射击](movement.md)）。

> **但侧身有代价**：侧身状态下你的**射界与转向都变窄**。如果对方在横移，你可能会“露着头却打不到他”——所以侧身适合**架固定角度**，不适合**追移动目标**。

### 3. 掩体分三级——这是本篇最该背下来的一张表

<a id="cover"></a>

<a id="cover-tiers"></a>

社区与军事术语里有一对必须分清的词：**Cover（掩体）= 能挡子弹**、**Concealment（遮蔽）= 只挡视线**。塔科夫里两者待遇完全不同：

| 级别 | 例子 | 能做什么 | 不能做什么 |
|------|------|----------|------------|
| **硬掩体（Cover）** | 混凝土墙、建筑转角、集装箱、发动机、大石 | **可以在这里换弹、打药、等他**——这里是他打不到你的地方 | 别忘了**换角度**，他可能正在绕你 |
| **半身掩体** | 矮墙、木箱、车头、窗台 | **蹲着打**：你只露出头部与枪口；**站起来就完全暴露** | 不要在这里换弹（你会被迫长时间停在一个可预测的高度上） |
| **遮蔽物（Concealment）** | 灌木、草丛、烟、门帘 | **只用来“消失”**——断掉视线、脱离接触 | ❌ **绝不能用来对枪**。它不挡子弹，一旦对方锁定你的位置，它会直接出卖你 |

**三条容易踩的细节**：

1. **材质决定它算不算掩体**。木质、薄铁皮挡不住高穿深弹药——**“能挡住视线”和“能挡住子弹”是两件事**（见[弹道与穿透机制](ballistics.md)）。判断不了的时候，按“遮蔽物”对待；
2. **高度决定你能不能蹲着打**。半身掩体站着打等于没有掩体；全高掩体才是能换弹的地方；
3. **遮蔽物的正确用法是单向的**：你在灌木后能看到他（或听到他），他看不到你——这是**脱离**与**设伏**的窗口，不是开火的窗口。

### 4. 换弹：这是“你的枪不能用”的窗口

<a id="reload"></a>

换弹不是小事——它是交火里**最容易被抓住的固定窗口**（社区共识：听到对手换弹，就是一个明确的进攻时机）。所以关键不是“换得多快”，而是**在哪换、什么时候换**。

**先弄清两种换弹**（键位以游戏内设置为准，见[操作与设置](../docs/game-settings.md)）：

| 方式 | 操作 | 特点 |
|------|------|------|
| **普通换弹** | 按 **R** | **保留**换下的弹匣（放回背心 / 口袋）。**背心没空间时会丢掉**——这一点很容易被忽略 |
| **快速换弹** | **双击 R** | **把弹匣丢在地上**，换得更快（社区口径约快 **0.5 秒**）。紧急情况下用，**记得事后捡** |
| **选择弹匣** | 按住 R + 滚轮 | 指定换哪一个——专门给“不同弹种混装”的场景 |
| **瞄具内换弹** | **武器掌握 L3 解锁** | 不用放下枪就能换——**这是唯一能显著缩短暴露时间的换弹方式**（见[武器掌握](weapon-mastery.md)） |

> **一个硬约束**：**弹匣必须放在背心或口袋里才能换**——背包里的弹匣按 R 是换不上来的。所以出发前把备用弹匣放进背心，不是整理强迫症，是**交火中能不能续火的区别**。

**什么时候换——四条时机**：

| 时机 | 说明 |
|------|------|
| **确认击杀之后立刻换** | 交火往往不止一个对手。**在你还“以为没事”的那几秒把弹补满** |
| **交火间歇 / 退到硬掩体后** | 这是标准换弹窗口：**先退到打不到你的地方，再换** |
| **推进之前** | 要进一个新区域、或者要主动压上去——**先把弹补满**，不要带着半匣进去 |
| **听到对手在换弹** | 这是**你的**窗口，不是他的——见[听声辨位与音频机制](audio.md) 的「声音线索」 |

**一条固定纪律**：**永远不要在暴露位置、在对方还能看到你的时候换弹。**宁可先退两步、退回硬掩体后再换——**换弹的时间是固定的，但“在哪儿换”是你选的。**

### 5. 副武器：最容易被忽略的一张牌

<a id="sidearm"></a>

主武器**卡壳、打空、或者耐久失效**的时候，你手里其实还剩一张牌——**副武器**。

站内[武器故障与耐久维护](weapon-maintenance.md) 记着一条很硬的机制：**主武器故障时，若带着已上膛的副武器，切换会获得约 5 秒的加速**。也就是说，游戏本身就在奖励“**带一把能立刻用的备枪**”这件事。

**判断要不要带副武器的两条账**：

- **带**：占格子、占重量（见[耐力与移速](stamina.md)），但换来一次“**卡壳之后不至于空手站着**”；
- **不带**：省格子，但把“主武器出问题”直接变成“这一局结束”。

**一条实用建议**：与其带一把完整的大枪当副武器，**不如带一把轻便的短枪或手枪，并且保证它是上膛的**——副武器的价值不在威力，在**“它立刻能响”**。

### 6. 进房间：开门、破窗、翻越的代价

<a id="entry"></a>

进入一个空间的方式，决定了**你在进门那几秒有多脆弱**。三种方式各有各的账单：

| 方式 | 音量 | 关键风险 | 该怎么做 |
|------|------|----------|----------|
| **开门** | 中（门轴与把手） | **门是双向的**——它既是你的临时掩体，也是给里面的人的一个提前预警 | **贴着门框**开门，不要站在门的正面；开完门先别进，**听一秒** |
| **破窗 / 翻窗** | 大（玻璃碎裂） | 碎玻璃声很远都听得见，而且**翻越动作期间你无法还击** | 只在**没有其他入口、或已经确认室内无威胁**时用；翻之前先看清落点有没有敌人 |
| **翻越（矮墙 / 栏杆）** | 中 | 同上——**动作期间不能开枪**，落地的位置也是可被预瞄的位置 | 翻越前先在心里确认“**翻过去之后我落在哪、身后有没有人**” |

**进门的固定顺序**（比“冲进去”慢半秒，但活得久得多）：

1. **贴边不贴正面**：站在门框侧面，而不是门的正前方；
2. **先看远角，再看近角**：人的注意力天然被深处吸引，而**近处的角落才是最容易藏人的地方**；
3. **进门后不要横穿门口**，沿着墙走，让门框始终在你和可能的来向之间；
4. **清完一个房间再进下一个**——不要一边进一边回头看走廊。

### 7. 打死一个之后：追不追

<a id="chase"></a>

这是交火后最容易犯错的一刻。**对方死了，但你身上有伤、弹匣不满、位置已经暴露**——而此刻你面对的通常是三选一：

| 你的判断 | 该做什么 |
|----------|----------|
| **场上只有他一个** | 不用追任何东西。**补弹 → 处理出血 → 换位**，然后回到原计划 |
| **他的队友就在附近**（听到了第二把枪、或者他是队伍里最先倒下的那个） | **不要追**。你追的是一个人，进去的是他的队友的射界。**守住他倒下的位置**，等他们来收尸 |
| **不确定还有没有别人** | **按“有”处理**：退到硬掩体、补弹、听 10 秒。**枪声是全图级的，你不去接他，他会来接你**（见[遇敌处置与接战决策](contact-drill.md)） |

**两条附加纪律**：

- **不追，是因为“追”这件事本身暴露时间最长**。追人意味着你在移动、在开阔处、而且弹药可能只剩半匣——三个变量同时变差；
- **“多杀一个”的收益，远低于“把已经到手的资产带出去”**。除非你在完成击杀类任务，否则**打完就该回到“撤离还是继续搜”的判断上**（见[战局流程与节奏](raid-flow.md) 的四条止损线）。

## 🧭 实战要点

1. **盯住两个你能控制的量**：暴露面积（侧身 + 蹲高）与暴露时间（短促点射 + 打完就退）。
2. **先预瞄后露身**，**绝不重复从同一处探头**——第二次是从同一个洞伸进同一个准心。
3. **分清朝三级**：硬掩体能换弹打药，半身掩体只能蹲着打，遮蔽物只能用来消失。
4. **不在暴露位置换弹**。宁可退两步，退回硬掩体后再换——换弹的时长固定，“在哪换”由你决定。
5. **备用弹匣放背心**——背包里的弹匣按 R 换不上。
6. **主武器故障或打空时切副武器**（有约 5 秒切换加速），别空着手站在那儿。
7. **开门贴着门框、先看远角**；翻越与破窗动作期间**不能还击**，只在确认安全时用。
8. **打死一个之后默认“还有第二个人”**：补弹、止血、换位，再决定追不追。
9. **打不中的正确反应是换角度，不是加时间**。

## ⚠️ 常见错误

- **反复从同一个位置探头**：这是被预瞄打死的最主要方式。
- **露出身体之后才开始找目标**：预瞄的反面，等于把寻找时间也送给对手。
- **在灌木或烟雾里对枪**：那只是遮蔽物，不挡子弹——它出卖你，不保护你。
- **在暴露位置换弹**：很多人不是被打死的，是在“以为能换完”的那两秒里被打死的。
- **备用弹匣塞在背包里**：交火中按 R 换不上来。
- **弹匣打空才换**：换弹窗口应该由你选，不该由弹匣决定。
- **不带副武器**：主武器一出问题，整局就结束了。
- **站起来从半身掩体射击**：等于主动放弃了掩体给的那一半优势。
- **进门时横穿门口**：门口是整面墙上唯一被预瞄的位置。
- **打完了站在原地看尸体**：枪声已经把别人引来了（见[搜刮效率与战利品取舍](looting.md)）。
- **为了多杀一个而追出去**：把自己从“有掩体的人”变成“正在移动的目标”。
