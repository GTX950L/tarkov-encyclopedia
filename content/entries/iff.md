# 敌我识别与身份判断 (Friend or Foe)

<a id="top"></a>

> “塔科夫不给你名字，只给你一个轮廓、一串脚步、和半秒的判断时间。”
> —— 为什么这里认错人不需要道歉

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 感知、身份与判敌机制 |
| **HUD 标识** | **完全没有**——没有小地图、没有队友点位、没有名字标签、没有敌人轮廓 |
| **队伍内识别** | 只能靠**外观约定**（臂章、服装）与沟通 |
| **敌方识别** | 靠**轮廓 → 行为 → 声音**三级判断，没有一键答案 |
| **唯一的官方队伍标识** | 臂章（Armband）：可选颜色，**不能被别人拾取、死亡不丢失** |
| **事后确认** | 狗牌（Dogtag）：显示姓名、等级、阵营、死亡时间、击杀者与武器 |
| **误伤代价** | 击杀队友：不计任务进度 + Karma 惩罚 + 其狗牌失去“战局内发现”状态（价值 ₽1） |
| **对照** | [竞技场](arena.md) 里队友臂章强制蓝、敌人强制红；本体**刻意不给** |

---

## 💡 核心机制

### 1. 敌我不由外观决定，而由“身份 + 行为”决定

塔科夫没有“阵营标签”这种东西。你会不会被攻击，取决于你**以什么身份进图**、以及你**做过什么**：

| 你的身份 | 与其他 PMC | 与 AI Scav | 与 Boss 势力 |
|----------|-----------|-----------|-------------|
| **PMC** | 默认敌对 | 默认敌对 | 默认敌对 |
| **玩家 Scav** | 默认敌对 | 默认和平（除非你先动手） | 默认和平 |
| **玩家 Scav（被标记叛徒后）** | 敌对 | **全场转为敌对** | 敌对 |

三条推论：

- **USEC 与 BEAR 之间没有任何和平机制**。同阵营、同一个来源的雇佣兵，见面照样互杀——“看到同胞”不是安全信号；
- **Scav 的和平是行为换来的**：你一开枪打 Scav，同局里周边的 AI Scav 立刻把你当敌人，你自己也被标成“叛徒”（见[声望与 Karma](karma.md)）；
- **合作撤离是唯一的跨阵营和平机制**：PMC 与 Scav 同时站在撤离区内才成立（见[撤离点详解](extraction-points.md)）。

### 2. 游戏刻意不给你的四样东西

| 其他射击游戏通常提供 | 塔科夫 |
|---------------------|--------|
| 队友名字与图标 | 无 |
| 小地图与队友点位 | 无 |
| 敌人红点或高亮轮廓 | 无 |
| 位置坐标读数 | 无（官方地图道具只显示地形布局，不标你的位置，也不标撤离点） |

这不是遗漏，是设计前提：**识别成本本身就是塔科夫的难度来源之一**。所以这篇条目讲的所有方法，本质都是“在没有答案的情况下如何提高胜率”。

### 3. 第一级判据：轮廓（Scav 与 PMC 的机体差异）

远距离、背光、只看得见一个影子的时候，先看**底层服装与装备轮廓**：

| 观察点 | Scav | PMC |
|--------|------|-----|
| 底层衣裤与袖子 | **平民服装，不随装备变化**（运动裤、夹克、工装） | 阵营制式迷彩或纯色 |
| 头部 | 常见软帽、便帽，甚至没有头盔 | 战术头盔，带导轨与夜视座 |
| 背包 | 小、软，常常不背 | 大而结构化的军用背包 |
| 胸挂 | 无甲布质胸挂居多 | 胸挂 + 软质层 + 插板 |
| 武器 | 老旧、基本不改装，常见霰弹枪与基础步枪 | 带瞄具、消音、握把等配件 |
| 耳机 | 少见 | 常见，是 PMC 的标志物之一 |

**最可靠的一条**：Scav 的**底层衣裤与袖子改不了**。哪怕一个玩家 Scav 或 AI Scav 穿上了从 PMC 尸体上扒下来的护甲、头盔和背包，他的袖子与裤脚仍然是平民装。看“袖子”，不看“甲”。

### 4. 第二级判据：行为（AI 与玩家）

| 观察点 | AI Scav | 玩家 |
|--------|---------|------|
| 移动 | 固定巡逻路线来回重复，会原地站定扫描 | 会绕侧、会停顿、贴着掩体走 |
| 搜刮 | 站姿简化动作，不蹲下，不按顺序翻箱 | 会蹲着翻尸体、连续搜容器、挑高价值物品 |
| 交互 | 基本不查弹匣、不用手术包 | 会查弹匣、会在掩体后打药、会跳跃翻越 |
| 语音 | 会无理由地自言自语、喊话 | 一般保持安静 |
| 遭遇反应 | 要么站桩还击、要么直线冲过来 | 会找掩体、会退、会绕 |

**但别把这张表当铁律**：官方有意让 AI 模仿玩家（AI 会捡尸体上的枪、会对玩家的动作作出反应），目的就是让“看行为认人”永远只能提高概率、给不出保证。

### 5. 第三级判据：声音

| 声音线索 | 含义 |
|----------|------|
| 俄语民用脏话、嘟囔、喊话 | Scav（AI 常在开火前喊话；0.16.5.0 起，近距离开火前必定先喊） |
| 英语战术用语 | USEC |
| 俄语战术用语（冷静、制式） | BEAR |
| 换弹、查弹匣、跳跃落地 | 大概率是玩家 |
| 长时间完全安静 | 大概率是玩家 |

**F1 嘟囔是探路手段**：喊一声，若对面回一句同样的话，多半是 AI Scav、或者一个想确认你身份的玩家 Scav。声音是塔科夫最快的判据——参见[听声辨位与音频机制](audio.md)。

### 6. 队伍内部：臂章是唯一的“官方”标识

系统不给队友标识，但给了**臂章**（Armband）——这是官方留给玩家的那块布：

- **臂章占一个专用装备槽**，按用途分两类：识别用的纯色款（蓝、红、绿、黄、白、紫、Alpha 等），以及阵营与身份款（BEAR、USEC、UNTAR、TerraGroup、Labs、Kiba Arms，以及 Prestige 1–6、The Unheard、Arena 等状态臂章）；部分需要通过任务或购买解锁；
- **两个关键属性**：**不能被其他玩家拾取**、**死亡后不丢失**——队伍的臂章颜色因此可以跨局长期固定，是“跨局稳定”的识别标记，比服装可靠得多；
- **实战约定**：选一个在环境里不常见、也不与 AI 势力撞色的颜色，开局统一口径：“**没有这个颜色的，一律当敌人**”；
- 臂章是纯外观件，**不影响受击判定**，也不提供任何数值加成。

### 7. 服装与伪装：外观被玩家接管之后

外观自定义（战术服装）已成为常规功能：在 Ragman 的“服务”标签里按**上衣与裤子分件**购买，BEAR 与 USEC 各有自己的部件池；**The Unheard 版的所有者可以混穿两个阵营的部件**。

后果有两个：

- **服装不再能证明阵营**：看到一个穿美式服装的人，不能推断他是 USEC，更不能推断他是“同乡”；
- **伪装成为战术**：PMC 故意穿得像 Scav 以降低被优先攻击的概率；玩家 Scav 穿上 PMC 的甲和头盔冒充 PMC——但袖子与裤脚会出卖他（见第 3 条）。

### 8. 特殊身份的识别

不是所有“人形目标”都是 PMC 或普通 Scav。这些势力能一眼区分，也能一眼误判：

| 身份 | 外观线索 | 行为线索 | 击杀的声望后果 |
|------|----------|----------|----------------|
| **Boss 护卫** | 与 Boss 同一套装备与配色，成组出现 | 紧贴 Boss、交替掩护 | 扣大量 Scav 声望 |
| **Raider**（实验室、储备站） | 制式军用装备，装备齐整 | 战术推进、会绕侧、反应快 | 不扣声望 |
| **Rogue**（灯塔） | **美式装备，看起来就是 PMC** | 驻守水处理厂与山间别墅区，会用固定火力 | 不扣声望；外形最易误判 |
| **邪教徒与祭司**（Sectant） | 深色简朴装束 | 夜间出现，静默接近，偏好冷兵器 | 不扣声望 |
| **叛徒 Scav**（Traitor） | 与普通 Scav 无差别 | 攻击过其他 Scav，**本局内全场被标为叛徒** | 击杀叛徒**加**声望且无惩罚 |
| **Goons 三人组** | 装备精良、外观独特 | 跨图流窜、长距离追击 | 不扣声望 |

**记住灯塔这一条**：Rogues 是 AI，却穿得像 PMC——外形判断会在这里失效。具体刷新位置与装备随版本变动，以游戏内为准（见 [Boss 图鉴](bosses.md)、[灯塔](lighthouse.md)）。

### 9. 事后确认：狗牌

打完才知道打的是谁，这是塔科夫式的确认方式。狗牌（Dogtag）显示持牌人的**姓名、等级、阵营、死亡时间、击杀者与所用武器**。

- **用途**：撤离前确认“刚才那一枪打的是谁”；按对手等级估算战利品价值；任务大量需求（例如成批上交 USEC 或 BEAR 狗牌）；
- **限制**：不能挂跳蚤市场，只能卖给 Therapist；价值随持牌人的等级与 Prestige 上升；
- **最值得记住的一条**：**击杀队友后，他的狗牌会失去“战局内发现”状态、价值被压到 ₽1**。这是系统开给你的误伤回执，也是[组队与协作](squads.md)里“误伤后别补枪”的技术原因。

### 10. 对照：竞技场为什么反而给标识

独立游戏《逃离塔科夫：竞技场》保留了同样的硬核规则——没有小地图、不显示队友位置；但从 **0.2.8.0** 起，在 TeamFight、BlastGang、CheckPoint 模式中，**队友的臂章被强制显示为蓝色、敌人被强制显示为红色**，连解说台词都改成“红队、蓝队”。

结论很清楚：BSG 完全知道“没有标识”会制造多少误伤。**在一个按分钟结算的 5v5 模式里，他们用强制染色立刻解决；在本体里，他们把它留成了战术压力。**

## 🧭 实战要点

1. **三个判据里有两个指向“敌人”再开枪**：轮廓、行为、声音。犹豫的成本通常低于误判的成本。
2. **开局定臂章与服装**：选不常见的颜色，统一口径“没有这个标记的一律当敌人”，并给每一个新队友讲一遍。
3. **F1 嘟囔探路**：进房前、听见动静后喊一声，回话的语气与位置能立刻缩小判断范围。
4. **用“我在哪”代替“你是谁”**：队内报位（“我在你左后方，不出声，别回头”）比互相试探更快也更安全。
5. **看袖子，不看甲**：Scav 的底层衣裤改不了，这是最便宜可靠的判据。
6. **夜间把识别成本算进去**：夜视与热成像只能给出“有人”和“很热”，不给身份——黑夜里先开口的一方通常活得更久（见[夜视与热成像](night-vision.md)）。
7. **误伤之后先定性**：喊“自己人”、停火、报位置，比任何补枪都值钱。

## ⚠️ 常见错误

- **以为“同阵营就是队友”**：USEC 与 BEAR 之间没有任何和平机制，同袍也照杀。
- **只看上半身下判断**：玩家 Scav 会穿 PMC 的护甲、头盔和背包；看袖子、看裤脚、看他枪上的改装件。
- **把灯塔的 Rogues 当 PMC**：AI 也能穿得像 PMC，外形判断在这里失效。
- **把 AI 行为清单当铁律**：官方有意让 AI 模仿玩家，行为判据只提高概率。
- **不看狗牌就补枪**：误伤后补枪，会把一次误会升级成确定的 Karma 与狗牌损失。
- **照搬竞技场的标识规则**：强制染色只存在于竞技场，本体里没有。
