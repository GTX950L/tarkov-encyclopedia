## 💡 核心机制

### 1. 用行为练，而不是用经验点

塔科夫没有传统的技能点分配。**你做什么，就增长什么**：

| 行为 | 相关技能方向 |
|------|-------------|
| 负重移动、奔跑 | 生理类（耐力、力量） |
| 开枪、命中、控制后坐 | 战斗类（各武器系熟练度） |
| 治疗、包扎、手术 | 实用类（医疗相关） |
| 搜刮、检视物品 | 实用类（搜索、专注） |
| 改装枪械、制造物品 | 实用类（改装、制造） |
| 使用藏身处设施 | 实用类（藏身处管理） |

> **没有“刷技能点”这回事**——技能只在**实际做出对应动作**时增长，而且（见第 4 节）当局内重复练同一个技能会**越练越慢**。

### 2. 五个类别

<a id="categories"></a>

站内早期版本把技能写成“三类”，这是**简化过度**——官方把技能分成**五个类别**，其中第五类是**阵营专属**、只有选择对应阵营的 PMC 才有：

| 类别 | 管什么 | 代表技能 |
|------|--------|----------|
| **生理**（Physical） | 身体机能：跑多久、背多重、受伤后能不能撑住 | 耐力、力量、活力、健康、抗压、免疫、代谢 |
| **精神**（Mental） | 感知与社交：看多远、搜多快、商人给不给面子 | 专注、感知、魅力、智力、记忆 |
| **战斗**（Combat） | **按武器系分别计算**的熟练度 | 各枪族熟练度（突击步枪 / 冲锋枪 / 霰弹枪 / 狙击步枪 / 精确射手步枪 / 轻机枪 / 手枪 / 左轮 / 近战 / 投掷物…）、后坐力控制 |
| **实用**（Practical） | 一切“效率类”动作 | 搜索、弹夹训练、武器维护、手术、急救、隐蔽行动、无声行动、瞄准训练、武器改装、藏身处管理、撬锁、夜间行动…… |
| **特殊**（Special） | **阵营专属**，BEAR 与 USEC 各有一套，互不相通 | 与所选阵营绑定的若干专属技能 |

**两条必须分清的概念**：

- **战斗类 vs 实用类**：战斗类技能是**按武器类型**算的（换枪 = 换投资对象）；实用类是**按动作类型**算的（换枪不影响）。
- **技能 vs 武器掌握**：技能里的“武器熟练度”改的是**数值**（后坐控制、换弹速度）；[武器掌握](weapon-mastery.md) 改的是**动作**（能不能在瞄具里换弹）。两者是两条独立的线，别混。

> 完整技能清单以**游戏内技能面板**为准——技能名与归属会随版本调整，本表只标类别骨架与代表性技能。

### 3. 五类里先练哪三类（为什么优先级是这个顺序）

- **生理类**：直接影响移速、负重、耐力上限——是**生存能力**的地基；
- **战斗类**：影响对应武器的后坐控制、换弹速度、瞄准稳定性——是**同一把枪在不同人手里表现不同**的原因；
- **实用类**：影响治疗速度、搜刮速度、改装与制造成本——是**效率**的乘数。

**新手优先级**：生理 → 实用 → 战斗。理由很直接——**前两类在每一局里都在替你省钱，战斗类只在你开枪时生效**。

### 4. 技能疲劳：越练越慢，而且当局内是有“记忆”的

<a id="fatigue"></a>

这是技能系统里**最容易被误解**的一条：很多人以为“只要多练就一定涨”，实际上系统专门做了防刷设计。0.12.1.5413（2019-12-24）起加入**技能疲劳机制**，英文 EFT Wiki 对它有一份很具体的说明：

**每个技能有两个阈值**（具体数值因技能而异，不公开），当局内的提升速度按下面的曲线走：

| 阶段 | 提升速度 | 游戏内提示 |
|------|----------|------------|
| 战局开始 | **129%** | 蓝色箭头 |
| 达到**阈值 1** 后 | **100%**（正常速度） | 无箭头 |
| 达到**阈值 2** 后 | **50%**（惩罚档） | 红色箭头 |
| 掉到 50% 后，**3 分钟**没再练这个技能 | **75%** | — |
| 掉到 50% 后，**16 分钟**没再练这个技能 | **100%**（完全恢复） | — |

**两个关键推论**：

1. **“一局狂练一个技能”是效率最低的做法**。过了阈值 2 之后你只剩一半效率，继续练等于**用两倍的动作换同样的收益**；
2. **恢复是“按技能”计时的，不是全局计时**。A 技能在罚档里的时候，你去练 B 技能，A 的计时照样在走——所以**交替练多个技能，比死磕一个更快**。

> **上表是英文 EFT Wiki 的口径**；具体的阈值 1 / 阈值 2 数值**官方不公布**，社区也测不出统一值（每技能不同、且可能随版本调整）。所以**不要记数字，记方向：见到红色箭头就换技能练。**

### 5. 精英级：51 级的专属能力

每个技能的上限是 **51 级**，到达即**精英级（Elite）**，解锁一项**该技能独有的能力**——不是数值加成，而是**质变**。已确认的几项（英文 EFT Wiki 口径，随版本调整）：

| 技能 | 精英级效果 |
|------|-----------|
| **搜索** | 可**同时搜索两个容器**（例如胸挂与背包） |
| **专注** | 搜刮经验加倍，且有几率**一开箱就发现物品** |
| **手术** | 手术速度进一步提升，**生命值惩罚大幅降低** |
| **魅力** | **额外增加一个每日任务槽**，并进一步降低各项服务费用 |
| **武器维护** | 使用修理包时**进一步降低磨损概率** |

**这就是“老号”与“新号”之间那道看不见的墙**：装备可以买，51 级的技能买不到——**只能靠时间堆**。

### 6. 藏身处是合法的训练场

射击场、健身房、图书馆等模块允许**离线训练相关技能**，把不在图里的时间也转化成成长。这是[藏身处](hideout.md)除了经济收益之外的第二种价值（详见[藏身处模块详解](hideout-modules.md)）。

- **健身房 / 射击场**：分别离线训练生理类 / 战斗类技能；
- **图书馆**：给**实用类技能 +30% 经验**，并额外给局内经验 **+15%**——**这是全站唯一一份“技能经验加成”**，对实用类占比高的玩家价值最高。

### 7. 赛季会重写技能起点

赛季模式提供个人修改器，其中包含“技能预升级”类型的便利项（例如开局即拥有较高的制造等级）。换句话说，**技能这一层也被赛季规则重新参数化**——玩赛季角色时，技能成长曲线与持久角色不完全相同（见[赛季与修改器](seasons.md)）。

## 🧭 实战要点

1. **交替练，别死磕**：见到红色箭头（50% 惩罚）就换另一个技能，让前一个在后台恢复——**这是把疲劳机制反过来用**。
2. **优先生理类**：移速与耐力是所有战术的前提，而且它**每一局都在生效**。
3. **利用藏身处**：能离线练的项目不要浪费；**图书馆要尽早升**（实用类 +30%）。
4. **按武器系聚焦**：战斗类熟练度是按武器类型算的，频繁换枪等于分散投资。
5. **把它当作长期变量**：技能不会一夜成型，但会在每一局里悄悄计价。
6. **练技能要顺路**：负重时顺便练力量、搜刮时顺便练搜索——**为练而练的效率永远低于顺路练**。

## ⚠️ 常见错误

- **完全不懂技能存在**：很多人以为打不过是因为“网速”，其实是熟练度差距。
- **只看装备不看角色**：同一套装备，技能不同，结局可能完全相反。
- **一局里死练一个技能**：过了阈值 2 只剩 50% 效率，剩下的时间基本白练。
- **忽略实用类技能**：治疗与搜刮速度在关键时刻就是生死差。
- **以为技能会跟角色走**：赛季角色是新的角色，技能从新起点开始。
- **把“感知”当听力技能**：感知管的是**物资探测**，不放大声音——这是站内被问得最多的一处误解（见[听声辨位与音频机制](audio.md)）。
- **以为 51 级只是数字**：精英级是**质变**（例如搜索能同时开两个容器），不是多一点数值。
