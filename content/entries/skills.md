# 技能系统 (Skills)

<a id="top"></a>

> “塔科夫的角色不会升级，他只会变得越来越熟练。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 被动成长系统 |
| **提升方式** | 重复对应行为，没有经验条可刷 |
| **类别** | 体能类、战斗类、实用类 |
| **上限特征** | 高等级提升显著变慢，精英级有额外加成 |
| **训练场所** | 实战 + 藏身处设施（射击场、健身器材等） |
| **新手须知** | 技能差异是“同样的装备打不过同一个对手”的隐形原因 |

---

## 💡 核心机制

### 1. 用行为练，而不是用经验点

塔科夫没有传统的技能点分配。**你做什么，就增长什么**：

| 行为 | 相关技能方向 |
|------|-------------|
| 负重移动、奔跑 | 体能类（耐力、力量） |
| 开枪、命中、控制后坐 | 战斗类（各武器系熟练度） |
| 治疗、包扎、手术 | 实用类（医疗相关） |
| 搜刮、检视物品 | 实用类（搜索、辨识） |
| 改装枪械、制造物品 | 实用类（改装、制造） |

### 2. 三类技能的不同回报

- **体能类**：直接影响移速、负重、耐力上限——是**生存能力**的地基；
- **战斗类**：影响对应武器的后坐控制、换弹速度、瞄准稳定性——是**同一把枪在不同人手里表现不同**的原因；
- **实用类**：影响治疗速度、搜刮速度、改装与制造成本——是**效率**的乘数。

### 3. 等级越高越慢

技能在高等级区间的提升速度明显放缓，越往后越需要长期投入。这构成了“老号”与“新号”的客观差距——不是玄学，是可以量化的操作优势。

### 4. 藏身处是合法的训练场

射击场、健身器材等模块允许**离线训练相关技能**，把不在图里的时间也转化成成长。这是[藏身处](hideout.md)除了经济收益之外的第二种价值。

### 5. 赛季会重写技能起点

赛季模式提供个人修改器，其中包含“技能预升级”类型的便利项（例如开局即拥有较高的制造等级）。换句话说，**技能这一层也被赛季规则重新参数化**——玩赛季角色时，技能成长曲线与持久角色不完全相同。

## 🧭 实战要点

1. **有意识地练**：带负重跑图练力量，用主武器打杂兵练熟练度，行为即训练。
2. **优先体能**：移速与耐力是所有战术的前提。
3. **利用藏身处**：能离线练的项目不要浪费。
4. **按武器系聚焦**：熟练度是按武器类型算的，频繁换枪等于分散投资。
5. **把它当作长期变量**：技能不会一夜成型，但会在每一局里悄悄计价。

---

## ⚠️ 常见错误

- **完全不懂技能存在**：很多人以为打不过是因为“网速”，其实是熟练度差距。
- **只看装备不看角色**：同一套装备，技能不同，结局可能完全相反。
- **忽略实用类技能**：治疗与搜刮速度在关键时刻就是生死差。
- **以为技能会跟角色走**：赛季角色是新的角色，技能从新起点开始。
