# 战斗复盘与常见死因 (Death Review)

<a id="top"></a>

> “塔科夫没有回放系统，但它会把凶手的手法写在结算界面上——只是大多数人从不看第二眼。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 复盘方法论（如何从死亡中提取可改进项） |
| **可用证据** | 死亡界面、医疗界面、战局结算界面 |

## 💡 核心机制

<a id="evidence"></a>

### 1. 先看清：游戏到底给了你什么证据

塔科夫不做击杀回放，但它给的信息其实够用——只是**分散在三个界面**上：

| 界面 | 你能读到什么 |
|------|-------------|
| **死亡界面** | 击杀者的**名字**、**致命一击打中的部位** |
| **医疗 / 治疗界面** | 悬停红色伤情图标，可看到**弹种**与**命中次数** |
| **战局结算界面**（Kill List） | 每个击杀者的**阵营**（BEAR / USEC / Scav 类型）、**交战距离（米）**、**所用武器** |
| **结算界面的表现统计** | **射击数 / 命中数 / 命中率** |
| **结算界面顶部的状态** | Survived / Killed in Action / Missing in Action / **Run Through** |

三条必须知道的边界：

1. **没有回放系统**——想知道自己是怎么被绕后的，只能自己录屏回看（显卡自带的即时重放就行，抓最近 5–10 分钟）；
2. **致命部位 ≠ 全部受击部位**。死亡界面写的是**最后致命那一击**，不代表你只被打中过一次；
3. **Run Through 不算 Survived**——撤得太快（时长或经验不足）不会记为生存，**会影响任务进度**。很多人“明明撤出来了却没算任务”，原因就在这。

> 另有一条近期的改动值得记住：**结算界面的击杀列表现在可以直接查看对方资料并举报**，不必再退出战局另找入口。

<a id="three-causes"></a>

### 2. 三类死因：先分类，再谈改进

绝大多数死亡可以归入三类。**分类的价值在于：三类的改进方向完全不同，混在一起就无从下手。**

| 类型 | 典型证据 | 真正的原因 | 改进方向 |
|------|----------|------------|----------|
| **信息劣势** | 没听到枪声就死了；从背后/侧面被击中；交战距离明显超出你的预期 | **你在被知道位置的情况下移动**——脚步、光源、开门、换弹声 | 见 [姿态、移动与射击](movement.md)、[听声辨位与音频机制](audio.md)：**开阔地冲刺、掩体前慢走** |
| **位置劣势** | 死亡距离很近；尸体位置在门口/楼梯/拐角；结算显示对方用了近战距离的武器 | 你在**低价值、可被预瞄的通道**里停留或推进 | 见 [敌我识别与身份判断](iff.md)：换角度、别贴同一扇门、别在同一位置二次开火 |
| **火力劣势** | 命中数不少但对方没倒；弹种是低价弹；对方穿的是高档甲 | **打中了但没打穿**，或**你打的是甲、对方打的是你的缝** | 见 [弹药选型速查表](ammo-table.md)、[护甲与头盔](armor.md)：先看穿深，再谈枪 |

**一个反直觉的结论**：第三类（火力劣势）其实**最好解决也最花钱**——换弹药就行。前两类才是长期问题，且**不花钱**。

<a id="five-numbers"></a>

### 3. 用五个数字做复盘（这才是“数据向”）

结算界面上真正值得抄下来的，只有五项：

| 记什么 | 它回答的问题 | 看到的模式 → 该怎么改 |
|--------|--------------|---------------------|
| **交战距离（米）** | 你的有效区间在哪？ | 总是 10 米内被杀 → 你在打不该打的近战；总是 100 米外被点名 → 你太爱走开阔地 |
| **命中数 / 射击数** | 你是不是“先开枪后瞄准”？ | 命中率极低 → 减少长点射、改用短点射或单发 |
| **弹种**（医疗界面） | 你的弹够不够格？ | 命中很多却没击杀 → **穿深不足**，这是唯一该花钱的改法 |
| **战局时长** | 你是不是走得太晚？ | 常常在最后几分钟死 → 提前一个撤离窗口走 |
| **结算状态** | 你是生存、阵亡，还是 Run Through？ | 频繁 Run Through → 你在“逃课”，任务进度没涨 |

> 记满十局，你就会看到**自己的固定死法**。塔科夫的死亡很少是随机的——**是同一类错误被不同的人反复利用**。

<a id="not-causes"></a>

### 4. 先排除这三样，再谈技术

有些“死因”根本不是打法问题，而是三个基础变量没到位——它们会让你**误判自己**：

1. **弹药穿深不足**：打中了、伤害数字也有，但对方只是掉甲。**这是最常见的“假技术问题”**；
2. **护甲等级错配**：低等级甲对高档弹几乎等于没穿。反过来，你打 5–6 级甲时用低价弹，等于给对方挠痒；
3. **耐力与超重**：跑不掉、趴不下、没耐力稳住枪——很多“枪法问题”其实是**负重问题**（见[耐力与移速](stamina.md)）。

**排除法很简单**：如果一局的“命中数 / 射击数”并不难看，但结果很惨——**问题多半在这三样里，不在手上**。

<a id="log"></a>

### 5. 复盘记录法：只记五行

不用记日记，**每局死完记一行就够**（游戏外的记事本即可）：

```
地图 / 交战距离 / 弹种 / 死亡部位 / 当时在做什么（推进？搜刮？打药？跑图？）
```

坚持十几局后，把「当时在做什么」这一列单独拉出来看——**多数人的死因会收敛到两三种固定行为**。改掉这两三种，生存率的提升比换任何一把枪都明显。

---

## 🧭 实战要点

1. **每局死完先看两处**：医疗界面的**弹种**、结算界面的**交战距离**。
2. **别把死归给枪法**：先排除弹种、护甲等级、负重三个基础变量。
3. **录屏是唯一的“回放”**：显卡的即时重放开着，遇上莫名其妙的死再回看。
4. **Run Through 要当回事**：它不给 Survived，任务进度不涨。
5. **“没听到枪声”不等于对方是挂**：消音器 + 远距离 + 高档弹，本来就是设计里允许的杀法。
6. **搜刮时死得最多**：搜尸体、翻箱子、打药时是最脆弱的三段时间，**先清场、再停留**。

---

## ⚠️ 常见错误

- **只记“被谁杀的”，不记“我当时在干什么”**：前者无用，后者才是可改进项。
- **把致命部位当成全部受击部位**：会严重低估对方火力。
- **不看弹种就下结论**：命中多却没击杀，九成是穿深问题。
- **每局换一套打法**：没有稳定的对照组，永远看不出模式。
- **忽视 Run Through**：以为撤出来就算成功，任务却没算。
