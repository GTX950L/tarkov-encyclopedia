# 储备站 (Reserve)

<a id="top"></a>

> “地下掩体、防空洞、信号弹——储备站的每一层都在讲一个军事基地的故事。”
> —— 任务党的中转站

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 中大型军事地图 |
| **体量** | 中大型（地面建筑群 + 地下掩体网络） |
| **raid 时长** | 中等 |
| **玩家数** | 中等偏多——**Scav 农场热门，Scav 进场量大** |
| **强度** | 中高（**军事物资区 = 装备水平整体偏高**） |
| **Boss** | **Glukhar**（带整队武装护卫） |
| **保险** | **正常生效** ✅ |
| **适合阶段** | 中期到中后期、Scav 农场、团队作战 |
| **标志性地点** | 主楼群（White Bishop 等代号建筑）、**D2 掩体**、信号塔、坦克停车场 |

---

## 💡 核心机制

### 1. 它是全游戏“Scav 密度最高”的图之一

储备站的 AI Scav **数量多、巡逻密集**，而且**玩家 Scav 的进场量也大**。这条事实带来两个方向相反的后果：

- **好处（对 Scav）**：想练枪、想稳攒钱，这里是全游戏最好的农场之一；
- **代价（对 PMC）**：**你分不清对面是 AI 还是玩家 Scav**——而杀错 Scav 会记在 Karma 账上（见[阵营关系与交战规则](engagement-rules.md)）。

> **纪律**：在储备站，**先确认身份再开枪**。这里误杀 Scav 的成本比在其他图高得多。

### 2. 它是“地面 + 地下”双层结构，两层规则完全不同

| 层 | 特征 | 主导打法 |
|----|------|----------|
| **地面** | 建筑群 + 坦克与军车残骸构成的稀疏掩体 | 中远距离交火，**空地是交叉火力的覆盖区** |
| **地下（D2 等掩体）** | 走廊、楼梯、铁门，结构复杂 | **贴脸遭遇与楼梯博弈**；同时是最容易迷路的地方 |

**关键**：**两层之间的转换点（楼梯口、掩体入口）是全图最危险的坐标**——因为守方拥有绝对先手。

### 3. 信号弹撤离：全游戏最有仪式感的撤离方式

储备站有一个标志性机制：**携带信号弹前往指定直升机坪触发撤离**。

| 要点 | 说明 |
|------|------|
| **前提** | **必须带着信号弹**——空手到了也没用 |
| **地点** | 指定直升机坪（不是任意撤离点） |
| **风险** | 直升机坪通常在**开阔处**，且信号弹会**明确宣告你的位置与意图** |
| **推论** | 用信号弹撤离＝**主动暴露**，所以要么确认周围安全，要么做好打一场的准备 |

（撤离点的类型与条件见[撤离点详解](extraction-points.md)。）

## 🗺️ 区域结构

<a id="areas"></a>

| 区域 | 特征 | 主要风险 | 该注意什么 |
|------|------|----------|------------|
| **主楼群（代号建筑）** | 多栋代号建筑，**内部房间与任务点密集** | 楼道与房间门口的固定伏击位 | 一次清一层；任务点常与交火点重合 |
| **D2 地下掩体** | **任务要地**，楼梯与地下走廊纵横 | **死亡博弈区**：贴脸遭遇 + 极易迷路 | 第一次进**先记撤离点**再探索 |
| **信号塔** | 制高点，**也是撤离点之一** | 视野与风险成正比——**塔上是全图靶子** | 看一眼就走，别在上面架枪 |
| **坦克停车场 / 空地** | 坦克与军车残骸构成**稀疏掩体** | **被多栋建筑交叉覆盖** | 跑酷要**分路段**，别一口气冲 |
| **边界带** | 地图边缘 | **有边界狙击手**（隐形、杀不死） | 见到警告标志立刻离开 |
| **直升机坪** | 信号弹撤离点 | 开阔、明确暴露 | 到之前先观察一轮 |

---

## 💡 核心打法流派

1. **任务推进流**：储备站是大量中期任务的舞台（特别是 Therapist 与 Prapor 线），跟着任务规划路线最省力。
2. **Scav 农场流**：AI Scav 数量多、巡逻密集，装备虽普通但稳定，攒钱练枪两相宜。
3. **地下博弈流**：守 D2 或反蹲 D2，楼梯口与拐角的对赌。

**再补两条**：

4. **信号弹速撤流**：任务拿到东西就走——**信号弹是一张“我不恋战”的声明**，适合低风险完成任务。
5. **空地夜行流**：空地白天是靶场，**夜间或低光时段通过**风险明显更低（见[光照与夜战](lighting.md)）。

## 🎯 Boss：Glukhar

<a id="boss"></a>

| 项目 | 内容 |
|------|------|
| **护卫** | ⚠️ **一支完整的武装小队**（多人、多兵种，含狙击手与重火力） |
| **威胁点** | **单人硬闯必被交叉火力覆盖**——这不是一个 Boss，是一个火力排 |
| **应对思路** | ① **拉开距离、制造人数差**；② 用掩体拆解他的队形；③ **或干脆绕行** |
| **判断纪律** | **打之前先数人头——数不清就当没看见** |
| **收益** | 稀有武器与任务物品 |

> **一条对比**：海关的 Reshala 是“4 个保镖”，储备站的 Glukhar 是**“一支编队”**。两者的挑战等级不在一个量级上。

**一条效率建议**：储备站的**任务点与高价值物资常在同一栋楼里**——做任务时顺手搜，比专程来搜更划算。

## 🧭 实战要点

1. **先确认身份再开枪**：AI Scav 与玩家 Scav 密度都高，误杀会记在 Karma 上。
2. **两次结构分开对待**：地面打中远距离，地下按贴脸遭遇准备。
3. **楼梯口是最危险的位置**：上下两层转换点永远属于守方。
4. **地下不熟先记撤离点**：掩体通道结构复杂，迷路比被打死更常见。
5. **空地分路段跑**：它是被多栋建筑交叉覆盖的，一口气冲等于赌运气。
6. **打 Glukhar 前先数人头**：数不清就当没看见。
7. **信号弹是主动暴露**：用它撤离＝宣告位置，先确认周围再打。
8. **Scav 来这里最划算**：AI 密度高，练枪与攒钱能同时进行。

---

## ⚠️ 常见错误

- **轻视 Glukhar 护卫队**：这不是一个 Boss，是一个火力排。
- **地下迷路**：掩体通道结构复杂，第一次进建议记撤离点再探索。
- **在开阔地带久留**：储备站的空地被多栋建筑交叉覆盖，跑酷要分路段。
- **没带信号弹就想走直升机坪**：那个撤离点**需要信号弹**才触发。
- **把玩家 Scav 当 AI 打**：储备站的 Scav 里混着真人，开火前先看行为。
- **在信号塔上架枪**：制高点是双向的，你看见别人的同时也在被看见。
