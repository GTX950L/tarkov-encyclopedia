# 特殊槽装备与工具 (Special Slot Equipment)

<a id="top"></a>

> “它不占背包、也不会被搜走——所以你根本没有理由不带。”
> —— 关于那三个格子

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 装备（角色面板上的**独立槽位**，与护甲 / 胸挂 / 背包并列） |
| **槽位数** | **3 个**（0.12.12.30 起；此前只有 1 个） |
| **核心属性** | **放进槽内的物品死亡不掉落、也不可被对手搜刮** |
| **使用方式** | 拖入槽位后，用数字键（4–0 一档）绑定调用 |
| **版本基线** | 1.1.5.1 |
| **重要提醒** | 官方数据里带这一标记的物品共 **45 件**，其中**大多数是任务与剧情道具**——本条目只讲**能在战局里用出价值**的那一部分 |

---

## 💡 核心机制

### 1. 这三个格子的真正价值：死亡不掉

特殊槽不是「多三个背包格」。它与其他任何容器有一条**性质上的区别**：

- 背包、胸挂、口袋、安全箱之外的所有容器，**死了就一起丢**；
- **特殊槽里的东西不会**——**死亡不掉落，对手也无法从你身上搜走**。

由此推出这条装备决策里最划算的一句：

> **凡是“你不希望每局都重新买一次”的常备工具，都应该放在特殊槽里。**

指南针、测距仪这类东西，价值全在“**你有、别人没有**”上。放在背包里意味着**每死一次就重新交一次学费**；放特殊槽则**一次投入、永久可用**。

### 2. 怎么装、怎么用

1. 在角色面板找到**特殊槽的三个格子**（就在口袋旁边），把物品从仓库或背包**拖进去**；
2. 鼠标**悬停在已装备的物品上**，按数字键（4–0 一档）即可把它**绑定到该键**；
3. 进图后按这个键调用——**与用药、用雷是同一套操作逻辑**。

三条容易踩的操作细节：

- **键位绑一次就永久生效**，因为物品本身不掉落；
- **按压模式可以改成“按住”**：松手即收起，避免打完架发现自己还在看指南针；
- **指南针可以边走边看、也可以举着枪看**，但**冲刺或开枪会自动收起**——它不是暂停键。

> **历史遗留的一条坑**：0.12.12.30 之前，指南针可以单独绑到 U 键（设置里有专门一项）。改成特殊槽系统后**那一项没有了**，只能通过**数字键绑定**。按老教程去设置里找“指南针按键”是找不到的。

### 3. 战局内能用的四类工具

| 用途 | 型号 | 说明 |
|------|------|------|
| **方位** | **EYE MK.2 专业手持指南针** | 不占背包格的方位参照，走图与报点的基础 |
| **距离** | **Vortex Ranger 1500 测距仪** | 远距离交火前先量距离，再决定抬多少 |
| **标记与布设** | **MS2000 标记器**、绊线安装套件、Wi-Fi 摄像头、信号干扰器 | 任务线与据点侦察的主力道具 |
| **信号与呼叫** | **Zid SP-81 信号枪**、RSP-30 / ROP-30 信号弹（七色）、迫击炮打击信号装置、数字加密无线电发射机 | 信号类是**条件型撤离与场景事件**的钥匙（见[撤离点详解](extraction-points.md)） |
| **开门与破障** | **SZ-1 炸药**、本地网络入侵设备、阀门手轮、气焊炬、船用修补套件 | 多数服务于特定场景与任务，不是通用消耗品 |
| **后勤** | **Leatherman 多功能工具** | 除任务外，也是[藏身处](hideout.md)工作台建造的必需件——**别为了交任务把它卖掉** |

**获取渠道**：工具类主要**走商人**（指南针与测距仪由 Jaeger 提供，多功能工具由 Mechanic 提供）；任务类道具则在**接受对应任务时发放或由任务线要求自备**。具体以游戏内为准。

### 4. 唯一的“规则级”物品：无名者之声

这一组里有一件不是工具，而是**一条挂在业力上的自愿约束**：

- **无名者之声（Mark of the Unheard）**——携带它时，**主动击杀 Scav 会扣 Fence 声望**，作为交换，Fence 替你支付部分战局内服务费；
- 它存在的意义在于证明一件事：**官方完全有能力约束 PMC 对 Scav 的行为，他们选择把这条约束做成“自愿”。**

完整规则见[阵营关系与交战规则](engagement-rules.md)，这里只做收录归属上的说明：**它是特殊槽物品里唯一一件会改变你与其他阵营关系的**。

### 5. 明确不收录的部分

那 45 件里，以下三类**不在本条目展开**，理由记下来避免反复提：

| 类别 | 例子 | 为什么不做 |
|------|------|-----------|
| **任务道具** | 各图平面图、RFID 门卡、Prapor 的信件、录音机 | 属**任务线内容**，逐件列出等于把任务攻略抄一遍，且随任务改动失效 |
| **剧情 / 邪教物品** | 圣物护符、装甲箱、伞绳 | 影响面窄，且涉及剧情，归[剧情章节与主线任务](story-chapters.md)与[任务系统](quests.md) |
| **场景专用件** | 阀门手轮、船用修补套件 | 只在个别场景有用，写进条目会摊薄主体 |

## 🧭 实战要点

1. **先把三个格子填满**：指南针与测距仪是所有玩家的通用解，**一次买、永久用**；
2. **第三格留给当期任务**：多数任务都需要携带标记器或摄像头进图，放特殊槽等于**免去“忘了带”的风险**；
3. **绑定键位这件事只做一次**：物品不掉落，键位也不会重置；
4. **把“按住”模式用起来**：松手即收起，比再按一次更接近肌肉记忆；
5. **入场前看一眼槽位**：这三个格子在**任何一次加载画面之前就决定了**，进图后补不了。

---

## ⚠️ 常见错误

- **把特殊槽当保险箱用**：它只有三个格子，**装不下值钱货**，塞满战利品是浪费；
- **为交任务卖掉多功能工具**：它同时是藏身处的建造必需件，回买要花更多；
- **去设置里找“指南针按键”**：那一项在 0.12.12.30 就取消了，现在只能绑数字键；
- **测距仪只用来测“多远”**：它更大的用处是**在决定要不要接战之前，先把距离变成已知数**；
- **以为信号弹只是照明**：在若干地图上，**信号弹是条件型撤离点的前置条件**（见[撤离点详解](extraction-points.md)）。
