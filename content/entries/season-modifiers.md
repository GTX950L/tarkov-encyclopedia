# 赛季修改器逐项 (Season Modifiers)

<a id="top"></a>

> “开季前的选卡不叫加点，叫签合同——签完这一季都不能改。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 赛季角色构筑系统（1.1.0.0 随第一赛季 KORD BREACH 实装） |
| **两类修改器** | **全局**（强制，无点数）＋ **个人**（自选，有成本） |
| **点数规则** | 起始 0 点；负面卡**给**点数，正面卡**消耗**点数；余额**不得为负** |
| **可否重选** | **不可**。赛季内锁定，唯一重置手段是重建赛季角色（清空一切） |
| **适用范围** | 仅赛季角色；持久角色与 PvE 不参与 |
| **跨赛季** | 每赛季重新设计，**上一季的数值与卡片不保证沿用** |

---

## 💡 核心机制

### 1. 六个全局修改器：赛季的“天气”

这些不花点数、不可关闭，全员一样。它们共同决定了这个赛季的经济与节奏基调：

| 全局修改器 | 效果 | 对本季的实际影响 |
|------------|------|------------------|
| **无保险** | 赛季内无法投保 | 死亡即全额损失，装备心态彻底改变 |
| **护甲短缺** | 商人护甲库存被削减 | 护甲变贵、变少，**自制与缴获成为主来源** |
| **黑师出没** | 黑师（Black Division）出现在更多场景 | 高危 AI 密度上升，遭遇战上限被抬高 |
| **巧手** | 制造时间缩短一半，制造技能起始等级极高（含额外制造位） | 藏身处制造从“副业”升为本季**核心产能** |
| **藏身处免 FiR** | 藏身处建造不再要求材料带“战局内发现”状态 | 升级不再被 FiR 卡住 |
| **老练 PMC** | 战局经验获得提升 | 等级与解锁进度整体加速 |

把六条合起来读，本季的主线其实被写在明面上：**保险没了、护甲买不到，所以你必须自己造**。藏身处制造 + 材料搜集构成了这个赛季的生存基础。

### 2. 个人修改器：正负对冲的点数市场

个人卡分正面（消耗点数）与负面（提供点数）两类，**余额不允许为负**——所以“多拿强度”只能靠“多背代价”换来。

**正面卡（消耗点数，部分示例）**

| 修改器 | 点数 | 效果 |
|--------|------|------|
| 街头税 | −1 | 每周一次，部分 Scav 会向你缴纳保护费 |
| 幸运 | −1 | 效果随机，属于高风险娱乐向 |
| 果汁时间 | −2 | 喝果汁获得止痛效果 |
| 节食 | −2 | 食物与饮品的消耗量减半 |
| 凝血倾向 | −2 | 出血概率下降 |
| 水合良好 / 食欲旺盛 | −2 | 水分 / 能量消耗下降 |
| 水手乡愁 | −2 | 吃罐头获得持续回血 |
| 塔科夫射手 | −2 | 栓动步枪技能成长加速，且起始等级更高 |
| 稳健骨骼 | −3 | 骨折概率与坠落伤害下降 |
| 短跑健将 | −3 | 跑速提升 |
| 马拉松选手 | −3 | 四肢耐力消耗下降 |
| 大力神 | −5 | 力量与耐力技能起始等级提高 |
| 青春 | −5 | 能量消耗下降、四肢耐力上限提高 |
| 神童 | −5 | 技能经验获取提升 |
| 保险箱匠 | −5 | 机械钥匙有一定概率不掉耐久 |
| 灌木之友 | −5 | 穿越植被的噪音与减速大幅降低 |
| 平均主义者 | −12 | **全部技能起始 25 级，但从此不能再提升**（制造除外） |
| Kappa 协议 | −12 | 直接获得 Kappa 安全箱 |

**负面卡（提供点数，部分示例）**

| 修改器 | 点数 | 效果 |
|--------|------|------|
| 第三只腿 | +1 | 移速下降，但 Therapist 处购物更便宜 |
| 杰基尔医生 | +1 | 获得“开放伤”后当局内无法移除 |
| 不幸 | +1 | 厄运有时会产生严重后果 |
| 血友病 | +2 | 出血概率上升 |
| 真疼 | +2 | 医疗包消耗增加 |
| 烦渴 / 慢性疲劳 | +2 | 水分 / 能量消耗加快 |
| 人格真空 | +2 | 魅力技能无法提升，且商人商品全线涨价 |
| 骨质疏松 | +3 | 骨折概率与坠落伤害上升 |
| 过敏 | +3 | 对随机的食物或药品产生过敏 |
| 无能 | +4 | 除栓动步枪外，全部技能成长速度下降 |

> 以上点数与数值为**第一赛季开季值的示意**。同一赛季内数值本身也经历过调整，且每赛季会重新设计——请以当前赛季的角色创建界面为准。

### 3. 三张需要重点权衡的卡

这三张卡是全系统里最容易被“看起来很强”骗到的地方：

**「平均主义者」（全部技能 25 级但封顶）**

听起来像免费大礼包，本质是**把一整季的技能成长空间一次性卖掉**。体力、代谢这类需要长期爬升才出精英技能的项目会永久停在 25 级——**换个说法：你买的是前 30 小时的便利，卖的是整季的上限**。

**「Kappa 协议」（直接拿安全箱）**

点数成本在开季时被下调过（预览版与实装版差异很大），但对构筑的挤压仍然明显——**它会锁掉若干高价值正面卡**。且注意：赛季角色不会继承你原有角色的 Kappa，**要么重做收藏家任务，要么点这张卡**。

**「灌木之友」（植被噪音与减速大幅下降）**

效果在开季时被加强过，但价值高度依赖地图：**森林、海岸线、灯塔、地面零点几乎必点；工厂、实验室、立交桥则接近废卡**。选卡前先想清楚这一季的任务会把你送去哪。

### 4. 互斥与预设

个人卡之间存在**互斥关系**——部分正面卡会直接禁掉对应的负面卡（反之亦然），因此“把强度叠满”在数学上不成立。游戏内提供**预设方案**，但预设只是起点：**点数结构必须自己算一遍**。

### 5. 为什么这套系统的争议不小

社区对赛季修改器的评价长期分裂，两条反对意见最集中：

1. **一次锁定、无法反悔**——选错等于整季（约四到六个月）的体验被绑死；
2. **负面积累的结构性偏斜**——正面卡消耗点数、负面卡供给点数，但“能治好的负面”和“治不好的负面”被标了同样的价，导致最优解趋于固定。

## 🧭 实战要点

1. **先定这一季要玩什么，再选卡**：任务路线决定地图，地图决定地形类卡的价值。
2. **算清点数总和再进游戏**：锁定不可反悔，重建等于从零开始。
3. **本季护甲要靠自己造**：全局修改器已经把答案写在明面上——优先藏身处制造相关路径。
4. **谨慎对待“封顶型”正面卡**：便利是即时的，上限是整个赛季的。
5. **缺 Kappa 的话想清楚要走哪条路**：重做收藏家任务，还是花点数买。
6. **留意互斥表**：选卡界面会给出冲突提示，务必逐条读完。

---

## ⚠️ 常见错误

- **照抄上个赛季的构筑**：每赛季会重新设计，点数与效果都可能改动。
- **把“无法提升”理解成“不用练”**：平均主义者的技能上限是硬天花板。
- **忽略全局修改器**：无保险与护甲短缺会改写你的整季经济模型。
- **不看互斥就下卡**：被互斥掉的卡等于白花点数。
- **在开季当天凭感觉点完**：卡选定即锁定，重建代价是整季进度。
