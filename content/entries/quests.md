# 任务系统 (Quests)

<a id="top"></a>

> “枪法决定你死不死，任务决定你强不强。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 成长主线系统 |
| **任务分类** | **静态任务**（无限期）+ **限时任务**（每日 / 每周） |
| **静态任务来源** | 七位商人（Fence 除外）的任务线 |
| **限时任务来源** | 除 Fence 外的商人发给 **PMC**；**Fence 发给 Scav** |
| **解锁方式** | 静态任务 1.1 起按**商人忠诚度**触发，不再是线性长链；**每日任务 5 级**、**每周任务 15 级** |
| **任务类型** | 击杀、搜刮、放置/拾取、撤离指定、Boss 猎杀、存活 |
| **终点奖励** | Kappa 安全箱（1.1 起前置条件减至 4 个任务，有效等级约 40） |

## 💡 核心机制

<a id="main-line"></a>

### 1. 任务是成长的唯一主线

塔科夫的等级只是门槛，真正的成长全部挂在任务上：

- **商人声望** → 解锁高级货架；
- **藏身处模块** → 大量升级材料由任务解锁或前置；
- **弹匣/武器/护甲解锁** → 商人高等级货架；
- **Kappa 安全箱** → 完成绝大多数任务线后的终极徽章。1.1 起门槛显著降低：前置任务减至 **4 个**、有效等级约 40，旧的“Kappa 之路”成就自第一赛季开始**永久不可获得**。

<a id="rework"></a>

### 2. 1.1 的任务体系重构（2026-08）

赛季系统上线时，任务体系一并被改写（详见[重大版本更新史](../docs/version-history.md)）：

- **解锁靠忠诚度**：任务由商人忠诚等级逐步开放，不再是“做完前一环才能做下一环”的长链；
- **任务可跳过**：不喜欢或卡住的任务可以选择放弃，成长不再被单个任务卡死；
- **奖励偏向货币**：任务收益更倾向卢布，而不是必须的实物；
- **多人协作**：队伍成员可以帮彼此推进任务进度。

结果：任务从“必须全清的长跑”变成“按需挑选的资源”，**成长路径的自由度大幅提升**——但也意味着“跟着任务列表走”不再是最优解，需要自己规划目标。

<a id="two-forms"></a>

### 3. 两种形态：静态任务与限时任务

这是理解任务系统最容易漏掉的一条分界——**它们规则完全不同**：

| | **静态任务**（商人任务线） | **限时任务**（每日 / 每周） |
|---|---|---|
| **期限** | **无期限**，放着不管也不会失效 | **有期限**，到期即消失 |
| **内容** | 人工设计、固定不变 | **条件与奖励由系统自动生成**，每人每期都不同 |
| **接取角色** | 大部分**必须以 PMC 完成** | PMC 由商人发；**Scav 由 Fence 发** |
| **解锁** | 按忠诚度逐步开放 | **每日：5 级**；**每周：15 级** |
| **难度与奖励** | 随任务线推进 | **随你的完成率浮动**——做得越顺，下一期越难、奖励越好 |
| **能否放弃** | 可以（1.1 起） | 可以直接**更换（Replace）** |
| **主要作用** | 声望、解锁、Kappa | **等级与声望的日常来源** |

**怎么一眼分辨**：任务列表里**带时钟图标**的是限时任务；商人头像右上角**绿色图标**表示有待接任务，**蓝色对勾**表示有任务可以交付。

<a id="operational"></a>

### 4. 每日与每周任务：最容易忽略的成长引擎

这是一条**不依赖任务线进度**的独立收益来源，也是很多玩家等级卡住的原因——**它每天刷新，不接就白白浪费**。

| 项目 | 规则 |
|------|------|
| **解锁等级** | 每日 **5 级**；每周 **15 级** |
| **刷新周期** | 每日约每 24 小时；每周更长 |
| **发任务的商人** | 除 Fence 外的商人（各自独立刷新） |
| **典型目标** | 上交指定物品（含 FiR）、击杀 N 名 Scav / PMC（可能限定距离、部位、武器）、击杀指定 Boss、从指定点幸存撤离 N 次、连续存活 N 局 |
| **奖励** | **经验 + 卢布（或美元/欧元）+ 商人与声望 + 物品**；完成固定给 **+0.01 声望** |
| **难度是否浮动** | **是**。完成率越高 → 后续越难、奖励越好；**连续失败会使任务明显变简单** |

三条很实用的机制：

1. **可以更换任务**（Replace 按钮），代价是**花钱 + 可能降低与该商人的忠诚度**，而且**每次后续更换的费用递增**——别当成免费洗牌；
2. **成功了却不交付，到期就算失败**。完成了目标记得回商人菜单点 Complete；
3. **转生会永久多给一个每日与每周槽位**——这是 [Prestige 转生](prestige.md) 里最实在的长期收益之一。

> **奖励规模的量级（社区观察，非官方，随等级缩放）**：高等级角色的每日任务大约在**数万经验**、**数十万卢布**的量级，并附带最多若干件物品；对 Peacekeeper 的奖励可能是欧元。**具体数值每人每期不同**，不要照抄。

<a id="scav-tasks"></a>

### 5. Scav 也有限时任务：Fence 与情报中心

**Fence 会给 Scav 角色发限时任务**，这是提升 **Scav Karma** 最稳定的一条路：

- **解锁前提**：藏身处**情报中心（Intelligence Center）1 级**——所以它是[藏身处](hideout.md)建造优先级很高的一个理由；
- **刷新**：约每 24 小时一次；
- **奖励**：**Scav 声望 0.01–0.04** / 每次，外加卢布与稀有物品（兴奋剂、钥匙、护甲等）；
- **为什么重要**：车辆撤离与合作撤离的声望收益会**递减**，而每日任务是**稳定、不递减**的来源——想爬到 6.0 的“Boss 保镖”门槛，基本靠它。

（详见[声望与 Karma](karma.md)）

<a id="rewards"></a>

### 6. 奖励的发放方式不同，别漏领

完成任务的奖励分两类通道，**发放方式差别很大**：

| 奖励类型 | 发放方式 |
|----------|----------|
| **经验、解锁物品、忠诚度提升** | **立即生效**，不需要领取 |
| **物品与货币** | 通过**游戏内邮件**发放，**有领取期限，过期即失** |

邮件界面里的 **Receive All** 按钮可以一次性收走**该商人全部待领奖励 + 所有已返还的保险物品**——这是最省事的习惯（见[邮件与领取](mail.md)）。

<a id="fir"></a>

### 7. “战局内发现（FiR）”到底怎么算

任务里常见的 FiR 要求，判定范围比多数人以为的宽：

**以下都算 FiR**：
1. 在**在线战局**中找到的物品（背包图标**右下角有对勾**）；
2. **任务奖励**发放的物品；
3. 在**藏身处制造**出来的物品。

另外两条容易踩的规则：

- **交付容器类任务物品（例如背包）前必须先清空容器**；
- **撤离类任务不认“匆匆撤离”**——搜刮与击杀获得的经验合计不超过 200、且战局内停留时间过短时，该次撤离会被判定为匆匆撤离，**不计入任务进度**（见[战斗复盘与常见死因](death-review.md)）。

<a id="failure"></a>

### 8. 任务的三种结局：放弃、失败、白干

| 结局 | 触发 | 后果 |
|------|------|------|
| **主动放弃** | 手动移除不需要的静态任务（1.1 起支持） | 该任务不再出现在列表，成长不被单点卡死 |
| **超时失败** | 限时任务到期未完成 | 任务消失；**部分任务的失败会降低声望** |
| **白干** | **目标全部达成，但到期前没点完成** | 直接按失败结算——**最冤枉的一种** |

**更换每日/每周任务本身也可能降低声望**，这是官方明确写过的规则。所以“换掉所有不想做的任务”并不是免费的策略。

<a id="types"></a>

### 9. 常见任务类型与对策

| 类型 | 难点 | 对策 |
|------|------|------|
| 击杀指定目标（含 Scav/PMC/Boss） | 依赖运气与地图理解 | 顺路做，别专程刷 |
| 搜刮/上交物品 | 物品锁在高价值区 | 提前查点位，进图直奔 |
| 放置/标记类 | 需要在危险区停留 | 先清场再执行，做完就走 |
| 撤离指定 | 与撤离点蹲守叠加 | 换时段/换路线 |
| 存活类 | 全程不能死 | 苟图流：小装进出 |

<a id="item-safety"></a>

### 10. 任务物品的安全

任务物品放进**安全箱**不会丢——阵亡也可以重打，但进度物品在箱里就永远在手。**接到任务的第一个动作：查物品是否可入安全箱。**

## 🧭 实战要点

1. **多线并行**：接满所有可用任务再进图，一次 raid 完成多个目标——任务效率的倍增器。
2. **进图前先看限时任务**：每日/每周是**免费的经验与声望**，不接等于每天在漏收益。
3. **按地图归组**：把同一地图的任务打包做，减少重复跑图。
4. **任务达成后立刻交付**：限时任务**目标达成但未交付，到期算失败**。
5. **别专程刷击杀任务**：击杀类任务顺路完成，专程去刷容易破防。
6. **卡任务的正确姿势**：查点位地图、换低峰时段、换装备等级——三选一总会解开。
7. **Jaeger 前置尽早做**：他的解锁任务卡着一条完整任务线。
8. **想刷 Scav 声望就先造情报中心**：Fence 的限时任务是唯一不递减的来源。

## ⚠️ 常见错误

- **纯打仗不接任务**：等级上去了，货架还是一级——成长原地踏步。
- **从不看限时任务栏**：每日与每周是**独立于任务线的收益**，漏接就是漏等级漏声望。
- **任务物品装背包不装箱**：阵亡一次，物品全还。
- **用换任务来“洗”出简单任务**：**每次更换都可能掉声望，且费用递增**——得不偿失。
- **忘了交付**：限时任务目标做完了不点完成，到期按失败结算。
- **顺序强攻**：低等级硬做高等级任务，死到退游。
- **忽略存活与撤离条件**：部分任务要求撤离才结算，而“匆匆撤离”不算数——杀完就浪的下场是白干。
- **不领奖励**：物品类奖励走邮件且**有过期时间**，忘了领就没了。
