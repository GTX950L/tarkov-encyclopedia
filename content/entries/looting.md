# 搜刮效率与战利品取舍 (Looting)

<a id="top"></a>

> “搜刮的胜负不在你捡到了什么，在你没捡到的那几分钟里发生了什么。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 战局内的操作与取舍（不是“哪儿有东西”） |
| **核心问题** | **这一堆里先拿哪个、拿不拿** |
| **三个约束** | **时间**（暴露窗口）× **格子**（容量）× **FiR**（能不能卖） |
| **最大误区** | 把“搜干净”当目标 |
| **机制依据** | 容器里的物品默认**是隐藏的**，要逐个“搜索”才识别——而这段时间你**不能开枪** |
| **配套条目** | [战利品分布与热点](loot.md) 讲**去哪儿**、[战局流程与节奏](raid-flow.md) 讲**什么时间去**；本篇讲**到了之后手上怎么拿** |

## 💡 核心机制

### 1. 搜索是一件“被按住”的事

<a id="searching"></a>

新手以为搜刮是“打开、看见、拿走”。实际机制是：

1. 打开一个容器或尸体，**里面的物品默认是遮蔽状态**；
2. 你需要**逐个“搜索”**，物品才会显形、才能被拖动；
3. **这一整套动作期间，你在原地、不能开枪、不能移动。**

也就是说，**搜刮不是“顺便做的事”，是把你自己钉在原地一段时间**——这就是它的全部风险来源。

**两条关于速度的硬知识**（来自官方 wiki 的技能页）：

| 事实 | 说明 |
|------|------|
| **搜索速度主要由“注意力”决定，不是“搜索”技能** | 搜索技能本身给的是每级 1%、满级约 +50% 的速度加成，而**实际的搜索速度取决于注意力（Attention）技能** |
| **搜索技能的满级特权才是质变** | 满级后可以**同时搜索两个容器**，并且**打开即可见**全部物品——这是全游戏最实用的被动之一 |

对实际行为的意义很直接：**在技能成型之前，搜刮的固有成本就是高的**，所以更应该靠“少搜、只搜对的”来弥补，而不是靠手速。

### 2. 尸体不是一个容器，是两个

<a id="two-containers"></a>

一具尸体上要搜的东西是**分开的**：

| 部位 | 是什么 | 说明 |
|------|--------|------|
| **背心 / 胸挂（rig）** | 他身上穿的装备容器 | 弹药、手雷、药——**高价值小件多半在这里** |
| **背包（backpack）** | 他自己背进来的容器 | 战利品总量在这里，但**空包很常见** |
| **直接装备** | 主武器、副武器、护甲、头盔、耳机 | 需要单独拾取 |
| **狗牌（dogtag）** | 尸体的身份标识 | 见 [敌我识别与身份判断](iff.md)、[组队与协作](squads.md) |

**顺序建议：先看狗牌 → 再掏背心 → 最后开背包。** 理由在第 4 节。

### 3. 三个脆弱窗口，搜刮占两个

<a id="windows"></a>

塔科夫里“最容易被打死”的时刻是固定的三个，其中两个属于搜刮：

| 窗口 | 为什么脆弱 |
|------|------------|
| **翻尸体** | 人站着不动、低头、注意力在菜单上 |
| **开容器** | 同上，而且**开容器有声音** |
| **打药** | 治疗动作锁住行动（见[战中伤情处置](combat-medical.md)） |

**一条配套纪律**：**搜刮前先清场，而不是搜到一半再抬头**。枪声已经把周边的人引过来了——所以正确的次序永远是“**确认安全 → 换位 → 再停留**”，而不是“先搜了再说”。

### 4. 尸体速捡：四步顺序

<a id="fastloot"></a>

面对一具尸体，正确做法不是“从头到尾全部翻一遍”，而是按下面这个顺序问四个问题：

| # | 做什么 | 为什么排在这个位置 |
|---|--------|--------------------|
| **①** | **先看狗牌** | 狗牌告诉你他是谁（见[敌我识别与身份判断](iff.md)），也**顺带告诉你这具尸体值不值得停留**——阵亡玩家的尸体才可能有好东西 |
| **②** | **拿“任务物品与硬通货”** | 这两类是**不可替代**的：任务物品错过这局就得等下一局；硬通货体积小、价值密度最高 |
| **③** | **再看背心，最后看背包** | 高价值小件在背心里；背包体积大但常是空的。**先小后大，因为大的更可能让你停太久** |
| **④** | **武器护甲最后考虑** | 它们占的格子最多，而且往往意味着你要放弃手里的东西 |

**最关键的一条**：**不要在尸体上整理背包。**先把东西抓进来，**走到下一个掩体后面再整理**。原地整理是“翻尸体”这个脆弱窗口里最亏的一段——你花了整段暴露时间，换来的只是整齐。

### 5. 战局内怎么判断“这东西贵不贵”

<a id="value"></a>

站内[战利品分布与热点](loot.md) 讲过“用每格价值而不是单价做取舍”，[跳蚤定价与手续费](flea-pricing.md) 讲的是卖出去之后要扣多少。**这里只补战局内那一眼怎么判**——因为你没有时间查价。

用**三层漏斗**，从快到慢：

| 层 | 问题 | 判据 |
|----|------|------|
| **① 是不是任务物品？** | 我正在做的任务要不要它？ | **任务物品优先级恒为最高**——它不能用钱替代，而且常常限时（这局没带出去就得重来） |
| **② 是不是“通用硬通货”？** | 是不是那种**人人都在找、体积又小**的东西？ | 规律是**小体积 + 稀有度 + 通用需求**三者叠加。想不出具体名单时，就按“**电子件 / 贵重品 / 药品 / 弹药**”四个类别扫——**记类别，不背型号** |
| **③ 每格价值划不划算？** | 换成同样格子的其他东西，它更值钱吗？ | 见 [战利品分布与热点](loot.md) §2。这一层是“取舍”，不是“识别” |

**三条容易被忽略的修正**：

1. **不能卖的，有时比能卖的更值钱。**任务物品、藏身处建材、以物换物配方材料（见[以物换物](barter.md)）都是“必须拿到手才有用”的东西——用售价去衡量它们会严重低估。
2. **看一眼就走的类别，比逐件研究更高效。**你不需要知道每一件的具体行情，只需要知道“**这一格要不要**”。
3. **FiR 是一个前置条件，不是附加属性。**撤得太早会让 FiR 作废（见[战局流程与节奏](raid-flow.md) 的 Run Through），所以“值钱”的前提是**这一局能按 Survived 撤出去**。

### 6. 格子的账：武器和护甲常常不该拿

<a id="grid"></a>

新手最容易犯的“搜刮错误”是**看见枪就拿**。算一下就明白：

| 拿什么 | 占格 | 真实收益 |
|--------|------|----------|
| **一杆长枪** | 通常 5 格以上 | 卖价不一定高，**而且会逼你放弃手里的枪**（除非手里的更差） |
| **一件护甲 / 头盔** | 数格，且**穿戴有代价** | 耐久可能已残，还有重量惩罚（见[耐力与移速](stamina.md)） |
| **同格的电子件 / 贵重品** | 通常 1–2 格 | 单位格的价值密度更高，**且不影响你的战斗状态** |

**判据**：当**换成同格数的战利品更值钱**、或者**穿上它会拖慢你的撤离**（见[战局流程与节奏](raid-flow.md) 的止损线）时——**不拿**。

**唯一例外**：你手里的枪快坏了、或者弹尽（见[武器故障与耐久维护](weapon-maintenance.md)），这时“捡一把能用的枪”是生存决策，不是收益决策。

### 7. 背包腾挪：把空格当成弹药

<a id="space"></a>

搜刮效率的一半取决于**你出发时留下的空间**：

| 纪律 | 为什么 |
|------|--------|
| **出发时留出 1×1 与 2×1 的空位** | 高价值小件几乎都能塞进去，不用现场腾挪 |
| **别把背包塞到只剩 0 格** | 塞满的背包会让你在尸体前“整理”，而不是“拿走” |
| **散件先合堆，再考虑丢** | 弹药、药品可以合并堆叠，腾出整格（见[背包与容器系统](inventory.md)） |
| **安全箱里留一格应急** | 最贵的小件（钥匙、狗牌、任务物品）优先塞进去——死了也不丢（见[安全箱与容器](containers.md)） |

### 8. 搜刮被打断怎么办

<a id="interrupt"></a>

搜刮中被枪声、脚步或投掷物打断时，**默认动作是“先离开这一段暴露，再判断”**——搜刮动作打断了不要紧，**位置被记住才要紧**。

处置原则与[遇敌处置与接战决策](contact-drill.md) 完全一致：**身份 → 是否被发现 → 距离 → 退路 → 收益**。区别只在于，你的起点是“手里有半包刚捡的东西”，所以**退路的权重要再上调一档**。

## 🧭 实战要点

1. **把“搜刮”理解为“原地静止一段时间”**——它是一次主动承担的风险，不是休息。
2. **先狗牌、再背心、后背包**：这三步就能覆盖尸体上绝大部分价值。
3. **不在尸体旁整理背包**：抓进来，走到掩体后再排。
4. **价值判断记类别，不背型号**：小体积 + 稀有 + 通用需求，三者叠加就是贵的。
5. **任务物品永远优先**：它有钱也买不到，而且常常限时。
6. **出发时留空格**，比到了现场再腾挪高效得多。
7. **搜一个地方之前先问“我退路在哪”**——搜刮的代价是静止，所以退路比平时更贵。

## ⚠️ 常见错误

- **以为搜刮是“顺手”的事**：它是全游戏最长的静止窗口之一。
- **把“搜干净”当目标**：清空一个房间的边际收益，远低于多停留一分钟的风险。
- **在尸体上慢慢挑**：这个窗口同时具备“静止、低头、有声”三个特征。
- **看见枪就捡**：占了最多格子，还让你放弃手里的武器。
- **用售价衡量任务物品**：需要它的那个任务不会因为你省钱而变简单。
- **背包塞满才出发**：等于把所有搜刮效率押在现场整理上。
- **只认定“能卖钱”的东西**：藏身处材料与以物换物配方常常更实用。
- **忘了 FiR 的前提**：值钱的东西，得先按 Survived 撤出去才算数。
