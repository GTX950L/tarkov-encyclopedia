## 💡 核心机制

### 1. 医疗品不是“血瓶”

每种医疗品功能明确，不会互相替代：

| 类别 | 解决什么 | 注意 |
|------|----------|------|
| 止血带/绷带 | 轻度/重度出血 | 只止血不回血 |
| 夹板 | 骨折 | 固定后可恢复奔跑 |
| 止痛药 | 疼痛、震颤 | **压制症状，不治疗** |
| 手术包 | 复位黑掉的肢体 | 贵、慢、但给“第二次机会” |
| 回血类 | 恢复部位血量 | 按部位类型细分 |
| 综合包 | 多功能合一 | 贵但省格省心 |

### 2. “黑屏”与手术包

肢体血量归零后“变黑”——功能丧失。只有**手术包**能把黑掉的肢体复位（恢复少量血量）。腿黑 + 有手术包 = 撤离希望；腿黑 + 没手术包 = 止痛药跛行逃命。

### 3. 止痛药的战略价值

强效止痛药可以**压制疼痛与震颤继续作战**——高端局顶着疼痛打完最后一梭子的操作，靠的就是它。但要清楚：血量缺口还在，下一发照样致命。

### 4. 兴奋剂与注射器：用一次，付一次利息

兴奋剂不是“更贵的血瓶”，它是**临时改写角色参数**的东西——耐力、负重、感知、回血速度都可能被改动。用之前先认三件事：

| 纪律 | 说明 |
|------|------|
| **有启动延迟** | 注射不是瞬发，效果要过一会儿才起来——**别在挨打的那一秒指望它** |
| **有结束惩罚** | 部分兴奋剂在药效结束时会有反噬。官方对 **SJ12（TGLabs）** 的描述就很直白：药效结束后**体温会飙升到 40–42 度**，作为身体系统失常的代偿 |
| **算进水的账** | **兴奋剂会加速脱水**（见[食物与水分](food-and-water.md)）——**带针就要多带水** |

按用途分三类就够用了：

| 类型 | 用来做什么 |
|------|------------|
| **回血 / 持续治疗类** | 交火结束后的恢复，替代一部分医疗包的工作 |
| **性能类**（耐力、负重、感知） | 用在“**必须搬完这一趟**”或“**必须跑到撤离点**”的时刻 |
| **特种 / 解毒类** | 针对毒素与中毒伤害——例如 **Perfotoran（蓝血）** 一类的血替代物，官方定位是强效解毒 |

> **一条口径更正**：**成瘾系统至今未实装**——官方 wiki 把“药物成瘾 / 幻觉”列在**未实装功能**清单里。所以不必为“上瘾”做规划，但**结束惩罚与脱水是现实存在的**。

**使用原则一句话**：**用在“不做这件事就出不去”的时刻，而不是“打得更舒服”的时刻。**

### 5. 治的时机：三个阶段，三套动作

医疗的失误大多不在“带错了什么”，而在“**在错的时机做了对的事**”：

| 阶段 | 只做这些 | 为什么 |
|------|----------|--------|
| **交火中** | **能一秒做完的事**：压制疼痛、止住大出血 | 在原地多待一秒，就是给别人一个固定的靶子 |
| **交火刚结束** | **止血 → 复位 → 补血**，并**立刻换位** | 枪声已经把周边的人引过来了（见[遇敌处置与接战决策](contact-drill.md)） |
| **撤离前** | 处理**肢体损毁**（手术包）、补齐状态、整理背包 | 损毁会拖慢撤离；但**手术包耗时最长，必须放在安全处做** |

**一张判断图**：**腿黑 + 有手术包 → 找掩体做手术**；**腿黑 + 无手术包 → 止痛药跛行撤离**；**头或胸损毁 → 无法救治，立刻撤离**。

## 🧭 实战要点

1. **最低配置**：一组止血 + 一副夹板 + 一份止痛。三个格子的“保命三件套”。
2. **按地图升级医疗**：短图三件套；长图加水与食物；高压图加手术包。
3. **先处理致命项**：大出血 > 骨折 > 疼痛。顺序错了会死在包扎的路上。
4. **综合包买省心**：中后期资金充裕后，大容量综合医疗包能取代一堆散件，格子效率更高。
5. **安全箱常备一套**：最简医疗放进[安全箱](inventory.md)，阵亡不丢，下一局立刻能用。

## ⚠️ 常见错误

- **只带回血不带止血**：血回得再快，止不住血照样流失。
- **止痛当治疗**：症状没了，血还在漏，“感觉良好”地死去。
- **手术包当主战医疗**：又贵又慢，用它做日常回血是奢侈浪费。
- **满配医疗不带食物**：长图后半段“渴死在满血状态”。
