# Boss 图鉴 (Bosses)

<a id="top"></a>

> “在塔科夫，Boss 不是关卡尽头的大魔王，是地图上随机移动的一笔奖金——附带很高的手续费。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 战斗系统综述 + 全 Boss 对照 |
| **数量** | 十余支首领势力，分布与刷新率随版本调整 |
| **共同点** | 高血量、带护卫、掉落优质装备与任务物品 |
| **共同风险** | 你面对的不是一个敌人，是一支编队 |
| **关键变量** | 刷新概率、刷新区域、是否游走、是否有专属机制 |

---

## 💡 核心机制

### 1. 刷新不是必然的

大多数 Boss 的刷新是一个**概率**，只有少数例外是接近 100%（例如灯塔半岛的 Zryachiy、迷宫里的 Tagilla 之影）。这意味着“去某张图打某个 Boss”本质是一次**期望值计算**，不是确定性任务。刷不到是常态。

### 2. 护卫比 Boss 更致命

Boss 的恐怖之处很少来自他本人，而来自**他身边的人**：

- Glukhar 的最大护卫编队规模在全游戏居首，单人硬吃基本等同于自杀；
- Kaban 带八人规模的随从，还配有楼顶狙击手与固定重武器阵地；
- The Goons 是**三人组的游走 Boss**，人数本身就是他们的机制。

统计上，死在护卫手里的玩家远多于死在 Boss 手里。

### 3. 游走型与据点型

| 类型 | 代表 | 特点 |
|------|------|------|
| **据点型** | Shturman、Kaban、Tagilla | 活动范围固定，可预判、可架枪 |
| **巡逻型** | Killa、Glukhar、Reshala | 在固定区域内移动，需要搜查 |
| **游走型** | The Goons、Partisan | 每局落到不同地图，无固定主场 |
| **强制型** | Zryachiy、Tagilla 之影 | 接近 100% 刷新，专门守卫某个场景 |

游走型是任务党最头疼的一类——你无法通过“去哪张图”来安排他们，只能靠情报和运气。

### 4. 收益结构

Boss 的价值通常在三个方向：**签名掉落**（专属武器/装备）、**任务物品**（多条任务线要求击杀或交付）、**经验**（击杀收益极高，是[联赛系统](leagues.md)的主要冲分手段之一）。相应地，失败成本是全套装备——尤其在保险不生效的场景里。

## 🛡️ 护卫编队

Boss 的威胁上限由**编队规模**决定。下表是可稳定参考的护卫结构（人数随版本可能微调）：

| Boss | 护卫规模 | 编队特征 |
|------|----------|----------|
| **Reshala** | 4 名 | 均衡配置，是最标准的“Boss + 小队”教学组 |
| **Shturman** | 2–3 名 | 小而精，配合锯木厂开阔地形成交叉火力 |
| **Sanitar** | 2–3 名 | 医疗系配置，护卫也带治疗能力 |
| **Glukhar** | **6 名（多兵种）** | 编队规模居首，含狙击手、重机枪与突击手 |
| **Killa** | 无 | **单人 Boss**，靠自身重甲与主动推进施压 |
| **Tagilla** | 无 | 单人，靠速度与近战爆发 |
| **Kaban** | 2 名贴身 + 4 名重装 + 2–3 名狙击手 | 全游戏最大的据点编队，另配固定重武器 |
| **Kollontay** | 4–6 名 | 数量浮动大，且他本人会瘫痪你的武器 |
| **Zryachiy** | 2 名邪教徒 | 人数少但精度极高，且有狙击位优势 |
| **The Goons** | 三人组（互为队友） | 人数本身就是机制，无额外护卫 |
| **邪教徒祭司** | 2–4 名战士 | 夜间与昏暗路线伏击，配合毒刀 |
| **Partisan** | 无固定护卫 | 以陷阱与地形为主 |
| **Tagilla 之影** | 无 | 靠迷宫的环境危害代替护卫 |
| **The Wedge（破冰船）** | 黑师编队 | 规模随场景推进，PvE 侧最高强度 |

### 刷新概率的两层结构

理解刷新要分两层看，这是多数攻略没写清的地方：

| 层级 | 含义 |
|------|------|
| **第一层：是否刷新** | 该 Boss 在本局是否出现，**每次战局独立重算** |
| **第二层：刷新在哪** | 若出现，落到哪个站点（各站点有独立权重） |

三条常见误解的更正：

1. **没有计时器、没有轮换**——连续刷同一张图不会提高概率，前一局刷到与否不影响后一局；
2. **概率会随版本与活动大幅变动**——社区实测数据在 20%–50% 区间反复浮动，且活动期常有临时改写；
3. **“必刷”是少数**——仅 Zryachiy、迷宫的 Tagilla 之影、破冰船的剧情 Boss 等属于接近 100%。

> 精确的当前刷新率请以社区实时追踪站点为准；本页只保证“两层结构”与“无序刷新”这两条结论可靠。

## 🎯 分区速览

### 海关 · Reshala

经典组合：Boss + 数名保镖，出现在加油站、宿舍等固定点。是多数玩家遇到的第一个 Boss，也是 Gunsmith 与任务线里的常客。

### 立交桥 · Killa

重甲冲锋型，在商场中庭与主力店铺之间移动。他不蹲点，而是**主动推进**——这意味着你很难靠架枪等他自己走进射界，必须准备在移动中接战。

### 森林 · Shturman

锯木厂的狙击手，带两名护卫，位置稳定。森林的开阔地形让这场战斗变成**谁先发现谁**的问题；也是少数能稳定安排“去打一次”的 Boss。

### 海岸线 · Sanitar

医生出身，护卫数人，医疗系掉落优质。注意赛季中他的刷新被拆分到海岸线与终点站两处，老攻略的“固定海岸线”说法已经过时。

### 储备站 · Glukhar

护卫编制最大的一位。打法核心是**拆队**：逐个方向清掉护卫，而不是指望正面接战。

### 工厂 · Tagilla

全游戏最小地图上的近战怪物：电焊面罩 + 大锤，听到枪声就冲。工厂的体量决定了他几分钟内就能找到你——这既是危险，也是**最快的狩猎效率**。

### 街区 · Kaban 与 Kollontay

全游戏唯一可能双 Boss 同图的地图。Kaban 自身不穿甲但护卫与工事齐全；Kollontay 的危险来自他那根会让周围人**武器卡壳**的警棍。两个据点相距较远，一次只打一边是基本纪律。

### 灯塔 · Zryachiy

半岛守卫者，血量池为全 Boss 之最，且不穿甲。几乎必刷，但**过桥需要准备**（DSP 信号装置）。两名邪教徒随从的威胁不低于他本人。

### 游走型三组

- **The Goons**：三人小队，包含携带榴弹发射器的成员。每局随机落在海关 / 森林 / 海岸线 / 灯塔之一。
- **邪教徒祭司**：夜间与昏暗路线上的伏击者，使用毒刀。
- **Partisan**：单独行动，擅长布置陷阱，追击他等于走进他设计好的地形。

### 破冰船 · The Wedge

黑师指挥官。全 PvE 场景中的最高强度目标之一，曾因过强在 1.0.5 被下调反应速度。

## 🧭 实战要点

1. **先数人头，再决定打不打**：护卫数量决定这场仗是否值得。
2. **弹药门槛高于枪法**：打 Boss 的最低标准是能穿透其护卫的护甲。
3. **控制交战距离**：近战型（Tagilla、Kollontay、Killa）必须留退路，狙击型（Shturman、Zryachiy）必须抢视线。
4. **别在开阔地处理任何 Boss**：他们的护卫天生擅长交叉火力。
5. **接受“刷不到”**：刷新是概率，反复空跑是正常成本。

---

## ⚠️ 常见错误

- **把 Boss 当单个敌人**：永远按“一支编队”来做预案。
- **带低穿弹**：对护卫无效的子弹，对 Boss 也无效。
- **在 Kollontay 面前贴脸**：警棍一出，武器卡壳，你就只剩腿。
- **忽略地图机制**：车行的地雷、灯塔的桥、迷宫的光照，都是战斗的一部分。
- **一局同时打两个 Boss**：街区的双 Boss 不是给你一次收两份的。
