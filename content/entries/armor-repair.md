# 护甲修复与耐久 (Armor Repair & Durability)

<a id="top"></a>

> “修一次，永久少一截上限——塔科夫的护甲只会变老，不会变新。”
> —— 编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 装备维护经济 |
| **三条修复途径** | 商人（Prapor / Skier / Mechanic）、修理包、藏身处 |
| **核心代价** | **耐久上限（Max Durability）永久下降** |
| **不可逆项** | 上限**永不回升**，卖出去也不会 |
| **效果衰减** | 耐久比例越低，实际防护等级越低 |
| **版本基线** | 1.1.5.1（商人整体价格已上调） |

---

## 💡 核心机制

### 1. 要管的是两个数字，不是一个

每件护甲有两组值：**当前耐久**与**耐久上限**。

- 当前耐久被打掉 → 用修复补回来；
- 但**补的过程会永久压低上限**。

所以护甲的实际寿命不是“修几次”，而是**“上限被削到什么程度才不再值得修”**。一件原本上限 80 的重甲，被反复修复到上限 60 之后，它的防护能力已经跌到低一档的水平——**你穿着重甲，实际享受的是中档防护**。

### 2. 上限损失由三个变量决定

| 变量 | 说明 |
|------|------|
| **谁来修** | 不同商人 / 修理包的削减系数差异很大 |
| **材质** | 材质自身的“修复品质”决定它抗不抗修 |
| **修复幅度** | **小幅度多次修**比**一次修一大堆**更保值 |

最后一条是最容易忽略也最实用的一条：**别等耐久见底再修**。

### 3. 商人的差异：品质与价格是两条反向的曲线

| 修复方 | 修复品质（越高越保值） | 修复成本（越低越便宜） |
|--------|------------------------|------------------------|
| **Prapor** | 最低 | 最便宜（且不随忠诚等级涨价） |
| **Skier** | 中等 | 中等（忠诚等级越高越贵） |
| **Mechanic** | **最高** | **最贵**（忠诚等级越高越贵） |
| **修理包** | 依材质而定，对部分材质接近 Mechanic | 单件最便宜 |

译者式的说法：**Prapor 是“修完就卖”的选择，Mechanic 是“修完自己穿”的选择，修理包是“修便宜货”的选择。**

> 上述品质/成本系数来自社区维基的实测整理，随版本可能调整，具体费用以游戏内为准。

### 4. 材质决定一件护甲的“可修复寿命”

不同材质天生抗修程度不同，同样是 6 级甲，命可以差出好几倍：

| 材质 | 修复品质（越高越好） | 备注 |
|------|----------------------|------|
| **UHMWPE（超高分子量聚乙烯）** | 高 | 与装甲钢同为最抗修的一类 |
| **装甲钢** | 高 | 重、抗修、便宜，性价比路线 |
| **芳纶** | 中 | 轻甲常见，修几次就明显掉档 |
| **钛 / 铝** | 偏低 | 可修但代价不低 |
| **复合材料** | 低 | 折中但整体吃亏 |
| **陶瓷** | **最低** | 防护好、极不耐修，一次性倾向明显 |
| **玻璃（部分面罩/护目镜）** | 最低 | 更极端的脆性 |

结论：**买陶瓷甲的时候，你买的是“这一局的防护”，不是“这一季的护甲”。**

### 5. 面罩、护目镜与附加护甲是特例

面具、护目镜、附加护甲板、装甲面罩这几类有一个长期的实现问题：**通过商人修复时，修复品质不会按预期提升**，结果是修完看起来没满、面罩可能还留着视觉损伤。

社区通行的处理方式：**这类部件走 Prapor 修**——因为品质本来就上不去，那就干脆选最便宜的。

另外，**面罩与护目镜的耐久独立于头盔本体**，两者分别损耗、分别修复。

### 6. 藏身处修理：便宜，但有门槛

藏身处路线（修理包 + 相应模块）的特点是：

- **单件成本通常最低**，尤其对中低档装备；
- 但需要**建成相应模块**，并保持修理包库存；
- 效果会随**模块等级**与相关技能（智力、轻甲/重甲技能、藏身处管理）提升；
- 使用修理包本身也能**反过来练轻甲/重甲技能**——这是很多人忽略的正循环。

对重甲与高价头盔而言，**长期在藏身处修**能省下的钱，往往超过一件新甲的价格。

### 7. 什么时候该放弃一件护甲

判断只有一条公式：

```
修复成本 + 上限损失的价值  <  同档次新甲的市场价？
```

越贵的甲越划算修（替换成本高），越便宜的甲越不值得修（修完不如换新）。低档软甲基本属于**消耗品**：跑一两轮、掉档了就卖，不要投入修理资源。

### 8. 1.1 之后的经济背景变了

1.1 版本对经济做了整体上调：**商人售价平均上涨约 25%**、**商人回购价平均下调约 20%**、**跳蚤市场手续费从 3% 提高到 5%**。

这三条叠加的直接后果是：**新甲的获取成本上升 → 修复的相对价值上升 → 材质与修复路径的取舍比以往更值钱**。同一时期赛季全局修改器里还有“护甲短缺”这一条，进一步把成本推高。

## 🧭 实战要点

1. **小幅多次修**：不要让耐久跌到三成以下再动手。
2. **自己穿的走 Mechanic / 藏身处**，准备卖的走 Prapor。
3. **陶瓷甲当消耗品用**，别指望它陪你过完整季。
4. **面罩与护目镜走 Prapor**，品质本来就没有升级空间。
5. **重甲优先藏身处修**，一次省下的就是一件软甲的钱。
6. **关注上限而不是当前值**：上限掉到一定程度，就该换新了。
7. **用修理包顺手练轻甲/重甲技能**，这是白拿的收益。

---

## ⚠️ 常见错误

- **以为修完就是新的**：上限只会一路向下。
- **拿高价头盔给 Prapor 修**：省下的钱抵不上掉的上限。
- **给低档软甲做修复规划**：那件甲的价值本来就低于修理费。
- **忽略面罩耐久是独立的**：头盔完好不代表面罩能用。
- **不看市场价就修**：有时新甲比修复更便宜，尤其在商人促销或战利品充足时。
