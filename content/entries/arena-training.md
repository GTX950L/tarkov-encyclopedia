## 💡 核心机制

### 1. 三条边界：先搞清竞技场能练到什么程度

<a id="cap"></a>

这三条决定了整套练法的上限，**任何“竞技场刷技能”的攻略如果没提这三条，都是不完整的**：

| 边界 | 内容 | 来源 | 后果 |
|------|------|------|------|
| **① 进度共享** | 角色等级、技能、武器掌握的进度在**两款游戏间双向同步** | 官方站点与 [Patch 0.1.6.0](https://arena.tarkov.com/news/patch-0160)（一级） | 竞技场里打出来的成长，回本体照样算数 |
| **② 对局内拉平** | 所有玩家**角色技能统一按 30 级**、**武器掌握统一按 3 级**结算 | Patch 0.1.6.0（一级） | 你练得再高，**在对局里也不会比对手多一点后坐力优势** |
| **③ 30 级封顶** | 技能经验只能累积到 **30 级**，再往上必须回本体练 | 社区实测（三级，Dignitas 指南） | 竞技场负责“起步”，本体负责“精通” |

**这三条合起来的意思是一句话**：

> **竞技场卖的是“单位时间内的交手次数”，不是“更高的技能上限”。**

所以正确的期待是：**用竞技场把一堆 5 级、10 级的技能快速推到 20–30 级**，让角色在每一局本体里都更跟手；而不是指望在竞技场把某个技能刷到 51 级精英。

### 2. 为什么竞技场的「单位时间技能经验」更高

<a id="why"></a>

不是因为它有隐藏倍率，而是因为**三个结构性优势**——这三条都能从规则直接推出来：

| 优势 | 机制 | 换算成什么 |
|------|------|-----------|
| **死亡成本接近零** | 无搜刮、无装备损失、重生制模式可反复复活 | 你敢主动找架打，**单位时间内的“有效动作”更多** |
| **交火密度高** | 场地是改造过的封闭竞技场，一局能跑完一圈；重生制一局常能打出两位数交火 | 每一枪、每一次换弹都在给战斗类技能计经验 |
| **技能疲劳按“局”重置** | 疲劳是**当局内**的递减曲线，换一局即重新开始（见[技能系统](skills.md#fatigue)） | 局越短，**“129% 开局段”占总时长的比例越高**，平均倍率更好看 |

> **第三条是推导**：技能疲劳的口径是“当局内递减、按技能分别恢复”，竞技场是否完全复用同一套曲线，官方没有单独说明。但即使不考虑疲劳，前两条已经足够让竞技场成为**练战斗类技能效率最高的地方**。

### 3. 逐技能练法总表

<a id="table"></a>

**读法**：✅ = 竞技场里有明确触发动作；🟡 = 有条件（看模式 / 职业 / 预设）；❌ = 竞技场里没有触发点。

#### 战斗类（竞技场的主场）

| 技能 | 竞技场怎么触发 | 效率 | 要点 |
|------|---------------|------|------|
| **突击步枪 / 冲锋枪 / 霰弹枪 / 狙击步枪 / DMR / 轻机枪 / 手枪** | 用对应枪族**开枪命中** | ✅ 最高 | **按武器系分别计算**——固定 2–3 个枪族，别每局换枪 |
| **后坐力控制** | **连续射击**（点射、压枪） | ✅ 最高 | 竞技场交火密集，是全游戏**唯一能连续练压枪**的地方 |
| **投掷物（手雷）** | 投出手雷并造成效果 | ✅ 高 | BlastGang 的装置攻防最需要投掷物，练得最自然 |
| **近战** | 近身挥击 | 🟡 一般 | 只在特殊活动（如刀战模式）里高效，常规局很少触发 |

> **为什么不建议“每局换枪”**：战斗类熟练度是**按武器平台分别累计**的。你打 10 局换 10 把枪，等于把经验摊成 10 份，每一把都停在低等级——这正是“打了很久还是不跟手”的常见原因。

#### 生理类（顺手就能练）

| 技能 | 竞技场怎么触发 | 效率 | 要点 |
|------|---------------|------|------|
| **耐力** | 奔跑、冲刺（负重压在“能跑但费劲”的区间） | ✅ 高 | 竞技场几乎全程在跑，**不刻意练也在涨** |
| **力量** | **负重移动**、投掷手雷 | ✅ 最高 | **穿 Enforcer 的重甲 + 轻机枪**，负重自然达标；本体里要靠背弹药凑重量 |
| **活力** | 受伤后存活、流血后止住 | ✅ 中高 | 重生制模式（CheckPoint / Last Hero）受伤频率最高 |
| **健康** | 受伤与恢复 | 🟡 中 | 与活力同源，别为了练它故意不吃药 |
| **抗压** | 受击、濒死 | 🟡 中 | 竞技场治疗及时，反而不好压到濒死线——**不要为了练它硬扛** |
| **免疫** | 持续承受负面状态 | ❌ 低 | 需要长时间负面状态，竞技场节奏太快，没有可持续的触发条件 |
| **代谢** | 进食与饮水 | ❌ 无 | 竞技场不涉及吃喝 |

> **生理类的正确姿势是“顺便”**：穿重装、多跑动、受伤就治，三项技能同时在涨；专门为了练某一项去设计动作，效率反而低。

#### 实用类（一半能练，一半练不到）

| 技能 | 竞技场怎么触发 | 效率 | 要点 |
|------|---------------|------|------|
| **瞄准训练** | **开镜（ADS）**、快速举枪 | ✅ 高 | 竞技场开镜频率远高于本体，这项成长很快 |
| **弹夹训练** | **换弹**（含战术换弹） | ✅ 高 | 一局换弹次数是本体数倍 |
| **急救** | 受伤后自己包扎、止血 | ✅ 中高 | 预设里带医疗包就能练；**别把治疗全推给队友** |
| **手术** | 使用手术包 | 🟡 有条件 | **只有预设带 CMS / Surv12 时才练得到**，多数竞技场预设不带 |
| **隐蔽行动 / 无声行动** | 蹲伏移动、慢走 | 🟡 中 | 竞技场地图小，蹲走机会不多，但对绕后有实际价值 |
| **武器维护** | 使用修理包 | ❌ 无 | 竞技场不修枪，武器耐久由预设给定 |
| **武器改装** | 改装枪械 | ❌ 无 | 预设编辑器在菜单里，不算局内动作 |
| **搜索 / 专注** | 搜刮容器、检视物品 | ❌ 无 | 竞技场没有战利品 |
| **藏身处管理** | 建造藏身处模块 | ❌ 无 | 竞技场没有藏身处 |
| **撬锁** | 开锁 | ❌ 无 | 竞技场没有可撬的锁 |
| **夜间行动** | 夜间战局 | ❌ 无 | 场地都是日间或人工照明 |

#### 精神类与特殊类

| 类别 | 结论 | 原因 |
|------|------|------|
| **专注 / 感知** | ❌ 练不到 | 两者都围绕**搜刮与物资探测**，竞技场没有战利品 |
| **魅力 / 智力 / 记忆** | ❌ 练不到 | 需要商人交互、任务交付与物品检视，竞技场只有菜单里的军械库 |
| **阵营专属（特殊类）** | ❌ 不适用 | 与竞技场无关，成长仍在本体 |

### 4. 一张表看清：能练 / 练不到

| 类别 | 能练 | 练不到 |
|------|------|--------|
| **战斗** | 全部（枪族熟练度、后坐力控制、投掷物） | 近战（仅活动模式） |
| **生理** | 耐力、力量、活力、健康、抗压（有限） | 免疫、代谢 |
| **实用** | 瞄准训练、弹夹训练、急救、（有条件）手术、隐蔽/无声 | 搜索、专注、武器维护、武器改装、藏身处管理、撬锁、夜间行动 |
| **精神** | — | 全部 |

> **记住这条判据**：**技能看“动作”，竞技场只提供“战斗动作”**。凡是需要“搜、建、改、买、吃”的技能，竞技场一律练不到——这不是版本问题，是模式设计决定的。

### 5. 四套训练课表

<a id="drills"></a>

每套课表按「目标 → 模式 → 职业 → 关键动作 → 判据」写，一次课 3–4 局，约一小时。

#### 课表 A：枪法课（练某一个枪族 + 后坐力）

| 项 | 内容 |
|----|------|
| **目标** | 把一个枪族的熟练度推到 30 级，同时练后坐力控制 |
| **模式** | CheckPoint ×2（重生多、交火密）+ Teamfight ×1（一命制，练决策） |
| **职业** | Assault（弹药选择面最广）或 Scout（弹药质量最好） |
| **关键动作** | **全程只用同一把枪**；每次交火打完一个弹匣再看结果；死了立刻复盘“这一枪该不该开” |
| **判据** | 结算后看该枪族熟练度是否在涨；**若已到 30 级就停**，继续打只涨角色经验 |

#### 课表 B：力量课（顺带耐力）

| 项 | 内容 |
|----|------|
| **目标** | 力量成长（本体里最难练的技能之一） |
| **模式** | CheckPoint ×2（重生制，跑动距离最长） |
| **职业** | **Enforcer**（护甲最好、负重最高） |
| **关键动作** | 穿满重甲 + 轻机枪；**不要蹲点**，每回合主动绕场；手雷能扔就扔 |
| **判据** | 负重压在“能跑但费劲”的区间；太轻练不到力量，太重跑不动反而少交火 |

#### 课表 C：医疗课（急救 + 有条件的手术）

| 项 | 内容 |
|----|------|
| **目标** | 急救（以及预设带手术包时的手术） |
| **模式** | CheckPoint ×2（可重生，敢主动吃伤害） |
| **职业** | Enforcer（血厚，扛得住） |
| **关键动作** | 受伤后**自己包扎**，不要等队友；预设里放 CMS / Surv12 才能练手术 |
| **判据** | 一局里至少完成 3 次自疗；**不要为了练治疗故意站在火线上** |

#### 课表 D：投掷与攻防课

| 项 | 内容 |
|----|------|
| **目标** | 投掷物熟练度 + 攻防决策 |
| **模式** | BlastGang ×2（唯一有攻守分工的模式） |
| **职业** | Assault（投掷物与步枪兼顾） |
| **关键动作** | 每回合至少一次投掷；**进攻回合负责清角，防守回合负责封路**；记住装置倒计时 **40 秒** |
| **判据** | 能说出“这一颗雷是为了逼位还是为了封路”——说不出来就是乱扔 |

#### 课表 E：30 级之后的长线课

| 项 | 内容 |
|----|------|
| **目标** | 把已到 30 级的技能继续推到精英级（51 级） |
| **在哪练** | **回本体**——竞技场在这一段不再给经验 |
| **怎么练** | 生理类靠负重跑图；实用类靠搜刮与自疗；战斗类靠固定枪族打图 |
| **加速器** | 藏身处**图书馆**（实用类 +30%）、**空气过滤单元**（生理类 +40%）、**靶场 3 级**（战斗类 +10%）——见[藏身处模块详解](hideout-modules.md#overview) |

> **藏身处加成在竞技场是否生效，官方没有说明，社区也没有统一测试**。保守按“不生效”做计划：把竞技场当**基础成长场**，把藏身处加成的部分留给本体战局。

### 6. 时间账：竞技场到底省了什么

| 维度 | 本体一局 | 竞技场一局 |
|------|----------|-----------|
| **单局时长** | 30–45 分钟（含跑图与撤离） | 10–30 分钟（**模式决定**：BlastGang 最长，Last Hero 最短） |
| **交火次数** | 通常个位数 | 重生制常达两位数 |
| **死亡代价** | 一整套装备 + 一局时间 | 一次重生（或等下一回合） |
| **能练的技能** | 全部 | **只有战斗动作相关的那些** |
| **技能上限** | 51 级（精英级） | **30 级** |

**结论**：竞技场的价值集中在**「把 0–30 级的战斗类技能快速拉起来」**这一段。它替代不了本体的搜刮、建造与任务，也替代不了 30 级之后的苦功。

## 🧭 实战要点

1. **先定一个枪族，打满四局**：战斗类按武器系分账，换枪就是换投资对象。
2. **练枪选 CheckPoint**：可重生、交火密，一局顶本体三局的交火次数。
3. **练力量穿 Enforcer 并主动跑动**：负重与移动同时满足，力量是竞技场里最“顺路”的技能。
4. **30 级就是终点线**：到线就换项目，别在竞技场里空耗——那一段经验竞技场不给了。
5. **每天先吃四场首胜**：四个职业各一次 +100% 经验，比多打两局更划算。
6. **把治疗握在自己手里**：急救是实用类里最容易在竞技场练起来的一项。
7. **别为练技能改变打法**：为了多开两枪而送命，丢掉的是这一局的全部交火机会。

## ⚠️ 常见错误

- **以为进度共享 = 战力共享**：对局内技能统一 30 级，你的练度不会变成当场优势。
- **指望在竞技场练满技能**：30 级封顶，51 级精英只能回本体。
- **把“竞技场武器等级”当“武器掌握”**：前者解锁配件（每枪 7–30 级），后者改换弹动作（固定 3 级）。
- **每局换枪**：战斗类按武器系分账，换枪等于把经验摊薄。
- **为了练免疫 / 代谢硬扛负面状态**：竞技场这两项几乎没有触发条件，纯浪费时间。
- **忽略模式差异**：一命制模式交火少、决策多；想堆交火次数就得选重生制。
- **拿旧攻略的 Sawmill 刷经验**：那张图已暂停用，1.7 倍系数作废。

## 💬 老兵经验

- 竞技场练的是手，本体练的是命。两样都得练。

- 技能条不会告诉你“这局打得好不好”，但交火次数会。

- 到 30 级就停手——继续打只是在给别人当靶子。
