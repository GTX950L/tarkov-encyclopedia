# 安全箱与容器 (Containers)

<a id="top"></a>

> “安全箱不改变你能打多猛，只改变你死了之后还剩多少。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 保底存储与收纳系统 |
| **安全箱数量** | 现役 **六个型号**（Alpha / Beta / Epsilon / Gamma / Kappa / Theta） |
| **共同特性** | **箱内物品阵亡不掉、无法被搜刮** |
| **限制** | 不能放**穿戴中或正在使用**的装备；箱内物品要**手动放入** |
| **获取路径** | 版本预购 / 商人交换 / 任务奖励 / **跨模式（Arena）路线** |
| **最大型号** | **Kappa**，3×4 共 **12 格**；其次是 **Theta** 的 10 格 |

---

## 💡 核心机制

<a id="why"></a>

### 1. 为什么安全箱是“版本分水岭”

一场战局的收益，**不取决于你搜到了什么，而取决于你带出了什么**。安全箱是唯一能保证“即使全灭也有收获”的机制。

由此产生一个后果：**安全箱的格数差异，直接决定长期收益效率**——这也是为什么[版本选择](../docs/buying-guide.md)里，安全箱尺寸被列为“买定离手、游戏内难以完全追平”的第一项。

<a id="models"></a>

### 2. 六个型号逐项对照

| 型号 | 尺寸 | 格数 | 获取路径 |
|------|------|------|----------|
| **Alpha 安全箱** | **2×2** | **4** | 标准版 / Left Behind 版自带；Peacekeeper 处也可获得 |
| **Beta 安全箱** | **3×2** | **6** | Prepare for Escape 版自带；**Peacekeeper 交换获得** |
| **Epsilon 安全箱** | **4×2** | **8** | 完成 Prapor 任务线 **「惩罚者 · 第 6 部分」** |
| **Gamma 安全箱** | **3×3** | **9** | **Edge of Darkness**（已停售）/ **The Unheard** 版自带 |
| **Theta 安全箱** | **10 格（非矩形）** | **10** | 经 **Ref 的任务链 / Arena 冠军路线**解锁 |
| **Kappa 安全箱** | **3×4** | **12** | 完成 Fence 任务 **「收藏家（Collector）」** |

三点必须看清：

1. **靠玩法能拿到的只有三个**——Epsilon（任务）、Theta（跨模式）、Kappa（任务）。**Kappa 与 Theta 是“免费玩家追平上限”的主要通道**；
2. **尺寸不是线性递增**：Epsilon 是 4×2，比 Gamma 的 3×3 少一格但更“扁”；**Theta 是 10 格但形状不规则**——**长条物品（步枪、部分钥匙）能否放进，比总格数更重要**；
3. **表内尺寸取官方 wiki 与中文 wiki，两者一致**；但**版本权益随时调整**，动手前以购买页与游戏内为准。

<a id="paths"></a>

### 3. 三条获取主线

| 路径 | 特点 | 适合谁 |
|------|------|--------|
| **版本自带** | 一次性、买定离手 | 已经确定要买高版本的人 |
| **商人交换** | 用材料换，绕开版本差异（如 Beta） | 不想为容器升级版本的人 |
| **任务奖励** | 靠玩法，**不花钱** | 全部玩家，尤其免费档 |

> **Kappa 的门槛值得单独提醒**：收藏家任务要求上交**一大批稀有物品，且必须“战局内拾取（found in raid）”**——**从跳蚤市场买的不算**。这是全站最硬的一条收集线，也是 [Prestige 转生](prestige.md) P5 及以上档位的硬性前置。

<a id="cases"></a>

### 4. 专用容器：把“一类东西”装进“一个盒子”

除安全箱外，还有一批**功能型容器**。它们不保证不丢（阵亡照样掉），作用是**压缩占格、方便管理**：

| 容器 | 收纳对象 |
|------|----------|
| **弹匣盒 / 弹药箱** | 整装弹匣、散装弹药——避免弹药把仓库吃掉 |
| **药品箱（Medcase）** | 医疗物资集中收纳 |
| **文件箱 / 钥匙收纳 / SICC** | 图纸、U 盘、钥匙、卡、钱包类小件 |
| **武器箱（含 THICC 型号）** | 整枪与配件，解决“枪太占格”的问题 |
| **物品箱 / 垃圾箱** | 杂项与大量低值物品的集中堆积 |
| **手雷盒 / 保温箱** | 投掷物、食品饮水的专用收纳 |

> 通用原则：**容器是“格子放大器”**——把一个 6×6 的箱子放进仓库，等于用一格换几十格的容量。仓库越满，容器越值钱。

<a id="future"></a>

### 5. 官方已预告的新型号

中文 wiki 的“即将更新”栏列出了两个新容器：**腰包（Waist pouch，4 格）**与 **Omicron 安全箱（12 格）**。

**Omicron 值得留意**：它的格数与 Kappa 相同，若落地，将改变“Kappa 是唯一顶级容器”的现状。**目前均未实装，仅作前瞻**。

## 🧭 实战要点

1. **安全箱装“回本件”**：钥匙、卡、任务物品、高价值小件——**别塞满弹药和枪**。
2. **进图前清空安全箱**：腾出格子，路上才有地方塞战利品。
3. **优先升级安全箱，而不是背包**：背包死了就没了，安全箱的内容物永远带出。
4. **用容器扩仓库，而不是买仓库行**：先看交换配方能否换到容器。
5. **想拿 Kappa 就别买对应材料**：found in raid 的硬要求，跳蚤买的不算数。
6. **注意长条物品**：4×2 与 3×3 的取舍，取决于你常带什么形状的东西。

---

## ⚠️ 常见错误

- **把安全箱当第二背包**：装了一堆弹药，真正值钱的钥匙反而没地方放。
- **以为专用容器也防丢**：**不防**。只有安全箱防丢，其他容器阵亡照掉。
- **为容器去升版本**：Beta 可用交换获得，**先查交换配方再决定花钱**。
- **忽略“不能放穿戴中的装备”**：正在用的枪和甲放不进安全箱。
- **从跳蚤买收藏家任务物品**：found in raid 不认，白买。
