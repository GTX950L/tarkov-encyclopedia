# 联赛系统 (Leagues)

<a id="top"></a>

> “它不问你打得好不好，只问你这一周打了多少。”
> —— 关于 1.1.5.1 的联赛的编者按

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 赛季内排名系统（1.1.5.1 上线） |
| **分组方式** | 每周 50 人同段位小组 |
| **排名依据** | **经验值（XP）总量**，与击杀技术无关 |
| **重置周期** | 每周重置（周日） |
| **段位数量** | 七个（I → VII 递进） |
| **适用范围** | 仅赛季角色；持久角色与 PvE 不参与 |

---

## 💡 核心机制

### 1. 它是天梯，不是匹配

最常见的误解：联赛会把你排进同段位的对局。**不会。**

联赛只是一块**每周排行榜**：把你和另外 49 名同段位玩家放进一个小组，按本周获得的经验值排序，周末统一结算升降级。你的对局对手依然是随机匹配的普通玩家。

### 2. 分组与升降规则

- 在赛季角色完成第一场 raid 后，你被分入一个 50 人小组；
- 结算时：
  - **最低段位**：前 25 名晋级，后 25 名留在原段；
  - **第二段位起**：前 25 名晋级，中间 15 名保级，后 10 名降级；
- 越往上，保级区越窄，竞争越激烈；
- 每周日重置，进入新一轮分组。

### 3. 只有 XP 算数

联赛统计的是**经验值**，来源包括：

| 计入 | 不计入 |
|------|--------|
| PMC 的 raid 经验 | Scav 获得的经验 |
| 商人任务经验（含每日/每周任务） | 竞技场中获得的经验 |
| 击杀、检视、行动等常规经验 | — |

这条规则的直接后果：**刷任务与猎 Boss 是最快的爬分方式**，而 Scav 玩法与竞技场对段位毫无帮助。

### 4. 奖励永久保留

每个段位都有对应奖励，以藏身处装饰物（浮雕类）为主，另有部分段位给予装饰海报、刀具、狗牌等。关键是：

> **奖励一旦解锁就永久保留，即使之后降级也不会收回。**

这条规则显著降低了“冲段位”的风险——冲上去拿到就赚了。

### 5. 段位与结算细则一览

| 项目 | 规则 |
|------|------|
| **组内人数** | 50 人（同段位随机分组） |
| **结算周期** | 每周一次，周末统一结算并重新分组 |
| **最低段位** | 前 25 名晋级，其余留在原段（不降级） |
| **第二段位起** | 前 25 名晋级，中间 15 名保级，后 10 名降级 |
| **高段位** | 保级区进一步收窄，晋级难度递增 |
| **段位层级** | 共七个（罗马数字递进） |
| **奖励形态** | 藏身处浮雕类装饰为主，另含海报、刀具、狗牌等 |
| **奖励归属** | **解锁即永久保留，降级不收回** |

> **为什么本页不逐项列出段位名称与奖励清单**：联赛于 1.1.5.1 首次实装，段位命名与各档奖励仍在调整窗口内，逐项列出会迅速过期。此处只保留**结构性规则**——结算位次、组内人数、奖励归属这三条是稳定的。

### 6. 反馈：被戏称为“刷经验模拟器”

由于排名纯看 XP 而不看表现，社区对其定位存在争议：有玩家认为这是一种良性的长期目标，也有玩家直接把它称作“破冰船刷经验模拟器”——因为高效率的 XP 农场（高经验地图 + 高价值击杀）几乎就是爬分的唯一解。

---

## 🧭 实战要点

1. **想爬分就选经验效率最高的地图**：XP/小时 是唯一指标。
2. **任务优先**：商人任务（尤其每日/每周）是稳定且可预期的经验来源。
3. **Scav 用来回血，不用来爬分**：它对段位没有贡献。
4. **周末前冲刺**：结算在周内固定时点，规划好最后一两局的节奏。
5. **拿到奖励就安心**：降级不收回，所以激进冲级的代价比想象中小。

---

## ⚠️ 常见错误

- **以为会匹配同段位对手**：它不是匹配系统。
- **靠竞技场刷段位**：竞技场经验不计入。
- **用 Scav 冲榜**：同样不计入。
- **把段位当成实力证明**：它衡量的是投入时长与效率，不是枪法。
