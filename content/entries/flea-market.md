## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 玩家经济系统 |
| **解锁条件** | 与**商人忠诚度 / 声望**挂钩（1.1 起调整）；历史上曾为固定等级门槛（约 15 级） |
| **赛季差异** | 赛季模式常通过全局修改器**进一步延后开放**，用于压制早期通胀 |
| **货币** | 卢布为主（部分物品可挂其他货币） |
| **买方** | **没有求购盘**——只能在别人已挂好的出售单里挑（见第 2 节） |
| **卖方** | 只能卖**战局里捡到的（FiR）**；挂单要交税，撤回不退税 |
| **卖家信誉** | 从 **0.20** 起步，决定**可同时挂单数**（1 → 8 单）；挂单没成交会掉信誉 |
| **货款到账** | 不直接进钱包，由 **Ragman 用邮件寄送**（有领取期限） |
| **限制** | 部分物品禁止上架（安全箱、比特币、货币、散装弹药与部分成品装备） |

## 💡 核心机制

### 1. 玩家对玩家的市场

跳蚤市场是全服玩家之间的交易平台：

- **卖出**：把战利品上架变现，价格随行就市；
- **买入**：从其他玩家手里淘枪、配件、任务物品与弹药；
- 价格由供需决定——**任务物品在任务周期里会暴涨**，这就是“倒爷”的生存空间。

> **先纠正一个最常见的误解**：跳蚤市场**没有“求购盘”**。它不是股票或 Steam 社区市场那种“买盘卖盘撮合”的拍卖行——**你无法挂出“我出 X 卢布收某物”的买单**。
> 全市场只有一种东西：**出售挂单（Offer）**。想买东西，就是在别人已经挂好的单子里挑一个点“购买”。
> 这一条决定了后面所有买卖策略——**你买到的价格，永远取决于当前有谁挂了单**。

### 2. 买方：三种拿货方式

<a id="buy"></a>

界面在 `交易 → 跳蚤市场` 下分三个标签页，买方用得上的是前两个：

| 方式 | 在哪 | 怎么用 | 适合 |
|------|------|--------|------|
| **① 直购（一口价）** | `浏览 / Browse` | 左侧分类或搜索框找到物品 → 看挂单列表 → 选中点**购买** | **急用**——任务物品、缺的弹、缺的配件 |
| **② 愿望清单** | `W-List / 愿望清单` | 右键任意物品 → **加入愿望清单**；集中在这里看它的**当前最低价与库存** | **不是急用**——用来盯价格，等它掉下来 |
| **③ 以物换物** | `浏览 / Browse` | 挂单的**要求栏可以填物品而不是货币**——所以列表里有一部分单子是“用物品换物品” | **清库存**：用闲置物品抵价，或专门去换某件稀有物 |

**三条买方判断**：

1. **便宜的单子会被秒**——市场是全服共享的，**看到明显低于均价的挂单，犹豫就等于放弃**；
2. **愿意等就用愿望清单**，别守在浏览页刷。任务物品的价格在**任务高峰期**最高、**低谷期**最低，跟着[经济周期](economic-cycle.md)走能省一大截；
3. **以物换物的单子要会算账**：它给的是**物品对物品**，得先把要求的那几件按跳蚤价折算成卢布，再和“直接买 + 把闲置物卖掉”对比——**两边的税不一样**，别只看标价（见[跳蚤定价与手续费](flea-pricing.md)）。

### 3. 卖方：挂单、信誉与槽位

<a id="offer"></a>

卖方动作都在 `我的挂单 / My Offers` 与顶部的**添加挂单**里。要点有四层：

**① 只能卖“战局里捡到的”（FiR）**——从跳蚤买来的东西**不能再挂回跳蚤**，从商人买来的也不行。这条直接封死了“低买高卖赚差价”的纯倒卖玩法。

**② 挂单要交税**，费率与挂价挂钩，且**挂价越离谱、税越重**（完整算法见[跳蚤定价与手续费](flea-pricing.md)）。撤回挂单**不退税**。

**③ 卖家信誉决定你能同时挂几单**（社区口径，随版本调整）：

| 信誉区间 | 可同时挂单数 |
|----------|--------------|
| 起始 0.20 以下 | 1 |
| 0.2 – 30 | 2 |
| 30 – 70 | 3 |
| 70 – 150 | 4 |
| 150 – 500 | 5 |
| 500 – 1000 | 6 |
| 1000 以上 | 8 |

- **信誉从 0.20 起步**，**每成交约 ₽50,000 涨 0.01**；
- **挂单没卖出去（含主动撤回）会掉信誉**——槽位是会**缩水**的；
- 槽位是硬约束：**挂一货架便宜货，不如挂两件大件**。

> 信誉与槽位的具体档位表属**社区整理**，官方未完整公布；数量级可信，边界值以游戏内为准。

**④ 卖出去的钱不直接进钱包**——货款由 **Ragman 用邮件寄给你**，有领取期限（见[邮件与领取](mail.md)）。**别卖完就下线，记得回去取。**

### 4. 卖不了的东西

并非所有物品都能上架，以下类别被**限定为商人交易**（官方与社区口径，随版本调整）：

- **安全箱**（所有型号）与**比特币**；
- **货币类**物品；
- **散装弹药**；
- 一部分**武器、护甲、胸挂、背包与头盔**（成品的限制比配件严得多）。

> 判断方法很简单：**右键物品，看有没有“上架跳蚤”的入口**。看不到就是不能卖。

### 5. 弹药与任务品的特殊行情

- 高端弹药常年是跳蚤硬通货（受获取限制版本影响波动）；
- 任务物品价格随“当前全服任务进度”波动——某任务火了，对应物品涨价。
- **赛季角色**要注意：跳蚤开放时间可能被修改器**进一步推迟**，早期只能靠商人与 raid 收益过渡。

## 🧭 实战要点

1. **变现优先级**：低价值杂货卖商人（免手续费省心），高价值物品挂跳蚤。
2. **买方要快**：市场是全服共享的，**看到明显低于均价的挂单，犹豫就等于放弃**；真想省钱就先把目标价格记在心里，出现即下手。
3. **不急的东西进愿望清单**：`W-List` 是唯一能替你“盯价”的地方，别守着浏览页刷。
4. **捡漏时段**：版本更新前后、深夜时段，定价失真多，适合淘宝。
5. **倒任务品**：预判任务趋势囤货有利润，但也有砸手里风险——量力而行。
6. **关注交易税**：挂高价不等于到手多，扣完税再比价。
7. **卖完记得取货款**：货款走 **Ragman 的邮件**，**有领取期限**——卖完就下线，等于把钱留在邮局（见[邮件与领取](mail.md)）。
8. **解锁前的过渡**：跳蚤开放前只能靠商人与 raid 收益，这也是[藏身处](hideout.md)的前期价值；赛季角色更要提前规划，因为开放时间可能被修改器推迟。
9. **配合商人价格重整**：1.1 之后商人售价整体上调，跳蚤与商人的**比价空间变大**，买前多看一眼往往能省一截（见[重大版本更新史](../docs/version-history.md)）。

## ⚠️ 常见错误

- **以为能挂“求购”**：跳蚤**没有买单**——你只能买别人挂出来的东西，不能挂个价等别人卖给你。想等价格下来，只能用愿望清单盯着。
- **从跳蚤买了再挂回去**：不允许。**只有战局里捡到的（FiR）才能上架**，“低买高卖”在跳蚤行不通。
- **什么都在跳蚤卖**：低价值物品的税可能吃掉全部利润。
- **抄最低价**：盲目跟最低挂价互相踩踏，学会挂“次低价”。
- **忽略上架位上限**：格子有限，挂一货架便宜货不如挂两件大件；而且**挂单没成交会掉信誉**，槽位会越用越少。
- **忘了取货款**：货款在邮件里，**过期就没了**。
- **忘了商人回购**：有时候商人直接买更划算，比价永远是第一步。
