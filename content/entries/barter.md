# 以物换物 (Barter)

<a id="top"></a>

> “商人从不做慈善。他用卢布卖你一件东西，也用一堆破烂卖你同一件东西——而破烂里，常常藏着套利空间。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 交易方式（物品换物品） |
| **提供方** | 全部商人（含 Fence 的黑市交换） |
| **解锁条件** | 与商人**声望等级（Loyalty Level）**绑定 |
| **是否用卢布** | 不用。**完全不涉及货币** |
| **库存规则** | 有**补货周期**与**限购数量**，与卢布商品一并刷新 |
| **核心用途** | 换到**没有卢布报价**的物品、绕开跳蚤手续费、用低价材料换高价成品 |
| **关键风险** | 换亏了不退款，**没有“按错”的撤销** |

---

## 💡 核心机制

<a id="two-ways"></a>

### 1. 商人的两张价签：卢布与物品

塔科夫的交易系统有两种原则：**“钱换物”**与**“物换物”**。同一件商品，往往同时挂着两张价签——一张是卢布价，一张是材料清单。

这带来一个直接结论：**一件东西“贵不贵”，要看你手里有什么**。

- 你仓库里堆着的那批材料，在跳蚤市场上可能只值几万；
- 但它们正好凑成一份交换配方时，**它们的“使用价值”是那件成品，而不是它们的市价**。

<a id="loyalty"></a>

### 2. 交换配方也被声望锁着

和卢布商品一样，**交换项同样按声望等级开放**：

- 声望等级不够，配方**不显示**或**不可用**；
- 部分配方有**限购数量**，每次补货重置；
- Fence 的交换项与其**Scav 声望（Karma）**挂钩，规则与常规商人不同。

> **一个需要核对版本的点**：官方支持页把“与该商人的**交易额**”列为提升声望的条件之一，但社区资料称第一赛季起已移除这项门槛。两者说法不一，**请以游戏内商人面板上写明的条件为准**，不要照搬任何单一来源。

<a id="evaluate"></a>

### 3. 怎么判断一次交换划不划算

方法只有一条：**把配方材料折算成卢布，再和目标物品的市价比**。

| 步骤 | 做什么 |
|------|--------|
| ① 列材料 | 记下配方要求的每一样物品与数量 |
| ② 查市价 | 逐样查**跳蚤最低价**（不是商人收购价） |
| ③ 求和 | 材料总市价 = Σ（单价 × 数量） |
| ④ 对比 | 与**目标物品的跳蚤价**比；差额就是这次交换的净收益 |
| ⑤ 加一步 | 若目标物品**不能上跳蚤**，则与它的**商人卢布价**比 |

**第 ⑤ 步是分水岭**：如果那件东西跳蚤买不到，你就没有“直接买”的替代方案，交换几乎是唯一路径，此时“划不划算”的问法本身就不适用了。

<a id="sources"></a>

### 4. 一个有用的估值锚：商人收购系数

判断“手里这堆材料值多少”，除了查跳蚤价，还可以用**商人收购系数**做快速估算——**卖给商人的价格 = 物品底价 × 该商人系数**：

| 商人 | 系数 | | 商人 | 系数 |
|------|------|---|------|------|
| **Therapist（治疗师）** | **0.63** | | Jaeger（猎人） | 0.60 |
| **Ragman（旧衣商）** | **0.62** | | Mechanic（技师） | 0.56 |
| Prapor（军备官） | 0.50 | | Skier（走私客） | 0.49 |
| Ref（竞技场裁判） | 0.50 | | Peacekeeper | 0.45 |
| | | | **Fence（黑市）** | **0.40** |

两条前提必须记住：

1. **系数乘的是“底价”，不是市场价**。而且**用过的、掉耐久的物品底价本身就被压低**——别拿一把打废的枪去算它“值多少”；
2. 系数表来自社区 wiki，**商人价格经历过整体重整**（见[商人系统](traders.md)），把它当作排序参考而不是精确账本。

<a id="examples"></a>

### 5. 什么时候交换明显更优

| 场景 | 为什么交换更优 |
|------|--------------|
| **物品没有卢布报价** | 只能换，没有第二条路。典型如部分弹药、配件与容器 |
| **材料你本来就有** | 成本是“沉没的手边货”，边际支出接近零 |
| **材料在跳蚤被压价** | 别人急着出手，你按跳蚤价收货，等于折价买成品 |
| **想绕开跳蚤手续费** | 交换不产生上架费与成交税（见[跳蚤定价与手续费](flea-pricing.md)） |
| **容器类升级** | 例：Beta 安全箱可由 **Peacekeeper 交换**获得（见[安全箱与容器](containers.md)） |

反过来说，**当材料市价高于成品市价时，交换就是亏的**——这在大版本后材料被炒高的窗口期很常见。

## 🧭 实战要点

1. **先把声望刷到能看配方**：看不到配方，等于没有这个体系。
2. **补货前对一遍配方**：值得换的配方通常会**售罄**，抢的是刷新那一刻。
3. **把“换来的东西”和“买来的东西”分开记账**：交换的隐性成本是材料的机会成本。
4. **囤料先想好用途**：为特定配方囤材料，比无目的地捡垃圾划算得多。
5. **对没有卢布报价的物品优先考虑交换**，那是硬需求。
6. **Fence 单独看待**：它的交换项与 Scav 声望挂钩，规则不通用。

---

## ⚠️ 常见错误

- **只看成品价格、不看材料总价**：这是最常见的亏法。
- **用商人收购价估材料**：那是卖出价，会用低于真实市价的方式高估收益。
- **拿磨损物品的底价当标准**：耐久会直接压低估值。
- **忘了限购**：以为能反复换，实际补货前只能换固定数量。
- **把交换当“免费”**：材料本来就是钱，只是形态不同。
