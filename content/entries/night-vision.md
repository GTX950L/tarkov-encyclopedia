## 💡 核心机制

### 1. 夜视仪的层级

夜视仪按**代际**分层，代际越高，图像越清晰、噪点越少、可视距离越远：

| 层级 | 表现 | 定位 |
|------|------|------|
| 一代 | 模糊、噪点多 | 入门，聊胜于无 |
| 二代 | 可用、边缘畸变 | 中档，多数玩家的选择 |
| 三代 | 清晰、远距 | 高端，价格昂贵 |
| 多目（四眼等） | 视野最宽 | 顶级，重量与价格都最高 |

部分型号使用**白磷**显像，画面更接近自然灰度，长时间观察更不易疲劳。

### 2. 型号对照：代际不是型号

上一节的**代际是性能档，不是商品名**——「三代」不是一个能买的东西。**这一节解决“买哪个”，以及更常被忽略的一件事：它装在哪。**

#### 2.1 头戴式夜视仪（NVG）

| 形态 | 代表型号 | 说明 |
|------|----------|------|
| **单目（入门）** | PNV-10T、PNV-57E | 苏系单目，代际靠后，价格最低的一档 |
| **单目（通用）** | L3Harris AN/PVS-14 | **最通用的一档**，配件生态最全，可上头盔也可头戴 |
| **双目** | Armasight N-15、L3Harris PVS-31A | 立体感与舒适度明显提升，重量翻倍 |
| **四目** | L3Harris GPNVG-18 | **视野最宽**，重量与价格同样顶格 |

**形态的分水岭是“目数”**：单目 → 双目 → 四目，每上一档，**视野与舒适度上升，重量与价格同步上升**。

#### 2.2 夜视瞄准镜（装在枪上）

NSPU-M 3.5x、Armasight Vulcan MG 3.5x Bravo 一类——**把夜视装到枪上，就等于把“观察”和“射击”合并成同一件事**，代价是重量与视场。

#### 2.3 挂架：最容易被漏掉的那一件

**没有挂架，夜视仪就是一块砖。** 官方数据里的挂架与它同样多：

| 形式 | 代表型号 | 适用 |
|------|----------|------|
| **头戴挂架** | Wilcox L4G24（黑 / 沙色） | 最通用的一档，装在头盔前部 |
| | ANAVS-69 | 另一套头戴平台 |
| | Wilcox Skull Lock Head Mount（PVS-14 用） | 以头盔为平台的紧固结构 |
| | AN/PVS-14 Dual Dovetail | **把单目改成双目的转接座** |
| | PVS-7 Wilcox Adapter | PVS-7 专用转接 |
| **头带 / 绳带** | Armasight NVG Head Strap | 最廉价的固定方式，不依赖头盔 |

> **一条买装备时会付出代价的推论**：**夜视装在头盔导轨上，所以“你的头盔支不支持导轨”决定了你能不能戴夜视。** 这也是为什么[护甲与头盔图鉴](armor-catalog.md)里那几款**模块化平台头盔**（如 Ops-Core FAST MT）值得多花的钱——它们买的是**扩展位**，不是护甲值。

#### 2.4 热成像型号

| 用途 | 代表型号 |
|------|----------|
| **头盔式** | T-7 热成像护目镜（带夜视挂架）、Iridium 军用热成像模块 |
| **枪用瞄具** | Trijicon REAP-IR、Flir RS-32、Armasight Zeus Pro 640、Cyclone Shakhin 3.7x、Sig Sauer Echo1、Torrey Pines T12W |
| **其他形态** | MP-155 Ultima 热像仪（霰弹枪专用） |

#### 2.5 关键数值：重量、视野、出处

选型的三个硬约束是**重量（背它就得少带别的）、视野（看得广不广）、从哪买**。已核到一级来源的写在表里；**未取到**的一律留白——**本站不凭印象填数**。

| 型号 | 形态 | 重量 | 视野 / 探测 | 出处 |
|------|------|------|-------------|------|
| **PNV-10T** | 双目（伪双目） | **0.8 kg**（占 2×1 格） | **第二代**；**一局内最多只能带 5 个** | Skier **LL2** |
| **L3Harris AN/PVS-14** | 单目 | **0.65 kg**（占 1×1 格） | **FOV 40°**，**最远探测 350 m**，**亮度可调** | Skier **LL3** |
| Armasight N-15 | 双目 | — | — | — |
| GPNVG-18 | 四目（带支架） | — | — | — |
| **T-7**（热成像） | 头戴式，带夜视挂架 | — | 两种视野模式：**Full View / Comparison View** | — |

来源：二级（英文 EFT Wiki）。**两件单目之间那 0.15 kg 的差距、以及「PVS-14 能看 350 m、PNV-10T 只说第二代」的差别，正好说明为什么「代际」不是选型的唯一一把尺**——同一代里，重量、视野与出处（LL2 还是 LL3）各自都可能成为决定项。

> **⚠️ 一处来源缺口（如实标注）**：本表只核到 2 款夜视仪与 T-7 的完整数值；**其余型号的视野角度在英文 EFT Wiki 上未列数值**（只有型号名）。**留白不是没查，是查不到可核的数**——这正是本页不写「约 90°」这类估值的理由。

**读型号的两条捷径**：

1. **前缀是厂牌**（L3Harris / Armasight / Wilcox），**数字通常是代际、倍率或口径**——**不是等级**，别按数字大小排序来理解性能；
2. **同型号可能有多种挂轨规格**（俄系侧轨 vs 皮卡汀尼一类）。**买之前先确认它配你的枪或你的头盔**——这是这类装备最常见的白花钱。

### 3. 热成像的逻辑完全不同

热成像不放大光子，而是**识别热源**。它的价值在于：

- 隔着部分植被、烟雾、昏暗环境发现目标；
- 不需要环境光，白天夜里都能用；
- 但画面分辨率有限，**不适合精细瞄准与辨认敌我**。

热成像瞄准镜通常安装在枪上，这意味着你必须**用主武器换视野**。

### 4. 电池成本

不少夜视设备需要电池供电，电池耗尽后设备就是一块砖。这意味着带夜视进图，**必须同时带备用电池**——这是最容易被忘掉的一项。

### 5. 反制与被反制

夜视不是单向优势：

- 你的**红外指示器/激光**在对手的夜视仪里非常醒目；
- **照明弹、战术手电、白磷**会直接“致盲”夜视使用者，闪光效应在夜视下更严重；
- 在真正全黑的环境里，没有夜视的人几乎是活靶子——所以它依然是夜图的主导装备。

## 🧭 实战要点

1. **先配电池再配夜视**：没有备用电池的夜视仪，是一次性道具。
2. **别在夜视下开强光**：你自己开灯，等于给全图报点。
3. **热成像用来发现，不用来精瞄**：看到热源之后，切换光学做精细射击。
4. **头戴夜视与高倍镜难以兼得**：大多数情况下需要在“观察”和“射击”之间做取舍，改装前先确认导轨与配件兼容。
5. **买夜视要按“两件”下单**：**设备 + 挂架**缺一不可；下单前先确认你的头盔有没有导轨位。
6. **白天也有用处**：昏暗的室内与地下空间，夜视带来的信息优势同样明显。

## ⚠️ 常见错误

- **忘记带备用电池**：夜视在关键时刻变砖，是最常见的高级玩家失误。
- **戴着夜视仪打远距离**：噪点与畸变会毁掉你的精度。
- **开强光/激光暴露自己**：在有夜视对手的局里，这是自报坐标。
- **把热成像当夜视的升级版**：两者解决的是不同问题，不能互相替代。
- **买了夜视忘了挂架**：到货才发现头盔没有导轨位——**这类返工每一轮都会有人踩**。
- **按数字大小理解型号**：L3Harris 后面的数字是型号代号，不是性能排序，别想当然。
