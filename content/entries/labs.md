## 💡 核心机制

### 1. 它是唯一一张“全员精英”的图

实验室和其他所有图的区别，可以用一句话概括：**这里没有“过渡遭遇”**。

| 常规图 | 实验室 |
|--------|--------|
| 有 AI Scav 搅局，交火强度参差 | **没有 AI Scav**，但有 **Raiders** 组队巡逻 |
| 一部分玩家是低装新手 | **进图的人几乎都带夜视与顶级弹药** |
| 死亡成本可控 | **死一次亏掉的，可能抵得上海关十次** |

**推论**：**实验室的胜负在进图前就决定了一半**——装备不达标的话，进去只是给别人送补给。

### 2. Raiders 不是 Scav，是一条战术链

Raiders 会**拉枪线、会包抄、会补枪**——他们的战术素养接近玩家小队。**把他们当 Scav 打的人都留在了里面。**

<a id="keycards"></a>

### 3. 钥匙卡经济：卡 ↔ 房间 ↔ 产出

实验室有**六张彩色钥匙卡**，每张对应一个独立房间。卡的颜色**固定对应一扇门**——颜色本身不代表贵重程度，真正的差别在**门后面是什么**。这让实验室形成了一条独特的循环：**买卡 → 进图 → 开房 → 撤出**，风险与回报都集中在那几个房间里。

| 钥匙卡 | 房间性质 | 主要产出 |
|--------|----------|----------|
| **蓝卡** | **隔离区**（医疗） | 医疗物资为主——**LEDX、除颤器**、眼底镜这类顶级医疗件的出处 |
| **绿卡** | **实验区** | 医疗件与技术件混装，另有零星弹药与武器配件 |
| **黑卡** | **医疗实验区** | 注射剂成堆，另有医疗箱与高级技术件 |
| **红卡** | **军械库** | 高级武器与武器箱、高价值杂项——**收藏家任务物品的集中地** |
| **紫卡** | **安全哨所** | 武器箱与高级技术件，是电子类高价值件出现得较稳定的一档 |
| **黄卡** | **报警／控制室** | 保险柜、电子件与杂项；**并控制停车场大门撤离点的广播开关**（见下节） |

> **表注**：**这张表按社区口径处理** —— 英文 EFT Wiki 只确认「有六个分别需要对应颜色卡的房间」以及「**黄卡＝报警系统控制室**」，其余**房间性质与主要产出的描述来自社区来源**，引用时请写成「社区口径认为…」；各来源对房间**编号**（G11 / G22 / R23 之类）的说法也不一致，本表**只写性质与产出、不写编号**——与站内「不列坐标」的原则一致。**颜色与门的对应关系是稳定的**，房间内的具体产出随版本微调。

**一条判断**：**卡的开销是固定的，收益是波动的。** 一张卡的价格来自它的期望产出，而不是它的历史最高价——所以「这张卡值不值得买」问的不是卡，是你的**路线能不能安全走到那扇门前、并且活着出来**。

<a id="broadcast"></a>

### 4. 出口会“广播”：全游戏最特别的一条机制

实验室有一套**全图广播系统**。**除了两处例外，你激活任何一个撤离点，都会向全设施播报一次**——所有还活着的人都知道「有人要从哪个口走了」。

| 撤离点 | 是否广播 | 附加条件 |
|--------|----------|----------|
| **通风管道** | **不广播** ✅ | **不能背背包**——带包就走不了 |
| **污水管道** | **不广播** ✅ | 需先降下水位，**要等约一分半** |
| 货运电梯 / 主电梯 / 医疗区电梯 | **广播** ⚠️ | 需先给电梯送电 |
| 停车场大门 / 机库大门 | **广播** ⚠️ | 需先去对应房间按开关开门 |

两条容易漏掉的细节：

1. **停车场大门的广播可以关掉**——报警系统控制室里有开关，**进那间房要黄卡**（见上节钥匙卡表）；
2. **激活撤离开关还有另一个副作用**：有概率**刷出 Raiders 并朝开关位置搜索**——所以「开完开关就在原地等」是最差的处理。

> **推论**：**实验室的核心不是「出口要卡」，而是「你一开出口，全图都知道你在哪」。** 这决定了它的节奏——捡满之后，**出口的选择比路线更重要**：带着一包东西走一个会广播的口，等于把这一局剩下的时间交给别人来蹲。这也是它 raid 时长短、却依旧寸步难行的真正原因。

### 5. 时间压力是全游戏最大的

实验室 **raid 时长短 + 全图 PMC 密度高**，容不下“再搜一间”。

### 6. 「暗版」：另有一套局（Blackout）

<a id="dark"></a>

常规版之外，实验室还有一套**「暗版」战局**——**全图断电、黑师接管、撤离点被锁**。它不是难度选项，是**一批换掉的规则**；照着常规版的记忆打会吃大亏。

**先说准入（这一条以前站内写错过）**：进「暗版」**靠的是钥匙卡，不是等级**。

| 项 | 内容 | 来源 |
|----|------|------|
| **准入** | **TerraGroup Labs 访问钥匙卡**，**进图消耗**；组队时**每人各带一张** | 二级（英文 EFT Wiki） |
| **从哪来** | 购买：Therapist **LL2 / LL3 / LL4**、Ref **LL3**；以物换物：Mechanic **LL1**（1× 武器零件）、**LL2**（Bulbex 电缆剪 + 管钳扳手） | 二级（英文 EFT Wiki） |
| **带不进去的东西** | **彩色卡一律不能带进图**，唯一例外是**黑卡**（TerraGroup Labs keycard (Black)） | 二级（英文 EFT Wiki） |

**规则变化**（与常规版的差别）：

| 项 | 「暗版」里是 | 来源 |
|----|--------------|------|
| **光照** | **全图灯全灭**，开局约 **10–15 秒**后断电；夜视/热成像从“建议”变成**前置条件** | 一级（灭灯）/ 社区口径（秒数） |
| **撤离点** | 只剩 **停车场大门（Parking Gate）与机库大门（Hangar Gate）**，且**必须先去系统管理办公室激活**才能用 | 二级（英文 EFT Wiki） |
| **转场** | **出图的转场不可用，进图的转场仍可用** | 二级（英文 EFT Wiki） |
| **战局时长** | **PvE 提高到 35 分钟**（比常规局更宽，但路更远、事更多） | 二级（英文 EFT Wiki） |
| **门禁** | **所有键盘锁共用一套 4 位码**，码在系统管理办公室的墙上；**每局重掷**——抄别人的码没用 | 二级（英文 EFT Wiki） |
| **管理办公室钥匙** | **Wedge 必掉**；他的随从与其他黑师**有概率**掉 | 二级（英文 EFT Wiki） |
| **事件任务线** | 5 环：Wrench and Waterboarding → Key to Every Door → My Blood Type Mark is on the Sleeve → Patch the Vulnerability → If I Can't Have It，全清解锁「Going Dark」成就 | 二级（英文 EFT Wiki） |

> **为什么「一套码开全门」是这张图最大的变量**：常规版里，价值集中在**你带了哪几张卡**；「暗版」里，价值集中在**谁先摸到系统管理办公室**。于是路线从“开哪几个房”变成“**抢哪一条去办公室的路**”——而办公室里同时有**全部门禁码**与**两个撤离点的激活开关**，等于把「钥匙」与「出口」锁在同一间屋。

> **⚠️ 一处社区口径**：有社区来源称，事件任务线的开场任务 Wrench and Waterboarding 另有**角色等级 30** 的门槛（未见于英文 EFT Wiki 的事件说明）——**引用时按社区口径处理**。

## 🗺️ 区域结构

<a id="areas"></a>

| 区域 | 特征 | 主要风险 | 该注意什么 |
|------|------|----------|------------|
| **车库层** | 相对开阔的地下层 | 视野尚可但掩体少 | 通常作为进场缓冲层 |
| **办公层** | 房间与走廊交错 | 房间门口固定伏击位 | 一次清一间，别串联推进 |
| **实验区与病房** | **任务与钥匙房密集** | 高价值区＝高遭遇率 | 开卡前先清周边 |
| **服务器机房** | **高价值电子件（显卡等）的经典出没地** | ⭐ 全图最热门的搜刮点 | 这里的人比你想象的多 |
| **雷达穹顶层** | 视野标志区，**交火核心** | 开阔 + 多向通视 | 通过时按“过街”处理：分段、贴边 |
| **垂直交通（电梯 / 楼梯）** | 换层的唯一途径 | ⚠️ **伏击圣地** | 换层前**先听、先看、先扔雷** |

## 🎯 关键 AI：Raiders

<a id="boss"></a>

| 项目 | 内容 |
|------|------|
| **身份** | **精英 AI**——装备精良、战术素养高 |
| **编队** | 常**组队巡逻**，会互相掩护与包抄 |
| **战术** | **会拉枪线、会补枪**——不是“站着让你打”的靶子 |
| **防护** | 穿**高等级护甲**，低穿弹基本无效 |
| **应对** | ① **高穿深弹药是硬门槛**；② **别在走廊里跟他们打“排队枪毙”**；③ 利用掩体与手雷拆解队形（见[交火中的技术动作](firefight.md)） |
| **对比** | 他们不是 Scav，也不是 Boss——**他们是“装备和你一样、战术比你好的对手”** |

> **一条判断**：**如果你打 Raiders 需要超过两梭子，那是弹药问题，不是枪法问题。**

## 🧭 实战要点

1. **夜视仪几乎是标配**：实验室光照昏暗，没有夜视就等于蒙眼格斗。
2. **穿甲弹必须带满**：Raiders 和玩家都穿高级甲，低穿弹在这里是水弹。
3. **先定楼层路线再进图**：实验室迷路 = 等死。规划“哪层进、哪层搜、哪层撤”。
4. **楼梯与电梯是伏击圣地**：换层之前先听、先看、先扔雷。
5. **进图前定好开哪几个房**：只认钥匙房，不认“顺路看看”。
6. **出口要比路线先想好**：除通风管道与污水管道外，**激活任何撤离点都会向全设施广播**——捡满之后，走哪个口是这一局最后、也最重要的一次决策（见上文[出口会“广播”](#broadcast)）。
7. **别贪最后一个房间**：时间压力 + PMC 密度，容不下加时。
8. **确认钥匙卡**：部分入口需要钥匙卡，没卡进不去——**出发前别忘带**。
9. **把医疗与备用弹带足**：这里的战斗不会是“一波结束”。
10. **知道还有「暗版」这回事**：准入、断电、撤离点、门禁全都不一样——**按一张新图重新熟悉，别照搬老路线**（规则见[核心机制 §6](#dark)）。

## ⚠️ 常见错误

- **带着森林装备进实验室**：远程枪在走廊里是烧火棍。
- **低估 Raiders**：他们会拉枪线、会包抄，把他们当 Scav 打的人都留在了里面。
- **贪最后一个房间**：实验室的时间压力与全图 PMC 密度，容不下“再搜一间”。
- **不带夜视**：光照是这张图的第一道门槛。
- **忘了带钥匙卡**：到了门口才发现进不去，等于白跑一趟。
- **在出口不设防**：实验室的撤离点会**广播**——开完开关就站在门口等，等于把自己的位置播给全场；**通风管道要卸背包**，这条别到了跟前才发现。
- **用低穿弹打 Raiders**：那不是“打得吃力”，那是“打不动”。
- **把暗版当常规版打**：「暗版」是**另一套局**——全图断电、只剩两个需激活的撤离点、**一套码开全部门**；**旧路线与旧撤离点都不成立**（规则见[核心机制 §6](#dark)）。
