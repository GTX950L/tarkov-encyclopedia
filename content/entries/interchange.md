## 💡 核心机制

### 1. 全室内 + 光线差 = “谁先看见谁”被放大到极致

立交桥的核心不是商场有多大，而是**它几乎没有自然光**：

| 常规经验 | 在立交桥的实际情况 |
|----------|--------------------|
| “开阔地最危险” | **这里的危险是“转角”**——视线被柱子与货架切成一个个短段 |
| “看得远有优势” | **看得远没用**，转角只给你 10 米 |
| “先开枪有优势” | **先“看见”才有优势**——而光线决定了你能不能看见 |

**三条推论**：

1. **照明手段不是可选项**：手电或夜视至少带一样，否则你在商场里就是半盲（见[光照与夜战](lighting.md)）；
2. **先手优势被放到最大**：室内距离短，**先看到对方的人几乎必胜**——所以“控制视野的来向”比“枪法”重要；
3. **背身是全图第一死因**：搜刮时背对入口，等于把命交给下一根柱子后面的人。

### 2. 环廊：一条有“方向性”的长视线

商场是**多层环廊**结构——这意味着存在**又长又直**的走廊。它塑造了两种完全不同的处境：

- **你是守方**（架着环廊）：你拥有先手，胜率极高；
- **你是攻方**（要穿过环廊）：**必须分段推进**，借柱子和店门一格一格换位置。

> **纪律**：**移动方永远吃亏**。所以在立交桥，“停在一个有掩体的位置等人来”往往比“沿环廊推进”更划算。

### 3. 地下层是一张独立的图

地下停车场与商场主体**规则完全不同**：更暗、更窄、声音传得更远、撤离点更多。它的价值在于**绕过主战场**——但代价是你放弃了视野，把遭遇距离压到**贴脸**。而且这片区域**住着 Tagilla**：地下不再是「安全的绕行路线」，走这条路之前先想清楚（见下文 [Boss](#boss) 一节）。

<a id="kiba"></a>

### 4. KIBA：一座需要三件东西才能进全的军械店

商场里有一家店，是**全图最难进、也最值钱**的战利品点——**KIBA 军械店**（KIBA Arms）。它把三种性质完全不同的「门槛」叠在了一起，缺一件就只进得去一半：

| 门槛 | 是什么 | 从哪来 |
|------|--------|--------|
| **外层店门钥匙** | 开 KIBA 的正门 | **图内拾取**：电力站管理室的书架上、Goshan 帐篷边的书后面；也可用 60 罐炼乳 + 10 包燕麦片找 Therapist 换 |
| **内层铁栅钥匙** | 开正门后面那道铁栅门 | **任务产出**：Mechanic 的**「枪匠 Part 11」**（需 20 级）——**这把钥匙不是买的，是做出来的** |
| **全楼通电** | 两道锁**都要求商场处于供电状态**才能操作 | 去电力站合闸（见下节） |

**为什么它值得单独讲**：它把「**任务奖励本身就是一把钥匙**」这个设计模式摆在了明面上——市面上买不到，只能靠做任务拿（或从别的玩家手里买）。同时它也是**多条件耦合**的教科书案例：**图内拾取 + 任务发放 + 环境条件，三者缺一不可**。

> **两条细则**：① 通电状态下开 KIBA 正门会**触发店内警报**——警报可以在商场内两处终端关掉（一楼保安室能关掉全部；二楼服务台只关不掉包含 KIBA 的那部分）；② **Killa 常在自动扶梯一带巡逻**，而 KIBA 就在商场中庭第一层，所以这里几乎每局都会打成小队对枪。**想练枪来这里，想稳赚要挑时候来。**

（顺带一提：**Kiba** 这个名字本身是个彩蛋——取自 Battlestate 首席动画师的昵称，见[彩蛋与制作组的恶意](easter-eggs.md)。）

<a id="power"></a>

### 5. 全楼的电，是「某个玩家按的开关」

立交桥的照明**不是常亮的**——它由**商场外电力站**的一个总闸控制。

| 状态 | 场上是什么样 |
|------|--------------|
| **未合闸**（默认） | 商场内部**只有应急照明与采光天窗**，绝大多数通道是暗的 |
| **已合闸** | 全楼照明点亮；同时**解锁一批需要供电的锁**——KIBA 两道门、ULTRA 医疗储藏室、停车场的 Object #21WS 容器与 Object #11SR 安全屋撤离等 |

这就解释了一件事：**「灯光骗术」之所以成立，前提是光照本身是个变量**。你在图上看到的明暗，不是版本固定的美术设定，而是**这一局有没有人先去电力站**的结果。于是：

- **你要用到那些需要供电的门** → 进图后先确认电合上没有；**没合就先想清楚值不值得去电力站跑一趟**（电力站离商场主体有距离，来回是一段暴露的时间）；
- **你只想安静搜刮** → 断电状态的商场对所有人都更暗，**夜视与手电的价值随之上升**（见[光照与夜战](lighting.md)）。

> **一条纪律**：**别在合闸的前后站在长视线上**。照明一亮，环廊上所有人的视野同时变长——那一刻暴露的多半不是你要找的人，而是你自己。

## 🗺️ 区域结构

<a id="areas"></a>

| 区域 | 特征 | 主要风险 | 该注意什么 |
|------|------|----------|------------|
| **商场主体（环廊）** | 多层环廊 + 店铺密布，**柱体、货架与橱窗构成复杂掩体网** | 长走廊上的先手对枪；**背身** | 移动时分段推进；停下时**背靠掩体、面向来路** |
| **OLI 超市** | 高价值物资区，**Killa 的经典活动范围** | 既是物资点也是 Boss 点 | 来之前先想清楚：**你是来搜的，还是来打的** |
| **IDEA 电器城** | 电子件与电脑集中区 | 搜刮党聚集 → **同行遭遇率高** | 直奔目标、快搜快走（见[搜刮效率与战利品取舍](looting.md)） |
| **Goshan 杂货区** | 生活类物资，通道较宽 | 视野相对开阔，反而更安全 | 适合练“低配快速搜刮” |
| **地下层与停车场** | 昏暗、狭长、**撤离点与埋伏并存**；**Tagilla 的据点** | 贴脸遭遇、无照明即盲、**在窄道撞上 Tagilla** | ⚠️ **必须带照明**；不熟就当“过路”不要深入；**听见锤声先拉开距离** |
| **商场外围（装卸区等）** | 进出商场的过渡带 | 撤离点附近的守株 | 撤离路线**提前定**，别现找 |

## 💡 核心打法流派

1. **室内清图流**：沿环廊逐店推进，考验转角预瞄与脚步管理。
2. **B 战术（地下流）**：走地下层规避商场主体交火，在出口处反向蹲人。**（注意：地下是 Tagilla 的地盘——这条路线不再是「安全的绕行」，见下文 [Boss](#boss) 一节。）**
3. **电子件淘金流**：直奔 IDEA 与电脑区，低配快速搜刮撤离。

**再补两条**：

4. **守点流**：立交桥是**守方优势图**——控制一段环廊或一个高价值店的门口，收益稳定（但同一个位置别久留）。
5. **灯光骗术**：**开灯的人会暴露位置**。你可以用照明看清自己，但**别在移动中一直开着**（见[光照与夜战](lighting.md)）。—**前提**是这张图的灯不是常亮的：谁去合上电闸，谁就改写了全场的光照（见上文[全楼的电，是某个玩家按的开关](#power)）。

## 🎯 Boss：Killa 与 Tagilla

<a id="boss"></a>

**立交桥有两个 Boss，而且可能同局出现**——一位是商场里巡逻的 Killa，一位是地下停车场的 Tagilla。两人在官方设定里是兄弟（**Tagilla 是 Killa 的弟弟**），但**活动区基本不重叠**：所以一局里听到两处互不相干的 Boss 交火声，是正常情况（见[Boss 图鉴](bosses.md)）。

### Killa（商场内巡逻）

| 项目 | 内容 |
|------|------|
| **外观** | 运动头盔 + 重型护甲 + 大弹容机枪——**全图最有辨识度** |
| **火力** | **持续性强**，正面换弹匣对枪**几乎必输** |
| **行为** | 主动性强，在商场中庭与主力店铺之间巡逻并主动接战 |
| **应对思路** | ① **集火头部 / 颈部**（护甲最薄处）；② **利用他换弹窗口**；③ 用掩体把交火拆成“短促点射”而不是对拼 |
| **装备要求** | 需要**高穿深弹药**——他的甲等级高（见[弹药选型速查表](ammo-table.md)） |
| **收益** | 稀有头盔与任务物品 |

> **一条声音纪律**：**听见 Killa 的机枪，别去看。** 那个声音说明他正在打别人，也说明你只要不出现，他就是免费的清场工具。

### Tagilla（地下停车场）

| 项目 | 内容 |
|------|------|
| **据点** | **Goshan 杂货区下方的地下停车场**——他不满图跑，基本守着这一片 |
| **外观** | 电焊面罩 + 大锤——**近战型的标志** |
| **火力** | **近身一锤致命**；当你的位置他够不到时（例如高处），会**改用霰弹枪**远距离输出 |
| **行为** | 主动性极强、**开局即激活**：会直接冲脸，也会设伏与破门 |
| **应对思路** | ① **保持距离用枪解决**，绝不在窄道里和他拼近战；② 他挥锤的瞬间会**短暂站定**——等这一拍再开枪；③ 他跑动中挨打不会停，所以别边退边乱开枪 |
| **装备要求** | 弹种穿深不够就**打腿**（护甲只覆盖胸腔，腹部与双腿裸露）；高穿深弹则优先**头部与后颈**（面罩护不住后颈）——见[护甲与头盔](armor.md) |
| **收益** | 电焊面罩（UBEY / Gorilla 两种）、Tagilla 版护甲与胸挂，以及任务目标 |

> **一条声音纪律**：**听见锤子敲铁管的声音，先退到能开火的距离再说。** 地下车库空间窄、光线暗、退路少——那正是他最喜欢的地形。
>
> **一条冷知识**：他那把大锤**捡不走**（官方设定为不可拾取），所以别指望靠杀他赚那把锤子——**值钱的是面罩与甲**。

## 🧭 实战要点

1. **带照明**：手电或夜视至少一样，否则商场内部与地下层就是盲区。
2. **分段推进，不要横穿环廊**：环廊的长视线永远属于守方。
3. **搜刮时背靠掩体、面向来路**：背身是立交桥最高频的死法。
4. **停下比移动安全**：这是少数几张“守方优势”的图。
5. **打 Killa 先看弹药穿深**：穿深不够就是给他挠痒。
6. **听见机枪别去凑**：他正在替你清场。
7. **地下层只当“过路”**：不熟就别深入，那里把遭遇距离压到贴脸——**而且 Tagilla 守在地下停车场**。
8. **撤离路线提前定**：外围与地下都有撤离点，但都要提前规划方向。

## ⚠️ 常见错误

- **在长廊对枪**：环廊视线长，先手开镜的赢面大——移动方应分段推进。
- **不开手电也不夜视**：商场内部与地下层光线差，没有照明手段就是盲人。
- **背身不管**：进店搜刮时背对入口，是立交桥最高频的死法。
- **一直开着灯移动**：照明同时暴露你的位置，需要时开、走位时关。
- **穿深不足去打 Killa**：他的甲等级高，弹不对就是白给。
- **在地下车库和 Tagilla 拼近战**：那里空间窄、退路少，正是他最喜欢的地形——保持距离用枪解决。
- **把两人的声音当成一个人**：Killa 是**长点射**的机枪，Tagilla 是**锤击铁管**——听到哪一种，决定你该退还是该等。
- **在 IDEA 恋战**：那里是搜刮党聚集区，多待一分钟就多一次同行遭遇。
