# 组队与协作 (Squads & Teamplay)

<a id="top"></a>

> “塔科夫里，队友是唯一不会出现在你 HUD 上的东西。”
> —— 关于信任的成本

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 社交与协作机制 |
| **组队上限** | 最多 **5 人**（PMC 与 Scav 各自成队） |
| **组队条件** | 同一时间、同一地图；出生点相近，其余靠沟通 |
| **身份标识** | **没有队友标识**——不显示名字、不显示轮廓 |
| **友伤** | 会伤害也会击杀队友，且**有惩罚** |

| **语音** | 游戏内 VOIP（近距离语音）可用 |

## 💡 核心机制

### 1. 组队提供什么、不提供什么

| 提供 | 不提供 |
|------|--------|
| 同一局内互相掩护、交叉火力 | 队友位置提示（HUD） |
| 战利品分配与搬运 | 共享护甲与医疗 |
| 队友死亡后可捡回他的装备 | 免除死亡惩罚 |
| 部分任务目标的进度共享 | 共享仓库与资金 |

**最重要的一条**：除了出生点，游戏**没有任何机制把队伍绑在一起**。走散、误伤、抢同一样战利品，全靠人说清楚。

### 2. 友伤的三重惩罚

击杀队友不是“内部矛盾”，系统有明确代价：

1. **不计入击杀任务进度**——白打；
2. **造成 Karma 惩罚**（Scav 阵营的声望损失尤其明显，见[声望与 Karma](karma.md)）；
3. **队友的狗牌失去“战局内发现”状态，价值被压到 1 卢布**——这条最容易被忽略：**你杀了队友，连他的狗牌都卖不出钱**。

> 推论：**误伤之后要做的是道歉与救药，不是补枪**。补枪把一次误伤变成一次确定的惩罚。

### 3. 保险与队友：一个反直觉的细节

[保险](insurance.md)的返还前提是“**没有人把东西拿走**”。因此：

- 队友倒下后，**别人不拿他的装备**，装备才有机会寄回；
- **把队友的装备藏起来**（塞到角落、扔进难到达的位置）是合法的团队行为，也是小队比独狼省钱的核心原因之一；
- 反过来，**赛季模式下保险被全局关闭**（见[赛季与修改器](seasons.md)），“队友帮藏装备”这条保障直接消失——死亡对装备的消耗变成不可逆的。

### 4. 1.1 的组队利好：击杀目标共享

任务体系重构后，**同一任务的多名队员，只要其中一人完成击杀类目标（例如击杀某个 Boss / 一定数量的特定敌人），其余队员的进度同步完成**。这大幅降低了“五个人各打一遍同一个 Boss”的重复劳动，也让组队做任务从“陪跑”变成“并行推进”。

### 5. 协作撤离与转场协同

- **合作撤离点（Co-op）**：需要 PMC 与 Scav 在撤离区内同时存在，才成立——这是唯一需要**跨阵营**协作的机制（见[撤离点详解](extraction-points.md)）；
- **转场**：需要**全队成员都在转场区**才能激活，少一个人计时就重置（见[转场与 BTR](transit.md)）；
- **付费车辆**：队内**每人各自付款**，不是一个人买单。

### 6. 分工与信息纪律

实战中队伍的效率来自分工，而不是人数：

| 角色 | 职责 |
|------|------|
| 前压位 | 开路、接第一枪、控制在最前 |
| 支援位 | 补枪与压制，不抢前压位的射界 |
| 观察位 | 长枪/倍镜，负责远距与信息 |
| 后勤位 | 医疗、弹药补给、战利品整理 |

**信息纪律比枪法重要**：报点用“方位 + 距离 + 是否移动”，而不是“那边有人”。

### 7. 沟通渠道：VOIP 是“喊话”，不是“无线电”

塔科夫有一项容易被误用的功能：**VOIP（游戏内近距离语音）**。它的关键属性是——**它是近场广播：你能说多远，附近的人就能听多远。**它**不是你队伍的内部频道**。

由此得出两条方向完全相反的纪律：

| 渠道 | 用途 | 纪律 |
|------|------|------|
| **外部语音**（第三方语音软件） | **队内报点、指挥、闲聊** | **一切战术信息走这里**。用游戏内语音报点，等于把情报同时发给对手 |
| **游戏内 VOIP** | **对外**：喊话、试探、迷惑 | **只在“想被听见”的时候用** |

**VOIP 真正的战术价值是“骗”，不是“说”**：朝走廊喊一句示好，能换来对方**先动、先暴露**；反过来，**在室内随便说话，就是免费给对面报点**（见[听声辨位与音频机制](audio.md)）。

另外三个沟通工具经常被混为一谈，这里划清：

| 工具 | 对象 | 用途 |
|------|------|------|
| **外部语音** | 队友 | 报点与指挥——**唯一该放战术信息的渠道** |
| **F1 角色语音** | 全场可听 | 播放角色台词，**用来伪装 AI Scav 或试探身份**（见[敌我识别与身份判断](iff.md)） |
| **Y 键手势 / 指令轮盘** | **AI Scav** | **对 AI 下命令**的入口，不是队内沟通（见 [Scav 指挥与随从系统](scav-command.md)） |

**一句话**：**队友在无线电里，对手在空气里。**这句话搞反，就等于把指挥系统送给了对面。

## 🧭 实战要点

1. **开局先定行动路线与撤离点**：三个人三条路线，等于三次走散。
2. **统一服装与臂章**：既然没有 HUD 标识，外观约定（臂章颜色、成套服装）是唯一有效的敌我识别方式，详见[敌我识别与身份判断](iff.md)。
3. **报点用方位不用地标**：队内约定“我几点方向”比喊地名快得多。
4. **误伤立刻定性**：喊出“自己人，别开枪”，比继续输出更值钱。
5. **战利品先讲分配**：价值高的东西先定归属，避免撤离前翻脸。
6. **死了别急着退**：如果队友有机会藏你的装备，保险才会生效。

## ⚠️ 常见错误

- **以为有队友标识**：没标识，靠约定。
- **五个人挤一条走廊**：一次扫射全员受伤，队形比人数重要。
- **误伤后补枪**：把误会升级成确定的 Karma 与狗牌损失。
- **同队抢同一样战利品**：塔科夫里队伍内战比外战更常见。
- **赛季里指望保险**：赛季 PvP 的保险被全局关闭，别按老习惯带唯一一套家当。
