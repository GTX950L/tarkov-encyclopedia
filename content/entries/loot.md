## 💡 核心机制

### 1. 战利品按“区域语义”分布，不按地图随机撒

塔科夫的容器与生成点不是均匀分布的，而是**跟着场景的功能走**。理解这一点，比背具体房间有用得多：

| 区域类型 | 典型内容 | 价值特征 |
|----------|----------|----------|
| **军方 / 军事区** | 弹药、武器配件、军用物资、护甲 | 单价中等、**成批出现**，弹药收益稳定 |
| **医疗区** | 药品、医疗器械、高价医疗耗材 | **单件极高**，是每格价值最高的一类 |
| **办公 / 行政** | 情报类物品、钱包、钥匙、电子件 | 体积小、单价高，适合背包紧张时优先拿 |
| **居住 / 宿舍** | 生活物资、工具、杂货、现金 | 量大质杂，需要筛选 |
| **商业 / 零售** | 电子、科技件、日用品 | 中高价值，**科技件是常青项** |
| **工业 / 仓储** | 建材、燃料、机械件、修理材料 | 藏身处材料的主力来源 |
| **钥匙房** | 上述类别的高浓度版本 | **收益上限最高，也最需要门票** |
| **Boss / 精英区** | 专属装备、任务物品、顶级弹药 | 高风险高回报，且常与任务线绑定 |

**判断优先级的方法**：走进一栋楼先问“这里原来是干什么的”，答案基本就是战利品类型。

### 2. 用“每格价值”而不是“单价”做取舍

背包是格子，不是重量。两件物品单价相同，体积差三倍，收益就差三倍。

实用的筛选顺序：

1. **情报类 / 医疗类小件** —— 体积小、单价高，永远优先；
2. **顶级弹药与弹药盒** —— 体积可控、需求常年稳定；
3. **钥匙卡与钥匙** —— 占格少、单价极高；
4. **高价值电子件**（显卡类等）—— 单价高但占格大，是背包富余时的选择；
5. **建材与杂货** —— 前期为藏身处而拿，后期按单价决定。

一条经验：**不要为了“看起来贵”的大件，挤掉三个小件的位置。**

### 3. 前期与后期的目标是两套

| 阶段 | 目标 | 优先内容 |
|------|------|----------|
| **前期** | 建藏身处、攒任务材料 | 建材、工业件、任务指定物 |
| **中期** | 装备循环与资金流 | 弹药、护甲、医疗、可上架的小件 |
| **后期** | 纯收益与任务收尾 | 高单价小件、Boss 专属、钥匙房 |

前期拿建材看起来“不值钱”，但它替你在藏身处省下的购买成本，远高于同一格位放一件杂货的差价。

### 4. 时段决定竞争强度

同一张图在同一天的不同时段，战利品环境完全不同：

- **开局前几分钟**：高价值区人流最密集，遭遇战概率最高；
- **中段**：玩家分散在各自路线上，收益稳定但高价值点多已被搜过；
- **末段**：撤离压力上升，愿意留下的玩家通常目标明确（任务或 Boss）。

给自己的定位很重要：**想安心拾荒就避开开局抢点，想做高价值拦截就守在高价值区的必经路线上。**

### 5. FiR 决定了哪些东西“必须带出去”

只有带**战局内发现**状态的物品可以上架跳蚤，而**保险寄回的装备会失去该状态**。推论很直接：

- 想卖跳蚤的物资，**必须真的撤离带出去**；
- 从尸体上扒下来的装备，**只能卖给商人或自己用**；
- 因此“把贵的小件塞安全箱”在收益上依然是最优解——安全箱内的物品不因死亡流失。

### 6. 风险预算：把地图拆成“能打”和“不能打”

同一个高价值区，是否值得进，取决于三件事：

| 变量 | 判断 |
|------|------|
| **入场门槛** | 是否需要钥匙 / 门禁 / 转场 / 特殊装备 |
| **撤离距离** | 拿到东西之后，还要走多远才安全 |
| **保险是否生效** | 不生效的场景（如迷宫）意味着一次失败全损 |

一条可执行的纪律：**先确认撤离路线，再决定要不要进高价值区。** 反过来做的人，通常在满载之后才发现自己没有出路。

### 7. 为什么本页不列具体坐标

刷新点、房间内容、容器类型都属于**版本高度敏感**的信息：

- 大版本会重做地图布局与容器分布；
- 小版本会调整特定房间的生成内容；
- 社区数据库通常比本页更新得更快。

所以本页提供的是**判断框架**，而不是点位表。需要精确点位时，请以当前版本的社区地图为准。

## 🧭 实战要点

1. **先读场景再读容器**：办公室找情报纸、医疗区找药、宿舍找杂货。
2. **按每格价值排序取舍**，不为大件牺牲格位效率。
3. **前期优先建材**，那是藏身处的钱。
4. **撤离路线先于战利品**：没有退路的房间不值得进。
5. **贵的小件进安全箱**，这是唯一不随死亡流失的位置。
6. **避开开局抢点**能显著提高生存率，代价是收益上限略低。
7. **钥匙房是收益杠杆**：有门票就把门票用在高价值区，而不是随手开箱。

## ⚠️ 常见错误

- **把“单价高”当成“收益高”**：忘了算体积。
- **最后一刻才发现撤离不顺路**：满载的背包是最难带的。
- **在 FiR 限制上吃亏**：扒来的装备挂不上跳蚤。
- **盲目信任旧点位图**：地图与容器分布会随版本重做。
- **为杂货放弃任务材料**：前期的任务材料优先级高于同格位的现金收益。
