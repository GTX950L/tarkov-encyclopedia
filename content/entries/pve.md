# PvE 模式 (PvE Zone)

<a id="top"></a>

> “PvE 拿掉的是真人对手，不是难度——它拿掉的是**不可预测**。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 独立游戏模式（合作向） |
| **官方定义** | “带**持久进度**的合作 PvE 模式” |
| **对手** | 全部为 AI：Scav、Raiders、Boss、**AI PMC** |
| **是否 wipe** | **永不重置**——等级、技能、武器掌握、商人声望、任务全部保留 |
| **角色档案** | **独立档案**。PvP 的装备与进度**不迁移**过来，反之亦然 |
| **联机** | 可组队，**最多 5 人** |
| **获取方式** | The Unheard / Edge of Darkness 自带；其他版本需单独购买（官网扩展包，或 Steam 上的 **PVE Zone**） |
| **当前状态** | **本节基线 1.1.5.1；1.2.0.0 将对 PvE 做一次集中改动（见第 8 节）** |

---

## 💡 核心机制

<a id="what"></a>

### 1. 它是什么：同一套游戏，换掉唯一的变量

PvE 保留了几乎全部系统——**同样的地图、任务、商人声望阶梯、藏身处、Kappa 路线、卢布经济、撤离规则**。唯一的替换是：**战局里不会出现真人**。

这个替换带来两个直接后果：

1. **“不可预测”消失了**。AI 会听声、会包抄、会压制，但它的行为有规律、有上限，**你可以学会它**；
2. **风险结构变了**。PvP 里最难防的是“一个你完全不知道存在的玩家”，PvE 里没有这一项。

但**别把它当简单模式**：Boss、Raiders 与成组的 AI PMC 依然会干掉轻率的战局，Killa、Goons、迷宫 Boss 这些名字在 PvE 里照样致命。

<a id="diff"></a>

### 2. 与 PvP 的差异清单

| 维度 | PvP | PvE |
|------|-----|-----|
| **对手** | 真人 PMC + AI | **全部 AI**（含 AI PMC） |
| **进度** | 赛季 wipe 定期清空 | **永不 wipe** |
| **角色档案** | 持久 / 赛季两档 | **独立第三档**，与 PvP 互不相通 |
| **跳蚤市场** | 全服玩家共同支撑 | **独立市场**，价格与流通量都不同 |
| **保险返还** | 被其他玩家彻底搜刮很常见 | **返还率明显更高**（AI 不像真人那样翻尸体） |
| **商人 Ref** | 可用 | **口径不一致，见第 6 节** |
| **组队** | 常规 | 支持，**上限 5 人** |
| **心理成本** | 高（装备恐惧） | 低——**这是它对新玩家最大的价值** |

其中**跳蚤与保险这两条最影响玩法**：PvE 的经济天花板更低（没有大量玩家互相倾倒物资），但**装备循环更稳**（返还多、损耗小），所以“攒钱”这件事的成功率更高、上限更低。

<a id="nowipe"></a>

### 3. 没有 wipe，意味着什么

这是一把双刃剑，值得单独说清：

| 好的一面 | 坏的一面 |
|----------|----------|
| 进度**永不归零**，随时可以停一段时间再回来 | **没有“重新开始”这个选项**——除非你自己愿意 |
| 藏身处与资产持续复利增长 | **经济会饱和**：钱和装备堆积到某个点后，目标感消失 |
| 技能、武器掌握练一次管一辈子 | 后期容易变成“无目的的刷”，社区里叫它“解决掉了这款游戏” |
| 任务进度线性推进，不被打断 | 赛季修改器带来的规则新鲜感**与你无关** |

**官方用来补这个缺口的是转生**：PvE **随 1.2.0.0 获得独立的 Prestige 系统**——因为 PvE 没有 wipe，**转生是 PvE 玩家唯一的重置手段**（见 [Prestige 转生](prestige.md)）。

<a id="servers"></a>

### 4. 服务器：本地跑还是官方服

进入战局前，位置选择界面上有一个**「在 BSG 服务器上运行」**开关：

| 模式 | 说明 |
|------|------|
| **本机运行** | 战局由你自己的电脑托管。启动快，但**吃你的硬件**，AI 表现也随机器状态波动 |
| **官方服** | 由 Battlestate 托管。**AI 表现更完整、体验更稳**，但需要等待匹配 |

**以下情况必须使用官方服**：

- **街区（Streets of Tarkov）**；
- **破冰船（Icebreaker）**；
- **终点站（Terminal）**；
- **任何组队战局**。

**建议**：只要不赶时间，**选官方服**——AI 的行为质量差别是能感觉到的，而 PvE 的全部挑战就来自 AI。

<a id="economy"></a>

### 5. 别把 PvP 的经济经验直接搬过来

PvE 的经济有三处结构性差异：

1. **跳蚤市场是独立的**——同样的物品，价格与成交量都不同，**PvP 的价格区间不能照搬**；
2. **保险返还率更高**——AI 的搜刮不像真人那样彻底，所以“死了还能拿回来”的概率更高，**保单的价值被放大了**；
3. **利润主要来自“生产”而不是“倒卖”**——没有大量玩家互相套利，**藏身处的产出与制造**比低买高卖更可靠。

<a id="traders"></a>

### 6. 商人：一处需要自己核对的冲突

**Ref 在 PvE 是否可用，两处来源说法不一致**：

| 来源 | 说法 |
|------|------|
| **官方 0.14.9.0 补丁说明**（引入 Ref 时） | “该商人在 PvE 模式中**不可用或不可见**” |
| **较新的社区资料** | Ref 现已同时存在于 **PvP 与 PvE Zone**；且 **PvE → Arena 的转移不可用，Arena → PvE 可用**，转移限额按模式分开计算 |

> **以游戏内商人列表为准**。若 Ref 在你的 PvE 里可见，则他提供与 Arena 相关的物品与转移服务；若不可见，说明你的版本仍沿用旧规则。

另有一条**无论如何都成立**的边界：**从 PvE 无法把资产转去 Arena**——单向通道只允许 Arena → PvE。

<a id="practice"></a>

### 7. 注意：练习（离线）模式不是 PvE

主菜单里的**练习 / 离线模式**经常被当成 PvE，但两者完全不同：

| | **练习（离线）** | **PvE** |
|---|---|---|
| 对手 | 可自选（含无 AI） | 固定为 AI |
| 进度 | **战斗结束后不保存** | 永久保存 |
| 用途 | 学地图、试枪、练手感 | 真正的进度推进 |

**用错会白忙一场**：在离线模式里完成的撤离、搜到的物资，**一件都不会留下**。

<a id="upcoming"></a>

### 8. 即将到来：1.2.0.0 对 PvE 的集中改动

官方 2026 年路线图把 **1.2.0.0**（2026 年 9 月末 / 10 月初）定为**PvE 专版**，已公布内容包括：

- **PvE 转生（Prestige）**——PvE 专属的重置系统，附永久奖励；
- **PvE bot 出生机制重做**——减少“成群刷新”的突兀情况；
- **PvE AI 行为重做**——交火逻辑更接近真人；
- **战局重连系统重做**（**对 PvP 与 PvE 全体生效**）；
- **EXFIL Brothers 计划**。

> 官方**尚未公布 PvE 转生的具体门槛数值**，预期与 PvP 同构。**本章在 1.2.0.0 落地后需要复核一次**——本条已登记进[待收录清单](../docs/roadmap.md)的版本复核项。

## 🧭 实战要点

1. **想学图、想练枪、怕丢装备**——PvE 是对的方向；但**别在离线模式里攒进度**。
2. **长期开官方服**，尤其打街区、破冰船、终点站与组队时。
3. **保险在 PvE 里更划算**，可以比 PvP 更大胆地投保整套装备。
4. **别拿 PvP 的价格做决策**：PvE 跳蚤是另一套行情。
5. **把重心放在藏身处制造与任务推进**上——这是 PvE 最稳的收益结构。
6. **1.2.0.0 前先想清楚**：转生一旦上线，**它会是你唯一的重置手段，且不可逆**（见 [Prestige 转生](prestige.md)）。

---

## ⚠️ 常见错误

- **把 PvE 当简单模式**：Boss 与 Raiders 的致死率没变，只是**对手换成了可学习的 AI**。
- **以为 PvP 进度能带过来**：两套档案完全独立。
- **把练习模式当成 PvE**：不保存任何进度。
- **照搬 PvP 的市场价**：独立市场，行情不同。
- **在 PvE 里等 wipe 来重置**：**永远不会有**，要重置只能等转生。
- **默认 Ref 一定在或一定不在**：这是有版本变动的项，**看游戏内**。
