## 💡 核心机制

### 1. 三种回合结构，决定三种节奏

五个模式看着多，拆开只有三种结构：

| 结构 | 模式 | 死亡后 | 节奏特征 |
|------|------|--------|----------|
| **一命制回合** | Teamfight、BlastGang、Shootout | 等下一回合 | 每一次交火都决定这一回合，**决策压力最大** |
| **重生制** | CheckPoint、Last Hero | 立刻重生（有保护期） | 单局能打十几次交火，**练枪效率最高** |
| **换边制** | BlastGang | 半场后攻守互换 | 必须两种角色都会打，**考的是全面性** |

这条差异比「模式名字」重要得多：**你想练的是“一次交火的质量”，还是“十次交火的稳定性”**，答案不同，选的模式就不同。

### 2. 五个模式逐项

**① Teamfight（团队战）——最标准的 5v5 回合制**

- 2 队 × 5 人，**先到 5 胜**（排位模式为 **7 胜**，见 [Patch 0.1.7.0](https://arena.tarkov.com/news/patch-0170)）。
- 回合内全歼对手即胜；**时间耗尽则进入加时**，地图中心激活一个目标点，占领或全歼对方即赢下该回合。
- 加时仍未决 → **清场队**入场：第一波 **Scav Raider**，第二波 **Killa + Tagilla**；清场队入场 **20 秒后**释放毒气，**每 3 秒对每个身体部位 3 点伤害**。
- 这条设计的意图很明确：**不让比赛拖成互相对蹲**。毒气会同时伤害双方，所以“等对方先死”是最差的策略。

**② BlastGang（爆破）——唯一有攻守不对称的模式**

- 2 队 × 5 人。攻方要**安放装置**，守方要**阻止或拆除**。
- **装置引爆倒计时 40 秒**（0.6.0.0 从 45 秒下调）。
- **8 回合后换边**，先到 **9 胜**获胜；**8:8 进加时**（4 回合，需赢 3 回合）；20 回合仍未决即平局。
- 每回合开始用**对局内赚到的钱在装备商店组配装**——这意味着**经济管理是模式的一部分**：赢回合有钱、输回合也有基础收入，怎么在“省一回合”和“买满配”之间取舍，是这模式真正的技术点。
- 因为要换边，**只擅长防守的玩家在这里会掉分**：进攻回合的得分才是净胜分。

**③ CheckPoint（据点）——可重生的团队死斗**

- 2 队 × 5 人，争夺地图上的目标点；**占领并守住目标点会持续累积分数**，先到目标分数者胜。
- **可反复重生**：每次死亡后可以换配装，装备可以从补给箱补充。
- **出生保护**：在己方基地内受到伤害 **-50%**、自动止血、持续回血；在次级重生区只持续 **3 秒**，且**一开枪立即失效**。
- 基地周围有**雷区**，防止对手压出生点。
- **这个模式是练枪的首选**：重生快、交火密、死了不心疼，一局的交火次数通常是回合制的两三倍。

**④ Last Hero（最后英雄）——6–10 人混战**

- 限时内**击杀最多者胜**，所有职业的预设都可选。
- 死亡后可换配装、可补给；重生后 **3 秒**保护（-50% 伤害、止血、回血），开枪即失效。
- 与 CheckPoint 的区别：**没有队友**。所有判断都得自己做，是练「1vN 处置」和「听声定位」最直接的地方。

**⑤ Shootout（巡回赛）——2v2 的小型锦标赛**

- **6 队 × 2 人**（或 4 队 × 3 人）打**循环赛**：每队都与其他队交手一遍。
- 胜场最多的两队进决赛；胜场相同则按综合表现选。
- 决赛为 **3 回合两胜**；单回合可全歼对手取胜，或加时占点取胜，加时未拿下则平局。
- 0.5.0 对它的评价是「重做后回归」——**这是最接近“排位天梯预演”的模式**：队少、局短、对手风格多样。

### 3. 胜负条件之外的四条隐藏机制

这四条不写在模式介绍的第一行，但会直接改变你的打法：

| 机制 | 规则 | 为什么重要 |
|------|------|-----------|
| **清场队与毒气** | Teamfight 加时未决 → Raider / Killa + Tagilla 入场，20 秒后全场毒气 | 僵持 = 双方一起死，**必须主动结束回合** |
| **装置倒计时** | BlastGang 安放后 **40 秒**引爆 | 守方拆弹窗口只有 40 秒，攻方要按这个时间设计掩护 |
| **重生保护** | 基地内 -50% 伤害；次级重生区 3 秒，开枪即失效 | 保护期是**给你找掩体**的，不是给你对枪的 |
| **装备商店** | BlastGang 每回合用局内资金买装备 | 连败也有基础收入，**不要为了省钱送掉关键回合** |

### 4. 十四张场地

场地是**改造出来的封闭竞技场**，规模普遍小于本体地图，一局能跑完一圈。掩体密度与高低差差异很大，**同一把枪在不同场地的手感完全不同**：

| 场地 | 原型与特征 | 支持模式 |
|------|-----------|----------|
| **Bay 5** | 港口区原 TerraGroup 安保货运仓库：货架与集装箱，**中近距离为主** | Teamfight · BlastGang · CheckPoint |
| **Bowl** | 旧体育场看台：**环形高低差**，中央开阔 | Teamfight · BlastGang · CheckPoint |
| **Fort** | 19 世纪海上要塞：石墙、甬道、**长视线与拐角并存** | BlastGang · CheckPoint · Last Hero |
| **Iceberg** | 苏联疗养院改建酒店：**室内多层**，走廊与房间 | BlastGang · CheckPoint |
| **Equator** | 商场中庭：**垂直空间 + 玻璃幕墙**，视野穿透多 | Teamfight · Last Hero · Shootout |
| **Chop Shop** | 郊外拆车厂：车辆掩体、**堆场式开阔地** | Teamfight · Last Hero |
| **Skybridge** | 火车站：站台长通道 + 列车掩体 | BlastGang |
| **Air Pit** | 机场航站楼：值机岛与安检通道，**对称结构** | Shootout |
| **Block** | 住宅区庭院：楼栋夹出的中庭，**短兵相接** | Shootout |
| **Factory** | 第 16 化工厂（0.5.0 新增战术地图）：**本体工厂的竞技场化改造** | Shootout |
| **Base** | 芬兰湾海岸旧养牛场：**开阔 + 少量建筑** | Last Hero |
| **Dorms** | 海关旁工人宿舍：**室内房间战** | Last Hero |
| **EMERCOM** | 保护区临时基地：帐篷与车辆掩体 | Last Hero |
| **Labs Replica** | 实验室复刻：**走廊与实验室房间**，TTK 极短 | Last Hero |

**两条读表提示**：

1. **「支持模式」栏会变**。0.5.0 停用了 Teamfight 下的 **Fort / Block / Skybridge** 三个组合，理由是“最不受欢迎的场地组合”——所以**这张表是 0.6.1.0 的快照，不是永久规则**。
2. **Sawmill 已暂停**（官方标注为后续开发暂停用）。旧攻略里它因 **1.7 倍经验修正**被当成刷通行证首选，**这条已经整段作废**。

### 5. 场地经验修正：现在怎么看

官方给场地设了**经验修正系数**（同一场比赛，不同场地给的角色经验不同）。这条机制仍然存在，但**逐场地的系数表已经随场地池轮换失效**：

- **仍在生效的例子**：0.6.0.0 把 **Fort 与 Iceberg** 的 PMC 经验修正提到 **150%**；
- **已经作废的例子**：旧版流传的「Sawmill 1.7 / Air Pit 1.35 / Bowl 1.35 / Bay 5 1.15 / 其余 0.9」——Sawmill 停用后，这张表的排序意义已经没了。

> **用法**：不要背系数表，**看当期哪张场地被官方标了加成**（补丁说明里会写），其余按“熟悉的图优先”选。刷通行证时，**场地系数 × 模式时长**才是真正的效率，单看系数会选到一张打不完的长局图。

### 6. 模式与「练什么」的对应

| 你想练 | 选什么 | 为什么 |
|--------|--------|--------|
| **枪法与压枪** | CheckPoint / Last Hero | 可重生，单局交火次数最多 |
| **一命制下的决策** | Teamfight / Shootout | 死了就等下一回合，逼你把每一次交火当最后一次 |
| **攻防与投掷物** | BlastGang | 唯一有攻守角色分工的模式，装置倒计时逼出投掷物使用 |
| **1vN 与听声** | Last Hero | 没有队友，所有信息自己判断 |
| **双人默契** | Shootout | 2v2 结构，配合权重最高 |
| **负重与力量** | 任意，但选 **Enforcer** 重装 | 技能成长看动作，不看模式 |

## 🧭 实战要点

1. **先算「一局能打几次交火」**：重生制（CheckPoint / Last Hero）> 回合制（Teamfight / Shootout）> 换边制（BlastGang）。练枪优先前两类。
2. **BlastGang 一定要打到换边**：只打半场等于只练了一半，而且看不到自己进攻端的漏洞。
3. **Teamfight 别拖进加时**：清场队 + 毒气会同时伤害双方，拖到那里等于把胜负交给 AI。
4. **CheckPoint 把重生保护用来换位**：3 秒保护结束后你就是活靶，保护期内该做的是找下一个掩体，不是对枪。
5. **按场地换枪**：室内图（Iceberg / Dorms / Labs Replica）带短枪，长视线图（Base / Fort）带长枪——同一把枪在两类图上的胜率差得很远。
6. **场地池先看一眼**：三个组合在 0.5.0 被停用，说明官方会按受欢迎程度调池子，别在过期攻略上做计划。

## ⚠️ 常见错误

- **在 BlastGang 只练防守**：换边后进攻端不会打，净胜分照样是负的。
- **把 CheckPoint 当 Teamfight 打**：可重生意味着“活着”不值钱，**占点分值才值钱**，蹲着不动是输。
- **在 Last Hero 找队友**：那模式没有队友，按小队战术打会被逐个击破。
- **背旧场地系数**：Sawmill 已暂停用，1.7 倍那条彻底作废。
- **忽略场地规模**：竞技场地图小，**绕后路线通常只有一两条**，被读一次就会被反制。
- **以为模式名字变了规则就没变**：Shootout 在 0.5.0 被重做过，旧版的规则描述不一定还成立。

## 💬 老兵经验

- 一命制教你怕死，重生制教你敢打。两种都得练。

- 竞技场没有“安全的角落”——地图小到绕后只要二十秒。

- 加时不是加时，是倒计时：清场队一进场，两边一起输。
