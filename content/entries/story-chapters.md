# 剧情章节与主线任务 (Story Chapters)

<a id="top"></a>

> “商人任务给你装备，剧情章节给你一个理由——为什么你还在塔科夫。”

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 主线剧情任务（区别于商人日常任务线） |
| **已知章节** | **Tour（游览）** → **Falling Skies（陨落之天）** → **The Ticket（车票）**，另有 They Are Already Here 等 |
| **推进方式** | **按章节顺序**，前一章是后一章的前置 |
| **关键分叉** | Falling Skies 结尾的**装甲箱归属**决定 The Ticket 的路线 |
| **结局数量** | The Ticket 共 **4 个结局**，全部经由**终点站**撤离收束 |
| **与前缀关系** | 是 [Prestige 转生](prestige.md) 多档门槛的**硬性前置** |

---

## 💡 核心机制

<a id="difference"></a>

### 1. 它和“商人任务线”不是一回事

塔科夫有两套任务体系，容易混淆：

| | **商人任务线** | **剧情章节** |
|---|---|---|
| **形式** | 每位商人各一条，彼此独立 | **单一主线，按章节串联** |
| **驱动** | 声望、解锁商品 | **叙事 + 结局** |
| **来源界面** | 商人菜单 | 部分章节**不在商人菜单**——例如 Mr. Kerman 要走**情报中心的笔记本电脑**联系 |
| **可否绕开** | 可以，只做想要的 | **不行，按顺序推进** |
| **终点** | 商店全开、Kappa | **撤离塔科夫的结局** |

一句话：**商人任务线是“工作”，剧情章节是“故事”**。但故事会卡住工作——因为转生门槛里全是剧情章节。

<a id="sequence"></a>

### 2. 章节序列与前置

| 顺序 | 章节 | 起点 / 前置 | 作用 |
|------|------|------------|------|
| ① | **Tour（游览）** | Mechanic 线，从**工厂**起步 | 主线序章；**打通灯塔进入权限** |
| ② | **Falling Skies（陨落之天）** | 需先推进 **Tour**；Prapor 声望 **L2** | 森林坠机调查；**结尾出现重大选择** |
| ③ | **The Ticket（车票）** | 承接 Falling Skies；需**情报中心 L1** | 终章；走向 4 个结局 |

另有 **They Are Already Here** 等章节穿插其间，**名单会随版本扩充**——所以“章节总数”不是一个固定数字。

<a id="tour"></a>

### 3. Tour：必须先走的那一步

Tour 是 Mechanic 线的剧情开头，**在工厂起步**。它的重要性不在于奖励，而在于**它同时是另外两条线的钥匙**：

- **Falling Skies 要求先推进 Tour**；
- **灯塔的进入权限**经由 Tour 剧情线取得（见[灯塔](lighthouse.md)）。

所以如果你发现某个任务“接不到”，**先回头看 Tour 推到哪了**。

<a id="falling-skies"></a>

### 4. Falling Skies：整个主线唯一的重大多叉

这一章从**森林的坠机现场**开始，是主线中**结构最完整、代价最明显**的一段。流程骨架：

1. **找到坠机**（森林）→ 与 Prapor 对话；
2. **升到 Prapor 声望 L2**，再向各商人打听；
3. **取回闪存盘**——在**海岸线**隧道附近的 G-Wagon 车上（向 Therapist 付 **2000 美元**可买情报，但**不是必需**）；
4. **取飞行记录仪**（森林坠机处）→ **放置**在**海岸线**岛上的屋子；
5. **上交材料**：**2 个工具箱、3 块充电电池、5 块印刷电路板**——**必须是战局内拾取**，且**都可在藏身处工作台制作**；
6. 等待数小时后，上交**机组录音**与 **Elektronik 的加密闪存盘**（均在**海岸线的主席宅邸**）；
7. **取回装甲箱**（森林坠机驾驶舱），进入**唯一的关键选择**。

**关键选择：装甲箱交给 Prapor，还是留下？**

| 你的选择 | 立刻得到 | 后续代价 |
|----------|----------|----------|
| **交给 Prapor** | **约 100 万卢布**、成就「Man's Word」，Prapor 声望上升 | 之后的**费用门槛更低**，但路线被锁进“与 Prapor 合作” |
| **自己留下** | 成就「Just Business」，箱子经**系统邮件**送到你手上（特殊物品） | **Prapor 声望显著下降**，且之后的**费用门槛更高** |

> **这是不可逆的分叉**：The Ticket 的路线会**根据这个选择分成两套**。**在下手前把两边后果都想清楚**——它不是“选哪个奖励好”，而是“选哪条剧情线”。

<a id="ticket"></a>

### 5. The Ticket：四个结局，都从终点站离开

终章需要**情报中心 L1**（Mr. Kerman 通过情报中心的笔记本电脑联系）。它有多条分支，**但共同要点是**：

- **3 份 TerraGroup 蓝色文件夹**——**不要求战局内拾取，跳蚤市场买得到**（这是少数“可以买”的主线材料）；
- **在立交桥 ULTRA 正门打出黄色信号弹**；
- **在立交桥单局内击杀 15 个目标**（中途撤离会**两层都作废重来**）；
- 若你当年**自己留下了装甲箱**，还需从**实验室**取回**实验型信号干扰器**（需实验室门卡）；
- **装甲箱开启是一次 54 小时的工作台制作**（用信号干扰器解锁配方）。

结局共 **4 个**，分别对应不同立场（全力查证 / 拒绝合作 / 转向 Lightkeeper / 反戈），**全部经终点站收束**——这也是[终点站](terminal.md)这张图存在的叙事意义。

<a id="lightkeeper"></a>

### 6. Lightkeeper：不是章节，是一条“解锁链”

**Lightkeeper（灯塔守护者）**容易被误当成章节，其实是**独立于章节的访问链**：

- 他**在灯塔半岛那座灯塔建筑的顶层**，一扇**上锁的门**后面；
- 通往他的桥由 **Zryachiy 与阔剑地雷**把守，需要**编码过的数字 DSP 无线电发射器**才能通行；
- 链子由 **Mechanic 的「Network Provider · 第 1 部分」**开启；
- 与他会面后，他会给一段**考核任务**（例如上交 3 份蓝色文件夹、在立交桥打信号弹、单局击杀 15 人），完成后交还装甲箱。

**领装甲箱前务必留一个空的“特殊槽位”**，否则无法接收（见[邮件与领取](mail.md)）。访问链的完整规则见[灯塔](lighthouse.md)。

<a id="prestige-link"></a>

### 7. 为什么它对你的“终局”影响最大

**转生的绝大多数档位，门槛都是剧情章节。** 官方 wiki 列出的前置包括：**Tour、Falling Skies、取得 Ticket from Tarkov、They Are Already Here、收藏家**。

这意味着：**不推剧情，就永远卡在低转生档**。而低档位意味着**转生能带走的技能与装备比例更低**——**剧情进度直接换算成终局收益**。

## 🧭 实战要点

1. **先推 Tour**：它同时卡着 Falling Skies 与灯塔。
2. **Falling Skies 的材料提前在藏身处做好**：3 电池 + 5 电路板 + 2 工具箱，都是工作台产线。
3. **装甲箱的选择要提前决定**：路线一旦分开，代价会一路滚到终章。
4. **等待是剧情的一部分**：多次“等数小时”的环节，**不能用任何方式跳过**。
5. **The Ticket 的 15 杀必须单局完成**，中途撤离两层都要重来——**别提前撤**。
6. **蓝色文件夹可以买**，别为它硬刷。

---

## ⚠️ 常见错误

- **以为章节也在商人菜单里**：Mr. Kerman 在**情报中心**，不在商人列表。
- **Prapor 声望没到 L2 就找坠机**：卡住却不知道卡在哪。
- **不推 Tour 就找灯塔入口**：没有权限，进不去。
- **装甲箱选完才去查后果**：不可逆，且会改变整条终章路线。
- **领装甲箱前没腾特殊槽**：道具卡在邮箱里取不出来。
- **把章节当“可选项”**：它决定你能到哪个转生档。
