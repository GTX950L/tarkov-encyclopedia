## 💡 核心机制

### 1. 模块化升级

藏身处由独立模块组成，各自升级、各自生效——**共 26 个模块、68 个等级**（数据端点口径；此前这里写「23 个」是照英文 Wiki 的旧清单，与站内的材料清单、进度清单对不上，2026-10-21 已统一）。代表性模块：

| 模块 | 作用 |
|------|------|
| **发电机 / 太阳能** | 供电，驱动其他模块；太阳能把燃料消耗砍一半 |
| **集水器** | 产净水（纯水是硬通货之一） |
| **营养部** | 产食物 |
| **医疗站** | 离线回血、产医疗品 |
| **情报中心** | 产情报类物品、缩短 Scav 冷却、减跳蚤手续费 |
| **比特币矿场** | 用显卡产比特币——最著名的离线收益 |
| **靶场** | 练战斗类技能（3 级起 +10%） |
| **图书馆** | 实用类技能 +30%、局内经验 +15% |
| **荣耀展柜** | 陈列战绩与战利品，并按陈列的狗牌等级给战斗类加成 |
| **Scav宝箱** | 定期“白嫖”Scav 装备箱 |

> **模块名以数据端点的译名为准**，旧写法（生成器 / 水收集器 / 营养单元 / 射击场 / 名人堂 / Scav 隐藏点）在[模块详解](hideout-modules.md#materials)的总表里并排列出，搜索旧名仍能命中。

### 2. 离线收益逻辑

模块按现实时间持续产出（部分需在线领取），**等级越高产出越快**。这就是“睡觉也在挣钱”——尤其适合游戏时间碎片化的玩家。

**建造耗时按小时计、而且是“离线也走”的那种**：以比特币矿场为例，三级建造时间分别是 **34 / 50 / 106 小时**（官方数据端点，二级）。也就是说，越往高阶走，**升级本身就是一件“靠时间换”的事**——它和 raid 的收益逻辑正好相反：**raid 里时间等于风险，藏身处里时间等于产量。**

全部 68 个等级的施工合计 **1013 小时（约 42 天）**，但关键路径只有 **218 小时（约 9 天）**——**会排的人按 9 天走，不会排的人按 42 天走**。排法与依赖关系见[模块详解](hideout-modules.md#deps)。

### 3. 技能训练

技能类模块可以**把不在图里的时间变成成长时间**，而且给的是**成组加成**，不是单个技能：

| 模块 | 给什么 | 前提 |
|------|--------|------|
| **图书馆** | 实用类技能 **+30%**，局内经验 **+15%** | 休息区 3 级 + 藏身处管理 5 级 |
| **空气过滤单元** | 生理类技能 **+40%** | 发电机 3 级 + 通风 3 级，**运行时持续消耗滤罐** |
| **靶场 3 级** | 战斗类技能 **+10%** | 靶场 2 级 |
| **荣耀展柜** | 战斗类技能（数值随陈列的狗牌等级变化） | 易碎墙 6 级 |

详见[技能系统](skills.md)与[模块详解](hideout-modules.md#overview)的满级总览。

### 4. 1.0 之后：藏身处成了“永久资产”

1.0（2025-11）引入**持久角色**：PvP / PvE 档案的等级与仓库进度长期保留，藏身处的投入不再随大更新清零（详见[重大版本更新史](../docs/version-history.md)）。这带来了一个思路转变：

- **持久档案**：藏身处按长期复利建设，值得往高阶模块砸资源；
- **赛季角色**：独立档案、每 4–6 个月重置，前期只建“够用”的功能模块，别把家底都搬进去。

## 🧭 实战要点

1. **供电先行**：发电机是地基，燃料别忘了补——断电的藏身处是摆设。
2. **新手三件套**：集水器 → 医疗站 → Scav宝箱。三个模块覆盖“喝水 + 回血 + 白嫖装备”。
3. **比特币矿场是后期项目**：显卡贵、回本周期长，先满足功能模块再考虑理财。
4. **任务物品攒着**：很多模块升级需要特定任务物品，提前留货能省一大笔（见[任务系统](quests.md)）。
5. **碎片化玩家的最优解**：上线时间少？藏身处收益占比反而更高——它的产出不看枪法看时间。
6. **按「关键路径」排工期**：施工离线也走，睡前开最长的一段，比白天干等省一半日历时间（[排法见这里](hideout-modules.md#deps)）。

## ⚠️ 常见错误

- **只建战斗设施**：靶场很爽，但水和医疗才是生存刚需。
- **忘补燃料**：出门三天回来，发电机凉了，产线全停。
- **跳蚤买齐一切**：能搜到的升级材料，先翻仓库再下单。
- **低估 Scav宝箱**：免费装备箱回不满，但它是零成本收益。
- **把易碎墙停在 3、4 级**：那个区间是负收益，要么不动、要么到 6 级（[说明](hideout-modules.md#routes)）。
