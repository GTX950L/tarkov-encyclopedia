# 藏身处 (Hideout)

<a id="top"></a>

> “raid 之间你在睡觉，藏身处在工作。”
> —— 穷人的复利

---

## 📸 基本信息

| 项目 | 信息 |
|------|------|
| **类型** | 离线成长系统 |
| **形态** | 可升级的地下基地，数十个功能模块 |
| **核心价值** | 离线收益、技能训练、Scav 冷却缩短 |
| **资源来源** | raid 搜刮 + 跳蚤市场采购 |

---

## 💡 核心机制

### 1. 模块化升级

藏身处由独立模块组成，各自升级、各自生效。代表性模块：

| 模块 | 作用 |
|------|------|
| **生成器 / 太阳能** | 供电，驱动其他模块 |
| **水收集器** | 产净水（纯水是硬通货之一） |
| **营养单元** | 产食物 |
| **医疗站** | 离线回血、产医疗品 |
| **情报中心** | 产情报类物品、提升 Scav 冷却 |
| **比特币矿场** | 用显卡产比特币——最著名的离线收益 |
| **射击场** | 离线练枪感 |
| **名人堂** | 陈列战绩与战利品（0.14 加入），并提供战斗技能加成 |
| **Scav 隐藏点** | 定期“白嫖”Scav 装备箱 |

### 2. 离线收益逻辑

模块按现实时间持续产出（部分需在线领取），**等级越高产出越快**。这就是“睡觉也在挣钱”——尤其适合游戏时间碎片化的玩家。

### 3. 技能训练

射击场、健身器材等模块可以**离线训练角色技能**（枪械熟练度、耐力等），把非 raid 时间变成成长时间。

### 4. 1.0 之后：藏身处成了“永久资产”

1.0（2025-11）引入**持久角色**：PvP / PvE 档案的等级与仓库进度长期保留，藏身处的投入不再随大更新清零（详见[重大版本更新史](../docs/version-history.md)）。这带来了一个思路转变：

- **持久档案**：藏身处按长期复利建设，值得往高阶模块砸资源；
- **赛季角色**：独立档案、每 4–6 个月重置，前期只建“够用”的功能模块，别把家底都搬进去。

---

## 🧭 实战要点

1. **供电先行**：生成器是地基，燃料别忘了补——断电的藏身处是摆设。
2. **新手三件套**：水收集器 → 医疗站 → Scav 隐藏点。三个模块覆盖“喝水 + 回血 + 白嫖装备”。
3. **比特币矿场是后期项目**：显卡贵、回本周期长，先满足功能模块再考虑理财。
4. **任务物品攒着**：很多模块升级需要特定任务物品，提前留货能省一大笔（见[任务系统](quests.md)）。
5. **碎片化玩家的最优解**：上线时间少？藏身处收益占比反而更高——它的产出不看枪法看时间。

---

## ⚠️ 常见错误

- **只建战斗设施**：射击场很爽，但水和医疗才是生存刚需。
- **忘补燃料**：出门三天回来，生成器凉了，产线全停。
- **跳蚤买齐一切**：能搜到的升级材料，先翻仓库再下单。
- **低估 Scav 隐藏点**：免费装备箱回不满，但它是零成本收益。
