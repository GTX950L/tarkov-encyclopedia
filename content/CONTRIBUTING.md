# 贡献指南 (CONTRIBUTING)

感谢关注《逃离塔科夫百科全书》！本项目欢迎一切形式的贡献。

## 🧭 我们要什么样的条目

- **机制导向**：解释“是什么、为什么、怎么用”，而不是罗列攻略套路；
- **数值克制**：游戏版本更新频繁，优先描述机制原理与决策思路；必须引用数值时，标注“以游戏内为准”；
- **不用配图**：全站坚持纯文字 + 表格呈现（弱网可读是本站的设计前提）；
- **中英对照**：术语首次出现时给出英文名。

## ✍️ 新建条目流程

1. 查看[待收录清单](docs/roadmap.md)并认领（或在 Issue 中提议新条目）；
2. 复制[条目模板](template.md)开始撰写；
3. 保持固定骨架：基本信息表 → 核心机制 → 实战要点 → 常见错误 → 老兵经验 → 相关条目 → 回顶部；
4. frontmatter 填写标签（参考现有条目的标签体系）；
5. 提交 PR 前，本地跑一遍校验：

```bash
python scripts/check_entries.py
```

## 🔗 一致性要求（改一处，一处不落）

新增/修改条目后，以下位置需要同步：

- [ ] `mkdocs.yml` 的 `nav` 注册；
- [ ] `entries/index.md` 总览表；
- [ ] `README.md`（根目录）与 `content/README.md` 的条目计数；
- [ ] `tags.md` 标签汇总；
- [ ] `CHANGELOG.md` 记录变更。

> CI 会运行 `scripts/check_entries.py` 做断链与结构校验，请确保通过。

## 🐛 报告问题

- 数值过期 → Issue 标注版本号；
- 事实错误 → 给出复现路径（哪张图、哪个机制）；
- 措辞/链接问题 → 直接指明位置。
