## 1. 起因：一封留在车里的威胁信

> 📖 **剧情简介**（游戏内文本，经中文 Wiki 转录）
>
> 「宿舍楼旁停着一辆轿车，车上留下了一份颇为粗俗的威胁信。」

**这是全十章里最不起眼的一个开头**：没有求救、没有委托、没有神秘人，只有一辆车和一封骂人的信。

但这个名字——**意外证人**——把处境说清楚了：

- 你不是被谁雇佣的，你是**路过**；
- 你看到了不该看的东西（一封信、一辆带血的车）；
- 从这一刻起，**你成了这桩事的当事人**，虽然你什么也没做。

这一章也因此和另外九章不同：**它不是别人交给你的活，是你要不要管这件事的问题。**

## 2. 经过：一条街上的小人物，一路查到 Boss 的窝棚

### 2.1 第一幕：先查死者

> **找出科兹洛夫的住址** → **搞清楚科兹洛夫到底被卷进什么麻烦里了**

科兹洛夫是那辆车的主人。**车上有血，信里有威胁**——这两件事放在一起，最自然的推断是他出事了。

这一格的设计很讲究：它不给你「去找谁问」的指引，只让你**先把人是谁搞清楚**。整章的语气从这里就定下来了——**这是一桩案子，不是一个任务**。

### 2.2 第二幕：Skier 的名字出现了

> **询问 Skier 阿纳斯塔西娅的事情 → 进入 Skier 犯罪同伙的公寓 → 了解这位同伙的更多信息 → 阅读从公寓里找到的文件 → 向 Skier 报告 → 和 Ragman 交谈 → 找到阿纳斯塔西娅的公寓 → 调查公寓入口 → 深入了解阿纳斯塔西娅**

这一段信息量最大，也最容易读乱。把它摊平：

| 人物 | 在这件事里的位置 |
|------|------------------|
| **科兹洛夫** | 死了/出事了的那个人，车里那封信的对象 |
| **阿纳斯塔西娅** | 科兹洛夫要保护的人（他给她留了东西） |
| **Skier** | 海关的地头蛇、明码标价的情报贩子（见[商人群像](../entries/trader-profiles.md)），他知道阿纳斯塔西娅是谁 |
| **Skier 的同伙** | 中间人，公寓里留着文件——线索在这里拐了个弯 |
| **Ragman** | 管衣物与流通的人，阿纳斯塔西娅这条线要靠他 |

**注意这一段的写法**：你先找 Skier，再进他同伙的公寓，**读完文件之后还要回去向 Skier 报告**。也就是说——**Skier 在借你的手查他自己的人**。这是本章最像「黑帮片」的地方：他不阻止你，他让你查，然后听你汇报。

### 2.3 第三幕：从信使到 Boss

> 找到**信使帕沙** → 搜索偷袭位置周围 → 与 Skier 对话 → 找到 **Reshala 的储藏处** → 调查 Reshala 的窝棚 → 找到科兹洛夫的藏身处 → 找到并获取科兹洛夫的证据

线索最后指向**Reshala**——海关的 Scav Boss。这一幕把事情的性质彻底改变了：

**一开始你以为是一桩私人纠纷（一封威胁信），查到中段发现牵涉本地犯罪网络（Skier 的同伙、信使、偷袭），最后一格告诉你，证据在 Boss 的窝棚旁边。**

而「科兹洛夫的证据」这件道具的描述，是这一章的落点：

> 🗣️ **犯罪证据录音带**（游戏内物品描述）
>
> 「科兹洛夫为阿纳斯塔西娅准备的录音带。从科兹洛夫的来信判断，里面是**城市当局与当地犯罪分子勾结的铁证**。」

**「城市当局与当地犯罪分子勾结」**——一句话把层级拉开了：这不是街头仇杀，是**官商匪一体**。

## 3. 结果：一份能扳倒人的东西，落在你手里

| 变化 | 内容 |
|------|------|
| **获得** | 科兹洛夫的证据（犯罪证据录音带）——**当局与犯罪分子勾结的铁证** |
| **关系** | 你替 Skier 查清了他同伙这条线；和 Ragman、Reshala 的地盘都打过照面 |
| **叙事** | 你知道了海关这条街上「为什么是这样」：**上面有人** |

这一章不改变终局，也不解锁别的章节。它的作用是把塔科夫的**地面层**铺开：前面几章讲的是集团、军机、EMP，这一章讲的是**一条街上的人怎么被上面的人吃掉**。等到[门票](the-ticket.md)里 Kerman 要「重大罪证」时，你会明白这种证据在塔科夫是什么分量。

## 🧭 走这一章的几个判据

- **触发方式是「走过去」**：不需要接任务，靠近那辆白车就开。错过它的人多半是没往宿舍楼那边走。
- **文件要读，不要只拿**：公寓里的文件是下一步的判据。
- **Reshala 那一段是整章最硬的**：他的地盘不是随便进的，做好打一堂的准备，或者挑他在别处的时候去。
- **证据到手就算结账**：不需要交给谁，它是你的。

## ⚠️ 常见误解

- **「这章是 Skier 的任务」**：Skier 只是中途出现的人，这一章从头到尾是你自己在查。
- **「科兹洛夫是被随机打死的」**：他的死法和那封信、和阿纳斯塔西娅、和当局都有关系。
- **「证据交出去能换好处」**：这一章的交付物不进任务栏，它留在你身上。
