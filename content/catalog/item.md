# 物品详情（Item Detail）

> 版本基线：2026 年 10 月 ｜ 1.2.0.0（第一赛季 KORD BREACH）｜ 数据来源：tarkov.dev（二级）
> 单件物品的完整页面。数值随版本调整，引用时请附「以游戏内为准」。

<a id="top"></a>

## 📸 本页是什么

[物品图鉴](index.md) 的分类页是**一排同类物品横着比**；这一页是**单件物品竖着看** —— 官方介绍、重量与占地、商人买卖价、怎么拿到它、有没有任务要它，一屏读完。

> **这是一个视图页，不是 4979 个页面。** 全站没有给每件物品各生成一个 HTML —— 实测那样做站点会从 23 MB 涨到约 700 MB，而每页 146 KB 里绝大部分是站点框架开销。本页按地址里的物品 ID 渲染对应物品，**链接可分享、可收藏、可刷新恢复**。

## 📐 数据口径

| 项目 | 说明 |
|------|------|
| **收录范围** | 全部 **4979 件**物品（不含枪械预配方案），与[物品图鉴](index.md)同一份数据 |
| **官方介绍** | 游戏内物品描述的中文本地化原文 —— **4964 件有**，其余官方未提供中文，显示为空 |
| **价格** | **商人最低售价 / 最高回收**，静态快照；**不含跳蚤价**（站内不联网、不收实时价，与[配方速查表](../docs/recipes.md)同口径） |
| **占地** | 宽 × 高，即游戏内的格子数（不是体积、不是重量） |
| **外部链接** | 指向官方 Wiki 的对应条目；本站不收录配图（沿用全站约定） |
