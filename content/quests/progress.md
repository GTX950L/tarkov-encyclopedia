# 我的进度

<a id="top"></a>

> 第九篇把 515 个任务逐条列全了，但**进度记在哪**一直是本站的空档 —— 游戏内不给整体视图，跳蚤市场也查不到，每局都要靠回忆「这个我交了没有」，而回忆会出错。
>
> 这一页补上这件事，记三样：**任务打勾**、**物品囤了多少件**、**藏身处建到几级**。三样都只存在你自己的浏览器里 —— 不上传、不需要账号。

## 📸 一句话说明

| 项目 | 说明 |
|------|------|
| **记什么** | ① 任务完成（515 项）② **物品已囤件数**（79 种高频需求物品，按件记）③ 藏身处模块等级（**26 个模块**） |
| **怎么记** | 任务在**各自的任务页**上勾（标题左侧的方框）；物品与藏身处在本页直接改数字 / 选等级 |
| **分模式** | PVP / PVE / 赛季 三套独立记录，页面顶部的进度模式条切换 |
| **存在哪** | 本机浏览器的 localStorage，**不联网、不上传、不需要登录** |
| **最大限制** | 换浏览器、换设备、清缓存 = 进度归零。要迁移或备份，用[进度管理](#manage)的导出 / 导入 |
| **数据口径** | 任务与物品来自**持久 PvP** 档案；藏身处材料取自官方数据端点。三套模式**共用同一份清单**，差异见下文 |

## 📦 物品收集

口径与[任务图鉴总览](index.md)的「物品需求反查」表**完全一致**：把 515 个任务里真正要上交或放置的物品按物品聚合，只列**被 3 个及以上任务需要**的那些（共 79 种）。这是「值得提前囤什么」的清单，不是全物品库。

**按件记，不按「有 / 没有」记**：79 种里有 75 种的合计需求在 10 件以上（卢布 440 万、BEAR 狗牌 575 枚），两态根本表达不了「还差多少」。

<div id="tk-board-items">进度看板需要 JavaScript 才能显示。</div>

> **两个容易读错的数**：
>
> - 「**合计数量**」是这些任务要求的**总件数**（跨任务求和），不是单次需求 —— 别照着一个数字一次囤齐；
> - 「**达标**」只表示件数够了，**不代表任务能过**。约一半的需求带 **必须战局内找到** 的限制，跳蚤市场买的不算数 —— 标完之后回任务页看那一条的具体要求。

## 🧩 藏身处

**26 个模块、68 个等级、317 条材料**，逐级列在[藏身处模块](../entries/hideout-modules.md)页的 [§7 逐级材料清单](../entries/hideout-modules.md#materials)里。这一栏把它变成可操作的：选定模块当前等级后，直接显示**下一级需要哪些材料、要几件**，以及该级的前置设施、技能要求与施工时长。

<div id="tk-board-hideout">进度看板需要 JavaScript 才能显示。</div>

> **「可升下一级」只看材料够不够**：前置设施与技能等级是**游戏内状态**，本站没有这部分数据可依据，所以只做提示、不做判定。看到「前置 通风 2 级」请自行核对。

## 📥 进度管理

三条轨、三个模式的进度打成一个 JSON 文件导出；换设备时导入 —— **任务取并集、件数与等级取较大值**，都不会覆盖已有的进度。

<div id="tk-board-ops">进度管理需要 JavaScript 才能显示。</div>

## ⚠️ 三种模式：记录分开，但清单是同一份

模式条上的 PVP / PVE / 赛季 各自记一套，**互不影响**。但要说清一件容易误解的事：

- 本站任务图鉴的数据来自**持久 PvP** 档案（口径见[任务图鉴总览](index.md)）；
- **PVE 与赛季的任务有增删差异，本站没有逐条标注**（这是站内已知的覆盖缺口，登记在[待收录清单](../docs/roadmap.md)）；
- 藏身处的材料数据同样来自**持久 PvP** 口径；
- 所以切到 PVE 或赛季模式时，你看到的**仍然是 PvP 那份清单**，只是勾选记在另一个账本里。

**实务建议**：如果你的 PVE 进度需要准确，用「PVE」模式单独记，但把它当成一份**近似清单** —— 个别任务在 PVE 里可能不存在或另有一套条件，以游戏内为准。本站宁可把这句话写明，也不给一份看起来精确、实际对不上的完成度。

## 🧭 怎么用

1. **先选定模式**（页面顶部的进度模式条）。三个模式各自独立，随时可切。
2. **任务**去任务页勾。任选一个商人页，比如 [Prapor](prapor.md)，任务标题左边出现方框，点一下即标记完成；页首那张索引表会同步点亮。
3. **物品**在本页按件记：用 − / ＋ 调数字，也可以直接输入。物品可以按物品名或商人名筛选，也可以只看未达标的。
4. **藏身处**先选模块的当前等级，下面立刻显示下一级的材料清单，照着填「已囤」的数字；材料齐了这个模块会标成可升。
5. **回这一页看汇总**：任务按商人列出已完成 / 任务数 / 完成度；物品与藏身处各有自己的汇总卡。
6. **需要备份或换设备**，用「进度管理」的导出 / 导入。

想先确认某个任务的要求再勾，从[任务图鉴总览](index.md)按商人或按地图进去 —— 本页只负责记，不解释内容。

## 🚫 这个功能刻意不做的事

| 不做 | 为什么 |
|------|--------|
| **不自动推断前置完成** | 任务有失败条件、有分支、有跨商人的进度计数器（判读见[任务图鉴总览](index.md)）。推断出来的进度会让读者据此跳过准备，**比没有进度更危险** |
| **不读游戏日志、不识别截图** | 那需要读你本机的游戏文件或上传图片，与「不联网、不上传」直接冲突。本站不做 |
| **不判定前置设施与技能** | 技能等级、设施等级都是**游戏内状态**，本站没有数据可依据 —— 只把该级的要求列出来提示，判定留给读者 |
| **不因为勾选改动正文** | 要求 / 奖励 / 前置一个字都不动。进度是可丢失的本地数据，正文是站点资产，两者不混 |
| **不做账号、不做云同步** | 本站是静态站，没有服务端。任何「进度存在账号上」的说法在这里都不成立 |

## ⓘ 数据与隐私

本站不收集任何个人信息，也没有服务器可以收集。进度写在你自己浏览器的 localStorage 里，键名 `tarkov_progress_v1`，删掉它就等于清空全部进度。

三点需要知道：

- **物品与藏身处的键是中文名**（这两份派生数据里没有稳定 id）。若将来官方译名变动，旧记录会失效 —— 任务那一栏不受影响，它用的是数据端点的 id；
- **浏览器隐私模式 / 禁用 localStorage** 时记录在当前页面内仍可用，但**关掉就没了**（脚本会静默降级，不弹错）；
- **导出文件是明文 JSON**，含三条轨、三个模式的进度，没有身份信息。它和你的游戏存档无关，只对本站这一页有意义。
