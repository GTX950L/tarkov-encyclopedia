# 任务全景图 (Quest Tree)

> 版本基线：2026 年 10 月 ｜ 1.2.0.0（第一赛季 KORD BREACH）｜ 数据来源：tarkov.dev（二级）

<a id="top"></a>

> **515 个任务、238 条前置边，按 11 位商人分列铺开的一张大图。** 这一页回答「**全貌长什么样**」——链从哪起、往哪走、哪几处汇到 Kappa 线；单个任务「卡在哪个前置、做完放开哪些」这两件事，仍归[我的进度](progress.md)的**依赖树**管（那是定向问答，这是全站地图）。

<div id="tk-quest-tree">任务全景图需要 JavaScript 才能显示；本页的图例与说明不需要脚本。</div>

## 🧭 怎么看

| 操作 | 结果 |
|------|------|
| **拖拽** | 平移（手机单指同） |
| **滚轮 / + − 按钮** | 缩放（以指针位置为锚）；手机双指捏合同 |
| **搜索框** | 输中文任务名：**不匹配的节点变淡**，视图自动移到第一个匹配 |
| **单击节点** | 弹信息面板：商人 / 等级 / 前置与后续个数 / **三态切换**（与「我的进度」同一份本机记录，改哪边都是同一笔）/ 打开任务详情 |
| **悬停节点** | 高亮它的**全部前置与后续连线**，相关任务加深 |
| **复位** | 回到「整宽可见」的初始视图 |

## 🎨 图上有什么

| 元素 | 含义 |
|------|------|
| **一位商人一列**（Mechanic → Lightkeeper，与左侧导航的商人页同序） | 列顶写着商人名与该列任务数 |
| **卡片 = 一个任务**；`Lv.N` = 接取等级（0 级不显示） | 名字过长的以省略号截断，悬停看全名 |
| **卡片底色** | 🟩 已完成 ／ 🟨 进行中 ／ 无色 未标记（读[我的进度](progress.md)本机记录，实时同步） |
| **卡片内圆点** | 🟡 Kappa 收藏家线（13 个） ｜ 🟣 Lightkeeper 线（7 个） |
| **连线** | 前置 → 后续。**同列实线、跨列虚线**（跨商人的依赖有 63 条，虚线让默认视图干净）；悬停节点时相关连线加深 |
| **列内顺序** | 不是按等级硬排：**按「链簇」聚合**——同一组互相依赖的任务连成块、簇内按链的先后排，孤立任务随同期落位。所以「一条链顺着往下读」是通的，但相邻两卡不保证等级连续 |

## 📐 口径与边界

- **画的是什么**：`taskRequirements` 里的**前置任务边**（官方任务定义，与[任务图鉴](index.md)的「解锁收益」、[我的进度](progress.md)的依赖树**同一张边表**）。整个图是**只读的任务结构**，不含走位路线与执行顺序（口径同[引用说明第六节](../docs/citation.md)）。
- **不画什么**：限时与活动任务不在 515 条口径内（见[补遗页](event-quests.md)）；每日 / 每周任务同样不在。
- **布局是站内算的**：515 个节点里 **296 个没有任何前置**（多是各商人的开局任务）——全部「摊平」排没法定序，所以按**链簇**聚合排布（生成脚本 `scripts/gen_quest_tree.py`，产物入库、随数据重跑）。
- **进度记录存在哪**：本机浏览器 localStorage（键 `tarkov_progress_v1`），与[我的进度](progress.md)完全同一份 —— 这一页只是它的一种画法。
