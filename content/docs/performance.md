# 配置、性能与现实门槛

<a id="top"></a>

> 这一页回答三个问题：**官方要求什么配置、实际瓶颈在哪里、哪些开关值得动一下**。
>
> 数据基线：**游戏版本 1.1.5.1**。配置要求取**官方商店页**口径，其余逐条标注来源层级——**“官方”与“社区共识”在这里是分开写的**，请按标注判断该信几分。

---

## 📋 官方配置要求

| | 最低 | 推荐 |
|---|---|---|
| 操作系统 | Windows 10 | Windows 11 |
| 处理器 | AMD Ryzen 5 3600 或同级 | Intel Core i7-14700F 或更高 |
| 内存 | **16 GB** | **64 GB** |
| 显卡 | GTX 1660 或同级 | RTX 4070 或更高 |
| DirectX | 11 | 11 |
| 存储 | **80 GB** 可用空间 | 80 GB 可用空间 |

> **先盯住推荐配置里的那一行内存：64 GB。** 这个数字在同类游戏里高得反常——它的意思不是“64 GB 才能玩”，而是**官方自己承认大图会把内存吃到很高的水位**。16 GB 只是能进游戏的门槛。

---

## 🧠 真正的瓶颈不是显卡

Tarkov 的负载结构和多数 FPS 不同。下面三条是**社区长期共识，不是官方口径**，但解释了“为什么换了显卡没感觉”：

| 资源 | 为什么重要 | 你会看到什么 |
|------|-----------|-------------|
| **CPU 单核性能** | 大量物理、AI 与战局逻辑压在少数线程上 | 显卡再好也拉不动；换 CPU 的收益常大于换显卡 |
| **内存容量** | 大图（街区、灯塔、终点站）的资源常驻内存 | 16 GB 会开始大量换页——表现为**周期性微卡顿**，而不是持续低帧率 |
| **存储速度** | 资产流式加载 | 机械硬盘 → 加载久、开战晚、贴图迟到。**SSD 是硬要求，NVMe 更稳** |

> **为什么“把画质全拉低”经常没用**：那样只减轻了 GPU 负担，而瓶颈在 CPU 与内存上——于是你会看到“帧数没变、画面却糊了”。真正有效的杠杆是**降低 CPU 侧负载**（可见距离、物体 LOD，以及地图本身的规模与 AI 数量）和**给内存减负**（关掉浏览器这类后台大户）。

## 🎛️ 官方明确写过用途的开关

这几个可以放心动——它们的用途是**官方在补丁说明或支持页里写明的**：

| 选项 | 位置 | 官方说明 |
|------|------|----------|
| **体积光（Volumetric light）计算** | 图像设置 | 补丁 **0.16.1.2** 新增“关闭体积光计算”：**关闭可提升低端设备在所有地图的客户端性能**。该选项**默认开启** |
| **DLSS** | 图像设置 → NVIDIA DLSS | 官方支持页：DLSS 需要 **RTX 20 系及以上**；**GTX 10 / 16 系没有 Tensor 核心，不支持** |
| **DLSS 模型预设** | 图像设置 → DLSS Preset | **游戏内可直接切换，战局中也能改**。默认预设为 **Preset D**；想要更清晰可试 **Preset J / K**（Transformer 模型，K 比 J 更稳、鬼影更少） |

> **一个容易白折腾的点**：如果你用过 NVIDIA App 改 DLSS 预设，**NVIDIA App 的优先级高于游戏内设置**，会把你游戏里的选择覆盖掉。想用游戏内切换，先在 NVIDIA App 里把 “DLSS Override - Model Presets” 设为“使用 3D 应用程序设置”。

### 画质与可见性的取舍原则

比起抄一张具体数值表，记住这条原则更耐用：**凡是让画面“变糊、变暗、变花”的选项，往往既吃性能又伤可见性，一律关掉。** 属于这一类的有——噪声（Noise）、色差（Chromatic aberration）、动态模糊（Z-Blur）、草地阴影（Grass shadows）：它们对画质几乎没有贡献，却直接妨碍你辨认远处的敌人。

另一类**只看性价比**：

| 选项 | 建议 | 理由 |
|------|------|------|
| 阴影质量、环境光遮蔽（HBAO）、屏幕空间反射（SSR） | **调低或关闭** | 吃性能多，战术价值低 |
| 纹理质量 | **显存够就调高** | 显存 8 GB 以上时对帧数影响很小，属于“免费”的画质提升 |
| 可见距离 / 物体 LOD | **双刃剑** | 调高能更早看到远处目标，但吃的是你最缺的 CPU 资源 |

> 多数玩家把可见距离落在 **1000–1500**、物体 LOD 落在 **2–2.5**。**这组数字是社区共识值，没有官方背书**——请用**离线战局**自己试，别在实战里摸索。

## ⚙️ 系统侧：几条不花钱的

以下均为**社区通行做法，非官方建议**，代价与收益都写在一起，自己权衡：

| 做法 | 收益 | 代价 |
|------|------|------|
| BIOS 里打开 **XMP / EXPO** | 内存跑回额定频率（不少整机默认仍在 2133 MHz，白白丢帧） | 无 |
| 开启**硬件加速 GPU 调度（HAGS）** | Windows 11 显示设置里可开，对帧生成时间的稳定性有帮助 | 需重启；个别驱动组合下收益不明显 |
| 关闭**基于虚拟化的安全性（VBS / 内存完整性）** | 在 CPU 受限的游戏里通常有可感知收益 | **牺牲一层系统安全防护**——在意安全就不要关 |

> 还有两条老规矩仍然成立：**把游戏装在 SSD 上**；**战局前关掉浏览器这类内存大户**——在 16 GB 的机器上，一个 Chrome 就可能是最后一根稻草。

## 🛡️ 反作弊与安装

- **BattlEye** 为核心层反作弊（官方商店页标注）。**卸载游戏后需要手动移除**，不会随卸载自动清干净；
- 由此推出一条实用结论：**别装任何“画质增强”“解锁帧数”类第三方修改**。为几帧冒账号风险不划算；
- **Steam Deck 官方标注为不支持**（Unsupported），不要为玩塔科夫去买掌机。

## 🔭 即将变化：Unity 6 与 FSR 4.0

官方在 2026 年 5 月的 TarkovTV 里公布了**把引擎升级到 Unity 6、并加入 FSR 4.0** 的计划，列在 2026 年 Q3 的路线图上。社区在测试服（ETS）上的初步反馈是：**渲染性能有明显改善，但服务器同步与 AI 峰值造成的卡顿不在此列**。

这不是“现在就该换机器”的理由，但意味着两件事：**当前这套配置门槛可能会松动**，而**本页的推荐值需要在新版本落地后重新核对一次**。

> **来源层级说明**：引擎升级与 FSR 4.0 出自官方直播及路线图的媒体转述，**尚未在正式服落地**；上表标注“官方”的条目出自官方补丁说明或官方支持页；标注“社区共识 / 社区做法”的内容**没有官方背书**，只作起点参考。
