# 配方速查表（制作与交换）

<a id="top"></a>

> 两类配方一处查：**藏身处制作 214 条**、**商人交换 855 条**。每条给出产出、设施或商人、等级与材料清单（制作另含时长）——**不含价格与利润**，那属于实时数据，原因见下。

<div id="tk-recipe-browser">配方查询需要 JavaScript 才能显示；本页其余说明不需要脚本。</div>

## 📸 数据口径

| 项目 | 说明 |
|------|------|
| **制作配方** | **214 条**，覆盖 8 个设施：工作台（94）、卫生间（41）、医疗站（28）、情报中心（26）、营养部（19）、集水器（4）、酿酒处（1）、比特币矿场（1） |
| **交换配方** | **855 条**，覆盖 8 位商人；其中 **66 条需要先完成任务解锁**，表内单独标注 |
| **数据来源** | `json.tarkov.dev/regular` 的 `crafts` / `barters`（**二级来源**），抓取于 **2026-10-06** |
| **口径提醒** | 持久 PvP 档案口径。赛季角色的全局修改器会改写部分数值（例如本赛季「巧手」把制作时间减半）——本表列的是**基础值**，进赛季前先看[赛季修改器逐项](../entries/season-modifiers.md) |
| **不含什么** | ① **价格与利润**（见下节）；② 坐标与点位；③ 逐步攻略 |

## 💡 怎么用

1. **想知道「这件东西怎么做」** → 搜索框输入物品名，产出与材料两侧都会命中；
2. **想清仓库** → 输入某件材料的名字，能查出**哪些配方会用到它**——进图前决定「这件留不留」时最常用；
3. **按设施或商人缩范围** → 做藏身处升级时先筛设施；卡商人忠诚度时先筛商人；
4. **「工具」类材料不消耗** → 工作台与医疗站配方常带工具（如 Elite 钳子），它只在制作时占用、不会用掉，表内标为「工具」；带「任务」标记的材料是任务物品，不能直接购买。

## 📐 为什么不列价格与利润

同类数据站（如[中文 Wiki](https://www.eftarkov.com/)、tarkov-market）会给出「材料成本 / 售出价格 / 利润」三列——本站**有意不列**：

- 价格是**实时数据**：同一条配方今天的利润与三天后可能完全不同，写进静态页等于给读者一个会过期的答案；
- 本站的引用规矩是「**引具体数值必须附加版本限定**」（见[数据口径与引用说明](citation.md)）——实时价格连这条限定都做不到。

**要算利润**：把这里的材料清单抄到物价站查当日价即可——那些站点的价值在**实时**，本站的价值在**结构**（谁、什么等级、要什么、多久）。

## ⚠️ 已知边界

- **6 种物品未收录译名**：情报中心「钥匙卡重编码」类配方用到的 6 种材料在数据端点的译名字典里没有名字，表内统一显示为「未收录物品」——**不猜名字**，端点补齐后重新生成即可补上；
- **数量带小数的材料**：GP 币这类可分割物品会出现小数（如 ×0.42），按数据原样显示；
- 数据端点会随游戏版本更新，本表的抓取日期见上表。
