# 操作与设置

<a id="top"></a>

> 本页属于**参考区**（不计入条目数）。设置项随版本变动较大，**以游戏内实际选项为准**；本页只回答一个问题：**哪些设置真的会影响战斗结果。**

## 🖱️ 灵敏度与视野

| 项目 | 该怎么想 | 注意 |
|------|----------|------|
| **鼠标灵敏度** | **没有“正确值”，只有“一致性”**。改了灵敏度就等于**重置肌肉记忆**——定型之后尽量不要再动 | 基准判断：**能在一次大幅转身里稳定停在目标上**，而不是甩过头 |
| **瞄准灵敏度**（倍镜/普通分开设置） | 高倍镜通常要**比腰射更低**，否则微调会抖 | 倍镜下把灵敏度调低，是打远距离最便宜的一次提升 |
| **视野（FOV）** | 视野大 → 画面包角大、**但目标在屏幕上更小**；视野小 → 目标大、**但侧后方盲区更大** | **视野不改变“你能看到多远”**（那是渲染距离与瞄具决定的），只改变你能同时看到多宽 |

## ⌨️ 键位：真正值得改的只有几个

- **【最值得改的一个】把“检查武器”和“排除故障”合到同一个键**：在**控制设置**里，把**检视当前武器**与**检查弹匣 / 排除故障**绑到同一个键，并分别设置按键模式为**按下**与**松开**。这样**按住=检查，松开=排除故障**，卡壳时省掉一次切换键位的操作。这是全网通行的一条改键，也是本页最有实用价值的一条；
- **侧身与蹲**：确保在**不影响 WASD 移动**的前提下能按到——它们是每一场交火都要用的；
- **医疗与投掷物**：放在手指**不用离开移动键**就能触及的位置；
- **注意“按键模式”**：现在不少功能支持**按下 / 松开 / 双击**三种触发方式，同一个键可以承载两个动作（上面那条改键就是靠它实现的）。

## 🔊 音频：影响最大的一项

**先说结论：游戏内的耳机装备比任何设置都重要**（见[听声辨位与音频机制](../entries/audio.md)）。设置只做两件事：

| 设置方向 | 目的 |
|----------|------|
| **拉开“小声”与“大声”的差距** | 让远处的脚步、开镜声**不被自己的枪声压平**——这是所有音频设置里唯一真正影响战术的部分 |
| **保持方向性** | **不要开启系统级的音效增强、虚拟环绕或均衡器**。它们会把双声道定位算法弄乱，**方向准度比音质重要得多** |

> 还有一条常识性的纪律：**戴耳机，而不是外放**。外放等于把信息丢了一半（而且会吵到别人）。

## 🖥️ 画质：哪些项目真的“影响看得见人”

画质设置分成两类——**只有一类影响战斗**：

| 影响战术 | 为什么 |
|----------|--------|
| **后处理 / 锐化** | 直接改变画面的对比度与边缘清晰度，**影响“能不能第一时间从背景里分离出人形”** |
| **抗锯齿** | 过度模糊会让远处的目标更难辨认，**边缘糊掉就等于认不出轮廓** |
| **阴影** | **阴影是双刃剑**：关掉可以降低视觉噪音、提升帧数，但也**放弃了影子这个额外的索敌线索** |
| **植被密度** | 与侦测相关（见[AI 行为逻辑](../entries/ai-behavior.md)的植被规则），也直接决定你能不能看穿树丛 |

| 基本不影响战术 | 说明 |
|----------------|------|
| **纹理质量、水面、云、贴花** | 只改变观感与帧数，不影响索敌 |
| **各项性能开关** | 属于帧数预算问题——见[配置与性能](performance.md) |

**判断原则**：**先保帧数与“边缘清晰”，再谈好看。**在塔科夫里，**能稳定 60 帧的模糊画面，胜过 30 帧的高清画面。**

## 🎮 值得知道的操作（容易漏的那几个）

| 操作 | 作用 |
|------|------|
| **双击 O** | 显示**当前可用的撤离点列表**——**没有小地图**，这是唯一的官方信息（见[撤离机制](../entries/extraction.md)） |
| **C + 滚轮** | 调整蹲伏高度，只露眼睛不露身体（见[姿态、移动与射击](../entries/movement.md)） |
| **G** | 手雷选择：快捷栏上的图标会显示下次使用的是哪一颗；**长按可以指定具体投掷物** |
| **双击消耗品** | **自动使用**该物品（等价于右键菜单里的“使用”） |
| **H / Ctrl + H** | 开关战术装置与头盔照明；**Ctrl + H 切换模式** |
| **Y 键** | 手势 / 指令轮盘——**对 AI Scav 下命令的入口**（见 [Scav 指挥与随从系统](../entries/scav-command.md)） |
| **F1** | 角色语音，用于试探与伪装（见[敌我识别与身份判断](../entries/iff.md)） |

## ⚠️ 三个设置层面的常见错误

- **频繁改灵敏度**：每一次改动都在推翻你已经建立的肌肉记忆。**先固定，再适应**；
- **开胜利者画质**：把帧数与边缘清晰换成纹理细节，是性价比最低的一种“提升”；
- **让系统软件接管音效**：第三方音效增强会破坏定位，而**定位是塔科夫最重要的信息通道**。
