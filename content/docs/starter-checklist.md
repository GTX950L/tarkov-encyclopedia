# 新手开局检查清单

<a id="top"></a>

> **这一页是给打印用的。** 它把「每一局要做什么」压成一张勾选表——**进图前照着勾一遍，撤离前再勾一遍**。它是[新手成长路线](progression.md) 的配套页：那边讲「每个阶段该达到什么」，这边只管「**这一局手上别漏什么**」。

> 📈 **本页只列动作，不列数值与型号**——装备选型随版本变，勾选表要能长期贴在墙上用；具体数值以游戏内为准。

---

## ① 进图前（在藏身处 / 装备界面）

**先定这一局的目标，再定装备档位**——目标不同，带的东西不同。

- [ ] **写下这一局的目标**：练图 / 做任务 / 攒钱 / 打硬仗（选一个主要的）
- [ ] **想好两条撤离路线**：一条主用、一条备用（想不起来先看[撤离点详解](../entries/extraction-points.md)）
- [ ] **武器**：一把打得顺的枪 + 至少 1 个备用弹匣（弹仓供弹的栓动武器除外）
- [ ] **弹药**：带得起的里面**穿深最高**的那一档——**子弹比枪重要**
- [ ] **医疗三件套**：止血 + 止痛 + 包扎
- [ ] **补给**：长图带水与食物，短图至少带水（[食物与水分](../entries/food-and-water.md)）
- [ ] **安全箱**：钥匙、贵重小件、任务物品——**别塞满弹药**
- [ ] **特殊槽三格**：填满（死亡不掉、对手搜不走）
- [ ] **保险**：全选投保
- [ ] **任务**：把可用任务接满（含每日 / 每周限时任务）
- [ ] **止损线**：这一局**什么时候必须收手**，先想好

---

## ② 战局内（进图之后）

- [ ] **出生后先听 2 秒再动**——头 30 秒是死亡密度最高的窗口（[开局与出生点](../entries/spawn-and-opening.md)）
- [ ] **按计划抢点**，路上不恋战
- [ ] **搜刮前先清场**——翻箱子、搜尸体、打药是三段最脆弱的时间
- [ ] **遇到人先过五问**：身份 → 是否被发现 → 距离 → 退路 → 收益（[遇敌处置与接战决策](../entries/contact-drill.md)）
- [ ] **动了就动到底**：要么先手打完，要么脱离断联，别站在原地犹豫
- [ ] **止损线一触发就撤**，不追加贪心

---

## ③ 撤离前

- [ ] **看一眼这一局的战利品**：够本就走，不足预期也别硬凑
- [ ] **确认撤离点「现在可用」**（双击 O 看列表，但列表不告诉你怎么走）
- [ ] **别在撤离点附近恋战**——那里最容易「满载而亡」
- [ ] **撤离后核对结算状态**：**不是 Survived，物品就不算战局内发现（FiR）**，很多任务会因此白做

---

## ④ 回藏身处（一条龙）

- [ ] **先清空邮箱**——保险返还、货款、任务奖励都在里面，**会过期**（[邮件与领取](../entries/mail.md)）
- [ ] **补藏身处燃料**（建了相关模块的话）
- [ ] **卖货变现**：低价值卖商人、高价值先比价再挂跳蚤
- [ ] **接新任务 / 交付已完成的任务**（记得回商人菜单点「完成」）
- [ ] **补装**：把这局消耗的弹、药、装备补齐，为下一局做好准备

---

## 🎯 三条最容易漏的

1. **撤离点没确认** → 超时判 MIA，全部身家一起丢；
2. **忘了交付 / 忘了领邮件** → 任务按失败结算、奖励过期作废；
3. **撤得太快** → 判「匆匆撤离」，物品不算 FiR，很多任务白做。
