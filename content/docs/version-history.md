## 🧱 第一阶段：八年封闭测试的开端（2016–2019）

### 关键节点

- **2016-08-04**：封闭 Alpha 上线——塔科夫正式向玩家开放。
- **2017-07-28**：转入封闭 Beta，此后八年一直挂着 beta 标签。
- **0.12.0.0（2019-10）**：**藏身处**系统上线、**储备站**地图加入、引擎升级到 Unity 2018.4、战后必须治疗才能再战。

### 作用

这是塔科夫从“硬核射击 demo”变成“长线 RPG”的转折点：

- 藏身处把**离线时间**变成了成长资源，玩家第一次有了 raid 之外的事可做；
- 战后治疗机制把“装备循环”变成了经济压力，钱第一次成了硬约束；
- 储备站的加入让中期玩家有了军事题材的高价值目标点。

### 玩家反馈

- 藏身处被普遍视为**最成功的系统设计之一**——“终于不用每一分钟都在枪口下了”；
- 但战后治疗+藏身处升级的**“肝度”**也开始被讨论，这套设计后来成为“塔科夫像上班”这一批评的源头。

## 🏙️ 第二阶段：内容扩张期（2020–2023）

### 关键节点

| 版本 | 时间 | 核心内容 |
|------|------|----------|
| 0.12.6 | 2020-05 | 海关地图大扩建、Shturman（森林 Boss）、超重系统重做 |
| 0.12.12 | 2021-12 | **灯塔**地图上线、**惯性系统**、VOIP 语音 |
| 0.12.12.30 | 2022-06 | 灯塔扩建（可上岛）、Goons 精英 AI |
| **0.13.0.0** | 2022-12-28 | **街区（Streets of Tarkov）首版**、Oculus 音频、技能重做、装备维护套件 |
| 0.13.5.0 | 2023-08 | 街区扩建（Concordia）、新 Boss Kaban、**装备预设**、**随机容器刷新** |

### 作用

- **街区**是塔科夫史上体量最大的地图，把“城市巷战”做成了独立玩法；
- **惯性系统**彻底改变了移动手感：急停、拉扯、贴掩体的操作逻辑被重写，这一改动至今仍是核心手感差异点；
- **随机容器刷新**打击了“背路线刷物资”的固定套路，逼玩家重新学会探索；
- **装备预设**让“进图配装”从手工劳动变成一键操作，直接影响出图效率。

### 玩家反馈

- 街区上线即遭遇**性能灾难**：严重掉帧、崩溃、撤离困难，被玩家戏称“幻灯片街区”，后续多个补丁才逐步修复——这是塔科夫口碑最差的一次地图发布；
- 惯性系统**评价长期分裂**：支持者认为它让战斗更真实，反对者认为它让新手门槛更高、手感发飘；
- 装备预设几乎**零差评**，被公认为最实用的 QoL 更新之一。

## 🛡️ 第三阶段：系统重构与 Unheard 风波（2023-12 – 2025）

### 关键节点

**0.14.0.0（2023-12-27）——护甲与命中系统大重构**，本次更新是 0.12 以来最大规模的玩法改造：

- **命中区细分**：头部拆成多个区域（对应头盔护区），胸腔、胃部、骨盆各自独立；
- **插板式护甲**：一次性引入 **37 种弹道插板**，护甲的耐久与防护由插板组合决定；
- **移动能力**：翻越障碍物、**换肩**（左右肩切换）、后坐力机制重做；
- **新内容**：**Ground Zero** 新手地图（限 1–20 级 PMC）、新 Boss Kollontay、街区的 BTR 装甲车服务、海岸线重做；
- **收藏与荣誉**：成就系统、藏身处**名人堂**（可陈列战利品并获得战斗技能加成）。

**2024-04-25：The Unheard Edition 与 PvE 模式**

- 新增 250 美元档位的 The Unheard 版本，**PvE 合作模式被绑定在该版本内**；
- 曾承诺“后续所有 DLC 免费”的 Edge of Darkness（EoD）用户认为自己被欺骗，社区爆发塔科夫史上最大规模的一次反弹；
- BSG 随后让步：EoD 用户获得 **6 个月 PvE 权限**，并承诺 PvE 最终面向所有玩家开放。

**同期：Arena 独立竞技模式**上线——脱离搜刮撤离循环，纯枪法与团队对抗。

### 作用

- 护甲重构让“为什么这一枪没打穿”第一次有了**可读的解释**：防护是有区域、有插板、有耐久的；
- 插板系统把护甲从“一件装备”变成了“一套配置”，装备管理深度大幅提升；
- PvE 模式的引入孵化出一个**与 PvP 平行、压力更低**的生态，官方后来表示长期看约半数玩家会流向 PvE。

### 玩家反馈

- 护甲与命中区重构**总体好评**，被认可为“死亡终于可解释”；争议集中在插板价格与管理繁琐，“改完更硬核也更累”；
- Unheard / PvE 定价事件是**公关灾难**，官方定义“PvE 不是 DLC”被广泛批评为文字游戏，P2W 指控持续数月；
- PvE 模式本身在此后**口碑回升**，成为大量休闲玩家的常驻选择。

## 🚀 第四阶段：1.0 正式版（2025-11 – 2026-06）

### 关键节点

**1.0.0.0（2025-11-15）——走出八年 beta**

- **剧情战役**上线：约 20–30 小时的叙事流程，包含分支选择与结局（此前“逃离塔科夫”只是标题）；
- **Terminal 地图**作为剧情压轴场景加入，含动态天气与随机撤离点；
- 新阵营 AI（RUAF 与 Black Division）进入常规战局，AI 行为与协同明显强化；
- **Steam 同步上架**，老账号可绑定免重购；
- 等级体系与成长曲线重构，**强制 wipe（含 PvE 档案）**；
- 面向新手的强化引导与教学。

**1.0 之后的补丁节奏**

| 版本 | 时间 | 核心内容 |
|------|------|----------|
| 1.0.1.0 | 2025-12-24 | 首发问题修复与平衡调整 |
| 1.0.2.0 | 2026-02-10 | 稳定性、任务与藏身处修复 |
| 1.0.4.0 | 2026-03-27 | 内容与平衡补丁 |
| 1.0.5.0 | 2026-05-25 | **Icebreaker 事件**与专属剧情章节、新增 PvE 场景 |

### 作用

- 剧情模式把塔科夫从“只有循环”变成“有终点”，给了休闲与叙事向玩家一个入口；
- Steam 上架带来**大规模新玩家流入**，也让“八年 beta 的老游戏”重新进入主流视野；
- 强化教学显著降低了开局的劝退率，但塔科夫的核心难度并未降低。

### 玩家反馈

- 媒体与玩家共识是“**内容够分量，上线不够平稳**”：剧情战役与地图获得肯定；
- 首发期的**排队、登录失败、网络抖动**被集中吐槽；
- Steam 首发评价长期徘徊在**约五成好评**的水平，“老玩家要重新买一份”也引发不满（尽管绑定老账号可免）；
- PvE 档案被强制重置一事同样招致抱怨。

## ♻️ 第五阶段：赛季化与商业化（2026-07 至今）

### 关键节点

**2026-07-08/09：Expansions Hub 与 TarCoin 上线**

- 客户端内商店落地，使用新货币 **TarCoin**（战局内可获得，也可官方渠道购买）；
- 用于外观、仓库扩容、PvE 模式解锁等——塔科夫第一次把**付费内容搬进游戏本体**。

**1.1.0.0（2026-08-03）——赛季系统 + 第一赛季 KORD BREACH**

- **持久角色**：PvP / PvE 档案的等级与仓库进度**长期保留**，不再随每次大更新清零；
- **赛季角色**：独立档案、独立服务器，每 **4–6 个月**重置一次，玩家可自由选择是否参与；
- **修改器系统**：
  - *全局修改器*（全服统一，赛季 PvP 中**保险被禁用**、护甲短缺、制造时间减半等）；
  - *个人修改器*（点数制：选负面得点数，换正面增益，结余不得为负）；
- **免费战斗通行证**：以 TerraGroup 文档类物品推进，进度在 PvP / PvE / 赛季间互通；
- **任务系统重构**：任务解锁改为按**商人忠诚度**触发（不再是一条线性长链）、允许跳过不喜欢的任务、奖励向货币倾斜；
- **Kappa 容器门槛下调**：前置任务减至 **4 条**（**官方公告口径**；上线后实测为 **5 组**，且「化学」「缝补」两条实际卡在更低一环——差异见[商人任务线图鉴](../entries/trader-questlines.md) 的 Kappa 专节）、有效等级约 40（实测 **42**）；旧的“Kappa 之路”成就自第一赛季起**永久不可获得**；
- **经济重整**：商人售价整体上调约 **25%**，抑制早期通胀。

**1.1.5.0（2026-09-08）——灯塔重做**

- 水处理厂**移除地雷与固定炮塔**，Rogue 基地迁至山区别墅；
- 新增地下通道缩短南侧撤离路线、开阔路段增加掩体、**BTR 装甲车巡逻**；
- Lightkeeper 任务线彻底重做，灯塔加入前往 Icebreaker 的中转；
- 削减了 Icebreaker 上刷 Wedge / Black Division 的经验收益。

**1.1.5.1（2026-09-15）——联赛系统**

- 赛季角色完成首场 raid 后进入 **50 人小组**，按周经验结算：**前 25 名升级、中间 15 名维持、后 10 名降级**；
- 经验来源覆盖击杀（PMC / Scav / Boss）、任务与物品检视——实质是给赛季角色加了一层周循环。

**1.2.0.0（2026-10-06）——PvE 专版：转生、AI 重做与老带新计划**

这是 1.0 之后**第一次专门为 PvE 做的一次集中更新**，也是本站当前基线。四条主线：

**① PvE 转生（Prestige）上线，共 6 档**

- **只重置 PvE Zone 档案**，**不影响竞技场（Arena）**进度；
- 可保留**部分装备 + 一定比例的技能与武器掌握（最高 50%）**；门槛逐档递增，可能包含角色等级、特定任务、藏身处模块、通关主线、仓库物品与金额、技能等级六类条件；
- **PvE 第一档门槛比 PvP 更宽松**；
- **转生奖励永久保留，wipe 也不丢**——这是本次更新对长期玩家最重要的结构性变化；
- 奖励分两层：**大部分永久但仅限 PvE 角色**；**一小部分只能靠 PvE 转生获得、但可用于全部模式**（TarCoin、uniques 军牌 / 靶场靶标 / 藏身处海报 / 近战武器 / Tarko 手办 / Gamma 安全箱）；
- **一条给老玩家的通道**：**自 1.0 以来没重置过进度的玩家**，可用第一次转生切到当前进度框架，并**解锁发行内容、剧情主线、Icebreaker 章节与后续全部活动**。

**② PMC bot 行为重做（PvE 专有）**

- **移动**：更主动涌向兴趣点与任务区，会出现在以前不去的区域，路线不再线性；
- **数量**：**开局必有 bot**，数量波动收窄，跨图分布更均匀；**迷宫新增 PMC bot 出生点**并参与战斗；
- **等级**：按地图匹配（**实验室高等级 bot 更多**）；
- **装备与难度**：**由等级与阵营决定**——低等级 bot 用低忠诚度阶段的装备、威胁更低；高等级 bot 配更好的枪与护甲。

**③ bot 阵营关系重做（PvE 专有）**

- **USEC 与 BEAR 的 PMC bot 结伴概率显著提高**；
- PMC bot 有**小概率**对玩家保持中立，直到你靠近或先动手；
- **对 Scav 的中立机会减少**，更常主动攻击 Scav 与 Boss；
- **不会先攻击玩家 Scav**，除非对方靠近或先动手。

**④ EXFIL Brothers 计划（全模式通用，与 Arena 无关）**

- **Operator（干员）**＝注册满 7 天且任意模式 30 级；**Candidate（候选人）**＝注册不满 7 天；
- 走**官网**推荐链接绑定，**组队打图双方各得 5% 经验加成**；
- 候选人每到 **10 / 20 / 30 级**，双方分三批解锁奖励（卢布、比特币、各类 uniques 容器等）；
- **Candidate 窗口只有 7 天且不可续期**——过期后只能带 Operator，无法拿新人档奖励。

**同期还有一批 QoL 与地图改动**：

| 类别 | 内容 |
|------|------|
| **PvE 卢布购买** | Expansion Hub 开放**用真钱购买 PvE 卢布**，**PvP 不开放** |
| **服务器同步** | 改进**服务器端玩家位置同步**（减少橡皮筋效应），官方说明后续还会继续优化 |
| **商人交易** | 新增 **Ctrl + 左键**在购买/出售界面间切换 |
| **好友列表** | 支持**置顶**特定玩家 |
| **Run-Through** | 撤离倒计时**变色提示**：能拿到该状态时显示**白色** |
| **鼓形弹匣** | 装填、卸弹、显示已装填弹药、整包装入均获改善 |
| **军牌与结局** | 可在角色界面查看自己的 PMC 军牌；个人主页可选择展示的结局（PvP / PvE / 赛季档案均可） |
| **海关** | PMC 与 Scav **撤离点新增出口**；**上锁容器保证出货**；宿舍上锁房间与 USEC 仓库新增战利品点；新增 **ZB-1013 Key** 与 **Guard Post Key** 两把钥匙；信号枪撤离点不再被沿墙移动的狙击手射击；董事办公室保险箱可开启；锅炉房地窖撤离不再受出生点限制 |
| **立交桥** | 新增战利品点（Emercom 营地、Object #11SR / #14 / #21WS、OLI 服务区、Kiba Arms 等）；**上锁容器保证出货**；新增容器**含 PMC 尸体**；**收银机规则拆分——ULTRA 独立门店免钥匙，Goshan / IDEA / OLI 仍需钥匙**；三家收银机战利品模板更新 |
| **海岸线** | **环境音频重做**（官方未列出具体调整项） |
| **全局修复** | 单发与自动射击的**音量差异此前不正确**，现已修正；修复 Lab _bot 透视透明物体、PvE 加载卡在“Loading configuration files”、Terminal 无法离开起点、Factory 开局 Tagilla 刷在玩家附近等 |

> ⚠️ **一项需要澄清的落差**：本站此前按官方路线图登记过「**战局重连系统重做**」属于 1.2.0.0。**该内容未出现在 1.2.0.0 的官方补丁说明中**——本次实装的是**服务器端位置同步改进**（并说明后续继续优化），**断线重连本身没有作为独立条目实装**。

### 作用

- **PvE 补上了唯一的“重开”选项**：在永不清零的模式下，转生把“重新开始”变成一件可以主动选择、且**带永久回报**的事；
- **转生奖励跨 wipe 保留**，直接回应了“长期目标会被 wipe 抹掉”这个老问题——**这对留存的作用可能大于任何一张新地图**；
- **AI 重做改变了 PvE 的难度结构，而非整体难度**：强度被按 bot 等级重新分配（低档更弱、高档更强），并让 bot 更贴近真人行为路线；
- **EXFIL Brothers 是一次直接的价格化尝试**：把“带新人”这件一直靠玩家自觉的事写成了带奖励的机制。

### 玩家反馈

- **转生奖励永久保留被视为本次最大的实质利好**，媒体与社区普遍把它读作对长期玩家的承诺；
- **AI PMC 的装备跟等级绑定被普遍称赞**——过去“低等级图刷到高等级 bot”是纯粹的挫败来源，现在这一层被修正了；
- **“USEC 与 BEAR 结伴”**改变了老玩家对 PvE 交火节奏的预期，初期需要重新适应；
- **PvE 可以直接买卢布**在 PvE 社区内评价偏正面（省去起号期攒钱），但在 PvP 社区引发“PvE 花钱换进度”的讨论——官方把它**限制在 PvE** 正是为了避开这个争议。

### 1.1.x 赛季化阶段的作用与反馈

**作用**

- 赛季系统同时服务两类玩家：想开荒的进赛季，想稳定的留在持久档案——塔科夫第一次为“不想 wipe”的玩家提供了官方出口；
- 商业化补全了长期运营的资金结构，代价是**游戏气质被动摇**；
- 灯塔重做把这张长期被当作“过路图”的地图重新拉回争夺视野。

**玩家反馈**

- **持久角色广受欢迎**——“终于不用为了赶 wipe 而熬夜刷装备”是主流意见；
- **赛季 + 通行证 + 付费货币**评价严重分化：反对者认为这是“手游化”“背离塔科夫气质”，支持者认为只要不卖属性就不算越界；
- 联赛被普遍**质疑含金量**：“50 人小池子不是排行榜，更像匹配舱”，且奖励细节长期未公开；
- 灯塔重做**方向获肯定**（拆地雷、加 BTR 让穿图更合理），但新 Marked Room **战利品偏薄**被集中批评，官方公开承认并承诺补强。
