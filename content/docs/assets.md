# 素材来源登记表

## 为什么有这一页

全站审查（2026-11-03）指出一处短板：版权边界写得清楚（见 [LICENSE-NOTICE](https://github.com/GTX950L/tarkov-encyclopedia/blob/main/LICENSE-NOTICE.md)），
但只有**类别级**说明，没有逐项清单。要为「这张底图哪来的、什么版本、改没改过」举证时，
只能去翻 git 历史。

本页把每一类素材的来源、许可、入库时间、修改情况落成表。判据只有一条：
**读者拿着这张表，不必打开仓库也能判断某张图能不能拿走用。**
