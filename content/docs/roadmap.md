**① 术语气泡钳制（修掉第三十五批登记的 `ammo-table` 窄屏溢出）**

上一批把这条登记为「待修复」，症状写的是「页面被撑宽」。**实测后要修正这个描述**：主题给 `html` 设了 `overflow-x:hidden` + `scrollbar-gutter:stable`，所以溢出的部分**既滚不到、也看不见——它就是被裁掉**。390px 下 [更新日志](../CHANGELOG.md) 的「叛徒」气泡右侧被切 **61px**，文字断在半句上。

| 层 | 现象 | 实测 |
|----|------|------|
| 1 | `visibility:hidden` 的绝对定位盒**仍计入滚动溢出区** | 注入 `display:none` → 文档 `scrollWidth` 469 → 369，立刻归零 |
| 2 | **伪元素的包含块锚在 inline 的「第一段」上，不是边界框** | 「PMC 业力」在 390px 下被切成 `[298,350]` + `[16,31]` 两段；`getBoundingClientRect()` 给的是**并集** `[16,350]`（宽 334），而包含块原点在 **298**（用 `position:absolute;left:0` 探针实测）。拿并集当锚，气泡被甩出框 **249px**（390px）/ **484px**（768px） |
| 3 | **`left:50%` 在这类跨行 inline 上解析成 `0px`**，不是半宽 | 所以「让 CSS 兜底居中」这条退路根本不成立——**偏移量必须每次显式写**，不能靠「反正居中装得下」就跳过 |

### 🧭 「侧栏导航偶发不回顶」的竞速根因与五层修复（第五十三批）

> **触发**：读者**第三次**报告「点击左侧导航后，新页面没有回到顶部」。前两轮（初版兜底、v1.33.0 三层兜底）都测过「20/20 归零」——**但测的是快网 + 等待期手不动的场景**，竞速的另一半从未被找到。

**① 复现条件（受控实验，可复用）**：Playwright + CDP 慢网（400ms 延迟 / 120KB/s）+ **等待期内滚动一次** → 修复前 **2/8 通过**（6 次停在 999px，即等待期滚动到的位置）。**「偶发」= 竞速**：快网时每次都赢、慢网时才看得见输面。

**② 根因链（探针还原）**：Material 对 `history.state.y` 的**写链**（滚动 → 节流约 100ms → `replaceState` 写**当前 entry**）与**读链**（切换完成 → `scrollTo(0, state.y ?? 0)`）之间有**三个竞速点**：① pushState 后、内容到达前（DOM 还是旧页）的任何滚动都会**写脏新页 entry**；② 切换完成时「最后一次写入」与「读取」常**同帧背靠背**（rAF 级的清状态插不进去）；③ `document$` 复位在慢网下会**迟到或错过本次通知**。

**③ 修法（五层，`content/javascripts/scroll-fix.js`）**：点击即时复位 → `scrollRestoration = "manual"` → `document$` 复位（**popstate 明确豁免**，尊重后退恢复）→ **导航窗口 rAF 消毒**（清 state.y、不动位置）→ **revert 调用拦截**（hook `window.scrollTo`：窗口内两参数的 `scrollTo(0, 非0)` 一律改写为 `scrollTo(0, 0)` —— 全站唯一如此调用的是 revert 自己）。另修一处积弊：脚本**防重初始化**（instant 切换会重放脚本，此前每换页都会多挂一份监听器与订阅）。

**④ 验证矩阵**：慢网×8：**2/8 → 8/8**；真实 Edge（headed）慢网×3 + 快网×2 + 连续快速点击：**0 失败**；后退恢复 ≈1032px **未被破坏**。

> **判据（本批新增，可复用）**：**「修过两次仍第三次复发」的问题，先怀疑「验收场景漏了竞速的另一半」。** 快网 + 手不动的验收 = 只测了竞速的顺风局；**换网速、换时机（等待期动手）再测**，才能把「偶发」逼成「必现」。（方法侧沉淀：CDP 慢网与「等待期滚动」这类**反常规动作**要进验收剧本；探针 hook `window.scrollTo` 记录全量调用与堆栈，是解开这类时序问题的第一手段。）

它一直躺在同一个渲染对象里。**「技能」那半句对**。原句把「有数据」和「没数据」混成了一句话，
所以修法不是删掉，而是**拆成两句**。

> **判据（本批新增）**：凡是站内自己写「本站没有 X 数据」的地方，**都要回数据文件核一遍**。
> 「没有数据」是最容易写错也最容易长期存活的一类断言 —— 它不指向任何页面，grep 关键词也搜不到，
> 只有**真的去读一遍渲染对象**才会发现。

**现在可升**（前置通 + 材料齐）｜**前置未通**（写明缺哪个模块几级）｜**材料未齐**（前置通、材料不够）｜**已建满**。
