# 新手成长路线

<a id="top"></a>

> 按“阶段目标”划分的成长路线。等级只是参考，完成目标才是实质进度。
>
> 还没入手？先看[购买指南（地区与版本）](buying-guide.md)——版本档次会直接决定你起步时的仓库与安全箱空间。**看不懂黑话**？见[术语与黑话速查](glossary.md)。

## 🥚 第 0 阶段：进图之前

**目标**：把“第一次进图就崩”的概率降到最低。这一阶段不追等级，只补准备。

**① 先把官方教程做完——不要跳**

自 1.0 起，**创建角色后会自动进入一段教程**：在**地面零点的定制战局**里教操作、基础战斗、枪械操作与治疗。官方另外还提供了一套**分步成长指引**。

- 教程里的区域是**受控的**——不该去的地方都被挡住，**遇到敌人说明你走对了**；
- 教程中**你不会死**，可以放开手脚试枪、试治疗、试搜刮；
- 老兵共识很直接：**跳过教程是新手最贵的错误**。

**② 先离线、再 PvE、最后 PvP**

次序很重要：

| 阶段 | 用什么 | 得到什么 |
|------|--------|----------|
| **学地图** | **练习（离线）模式** | 无风险的**布局、出生点、撤离点、视线与伏击区**；开 AI 可模拟实战 |
| **攒第一笔钱** | **[PvE 模式](../entries/pve.md) 或 Scav** | 永久进度（PvE）或零风险收益（Scav） |
| **正式对战** | **PMC** | 真正的进度与风险 |

> ⚠️ **离线模式什么都不保存**——它是地图教室，不是进度来源（见 [PvE 模式](../entries/pve.md)）。

**③ Scav 是你的启动资金**

Scav 每局自带**随机装备**，**零风险、免费钱**。三条用法：

1. **用它学图**，死了不心疼；
2. **用它攒钱**，装备与卢布留给 PMC；
3. **用它练 AI 战**，AI 的反应模式与真人不同，但枪法与走位通用。

**对新手最划算的 Scav 时机是战局后半段**（社区经验：**剩余约 10–15 分钟再行动**）——此时 PMC 大多已撤离或阵亡，生存率明显更高，而箱子大多还没被翻完。

**④ 第一张正式图：地面零点**

**地面零点是为新玩家设计的**（低等级下玩家人数更少），任务也从这里起步。其次是[海关](../entries/customs.md)。

**⑤ 无论如何先学撤离点**

这是唯一一条“不知道就必然亏”的知识：

- 游戏内**双击 O** 可以看到**当前可用的撤离点列表**——但**它不会告诉你路怎么走**（没有小地图）；
- 不知道路就只能**等到超时，判定为 MIA，全部装备与战利品一起丢**；
- **进图前想好两条撤离路线**，一条主用、一条备用。

**⑥ 起手装备：少而够**

| 类别 | 带什么 |
|------|--------|
| **武器** | 一把便宜且你打得顺的枪 + **至少 1 个备用弹匣**（弹仓供弹的栓动武器除外） |
| **弹药** | **带得起的里面穿深最高的那一档**——子弹比枪重要 |
| **医疗** | **止血 + 止痛 + 包扎**三件套；这是保命底线，不是可选项 |
| **安全箱** | 放**钥匙、贵重小件、任务物品**；不要塞满弹药 |
| **其余** | **越少越好**。首局 PMC 的目标不是打架，是**完成任务 + 活着出来** |

**⑦ 你会遇到什么敌人**

认得出对手，才知道该不该打：

| 敌人 | 特征 | 对策 |
|------|------|------|
| **Scav** | 当地武装，多为 AI；**战局中段起会有玩家操控的 Scav 加入** | 玩 Scav 时**别先开枪**；攻击同类会掉 Fence 好感 |
| **PMC** | 真正的玩家（PvE 里是高级 AI） | 默认**见即战**；信任在这个游戏里很贵 |
| **Raider** | 精英 AI，多出现在[储备站](../entries/reserve.md)/[实验室](../entries/labs.md)；装备精良、**爱扔手雷** | 当 Boss 打，别当 Scav 打 |
| **Rogue** | [灯塔](../entries/lighthouse.md)**水处理厂的失联美军**；**索敌距离远**、武器几乎无后坐力 | **被锁定立刻找掩体换位**，别站原地对枪 |
| **Boss** | 多数图随机刷新，**带精英保镖**、投掷物扔得极准 | **别在同一个掩体逗留第二次** |
| **邪教徒** | **海关 / 森林 / 海岸线夜间**出没，重甲 + 高级穿甲弹；**体温低、热成像难发现**；首领用**毒匕首**（中毒需解毒剂类处理） | 夜间这四张图=提高一档警惕 |

**⑧ 医疗的优先级（新手最常搞错）**

**部位血量归零 = 该部位损毁**，后果各不相同；**头或胸损毁无法救治**，只能立刻撤离。

| 情况 | 用什么 |
|------|--------|
| 轻度出血 | 绷带 |
| **重度出血** | **止血带 / 止血剂**，或带止血功能的医疗包（医疗包耐久不足时止不住） |
| 骨折 | 夹板（手术包也可但很慢） |
| **肢体损毁** | **手术包**（耗时较长） |
| **头 / 胸损毁** | **无法救治**——**立即撤离**，任何额外伤害都致命 |

**部位损毁的实际影响**：手损毁 → 剧烈颤抖、无法精确瞄准；腿损毁 → 移速大降、视角摇晃；胃损毁 → 水分与能量快速流失。

**最后一条，也是最容易漏的一条**：认出对手只是第一步。真正决定生死的是**遇到人之后的那 3 秒**——该打、该躲，还是该走。把[遇敌处置与接战决策](../entries/contact-drill.md)的五问清单（**身份 → 是否被发现 → 距离 → 退路 → 收益**）读一遍，再去打第一局。

## 🐣 第一阶段：活下来（1–10 级）

**目标**：学会撤离、学会死得不亏。

- 读透[撤离机制](../entries/extraction.md)与[保险机制](../entries/insurance.md)；
- 用 **Scav** 熟悉 2–3 张地图（推荐[工厂](../entries/factory.md)、[海关](../entries/customs.md)、[地面零点](../entries/ground-zero.md)）；
- PMC 低配进图：便宜护甲 + 基础弹药，任务优先；
- **每局进图前投保**，养成肌肉记忆；早期装备尤其值得保——**别买贵甲，用 Scav 带出来的**；
- **每局回藏身处先清空邮箱**——保险返还与货款会过期，这是全站最容易无声亏损的一环（[邮件与领取](../entries/mail.md)）；
- **想先学图再打真人，就选 [PvE 模式](../entries/pve.md)**；**别用主菜单的练习（离线）模式攒进度**——它什么都不保存；
- **早期只带 1–2 件医疗**，别把背包塞成药房——**早撤、多撤**比在图上多待十分钟更赚；
- 攒第一桶金，解锁[藏身处](../entries/hideout.md)的基础模块（水收集器、医疗站）。

**毕业标准**：能独立说出一张图的 3 个撤离点及其条件。

## 🐤 第二阶段：练起来（10–25 级）

**目标**：建立任务主线与装备循环。

- 接满所有可用[任务](../entries/quests.md)再进图，多线并行；
- **5 级起每天先看限时任务栏**：每日（5 级）与每周（15 级）任务是**稳定的经验与声望来源**，不接就白白浪费一整天；**任务达成后记得回商人菜单点完成**，否则到期按失败结算；
- 跳蚤市场解锁（约 15 级），学会变现与比价；顺手学会**把交换配方折算成市价**再决定换不换（[以物换物](../entries/barter.md)）；
- **战局内发现（FiR）有一条硬门槛**：只有以 **Survived** 状态撤离的物品才算——**撤得太快会被判“匆匆撤离”，物品不算 FiR**，很多任务会因为这一步白做（见[任务系统](../entries/quests.md)）；
- 开始关注[弹药与穿深等级](../entries/ammo.md)，告别“垃圾弹混装”；
- **锁定 2–3 个武器家族开始练[武器掌握](../entries/weapon-mastery.md)**——它按平台共享进度，摊得太薄会永远停在 L2；
- 扩展地图池：[森林](../entries/woods.md)、[海岸线](../entries/shoreline.md)、[立交桥](../entries/interchange.md)；
- 着手**升级安全箱**：走 Prapor 的「惩罚者」任务线可拿到 Epsilon（[安全箱与容器](../entries/containers.md)）；
- 藏身处补齐：营养单元、情报中心、Scav 隐藏点。

**毕业标准**：商人普遍 2 级声望，装备死亡后能在两局内重建。

## 🦅 第三阶段：打明白（25–40 级）

**目标**：枪法、数值、地图三位一体。

- 系统学习[弹道与穿透机制](../entries/ballistics.md)与[枪械改装](../entries/gunsmith.md)；
- 按地图配弹配甲，形成自己的“进图检查清单”（详见[地图对照速查](map-guide.md)）；
- 把[姿态、移动与射击](../entries/movement.md)练成本能：**开阔地冲刺、掩体前慢走、探身必侧身**；
- **推进主线剧情**：从 **Tour** 起步，接上 **Falling Skies**——它是转生门槛的上游，早推早省事（[剧情章节与主线任务](../entries/story-chapters.md)）；
- 挑战 Boss：Reshala、Killa、Shturman、Sanitar、Glukhar；
- 深入[储备站](../entries/reserve.md)；攒够实力后进军[实验室](../entries/labs.md)；
- 推进 Gunsmith 任务线（Mechanic），免费学改装课。

**毕业标准**：能解释“为什么这一枪没打穿”，并据此调整下一局配置。

## 🏆 第四阶段：收尾与追求（40 级后）

**目标**：Kappa、主线终章，以及**转生**。

- 清任务线，冲 **Kappa 安全箱**（1.1 后门槛改为全体商人忠诚度，见[声望与 Karma](../entries/karma.md)）；注意收藏家要求的材料**必须战局内拾取**，跳蚤买的不算；
- **打完主线终章**：接上 **The Ticket**，四个结局全部经由[终点站](../entries/terminal.md)收束（[剧情章节与主线任务](../entries/story-chapters.md)）；
- **考虑 Prestige 转生**（[Prestige 转生](../entries/prestige.md)）。三条要点：
  1. **不可逆**——按下去就回不去；
  2. **门槛是主线 + 收藏家 + 藏身处 + 现金 + 技能**，所以上面两步是它的前置；
  3. **技能与装备的保留比例随档位提高**，**先把档位刷上去再谈转生更划算**；
- **转生前把“差一点的高难成就”做完**——进度会清零（[成就系统](../entries/achievements.md)）；
- 补全藏身处高端模块（比特币矿场等）；
- 把[技能系统](../entries/skills.md)的体能类练到位——它是所有战术的地基；
- 尝试自定挑战：单弹种周、低配日、Boss 狩猎全图鉴；
- 回馈社区：为这个[百科](../entries/index.md)补充条目（见[待收录清单](roadmap.md)）。

## ⚠️ 新手最容易犯的十个错误

按“代价从大到小”排：

1. **跳过官方教程**——省下 20 分钟，赔上几十局。
2. **不知道撤离点在哪就进图**——超时判定 MIA，全部身家一起丢。
3. **把好装备锁在仓库里不敢用**——没用上的装备等于不存在；死了还能靠保险与 Scav 补回来。
4. **弹药带最便宜的那档**——打中了打不穿，是最典型的“假技术问题”（见[弹药选型速查表](../entries/ammo-table.md)）。
5. **全程冲刺**——在建筑附近等于广播位置（见[姿态、移动与射击](../entries/movement.md)）。
6. **搜刮时被偷**——翻尸体、开箱子、打药是三段最脆弱的时间，**先清场再停留**。
7. **不看限时任务**——每日与每周是免费的经验和声望，漏接就是每天在漏收益。
8. **换了不想做的每日任务**——**会掉声望，而且费用逐次递增**。
9. **忘了交付 / 忘了领邮件**——任务做完不点完成按失败结算；物品奖励走邮件且会过期。
10. **把死亡归给自己的枪法**——先排除弹药、护甲等级、负重，再谈手感（见[战斗复盘与常见死因](../entries/death-review.md)）。
