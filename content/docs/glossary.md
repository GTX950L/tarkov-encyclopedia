# 术语与黑话速查

<a id="top"></a>

> 塔科夫的门槛有一半在**词汇**上：攻略里满屏的 FiR、LL、Kappa、Raider，游戏里一个都不解释。
>
> 本页按主题收齐常见术语。**全称、缩写、俗称都能在这查到**——所以中文名、英文名、社区叫法都列了出来。

## 🪪 身份与阵营

| 术语 | 原文 / 全称 | 说明 |
|------|-------------|------|
| **PMC** | Private Military Company | 你的主角色。**死亡会失去身上与背包里的一切**（安全箱内的除外） |
| **Scav** | Scavenger | 诺文斯克的本地武装。**玩家操控的 Scav 与 AI Scav 默认互不攻击** |
| **Player Scav** | 玩家 Scav | **战局开始约 15 分钟后**才加入。**先开枪会掉 Fence 好感，并被全场视作敌对** |
| **叛徒 / Traitor** | Traitor Scav | 以 Scav 身份**伤害过任何 Scav 阵营成员**的人。当局限定、不可撤销；**击杀叛徒反而加分**（+0.03） |
| **BEAR / USEC** | 俄系 / 美系 PMC 阵营 | 两者差异主要在**语音语言**与外观：BEAR 讲俄语，USEC 讲英语。**所有 Scav 都讲俄语**——所以 USEC 更难伪装成 Scav |
| **邪教徒 / 洗脚徒** | Cultist | 夜间出没于**海关、森林、海岸线**；重甲 + 高级穿甲弹，**体温低、热成像难以发现**；首领用毒匕首 |

## ☠️ 敌人等级（由弱到强）

| 术语 | 是什么 | 记住一句 |
|------|--------|----------|
| **Scav** | 普通 AI / 玩家 | 训练用靶，但成群时致命 |
| **Raider** | 精英 AI | 多出现在**储备站、实验室**；装备精良、**爱扔手雷**，按 Boss 的规格对待 |
| **Rogue / 叛变者** | 灯塔的失联前 USEC 佣兵（**1.1.5.0 后驻地从水处理厂搬到山间别墅**） | **索敌距离远、武器几乎无后坐力**；**只对 BEAR 与“带 BEAR 的队伍”直接敌对**，USEC 单人会被警告后放走；被社区俗称为“美军” |
| **Goons** | 游走的三人精英小队 | 机动出现，遭遇即高强度交火 |
| **Partisan** | 猎杀低业力玩家的游走 Boss | 出现在**森林类图**（森林最常见，另有海关、海岸线）；**PMC 业力越低越容易被猎杀**，连以 Scav 进图也躲不掉 |
| **Boss** | 各图首领 | 带精英保镖、**投掷物极准**；别在同一个掩体逗留第二次 |

> 完整对照见 [Boss 图鉴](../entries/bosses.md) 与 [AI 行为逻辑](../entries/ai-behavior.md)。

## 📈 进度与档案

| 术语 | 原文 | 说明 |
|------|------|------|
| **FiR / 战局内发现** | Found in Raid | 只有**以 Survived 状态撤离**的物品才带此标记。**撤得太快会被判“匆匆撤离”，物品不算 FiR** |
| **匆匆撤离** | Run Through | 搜刮与击杀经验不足、且战局内停留过短时撤离——**不给 Survived**，任务与 FiR 都不算 |
| **LL** | Loyalty Level | **商人忠诚度等级，共 4 级**；等级越高货架越高级、价格越优惠 |
| **声望 / 好感** | Standing / Reputation | 与商人（及 Fence 的 Scav Karma）的信任度，靠任务与行为增减 |
| **Scav 业力** | Scav Karma | **= Fence 声望**，**看得见**（交易菜单里商人图标下方）。管“你对本地人怎么样” |
| **PMC 业力** | PMC Karma | **隐藏参数**（0.15 起），官方称是两套独立系统。管“你这一局体面不体面”——**杀队友、长时间蹲着不动会降**，低了会招来 Partisan |
| **三种档案** | 持久 / 赛季 / PvE | **进度与装备互不相通**，是三个独立角色 |
| **Wipe** | 赛季重置 | 定期清空 PvP 进度；**PvE 永不 wipe** |
| **转生** | Prestige | **自愿把角色打回 1 级**，换跨 wipe 永久保留的奖励；**不可逆** |
| **Kappa** | Kappa 安全箱 | **12 格**的最大安全箱，收藏家任务奖励；也常被用来指“全清任务”这条路 |

## 🎯 装备与数值

| 术语 | 原文 | 说明 |
|------|------|------|
| **穿深** | Penetration | 决定**能不能打穿护甲**；与护甲等级（2–6 级）对应 |
| **碎甲** | 护甲伤害 | 不追求打穿，而是**把甲打坏**再补枪 |
| **人机工效** | Ergonomics | 影响**瞄准速度、瞄准保持时间、耐力消耗** |
| **MoA** | Minute of Angle | 精度单位，**数值越小越准** |
| **安全箱型号** | Alpha / Beta / Epsilon / Gamma / Theta / Kappa | 阵亡不掉的格子容器，容量与获取路径各不相同 |
| **THICC** | — | 大型专用容器，能收整枪与大量物品 |

## 🗺️ 地图与场景

| 术语 | 说明 |
|------|------|
| **BTR** | 装甲运兵车。可付费乘坐，也是随时可能送来敌人的变数；**货箱容量与声望挂钩** |
| **转场** | 不撤离、直接把战局接到下一张图 |
| **边界狙击手** | **隐形、无法杀死**的人工边界，分布在海关、灯塔、储备站、森林 |
| **阔剑** | Claymore 地雷。**打不掉，但位置固定、引爆后不重生**；仅在灯塔、地面零点、街区 |
| **地面零点** | Ground Zero，**面向低等级玩家**的市区图，官方教程也在这里 |

## 💰 经济与商人

| 术语 | 说明 |
|------|------|
| **跳蚤市场** | 玩家之间的交易平台；**约 15 级**解锁完整功能 |
| **手续费** | 上架与成交的税，定价不当会亏本 |
| **信誉值** | 跳蚤信誉，决定**你能同时挂多少件商品** |
| **GP 币 / Lega 奖章** | Ref 的两种“货币”，主要来自竞技场；**不能卖给商人、也不能挂跳蚤** |
| **Ref** | 竞技场主持人，供应稀有武器、护甲与容器 |
| **以物换物** | 商人处的**物品换物品**配方，不涉及货币 |

## 🏅 赛季与衍生

| 术语 | 说明 |
|------|------|
| **赛季修改器** | 改写部分全局规则的机制，每个赛季重新设计 |
| **联赛** | 每周 50 人的经验值天梯 |
| **竞技场** | Arena，**独立进度**的纯对抗模式；GP 币与 Lega 奖章的主要来源 |

## 🗣️ 国内社区常见叫法

| 俗称 | 实际指 | 备注 |
|------|--------|------|
| **白边** | Standard 标准版 | |
| **蓝边 / 金边** | The Unheard（未闻者版） | **注意：官网版与 Steam 版权益不同** |
| **黑边** | Edge of Darkness（EoD） | **已停售** |
| **邪教徒 / 洗脚徒** | Cultist | 两种叫法都常见 |
| **舔包 / 搜尸** | 搜刮阵亡者的装备 | |
| **蹲撤离点** | 在撤离点附近伏击 | 新手最常死于这一类 |

> **买版本之前**务必先看[购买指南（地区与版本）](buying-guide.md)——**“白边”与“蓝边”之间还隔着两档**，俗称容易让人误以为是二选一。
