# 地图对照速查

<a id="top"></a>

> 一张表回答：**这张图打什么、产什么、有什么坑、什么时候该来**。
>
> **本页不列具体坐标与点位**——那类内容变动最快、也最容易过期（原因见[战利品分布与热点](../entries/loot.md)）。这里给的是**选图与预期的判断依据**。

## ⚠️ 三类“设计好的死亡”

这些不是 bug，是**刻意设置的边界与机关**。认得出就能绕开（完整规则见[彩蛋与制作组的恶意](../entries/easter-eggs.md)）：

| 类型 | 在哪 | 关键规则 |
|------|------|----------|
| **雷区** | 森林（北部营地一带**无警示**）、灯塔水处理厂周边、海岸线 CCP 营地附近、东南角 | 地雷**肉眼不可见**，且**爆炸后会刷新、无法清干净**；踩中第一颗通常只伤腿，**治好后原路退回**，硬走第二颗基本必死 |
| **边界狙击手** | **海关、灯塔、储备站、森林** | **隐形、无法杀死**，是人工边界；遇到它只有一条路——离开边界 |
| **阔剑地雷** | **灯塔、地面零点、街区** | 探测 **5–10 米**、基本直接致死；**打不掉**，但**位置固定、引爆后不重生** |

## 🧭 五条通用原则

1. **先看保险是否生效**——终点站 / 破冰船 / 迷宫不返还，其余地图正常（见[保险机制](../entries/insurance.md)）。
2. **任务优先按地图归组**：同一张图的任务一次做完，比来回换图省一半时间（见[任务系统](../entries/quests.md)）。
3. **体量越大越吃队友**：街区这类图单排的风险不是战斗，是**迷路与被夹击**。
4. **地图的“强度”由敌人的护甲等级决定**，不是由地图大小决定——配弹比配枪重要（见[弹药选型速查表](../entries/ammo-table.md)）。
5. **同一张图在不同阶段是两张图**：早期人人搜刮、后期遍地 PvP；判断“今天该去哪”，先看赛季进度（见[经济周期](../entries/economic-cycle.md)）。
