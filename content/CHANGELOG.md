# 更新日志 (CHANGELOG)

本文件记录面向用户的条目内容变更。历史条目一经发布，只做修订不做改写。

> 📚 **分页口径**：本页只保留**当月**条目；跨月时把上个月整段移入仓库根的 `CHANGELOG-archive.md`（**内容原样搬，不改写一个字**）。
> 归档自 2026-10-22 起**移出站点构建** —— 更新日志是发布记录，不是资料页；读者要翻更早的版本看 GitHub Releases 即可，站内不再为 2,690 行历史付一次页面下载。

> **发版节奏（2026-10-26 起）**：**一个版本 = 读者能看见的一批变化**，一天最多一个。
> 门禁、体积、生成器内部实现与纯排版修正**不单独抬版本**，并入下一批；「一个版本一个 Release」的硬对应不变，Latest 仍须等于本页顶部版本。
> 判据与理由见[贡献指南](CONTRIBUTING.md) 的「版本粒度」一节（含 `v1.47.0` 起 151 个版本 / 122 个 Release 的实测）。

## 2026-11（v1.154.5）— 十章从「流程复述」改写成「剧情考据」，并把证据链与商人分工串起来

**触发**：上一版把十章各写成一页之后，读者反馈三句话——「还是太流水账」「内容不够详细」「没跟商人相关任务串起来」，并点名举了一个例子：**「无名者任务线里到最后蓝冰是干嘛的也不清楚」**。这三条都成立：上一版写的是**流程**（谁托你办、去哪、交什么），不是**剧情**（为什么、证据是什么、谁在撒谎）。

### 一、十章统一换结构：从「三段式」升级为「考据式」

每章从原来的「起因 → 经过 → 结果」三段，改成**八段固定结构**，把「读到的原文」和「编者的推断」彻底分开：

> 本章速览 → 这一章在问什么 → **因果链（阶段表）** → **档案室（原文／读得出什么／读不出什么）** → 核心概念深挖 → **谁在推你（商人介入点）** → **官方没说的空白** → **社区怎么猜（主张／依据／破绽／可信度）** → **在九份证据里 N/9** → 走这一章的判据 → 常见误解

新加的四块是这一版的重点，也是上一版缺的：**档案室**（逐条摆原文，并明写「这段读不出什么」）、**商人介入点**（谁在哪一步出手、他真正要什么、他图什么）、**官方没说的空白**（把「没有答案」写成条目）、**社区怎么猜**（每条推测都配破绽与可信度评级，不给结论）。

### 二、总览页新增「十章怎么串成一条线」

`entries/story-chapters.md` 新增 §3，直接回答「没串起来」：

- **§3.1 四条罪证线**：十条章按「证据能证明什么」重新归档为**化学线／武器线／人线／通道线**；
- **§3.2 九份核心证据表**：证据 × 出处章节 × 经谁的手 × 它证明了什么，并写清「**九份交八份**」的容错逻辑，以及**实际最常被漏掉的是 Boreas 的破冰船档案数据**（中文圈的「重大证据清单」常只有八条，恰好缺它）；
- **§3.3 商人分工表**：Mechanic（解释权）、Prapor（军方通道）、Skier（灰色中介）、Jaeger（替死者说话）、Lightkeeper（体制外清算）、Therapist（行政）、Ragman（人脉）、Fence（重编码）、BTR 司机（唯一不收钱）、Kerman（那张票）——**每个人卖的东西不一样，这才是「一件事要过五个人的手」的原因**；
- **§3.4 一句话**：十章讲的是同一句话，起因是那架飞机、经过是六章取证、结果是门票那一次清算。

逐章入口表也加了**证据列**（N/9），一眼能看出哪几章在给证据。

### 三、「蓝冰到底是干嘛的」——这是这一版单独答的问题

`story/the-unheard.md` 新增 §4「蓝冰到底是什么」，按**证据强度分三层**写，不许混着引：

| 层级 | 能说到什么程度 |
