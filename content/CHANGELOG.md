**几处关键事实（本轮取材于官方 wiki 与官方补丁说明）**

- **武器故障的 93% 硬阈值**：**耐久高于 93% 时机械故障不会发生**——故障因此不是运气问题，而是**耐久管理问题**；四种机械故障的**主因各不相同**（退壳失败看耐久、**供弹失败看弹匣**、**枪栓阻塞只看过热与耐久，且严重阻塞只出现在耐久 ≤5%**）；
- **过热是独立于耐久的第二条路径**：四种过热状态逐级加重，其中**中度会降低“最大耐久”**（打掉的是余寿），**极限必然阻塞**；而**轻微过热就已经让枪管在热成像里可见**；
- **排除流程与两个加成**：**L 检查 → Shift+T 操作枪机**；“故障排除”技能到**精英可跳过检查**；主武器故障时若带**已上膛的副武器**，可获 **5 秒切换加速**——**这是“带副武器”最硬的理由**；
- **维修要付两次代价**：武器维修套件**需要藏身处工作台、且不能带进战局**；而 0.13 的「维修套件与强化」规则是——**修一次扣一截最大耐久**（扣多少看**武器保养**技能）、**强化再次维修会被移除**；
- **顺手校准一对全站最易混的概念**：**武器保养（Maintenance，维修相关）≠ [武器掌握](entries/weapon-mastery.md)（Mastering，命中给经验、改换弹动作）**；
- **食物与水分的选型知识**：**水比食物难找、耗尽更致命**（耗尽后持续掉血，且**会拖慢耐力恢复**）；**干货会把你喝干**（炼乳一类“高能量 + 高负水分”是典型陷阱），**罐头与配给口粮才是口粮主力**；
- **一条口径更正**：**成瘾系统至今未实装**——官方 wiki 把“药物成瘾 / 幻觉”列在**未实装功能**清单里；
- **开局的匹配真相**：匹配**按队伍分配出生点**（一支多人队只占一个点）→ **同样的“满员”战局，单排多则到处是人、队伍多则出现大片无人区**；**开局的交火密度本身就是情报**；
- **服装的分工**：它是**纯外观件**（不提供防护与数值），**识别用臂章、伪装用服装**——而且伪装是**单向**的（PMC 能装得像 Scav，Scav 装 PMC 会被袖子出卖）。

## 2026-09（v1.14.0）

### 新增条目 · [Scav 指挥与随从系统](entries/scav-command.md)（69 → 70 篇）：把“一句话的声望待遇”补成一套可操作的子系统

**起因**：读者读完[阵营关系与交战规则](entries/engagement-rules.md)后指出——“里面说 Scav 高声望可以指挥其他 AI Scav，这一块儿详细写一下”。核对后发现全站对此只有**两行**：`scav-relations.md` 表格里的“AI Scav 会听从指令甚至协同作战”、`karma.md` 表格里的“AI Scav 听令概率”。而真实机制是**一整套指令系统**——**单开一篇**。

**关键取材：官方 0.13.5 补丁说明的「对人机的命令」段落**（IGN / consolepcgaming / 中文 wiki 三处互证）。它把六个命令逐条写了出来，并明确三件事：**指令由玩家主动发出**、**每条都有冷却**、**能否被服从取决于 bot 与你 Fence 声望的关系**。

| 指令 | 范围 | 作用 |
|------|------|------|
| **帮助** | 区域级 | 附近 bot 前往你身边并与敌人交战——**唯一的“叫援兵”** |
| **跟随** | 单体级 | 跟着你移动（0.13.5 起手势与语音短语“跟我来”都可以下） |
| **分散** | 区域级 | 找掩体并散布，防被一锅端 |
| **掩护** | 单体级 | 你旁边那个 bot 占据最近掩体 |
| **静默** | 区域级 | 停止交谈、开始倾听——**唯一不改变任何人位置的指令** |
| **停止** | 单体级 | 短暂停下看你，然后继续——**用来换随从** |

**本篇另外补上四条此前完全没有的内容：**

- **最容易漏的一条**：**6.0 以上**的玩家 Scav **被敌对势力或叛徒攻击时，附近 AI Scav 会主动离开守区、跨距离赶来支援**（普通 AI 基本不离开自己的生成区域）。这条改写了高声望 Scav 的定位——**“不是一个人，是带着警报器的一个人”**；
- **随从数量：把冲突如实写出来**。社区有“只能带 1 个”与“可带 1–4 个”两种口径，**官方未公布**；给出的可执行结论是“**先按 1 个做计划**，用「停止」换人”；
- **纠正一条流传说法**：有攻略称 6.0 以上可以**指挥 Boss 护卫**，**官方从未这样表述**——官方在该档只写“**大多数 Boss 对你中立、不主动攻击**”。把“不被攻击”读成“能指挥”是两回事；
- **失效条件与代价**：随从是**第一批反水的**（叛徒判定当局限定、全场生效）；随从开火会替你广播位置；**AI 会搜尸并拿走装备，且这些物品不走保险**（官方更新日志）。

**顺带给出三套战术组合**：哨兵开路（“跟随”优先给护甲更好的那个）、静默潜行（首个指令性价比最高）、**伏击反制（分散 + 帮助 = Scav 唯一的“以多打少”窗口）**。

**连带同步**：[Scav 互动与叛徒判定](entries/scav-relations.md)、[声望与 Karma](entries/karma.md)、[机制速查表](docs/mechanics.md) 的阵营规则各补一条指引；导航新增入口；总览页编号整体重排（69 → 70）；两处 README 计数与学习路径图（第五篇 13 → 14 篇）同步；标签仍为既有 **29** 个（未新造）。**指令集、键位与成功率已登记进[待收录清单](docs/roadmap.md)的版本复核项**——0.13.5 之后可能调整。

## 2026-09（v1.13.0）

### 新增条目 · [遇敌处置与接战决策](entries/contact-drill.md)（68 → 69 篇）：把“遇到人怎么办”补上

**起因**：上一轮补完[阵营关系与交战规则](entries/engagement-rules.md)之后，读者紧接着指出了它的下一步缺口——“**拾荒者碰到人是先躲起来还是直接开枪**”。这一问在站内**没有正面答案**：既有内容回答的全是**机制问题**（Karma 怎么算、AI 怎么感知），而这一问是**决策问题**。判据很清晰：全站凑不出“遇到人之后的前 3 秒该怎么做”的一段完整说明。

**本篇给出的是一条可执行的决策流程，而不是又一份机制说明：**

- **前 3 秒的五问清单，且顺序不可换**：身份 → 他有没有发现我 → 距离 → 退路 → 收益。“先算收益再认人”正是塔科夫里最贵的错误的生产方式（为了杂货打成叛徒、为了一个人头招来一队人）；
- **两张身份线分开写**：同一个局面，PMC 与 Scav 的答案**经常相反**，原因见第 9 节的不对称；
- **距离决策带**：贴身（**先动多半赢**）/ 中段（标准接战距离，**别在同一个掩体露第二次头**）/ 远段（**先看你打不打得穿**）/ 超出有效区间（**不该开枪**，因为枪声是全图级的）——并指出“隔着很远就被打中”这件事**本身就是身份判据**（普通 AI Scav 不会在极远距离开火）；
- **先手的两面**：先手命中会让 AI **掉精度**，这是塔科夫最便宜的优势；但**枪声是全图级的信息**，且 AI 在约 50 米内互相通报、预编队不受距离限制——所以**先手是用来决定打不打，不是用来打的**；
- **三种必须脱离 / 两种必须抢先动手**的情形，其中后者包含对方正在做**翻尸体、开容器、打药**这三件脆弱的事；
- **“躲”的三种形态与判定**：**静止不动 = 最危险**（AI 不会“你躲起来就忘”，它会记住最后确认位置并搜索、绕行、包夹）、就地隐蔽 = **只对“还没确认你”的对手有效**、**断联脱离 = 唯一真正有效的一种**；
- **断联脱离的五个技术细节**（本篇最值钱的一节）：走**软地表**（金属 / 玻璃 / 木板 > 混凝土 > 泥土 / 草）、**用慢走消除地形噪音**、**别顺着来路回退**（那正是对方第一个要搜的方向）、**冲刺只留给“已确定脱离”的那一段**、有条件就**反向制造噪音**调虎离山；
- **开枪之后的三个窗口**（3 秒 / 10 秒 / 30 秒），以及一条固定纪律：**交火结束即默认有人在来**；
- **第 9 节“一条不对称”**：**PMC 的命带着资产，Scav 的命是免费的**——这一个事实改写了同一局面下所有人的答案。

### 新增条目 · [阵营关系与交战规则](entries/engagement-rules.md)（67 → 68 篇）：把“谁能打谁”收成一张表

**起因**：阅读反馈里最反复出现的一类问题，是**身份如何决定交战关系**——“作为 PMC 进图是不是可以射击任何人”“作为 Scav 面对同行 / PMC / Boss 各会怎样”“PvE 里是不是同一套规则”。这三问在站内是**分散**的：[敌我识别与身份判断](entries/iff.md) 讲**怎么认人**，[Scav 互动与叛徒判定](entries/scav-relations.md) 只覆盖 **Scav ↔ Scav**，[PMC 与 Scav](entries/pmc-scav.md) 讲**两种角色的收益结构**——**没有任何一篇回答“开火之后会发生什么”**。全站检索「交战规则 / 自由开火 / 开火规则」**零命中**，属真空缺。

**本轮的关键发现（也是本篇最重的两块内容）：**

- **官方把业力拆成了两套独立系统**。官方支持站 `knowledge/519`《Karma in Escape from Tarkov》写明：**PMC 有自己的一套业力，Scav 有另一套独立的声望 / 业力**。前者是**隐藏参数**，管“你这一局体面不体面”——**击杀队友**与**长时间停在同一个点不动**会降；后者就是 Fence 声望。两条官方给出的自查手段一并收进条目：**战局结算界面的「总体声望变化」一行**，以及**涨与跌各自不同的音效提示**。
- **PMC 业力的执法者是 Boss「Partisan」**：低 PMC 业力会提高他在战局中出现的概率并让他主动猎杀你；**即便你以 Scav 角色进图，只要 PMC 业力低，照样是他的目标**；他与 Fence 声望**完全无关**。
- **更正一条流传极广的说法**：“PMC 击杀 Scav 会掉黑商好感”**不在官方扣分清单里**——官方列出的扣分只有两种，且都写明“以 Scav 身份”。真正存在的机制是：**击杀过 Scav 的 PMC 会被玩家 Scav 标价**（+0.02，杀过两人以上 +0.03）；唯一会因击杀 Scav 而扣分的情形，是自愿携带特殊设备「**无名者之声**」时。

**条目还收齐了这些此前散落或缺失的规则：**

- **两张交战矩阵**：「以 PMC 进图」与「以玩家 Scav 进图」分开列，逐行给出**默认关系 / 开火之后 / 业力代价 / 建议**；
- **官方的高声望例外清单**：高声望时“**大多数 Boss 对 Scav 中立**”，官方列出的例外是 **Killa、掠夺者系首领、Zryachiy**；
- **四类“不算 Scav 阵营”的 AI** 各自的翻脸条件（Raider 会先警告、被激怒会迁怒全场；邪教徒战士无视 Scav、祭司先躲）；
- **Rogues 的阵营判定规则**（USEC 单人会被命令离开、**队伍里带一个 BEAR 就全员无警告格杀**、USEC 一旦开火之后若干局都被当敌人、Scav 不靠近机枪台就没事）；
- **AI PMC 的四档态度**（无条件友好 / 友好除非你先攻击 / 中立除非出现敌意 / 警告后攻击），以及官方给的两条环境变量：**bot 的情绪状态与对方阵营**、**地面零点最友好而实验室最具攻击性**；
- **PvE 与 PvP 的差异清单**，并点明**练习（离线）模式是全游戏唯一可以随便开枪的地方**。

## 2026-09（v1.4.0）

### 新增：敌我识别与身份判断（47 → 48 篇）

- **第五篇 · 进阶战斗机制（+1 篇）**：[敌我识别与身份判断](entries/iff.md)——补上此前缺失的一条主线：塔科夫**没有队友名字、没有小地图、没有敌人轮廓**，判敌完全交还给玩家。

### 条目要点

- **敌我关系由“身份 + 行为”决定**：USEC 与 BEAR 之间没有任何和平机制；Scav 的和平是行为换来的（先开枪即被标记为叛徒）。
- **三级判据**：轮廓（Scav 的底层衣裤与袖子不随装备变化）→ 行为（AI 巡逻固定、不蹲下搜刮、不查弹匣）→ 声音（AI 常在开火前喊话；0.16.5.0 起近距离开火前必定先喊）。
- **队伍识别**：臂章（Armband）是唯一的官方手段——占专用槽位、**不能被拾取、死亡不丢失**，因此可以跨局固定颜色。
- **伪装与外观**：战术服装按上衣与裤子分件、BEAR 与 USEC 各有部件池，The Unheard 版可混穿，服装不再能证明阵营。
- **特殊身份**：Boss 护卫、Raider、Rogue、邪教徒、叛徒 Scav、Goons 的外观与行为线索，以及击杀各自带来的声望后果（灯塔 Rogues 是 AI 却穿得像 PMC，是本篇最重要的误判陷阱）。
- **事后确认**：狗牌显示姓名、等级、阵营与击杀者；击杀队友的狗牌失去“战局内发现”状态且价值 ₽1。
- **竞技场对照**：竞技场自 0.2.8.0 起在 TeamFight、BlastGang、CheckPoint 中把队友臂章强制为蓝色、敌人强制为红色——本体刻意不给，是设计取舍而非遗漏。
