## 🧭 怎么用这张图

| 操作 | 结果 |
|------|------|
| 滚轮 / 放大缩小按钮 | 缩放（以指针位置为中心）；按住拖动平移。**标注在任何缩放级别都是同一大小**（屏幕锚定），左下角有随缩放换档的比例尺 |
| 单击任务区域 | 只显示这一个任务，下方弹出信息卡 |
| 单击**重叠处** | 该点压着多个任务时，弹一个列表让你挑（单一命中则直接选中，不多一步） |
| 双击任务区域 | 打开任务详情 |
| **任务搜索框** | 控件条里输入任务名或**地名**（**中文或英文**都能搜，商人名也参与匹配）→ 回车或点结果：地图只剩该任务、下方弹出信息卡，**视图自动移到它所在的位置**，地名标签也会保显一次 |
| **任务点位筛选** | 全部任务 / 只看未完成 / 只看进行中 —— 按「我的进度」过滤图上画出的区域；**有进行中的任务时打开本页，默认就是「只看进行中」**（没有就显示全部） |
| **地图下方清单** | 这张图的任务按商人分组，带**进度三态**（未标记／进行中／已完成，与「我的进度」同步）、组内完成度条与**行前提示**（钥匙／自备）；可按进度筛；点一行，上面地图就只剩它并自动定位 |
| **出击清单** | 清单行左侧的「+」把任务加进出击清单（可多选）—— 汇总条给出区域数与钥匙数，「只看这些」让地图**同时**显示这几个任务的区域，一次 raid 推进几票用 |
| **点击地名 / 撤离点** | 弹小卡：这是什么 + 去哪读（地名 → 本图条目；撤离点 → 撤离点详解）—— 不直接翻页，防误点丢地图状态 |
| 图层按钮 | **任务区域** / 撤离点 / 转场点 / 上锁 / 危险区，各自可开关 —— 想纯看地形时把「任务区域」整个关掉 |
| 悬停撤离点 | 看阵营，以及**要不要缴钱／缴物**；多版本图的出口会标注「仅某版有」，车辆撤离若两模式价格不同还会写出 PvE 的价 |
| 测距 | 点两个点量**直线**距离（米）；画布左下角的比例尺与它同源 |
| 全屏 | 铺满屏幕看细节 |

> **地名标签会自动避让**：缩放级别低时，挤在一起的地名只显示一部分（撤离点、转场点优先），其余先只留红点 —— **放大后自然浮现**，搜索或点击定位到的那个标签保证显示。点永远都在，被避让的只是字。

> **框有的是「点」，有的是「一整片区域」，这是数据本来的样子。**「在XX击杀 N 个」这类任务，上游给的就是一整片范围；本站按占图面积分了三档显示 —— **区域级目标会压到很淡**（悬停或选中时恢复），免得它盖住整张图、把几十个点级目标一起埋掉。悬停时会直接告诉你它占本图多少面积。
