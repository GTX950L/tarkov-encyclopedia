### 地名与撤离点都说中文了吗

**大部分是，但不是全部 —— 这是有意的。**

| 类 | 怎么做 | 例 |
|----|--------|-----|
| **通用地名 / 设施名** | 译成中文，**用社区通行的叫法**、不按字面直译 | `White Bishop` → 白象；`Skeleton` → 骨架楼；`Crackhouse` → 制毒屋 |
| **游戏内的品牌与店名** | **保留原文**，能给确定用途的加中文类别词 | `IDEA` → IDEA 电器城；`KIBA` → KIBA 军械店；`Goshan` → Goshan 杂货区 |
| **俄文招牌** | 译成中文（俄文对中文读者等于不可读），原文用括号保留 | `АПТЕКА` → 药店；`МУЗЕЙ ИСТОРИИ` → 历史博物馆 |
| **代号 / 编号** | 原样保留 | `K1`–`K6`（储备站代号）、`ZB-013`、`E5` |

> **为什么品牌不硬译**：游戏里的门头就写着那个原文 —— 读者在地图上看到 `IDEA` 能直接对上商场里的招牌；
> 译成「理念超市」反而找不到。**不确定卖什么的（多数服饰品牌）连类别词也不加** —— 猜错比英文更难用。

覆盖情况：地名词表 **257 / 303**（余下的是上表第二、四类，按规则保留原文）；撤离点名 **141 / 141**（合并与画布过滤后的显示口径，内部 id 已转写为可读名）。

### 两张图没有任务点位，不是漏抓

**破冰船**与**终点站**的「任务区域」是空的 —— 因为**上游还没为这两张图的任务给出坐标**（实测：上游任务数据里引用破冰船地图区的次数为 **0**）。
站内有这两张图的任务与打法说明，只是地图上暂时画不出位置。**数据没有就是没有，不编位置。**

## 🧭 地图上有什么

| 元素 | 含义 |
|------|------|
| **红点 + 名称** | 地名锚点。坐标由上游数据投影而来，**不是手工摆的**。**字会自动避让**：缩放级别低时挤在一起的地名只显示一部分（撤离点、转场点优先），其余先只留红点，**放大后自然浮现**——点永远都在，被避让的只是字 |
| **彩色方框** | **任务目标区域** —— 单击只看它、双击进详情、悬停看目标原文。**颜色只区分「做什么」**：到访（蓝）／放置（橙）／标记（紫）／击杀（红）／使用（青）。它是图层开关里的一项，想纯看地形时整个关掉 |
| **蓝／橙／紫方块 + 名字** | **撤离点**，按阵营分色：PMC（蓝）／Scav（橙）／共用（紫）。名字由上游的内部 id（`ex_customs_scav_gasstation`）转写而来 —— **词表里没有的保持英文**，不硬翻。⚠️ 阵营是上游的 `faction` 字段，**不等于「谁能用」**，通行条件见[撤离点详解](../entries/extraction-points.md) |
| **青色三角 + 名字** | **转场点** —— 不结束战局直接换图（见[转场与 BTR](../entries/transit.md)） |
| **紫色小方块** | **上锁位置** —— 有钥匙的可以点击跳到那件钥匙的物品页（两边用同一套物品 id） |
| **红色点线多边形** | **危险区**（雷区一类） |
| **淡红建筑** | 底图自带的上锁建筑色块。与紫色方块是**两个来源**：一个画在底图里，一个来自点位数据 |

### 为什么有的框特别大

**因为数据本来就有大有小 —— 那不是画错了。**

实测本站 589 条任务区域占图面积：**中位数 0.005%**（绝大多数是「这一小间屋子」），
但尾部极大 —— 最大的一条占了整张图的 **100%**。按目标类型看更清楚：

| 目标类型 | 中位占图面积 | 说明 |
|----------|--------------|------|
| **击杀／射击** | **9.6%** | 「在图里击杀 N 个」——语义上就是**一整片区域**，不是一个点 |
| 使用物品 | 0.43% | |
| 到访 | 0.009% | 「到某栋楼」——一个点 |
| 放置 / 标记 | **0.001%** | 「放在某张桌子上」——精确到一个点 |

同一张图上两者差**四个数量级**，用同一种画法必然有一头不合适。所以本站按占图面积分了三档：

- **点级（< 2%）**：常规显示，实线细边
- **中档（2–20%）**：填充略淡
- **区域级（> 20%）**：**压到几乎只是底纹**，悬停/选中时恢复；悬停提示会写明「占本图约 N%」

> ⚠️ 另外还有 **2% 的区域边角越出了地图范围**（上游坐标如此，最极端的一条面积是画布的 3.4 倍）。
> 本站会把它们**裁到画布内**：不裁的话，框虽然被画布剪掉了看不见，**但命中区还在** ——
> 会出现「点空白处却选中了某个任务」。整条都在画布外的 1 条已跳过。

### 点不准怎么办

任务区域重叠是**常态**（海关最密处一个点压着 6 个框 —— 实测）。所以：

- **绘制顺序按面积从大到小**：大框垫底、小框在上。反过来的话，一片区域级目标会把下面几十个点级目标全挡住，那些任务就永远点不到了；
- **单击重叠处会弹选择列表**，把该点下的**所有**任务列出来（按最上层在前），
  点哪个选哪个 —— 靠的是浏览器给的「该点下的整叠元素」，不是「谁盖着谁」。

> 单一命中时**不弹列表**，仍是「点一下就选中」—— 不为少见情况给常见操作加步骤。

### PvE 与 PvP 的地图有什么区别

**结论：地图本身几乎一样，只有车辆撤离的价钱不同。**

上游对 PvE 有**独立的数据端点**，两边确实是两份数据。逐条比对（17 个地图条目 × 19 个字段）的结果：

| 项 | PvE vs PvP |
|----|-----------|
| **底图、投影参数、地名锚点** | **完全相同**（逐条哈希一致） |
| **上锁位置、危险区、转场点、战利品容器、固定武器、开关** | **完全相同** |
| **撤离点（位置、名字、阵营）** | **完全相同** |
| **任务目标区域** | 477 个共有任务里仅 **1 个**不同 |
| **⚠ 车辆撤离要缴的卢布** | **不同 —— 而且只差在 4 张图** |

**车辆撤离（V-Exit）的价目**（本站逐个标在撤离点上，悬停可见）：

| 地图 | 撤离点 | PvP | **PvE** |
|------|--------|-----|---------|
| 森林 | 南区付费车辆 | 20,000 | **5,000** |
| 海岸线 | 付费车辆出口 | 20,000 | **5,000** |
| 街区 | E7 车辆出口 | 20,000 | **5,000** |
| 中心区 | 付费车辆出口 | 20,000 | **5,000** |
| 海关 | 付费车辆撤离点 | 20,000 | 20,000（**相同**） |
| 立交桥 | 付费车辆撤离点 | 20,000 | 20,000（**相同**） |

> ⚠️ **注意：不能笼统说「PvE 更便宜」。** 海关与立交桥的两个 V-Exit 在两个模式下**都是 20,000** ——
> 只有上表前四张图不同。所以本站**逐点标注**（悬停时写「⚠ PvE 模式只需 5,000 卢布」），
> 而不是在页面上给一句全局结论。

**差异只在别处**：Boss 刷新点在 PvE 下**系统性更多**（中心区 6 / 0、立交桥 12 / 2、街区 12 / 2、
储备站 13 / 4 —— 对应 1.2.0.0「AI PMC 分布重做、迷宫新增 AI PMC 出生点」）。
本站**没有画 Boss 图层**，所以地图上看不到这一项；这部分差异见[中心区](../entries/ground-zero.md)
一类条目里的难度说明。

**任务也有版本之分**：上游数据里 **23 对**任务是同一任务的 `-pvp-zone` / `-pve-zone` 双实例
（如 `easy-money-part-1`、`to-great-heights-part-1~6`），进度分开算；
另有 4 个 `new-beginning-*` 只有 PvP 版。详情见[任务图鉴](../quests/index.md)。

### 撤离点的三个坑（都是核对时挖出来的）

| 现象 | 原因 | 本站怎么处理 |
|------|------|--------------|
| **总数比游戏里多** | 上游把**同一张图的多个版本**（工厂日/夜、中心区低等级/高难）的撤离点合并了，同一个出口**出现两遍** | **按「名字 + 位置」合并**，阵营取有值的那份（原先重复的那份阵营为空、显示成「—」） |
| **有的出口只在一个版本有** | 各版本的撤离点列表本就不同（中心区**低等级版 9 个、高难版 6 个**，与[中心区条目](../entries/ground-zero.md)写的一致） | 悬停时标注「**仅 XX 版有，缺 XX 版**」—— 实测工厂的「2 号门」只在日间版 |
| **图例上数字是假的** | 上游有个别点**坐标根本不在本图范围内**（中心区的 `UN Roadblock` / `East Gate` 与森林、街区的同名点坐标几乎相同，属**上游把别的图的点混进来了**）；另外实验室有 5 个点落在**上游瓦片没覆盖**的区域 | **画布外的点不画，也不计入总数** —— 画出来会被裁掉、看不见，**却照样算进数字**，那比不画更糟 |

> 合并前中心区显示 15 个撤离点，**实际只有 6 个**（6 个是重复、3 个坐标在图外）。
> 现在 13 张图共 **763 个图层点**，上游给了 777 个 —— 少的 14 个就是上面这些，
> 生成时会在日志里逐图报数。

### 常用操作

| 操作 | 结果 |
|------|------|
| **滚轮** | 缩放，**以指针位置为中心**（不会越缩越偏）。**标注在任何缩放级别都是同一大小**——屏幕锚定，工厂和街区的地名一样大 |
| **按住拖动** | 平移 |
| **放大 / 缩小 / 重置** | 按钮入口（触屏与不习惯滚轮的读者）；「重置」兼找回全图 |
| **全屏** | 铺满屏幕看细节 |
| **比例尺** | 画布左下角，随缩放换档（20 m – 5 km）；与测距用同一份换算数据 |
| **测距** | 点两个点量**直线距离（米）**；⚠️ 是直线，不是走路距离 |
| **单击任务区域** | 只显示这一个任务，下方弹出信息卡（任务名／类型／区域数／你的进度状态／目标原文） |
| **单击重叠处** | 该点压着多个任务时弹一个列表让你挑（**单一命中则直接选中**，不多一步） |
| **双击任务区域** | 打开任务详情 |
| **任务搜索框** | 控件条里输入任务名（**中文或英文**都能搜，商人名也参与匹配）→ 回车或点结果：地图只剩该任务、弹出信息卡，**视图自动移到它所在的位置**；搜**地名**时标签会保显一次，不被避让挤掉 |
| **任务清单（地图下方）** | 「这张图上的任务 · N 个」按商人分组，带**进度三态**（未标记／进行中／已完成，与「我的进度」同步）、组内完成度条与**行前提示**（钥匙／自备）；可按进度筛；点一行，地图就只剩它并自动定位 |
| **出击清单** | 清单行左侧的「+」把任务加进出击清单（可多选）—— 汇总条给出区域数与钥匙数，「只看这些」让地图**同时**显示这几个任务的区域；一次 raid 推进几票时用它 |
| **点击地名 / 撤离点** | 弹小卡：这是什么 + 去哪读（地名 → 本图条目；撤离点 → 撤离点详解）—— 不直接翻页，防误点丢地图状态 |
| **任务筛选** | 全部 / 只看未完成 / 只看进行中 —— 后两个**读的是[我的进度](../quests/progress.md)**；**有进行中的任务时打开地图默认切到「只看进行中」**（没有就显示全部） |
| **图层开关** | **任务区域** / 撤离点 / 转场点 / 上锁 / 危险区，各自可关，**按钮上带条数**——想纯看地形时把「任务区域」整个关掉 |

## 🔗 和任务系统怎么联动

地图上的**彩色方框就是任务目标区域** —— 这一页因此不只是「看地形」，而是任务图鉴与我的进度之间的那座桥。

**从名字进**：控件条的**搜索框**按任务名（中文或英文）直接定位 —— 输入、回车，地图就只剩该任务、弹出信息卡，视图自动移到它所在的位置。这是从任务图鉴走进一张图的**最短路径**：不必先展开清单，也不必在上百个方框里翻。

**从进度进**：**地图下方的清单**就是这张图的进度控制台 —— 每个任务带三态徽章（未标记／进行中／已完成），组头写着该商人在这张图上「已完成几／共几」，顶部四个筛选钮各带条数。「今晚还想清海关的哪几个」不再要去[我的进度](../quests/progress.md)的 515 条里翻，点一行，上面地图就只剩它并自动定位。三态数据与进度页**同一份本机存储**，在任一端勾选，另一端（含另一个标签页）实时跟着变；勾选与取消仍在进度页做，地图这边只读。

**从计划进**：清单行左侧的「+」把今晚要做的几个任务加进**出击清单**（可多选）—— 汇总条告诉你要跑**几处区域、带几把钥匙**，「只看这些」让地图同时显示这几个任务的区域。一次 raid 推进几票时，这是比「单选一个任务」更贴战的看法；竞品（tarkovhideout 的 Raid Planner）的核心场景正是这个。

> ⚠️ **任务区域不标楼层**：上游坐标数据只有平面 x/z、**没有楼层字段**，用几何归属猜不可靠（同一个平面位置多层重叠，二楼的目标会同时命中一楼）—— 所以清单只给区域总数，**不猜在第几楼**，楼层请用手动切换按钮。理由与关闭条件见[引用说明 B13](../docs/citation.md)。

**进度从哪来**：[我的进度](../quests/progress.md)把勾选存在**你本机浏览器的 localStorage**（键 `tarkov_progress_v1`），不登录、不上传、本站也没有服务器。地图读的是**同一份数据** —— 两边用的是**同一套任务 id**，所以不需要任何同步动作。

> **两条边界**：① **地图只读进度**，不会替你勾选或取消任何任务；② **进度是本机数据**，换浏览器、清缓存就没了（那一页有导出与导入）。
