## 📸 这一页是什么

站点此前对地图的处理是：讲述**判断依据**（这张图打什么、产什么、有什么坑），但**不列点位** —— 理由写在[战利品分布与热点](../entries/loot.md)里。那条理由至今成立，因为点位信息的特点是**版本一变就整批作废**。

这一页把「点位」单独接出来，靠三件事把那条理由消化掉：

| 办法 | 做法 |
|------|------|
| **底图与标注分离** | 底图是矢量的，标注是数据。改版只需重跑生成器，不用重画图 |
| **不写死在地图里** | 地名锚点、楼层结构来自数据源，而不是画在图上的字 |
| **保底可读** | 底部这段是**无脚本也能看的说明**；地图本身取不到时，页面不会空 |

> **因此这一页不是「条目」，是「工具」**——它挂在查阅栏目下，与[物品图鉴](../catalog/index.md)、[任务图鉴](../quests/index.md)同类。

### 🧭 怎么看这张图

| 元素 | 含义 |
|------|------|
| **红点 + 名称** | 地名锚点（如上图例）。坐标来自上游数据投影，**不是手工摆的** |
| **淡红建筑** | **上锁房间** —— 上游图层里独立标出（如 `Big_red-2f-locked`、`Gas_Station-locked`），意味着这里**需要钥匙或开了锁才能进** |
| **红色斜纹区** | 危险区（雷区一类） |
| **楼层按钮** | 海关分 5 层：地面 / 地下 / 1–3 层。切换后只显示所选楼层 |

**一条读图纪律**：这张图给的是**位置关系**，不是**路线**。知道宿舍区在西、军事检查站在东，和知道「从哪条路走过去」是两件事 —— 后者属于走位，本站不做（见下方边界）。

### 🎯 和正文怎么配合

海关的正文讲的是**为什么**，这里给的是**在哪**：

## 📐 口径与边界

**底图不是本站画的。** 它来自社区开源项目 [the-hideout/tarkov-dev-svg-maps](https://github.com/the-hideout/tarkov-dev-svg-maps)（作者 **Shebuka**），采用 **CC BY-NC-SA 4.0**，与本站正文同许可；本站把配色换成了浅色板，**矢量数据一字未改**。三条使用边界：

1. **署名**：作者 Shebuka / tarkov-dev-svg-maps，许可 CC BY-NC-SA 4.0；
2. **上游版权**：《逃离塔科夫》地图内容的著作权仍属 **Battlestate Games** —— 这份 CC 许可覆盖的是**矢量绘制这一层**，不等于地图版权已获授权；
3. **禁用作弊用途**：上游明确禁止把素材用于 in-game radar / ESP overlay / 作弊客户端改图 / 自动化脚本与 pixel-bots，**违反则许可自动撤销**。本站是资料百科、不在禁止范围；但本站是公开仓库，若有人 fork 后用于上述用途，与本站无关。

完整口径见[数据口径与引用说明](../docs/citation.md)第四节「交互地图的数据口径」。

> **点位坐标的可信度**：坐标由上游地名锚点的世界坐标经投影公式换算而来，**不是人工放置的**。公式用两个具名图层（`Big_red-2f`、`Gas_Station`）做过锚点反推验证，偏差 1.5–3.4%（系统性、方向一致，来自边界留白）。**它够用来回答「在哪一侧」，不够用来量距离** —— 需要精确位置时以游戏内为准。
