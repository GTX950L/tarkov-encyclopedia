## 📸 这一页是什么

站点此前对地图的处理是：讲述**判断依据**（这张图打什么、产什么、有什么坑），但**不列点位** —— 理由写在[战利品分布与热点](../entries/loot.md)里。那条理由至今成立，因为点位信息的特点是**版本一变就整批作废**。

这一页把「点位」单独接出来，靠三件事把那条理由消化掉：

| 办法 | 做法 |
|------|------|
| **底图与标注分离** | 底图是矢量的，标注是数据。改版只需重跑生成器，不用重画图 |
| **不写死在地图里** | 地名锚点、楼层结构来自数据源，而不是画在图上的字 |
| **保底可读** | 底部这段是**无脚本也能看的说明**；地图本身取不到时，页面不会空 |

> **因此这一页不是「条目」，是「工具」**——它挂在查阅栏目下，与[物品图鉴](../catalog/index.md)、[任务图鉴](../quests/index.md)同类。

### 🧭 怎么看这张图

| 元素 | 含义 |
|------|------|
| **红点 + 名称** | 地名锚点（如上图例）。坐标来自上游数据投影，**不是手工摆的** |
| **彩色方框** | **任务目标区域** —— 悬停看「哪个任务、要做什么」，点击直接进任务详情。**颜色只区分「做什么」**：到访（蓝）／放置（橙）／标记（紫）／击杀（红）／使用（青） |
| **淡红建筑** | **上锁房间** —— 上游图层里独立标出（如 `Big_red-2f-locked`、`Gas_Station-locked`），意味着这里**需要钥匙或开了锁才能进** |
| **红色斜纹区** | 危险区（雷区一类） |
| **楼层按钮** | 海关分 5 层：地面 / 地下 / 1–3 层。切换后只显示所选楼层 |
| **任务筛选按钮** | 全部 / 只看未完成 / 只看进行中 —— 后两个**读的是[我的进度](../quests/progress.md)** |

**一条读图纪律**：这张图给的是**位置关系**，不是**路线**。知道宿舍区在西、军事检查站在东，和知道「从哪条路走过去」是两件事 —— 后者属于走位，本站不做（见下方边界）。

### 🎯 和正文怎么配合

海关的正文讲的是**为什么**，这里给的是**在哪**：

| 你想知道 | 去哪 |
|----------|------|
| 这张图该不该来、打什么、什么阶段来 | [海关条目](../entries/customs.md)（地形三分、任务密度、Reshala 与保镖） |
| **宿舍区、加油站、检查站在图的哪一侧** | 本页 —— 上图 |
| 从哪撤、撤离点什么条件 | [撤离点详解](../entries/extraction-points.md) |
| 和其余 12 张图的横向对照 | [地图对照速查](../docs/map-guide.md) |

### 🔗 和任务系统怎么联动

地图上的**彩色方框就是任务目标区域** —— 这一页因此不只是「看地形」，而是任务图鉴与我的进度之间的那座桥：

| 你想知道 | 怎么用 |
|----------|--------|
| **某个任务**的目标在图的哪里 | 悬停方框 → 显示任务名与目标原文；**点击直接进任务详情** |
| **还剩哪些任务没做** | 点「**只看未完成**」—— 它读的是你自己的进度 |
| 某处「我是不是已经做过了」 | 「全部」模式下，**已完成的任务区域会自动变淡**（不消失，仍可查看） |

**进度从哪来**：[我的进度](../quests/progress.md)把勾选存在**你本机浏览器的 localStorage**（键 `tarkov_progress_v1`），不登录、不上传、本站也没有服务器。地图读的是**同一份数据** —— 两边用的是**同一套任务 id**，所以不需要任何同步动作：你在进度页勾一下、或者用它的[「从游戏日志同步」](../quests/progress.md)一次性补齐历史，回到这一页点「只看未完成」就能看到差别。

> **两条边界，写在这里免得误解**：
> ① **地图只读进度**，不会替你勾选或取消任何任务 —— 要改进度去[我的进度](../quests/progress.md)；
> ② **进度是本机数据**，换浏览器、清缓存就没了（那一页有导出与导入，可换设备搬）。

## 📐 口径与边界

**底图不是本站画的。** 它来自社区开源项目 [the-hideout/tarkov-dev-svg-maps](https://github.com/the-hideout/tarkov-dev-svg-maps)（作者 **Shebuka**），采用 **CC BY-NC-SA 4.0**，与本站正文同许可；本站把配色换成了浅色板，**矢量数据一字未改**。三条使用边界：

1. **署名**：作者 Shebuka / tarkov-dev-svg-maps，许可 CC BY-NC-SA 4.0；
2. **上游版权**：《逃离塔科夫》地图内容的著作权仍属 **Battlestate Games** —— 这份 CC 许可覆盖的是**矢量绘制这一层**，不等于地图版权已获授权；
3. **禁用作弊用途**：上游明确禁止把素材用于 in-game radar / ESP overlay / 作弊客户端改图 / 自动化脚本与 pixel-bots，**违反则许可自动撤销**。本站是资料百科、不在禁止范围；但本站是公开仓库，若有人 fork 后用于上述用途，与本站无关。

完整口径见[数据口径与引用说明](../docs/citation.md)第四节「交互地图的数据口径」。

> **任务点位从哪来**：来自 `json.tarkov.dev` 的 `tasks` 端点（**二级来源**）里每个目标的 `zones` 字段 —— 即**上游数据里本来就有的坐标**，本站只是把它们画出来，没有自行测算。
>
> ⚠️ **这里要说清与条目正文的分工**：正文侧（[任务图鉴](../quests/index.md)的生成器）**照旧在抓取阶段丢弃坐标**，一行没改；坐标走**另一条管线**（`scripts/gen_maps.py`），两边分开存放、互不污染。这正是[引用说明第六节](../docs/citation.md)那条新口径的落地方式：**坐标不进正文，集中收在地图**。
>
> **描述可能缺一层，是有意的**：目标描述按**索引**从站内任务数据里取。逐任务比对过 —— 站内 515 个任务里 498 个能与上游对上，其中 **494 个目标数完全一致**；剩下约 4% 因上下游版本不同（上游已下线的限时任务）对不齐，**这时只显示「任务名 + 目标类型」、不给描述**。宁可少给一层，不给错的那层。

> **点位坐标的可信度**：坐标由上游地名锚点与任务区域的世界坐标经投影公式换算而来，**不是人工放置的**。公式用两个具名图层（`Big_red-2f`、`Gas_Station`）做过锚点反推验证，偏差 1.5–3.4%（系统性、方向一致，来自边界留白）。**它够用来回答「在哪一侧」，不够用来量距离** —— 需要精确位置时以游戏内为准。
