### 地名与撤离点都说中文了吗

**大部分是，但不是全部 —— 这是有意的。**

| 类 | 怎么做 | 例 |
|----|--------|-----|
| **通用地名 / 设施名** | 译成中文，**用社区通行的叫法**、不按字面直译 | `White Bishop` → 白象；`Skeleton` → 骨架楼；`Crackhouse` → 制毒屋 |
| **游戏内的品牌与店名** | **保留原文**，能给确定用途的加中文类别词 | `IDEA` → IDEA 电器城；`KIBA` → KIBA 军械店；`Goshan` → Goshan 杂货区 |
| **俄文招牌** | 译成中文（俄文对中文读者等于不可读），原文用括号保留 | `АПТЕКА` → 药店；`МУЗЕЙ ИСТОРИИ` → 历史博物馆 |
| **代号 / 编号** | 原样保留 | `K1`–`K6`（储备站代号）、`ZB-013`、`E5` |

> **为什么品牌不硬译**：游戏里的门头就写着那个原文 —— 读者在地图上看到 `IDEA` 能直接对上商场里的招牌；
> 译成「理念超市」反而找不到。**不确定卖什么的（多数服饰品牌）连类别词也不加** —— 猜错比英文更难用。

覆盖情况：地名词表 **257 / 303**、撤离点名 **142 / 162**；剩下的就是上表第二、四类。

### 两张图没有任务点位，不是漏抓

**破冰船**与**终点站**的「任务区域」是空的 —— 因为**上游还没为这两张图的任务给出坐标**（实测：上游任务数据里引用破冰船地图区的次数为 **0**）。
站内有这两张图的任务与打法说明，只是地图上暂时画不出位置。**数据没有就是没有，不编位置。**

## 🧭 地图上有什么

| 元素 | 含义 |
|------|------|
| **红点 + 名称** | 地名锚点。坐标由上游数据投影而来，**不是手工摆的** |
| **彩色方框** | **任务目标区域** —— 单击只看它、双击进详情、悬停看目标原文。**颜色只区分「做什么」**：到访（蓝）／放置（橙）／标记（紫）／击杀（红）／使用（青） |
| **蓝／橙／紫方块 + 名字** | **撤离点**，按阵营分色：PMC（蓝）／Scav（橙）／共用（紫）。名字由上游的内部 id（`ex_customs_scav_gasstation`）转写而来 —— **词表里没有的保持英文**，不硬翻。⚠️ 阵营是上游的 `faction` 字段，**不等于「谁能用」**，通行条件见[撤离点详解](../entries/extraction-points.md) |
| **青色三角 + 名字** | **转场点** —— 不结束战局直接换图（见[转场与 BTR](../entries/transit.md)） |
| **紫色小方块** | **上锁位置** —— 有钥匙的可以点击跳到那件钥匙的物品页（两边用同一套物品 id） |
| **红色点线多边形** | **危险区**（雷区一类） |
| **淡红建筑** | 底图自带的上锁建筑色块。与紫色方块是**两个来源**：一个画在底图里，一个来自点位数据 |

### 常用操作

| 操作 | 结果 |
|------|------|
| **滚轮** | 缩放，**以指针位置为中心**（不会越缩越偏） |
| **按住拖动** | 平移 |
| **放大 / 缩小 / 重置** | 按钮入口（触屏与不习惯滚轮的读者）；「重置」兼找回全图 |
| **全屏** | 铺满屏幕看细节 |
| **测距** | 点两个点量**直线距离（米）**；⚠️ 是直线，不是走路距离 |
| **单击任务区域** | 只显示这一个任务，下方弹出信息卡（任务名／类型／区域数／你的进度状态／目标原文） |
| **双击任务区域** | 打开任务详情 |
| **任务清单** | 地图上方那行「这张图上的任务 · N 个」—— 展开按**商人**分组，点一下地图就只剩它 |
| **任务筛选** | 全部 / 只看未完成 / 只看进行中 —— 后两个**读的是[我的进度](../quests/progress.md)** |
| **图层开关** | 撤离点 / 转场点 / 上锁 / 危险区，各自可关，**按钮上带条数** |

## 🔗 和任务系统怎么联动

地图上的**彩色方框就是任务目标区域** —— 这一页因此不只是「看地形」，而是任务图鉴与我的进度之间的那座桥。

**进度从哪来**：[我的进度](../quests/progress.md)把勾选存在**你本机浏览器的 localStorage**（键 `tarkov_progress_v1`），不登录、不上传、本站也没有服务器。地图读的是**同一份数据** —— 两边用的是**同一套任务 id**，所以不需要任何同步动作。

> **两条边界**：① **地图只读进度**，不会替你勾选或取消任何任务；② **进度是本机数据**，换浏览器、清缓存就没了（那一页有导出与导入）。

## 📐 数据从哪来

| 数据 | 来源 | 说明 |
|------|------|------|
| 底图 | [the-hideout/tarkov-dev-svg-maps](https://github.com/the-hideout/tarkov-dev-svg-maps)（10 张矢量 SVG）+ tarkov.dev 瓦片（破冰船 / 实验室 / 迷宫） | 矢量图**只换配色**、矢量数据一字未改；瓦片拼成单张位图并按浅色主题调色 |
| 地名锚点 | tarkov.dev 的 `maps.json` | **303 个**，其中中文译名逐图核对；拿不准的保持英文 |
| 任务点位 / 撤离点 / 上锁 / 危险区 / 转场点 | tarkov.dev 的 `maps` 与 `tasks` 端点（**二级来源**） | 坐标是上游给的，**不是本站测算的** |
| 进度 | 本机 localStorage | 不联网 |

> ⚠️ **底图的版权分层**：CC 许可覆盖的是**矢量绘制这一层**，《逃离塔科夫》地图内容的著作权仍属 **Battlestate Games**。这份 CC 不等于「地图版权已获授权」。
>
> ⚠️ **上游的禁用作弊条款**：上游明确禁止把这些素材用于 in-game radar / ESP overlay / 作弊客户端改图 / 自动化脚本与 pixel-bots，**违反则许可自动撤销**。本站是资料百科、不在禁止范围；但本站是公开仓库，若有人 fork 后用于上述用途，与本站无关。
>
> **任务点位的准确性**：坐标由上游世界坐标经投影公式换算，**不是人工放置的**。公式用两个具名图层做过锚点反推验证，13 张图全部复核过。**它够用来回答「在哪一侧」，不够用来量距离** —— 需要精确位置时以游戏内为准。
>
> ⚠️ **没有画的图层**：上游还有**战利品容器**（单图数百条）与**出生点**。容器**只给位置、不给类型**（那个字段是游戏内的模板 id，查不到名字），铺上去只会把地图糊住；出生点的口径问题站内已登记为[未决项 B7](../docs/citation.md)。**画得出来，不等于值得画。**
