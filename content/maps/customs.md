## 🧭 怎么用这张图

| 操作 | 结果 |
|------|------|
| 滚轮 / 放大缩小按钮 | 缩放（以指针位置为中心）；按住拖动平移 |
| 单击任务区域 | 只显示这一个任务，下方弹出信息卡 |
| 双击任务区域 | 打开任务详情 |
| 图层按钮 | 撤离点 / 转场点 / 上锁 / 危险区，各自可开关 |
| 测距 | 点两个点量**直线**距离（米） |
| 全屏 | 铺满屏幕看细节 |
