# 单条事实订正

目标：把一条事实改对，**并且让站内所有依赖它的结论同时变对**。

## 第一步：先读规范，再动手（不要跳过）

| 读什么 | 为了拿到什么 |
|--------|-------------|
| `content/docs/citation.md` | 这条事实属于哪一档口径（静态 / 动态 / 社区）、A/B 未决项里有没有它、改完要不要动页眉 |
| `content/docs/roadmap.md` 的「📈 版本敏感内容」 | 这条事实是不是已被登记为「收录前需复核」——若是，登记条目要一并结案 |
| `content/CONTRIBUTING.md` | 体例仲裁规则（如地图的老图 / 新图两套体例、Boss 节命名判据） |
| `content/template.md` | 条目骨架与页脚三行写法 |

> **跳读的代价**：体例规则写在贡献指南里、不在模板里，而**校验脚本不检查章节名与措辞**——只看模板会写出不合规的章节名，错误一路到线上。

## 第二步：核心判据（本册存在的理由）

> **同一个实体（Boss / 机制 / 物品）在站内出现超过一处时，改一处必须 grep 全站。**

落地前，以**官方实体名**为关键词跑一次全库 grep，然后**逐条问自己一句话**：

> 「**我这次改的这个结论，会不会让这一行变错？**」

```bash
grep -rn "<官方实体名>" content/ | wc -l      # 先看清它出现在几处、分别在哪些页
```

**为什么这条必须写下来**：连带错误之所以能长期存活，是因为它们长在**离「事实源头」较远的页面**——Boss 名册写在**地图页**、装备数据写在**另一个地图页**、总量结论藏在**互链语**里。**没有人会为了改一张图去翻图鉴，也没有人会为了改图鉴去翻街区页——这正是它们活下来的原因。**

## 第三步：总量词是这类错误的统一形式

> **「唯一 / 最 / 全部 / 首次」这类总量词，必须可复核；复核不了，就删掉这个字。**

不要换成「很少」「极少数」「基本」——那只是把可验证性丢掉而已。写「明确不做」时也一样：**凡写「不做」，都要附上 grep 结果**。没有数据的「不做」等于把同一个坑留给下一批。

## 第四步：执行链（顺序不要跳）

1. **多源复核官方事实**：EN wiki + 中文 wiki + 至少 1 个社区数据站；**来源一致才落笔**，不一致就登记进 `content/docs/citation.md` 第三节（A 类 = 两处来源不一致 / B 类 = 只有社区口径）。
2. **全库 grep 实体名** → 逐条判断「这行会不会变错」→ 列成待改清单。**这一步是本任务价值的全部所在，不要跳。**
3. 改「事实源头页」，再改每一处连带结论页；**连带页要把旧口径作为引文留下并标注「更正」**（如「本页此前写『…』——**不成立**」），这样读者不会以为站内一直在改口。
4. 派生文件（漏一个就是一处静默漂移）：
   - `content/CHANGELOG.md`：起新版本段，写明**改了什么、为什么、旧口径错在哪**；
   - `content/docs/roadmap.md`：把上一批登记的条目改为「已结案」，并起新批次小节；
   - `content/docs/citation.md`：新增 / 修改 A、B 类未决项时**同步两类计数**；
   - 条目页眉：若该条被 A/B 登记，**页眉第三行的编号要跟着变**（`scripts/check_entries.py` 会校验）；
   - `content/llms.txt`：只有全文结构或基线变了才动。
5. 回归：`scripts/build_glossary.py`（术语条数应不变）→ `scripts/check_entries.py`（必须全绿）→ `zensical build`。
6. 提交推送 → 线上逐条 grep：**新写法命中 + 旧写法归零**。注意：若旧写法被你**作为引文**写进「更正」块，它会命中 1 次，这是**正确**的——要打印上下文确认，而不是直接把命中数当错误。

## 第五步：三个坑

1. **`build` 通过 ≠ 渲染正确。** 表格「表头列数 ≠ 分隔行列数」时，Python-Markdown 会**放弃解析整张表**，以裸竖线段落输出，而 `build` 照常报 `No issues found`。收尾必须跑产物侧扫描：全站 grep `<p>|` 应为 0、表头列数 == 分隔行列数。
2. **改标题会改锚点。** 标题自动生成的 id 会变，而 `scripts/check_entries.py` **不校验 fragment**（`LINK_RE` 会把 `#` 之后剥掉）→ 必须手工 grep 一次「指向该页的带锚点内链」。显式 `<a id="..."></a>` 不受影响。
3. **标点体例会被顺手破坏。** 中文正文用全角（，：（））。新增段落混进半角，校验脚本**不报**。可复用扫描：正则 `[\u4e00-\u9fff][,;:()][\u4e00-\u9fff]` 逐行跑（排除表格行与含反引号的行），**应为 0**。

## 反面纪律：查出来了也可以不改

> **顺带查出的第二类问题：登记 + 报告，不夹带。**

「不把『顺手发现』当『顺手改』」——把第二类问题写进 `content/docs/roadmap.md` 的站务区（标为待修复），**本批不动**。这条已被验证过两次：正因为上一批只登记、没动手，本批才拿得到授权。
