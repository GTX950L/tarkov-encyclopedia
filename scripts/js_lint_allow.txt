# check_js_lint.py 白名单
#
# 为什么会有这个文件：极少数函数**确实**没有静态调用点 —— 它们是靠字符串名
# 被动态调用的（`window[name]()`、事件表里写死的方法名、外部脚本回调）。
# 删不掉，但也不该让门禁红着。
#
# 规则（脚本会强制）：
#   · 每条**必须**写理由，用 `  # ` 与键分开；不写理由 → 脚本直接报错退出；
#   · 键写成 `文件名:函数名`（只对那个文件生效）或 `函数名`（全局生效）；
#   · 理由里要写清**谁在调它** —— 「动态调用」四个字等于没写。
#
# 格式示例（当前无条目，下面是格式，不是配置）：
#
#   example.js:dynamicEntry  # 由 window["tk_<name>"] 从 quests-filter.js 的字符串表调用
